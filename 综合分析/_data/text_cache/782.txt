ited in addressing parametric uncertainties that affect system
dynamics and sensor/actuator parameters. Such parameter
variations corrupt residual signals, leading to performance
degradation through increased false alarms and missed de-
tections. The reference model-based approach [14], [22]–[24]
addresses these challenges by formulating fault detection as
an H∞ model-matching problem (MMP). The method uses a
reference model, which serves as an optimal residual generator
under the assumption of no model uncertainties aside from
disturbances. Simultaneously, it aims to minimize the H∞
norm of the difference between the designed residual generator
and this reference model. With model parameters estimated via
Bayesian inference, modelling errors are treated as stochastic
uncertainties, leading to an LMI solution originally derived in
Chapter 8 in [21].
