            Domain Name System (DNS) is the internet backbone
         for providing a mapping between human-readable hostnames
         and computer understandable Internet Protocol (IP) addresses.
         DNS protocol is designed with a decentralized hierarchical ap-
         proach. When a DNS client generates a DNS query asking for
         an IP address, the local DNS server responds after looking into
         its cache. It does not ﬁnd the answer within cache memory,
         it forwards the DNS query to recursive DNS resolver which
         tracks down the DNS record with repetitive DNS queries to
                                                                                                 Fig. 1: Domain Name System [1]
         root name server, Top Level Domain (TLD) name server and
         authoritative name servers until it gets the target authoritative
         answer [1]. Fig. 1 shows the working of the domain name
         system with sequence number marked on the direction of ﬂow.
            DNS tunneling is a method of using DNS protocol as a
         mean of encapsulating data transmission between a client and
         a server. The data is coded within records of an otherwise
         normal DNS request and the server may or may not return
         with some data encoded in the corresponding DNS response.
