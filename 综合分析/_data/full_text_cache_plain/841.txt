Web Page Tampering Detection Based on Dynamic
Temporal Graph Pre-Training
Yijia Xu , Qiang Zhang , Kaiyang Wang , Zhonglin Liu , Cheng Huang , Senior Member, IEEE,
and Yong Fang

Abstract—Web page tampering detection is crucial in web threat
perception. Current methods rely on monitoring historical changes
of web pages to identify anomalies. These approaches often struggle
to effectively distinguish between tampering and benign changes,
especially in the presence of numerous dynamic pages. Furthermore, the increasing complexity of website structures places more
resource demands on tampering monitoring and makes some malicious alterations more covert and challenging to detect. We propose a web page tampering detection based on pretraining with
dynamic temporal graphs. The core of the method involves constructing a website temporal graph model based on evolutionary
information, and enhances the graph feature perturbations to expose concealed tampering behaviors. Specifically, the framework’s
autoencoder is composed of enhanced DySAT, enabling it to handle
dynamic data. We introduce DySAT, bolstered with GATv2, to
capture dynamic attention. Additionally, we design a temporal
masking mechanism and prediction error to improve the effectiveness of generative self-supervised learning in temporal graph
pretraining. Experimental results on Webpage Tampering Dataset
(WPT-Dataset) demonstrate that our method outperforms other
comparative approaches in terms of both detection efficacy and
stability. Furthermore, the research findings on the anomaly detector and model performance provide direction for the practical
application of our method.
Index Terms—Web security, pre-training, dynamic graph,
temporal data, anomaly detection.

II. RELATED WORK
A. Content Anomaly
Some research focused on detecting anomalies based on web
page content, such as detecting malicious links, malicious web
pages, or phishing pages. Many malicious and phishing pages
result from changes in web page properties due to tampering
attacks. Zhiqiang Wu [11] targeted external website links for detection, proposing a malicious website detection method based
on multimodal fusion. This method extracted features from external web page texts, dynamic scripts, and images, constructing
a deep fusion model that combines these multimodal features to
identify anomalous external links. Qian Shao et al. [12] and
others suggested using Bert and a ternary decision algorithm to
detect hidden links on web pages. They extracted feature vectors
encapsulating text information from target external pages and
then classified hidden links using a comprehensive decision algorithm. The mainstream research trend for malicious or phishing web page detection involves combining machine learning
with web content feature extraction. G Pradeepa et al. [13]
introduced various machine learning algorithms for comparison
in malicious web page detection, among which random forests
achieved the best results. To enhance the training effectiveness
of machine learning, MF Rozi et al. [14] aimed to enrich web
page features by capturing the intent of web page JavaScript
content to improve the abstraction of the webpage’s source code
syntax tree. Peng Jiang et al. [15] conducted research on feature
engineering for malicious websites from a system provenance
analysis perspective, ultimately identifying eight useful features
for malicious website detection. Belfedhal et al. [16] proposed
a multimodal deep learning framework, processing each type
of feature with different deep learning models to enhance the
model’s overall analytical capability of web pages. In phishing

page detection, Asadullah Safi et al. [17] found that machine
learning techniques were applied in as many as 57 variations
within the field. Among them, random forests were the most
used, but convolutional neural networks achieved the highest
accuracy. Mahdi Bahaghighat et al. [18] evaluated eight major
unique scenarios of phishing websites, proving that most machine learning methods could excellently perform phishing site

Furkan Çolhak et al. [19] introduced dedicated multilayer perceptrons and pre-trained models. They designed a novel feature

Detecting web page tampering by identifying malicious content is a widely adopted approach, often relying on models
trained on static features such as text, HTML structure, or
embedded links. However, these models tend to struggle with
covert, low-amplitude tampering attacks, where feature fluctuations are too minor to trigger alarms. Moreover, their dependence on external links introduces temporal instability. Once a
referenced external page becomes invalid or changes, detection
performance degrades significantly. These limitations suggest
that current content-based methods underexploit the sequential
and contextual nature of tampering behavior, failing to capture
how content evolves over time as a result of cyber confrontation
dynamics. We should not overlook the dynamic information
resulting from the temporal sequence of web page tampering
as a product of cyber confrontation.
B. Tampering Detection
To detect web page tampering in complex website structures
and dynamic environments, website log files have become a
crucial data source for identifying it. Web server log files are
pivotal data sources for detecting web page tampering. Gaurav
Varshney et al. [20] proposed a tampering detection approach
reliant on domain expressiveness. They harnessed DNS history
to calculate hash values for crucial web pages and employed
browser verification to forestall malicious content modifications.
A drawback of these methods lies in the potential for attackers to
manipulate log files, prompting researchers to explore text-based
detection mechanisms. Xiangyu Fan et al. [21] introduced a
method grounded in text content to identify web page tampering
attacks. Their approach involved extracting semantic features
from text via the BiGRU model and incorporating CRF learning
for sequence state, resulting in feature-rich text representation.
Junlin Gao et al. [22] presented text content detection technology
using an enhanced Faster-RCNN model for web page tampering
detection. They employed a rectangular convolution kernel to
accommodate the text’s elongated and narrow characteristics
and used the Soft-NMS algorithm to minimize missed detection within densely populated regions. As feature engineering
advanced, the scope of feature extraction for web page tampering expanded. Hanji Shen et al. [23] introduced a tampering
attack detection method predicated on web page change features.
Their methodology refined feature engineering encompassing
time, amplitude, frequency, location, and content of web page
changes, contributing to training the final detection model.

Senhao Wen et al. [24] devised a comprehensive model for analyzing complete web page associations, combining techniques
such as topic analysis, visual similarity assessment, website
structure analysis, and external resource correlation to detect
malicious behaviors, including tampering. Luk Kim et al. [25]
proposed a dynamic analysis-based method to uncover vulnerabilities susceptible to web page tampering. Their approach
entailed gathering site information, identifying potential JS code
elements prone to tampering, and scanning vulnerability through
tampering testing, culminating in a vulnerability mining system.
In conclusion, although tampering detection methods based
on logs, text content, and structural analysis have advanced
significantly in terms of feature representation and data sources,
they still underexplore the structural and temporal relationships
between web pages, overlooking how changes tend to propagate
along specific paths. Most existing approaches treat pages as
isolated entities and lack the capacity to model temporal continuity and cross-page dependencies, making them less effective
at capturing unexpected, subtle, or progressive changes that
deviate from a page’s normal evolution. As a result, they often
fail to detect tampering behavior that unfolds gradually, spans
multiple pages, or remains within the acceptable thresholds of
single-page analysis. Furthermore, the limited utilization of deep
learning techniques leads to suboptimal representation learning and hinders the detection of context-sensitive tampering.
To address these limitations, we propose a dynamic temporal
graph-based approach that integrates both structural and temporal signals to enhance tampering detection in complex web
environments.
C. Temporal Graph Pre-Training
Recent spatio-temporal pre-training frameworks mainly target sensor-driven urban or neuro signals and assume three
conditions: dense and regularly sampled time series at nodes,
short-horizon forecasting or imputation objectives, and stable
spatial neighborhoods. Representative examples include PreSTNet [26] for traffic forecasting, spatial-temporal decoupled
masked pre-training [27] designed for heterogeneous spatiotemporal patches, unified or multi-subgraph urban pre-training
and prompting [28] aiming at city-level foundation models with
dense streams, importance-masked neuro-decoding pre-training
with fine-grained temporal masking [29], and PPT-GNN [30]
designed for network security. In our setting, web pages are
content-rich nodes and hyperlinks are edges. The graph evolves
irregularly and asynchronously with DOM changes, crawl gaps,
and missing timestamps. Edges are long-range and bursty
through cross-site redirects. The task depends on structural and
semantic generation and reconstruction rather than scalar forecasting. These spatio-temporal pipelines require dense per-node
time series and forecasting heads that do not supervise the
long-range link and content generation we need. Transferring
them would add heavy assumptions and still leave our core
challenges unresolved, including irregular dynamics, sparse and
noisy timestamps, and co-evolution of text and structure.
Generative self-supervised learning directly supervises structure and attribute generation and has recently advanced for

III. BACKGROUND
Web page tampering arises from the vested interests of malicious actors. As depicted in Fig. 1, it underscores the primary
objectives that drive the initiation of web page tampering attacks.
Cybersecurity attackers use web page tampering to covertly access sensitive user information, encompassing login credentials,
personal identification particulars, and credit card data. This data
extraction might entail minor tweaks to the frontend code of a
web page. However, web page tampering may cascade into more
profound security repercussions. After web page tampering, attackers may escalate their actions to include additional malicious
activities like embedding trojan viruses, hijacking user sessions,
and injecting concealed hyperlinks.
Web page tampering can potentially unleash significant financial fraud [34]. Attackers can manipulate data on bank or
payment pages, craftily deceiving users into transferring funds
to fraudulent accounts. From a societal viewpoint, web page
tampering is adept at disseminating deceptive information, enabling the manipulation of public sentiment to exert control over
information dissemination. The propagation of false propaganda
and the fabrication of news stories could incite social unrest.
Within the domain of websites, web page tampering erodes
users’ confidence in the authenticity of information sources,

2015

potentially catalyzing a crisis of trust between users and website
operators. Neglecting to rectify tampering vulnerabilities could
profoundly stain a website’s reputation. Furthermore, attackers
might exploit web page tampering, upload ransomware against
website owners, or peddle website vulnerabilities on the dark
web, all in pursuit of financial gains.
To differentiate web page tampering from the dynamic
changes of web pages, a thorough investigation of the feature of
page tampering is essential. According to Trendmicro’s analysis
report, many of the 1,300,000 website tampering incidents over
the past 18 years were acts of expression by hacker organizations
with political motives [35]. The objectives pursued by attackers
when executing page tampering underscore their intent to sustain
the tampered state for an extended duration. Moreover, the adversarial nature of the attacker-defender interaction illuminates
various distinctive traits of web page tampering.
r Concealment: The concealment of web page tampering
mainly falls into two types. Firstly, attackers endeavor
to modify page content without leaving traces, making it
appear indistinguishable from normal pages. This scenario
is often characterized by the embedding of hidden links,
where the tampered web page maintains these links for
an extended period to contribute to SEO fraud. However,
more frequently, attackers opt for visible page tampering
to amplify the impact of their modifications to achieve
their goals. Thus, the second type of concealment refers
to the methods attackers use to alter web pages without
triggering tamper detection systems. They exploit covert
tampering tactics to bypass defensive measures, enabling
unauthorized activities on web pages.
r Diversity: The diversity of web page tampering stems
from attackers employing various techniques and means
to alter content, increasing their chances of success and
stealthiness. The most common method involves modifying the web page’s source code, including HTML, CSS, and
JavaScript. Attackers alter the appearance and behavior of a
page by changing HTML tags, stylesheets, or script codes.
Replacing images, multimedia, and content on web pages is
also a crucial tactic for criminals to spread false information
and conduct scams. Moreover, attackers may modify a
page’s redirection rules or external links to redirect users
to malicious sites for information theft or other malicious
activities. Aggressively, attackers could directly modify
database query statements to manipulate or remove content
from databases.
r Real-time: Web page tampering can occur in real-time,
affecting users as soon as they access the page. Attackers
can tamper with the content dynamically based on the
specific requests and characteristics of the user, keeping
the tampered pages interactive. In actual web sessions,
such real-time tampering is more deceptive and concealed.
Furthermore, real-time tampering allows attackers to immediately observe the effects of their actions, meaning they
can adjust and optimize as needed to ensure the tampered
content more effectively achieves their objectives.
r Customization: Attackers carry out customized tampering
operations on targets based on specific purposes and needs,

making the tampering actions more precise and targeted.
This customization is usually goal-oriented. Attackers select specific web pages to tamper with, often because these

develop tampering strategies based on the characteristics of
the target website and the behavioral habits of specific user

r Automation: Under certain conditions, attackers utilize
automated tools and techniques for rapid, large-scale tampering operations. For instance, the exposure of some 0-day

Attackers can use tools and scripts to scan numerous web
pages and automatically execute code insertion or modification. Automated tools enable attackers to target multiple
victims simultaneously, achieving scaled attacks. They can
easily manage and control a large volume of tampering
actions to maximize their impact.

IV. PRELIMINARY
A. Temporal Anomaly
Contemporary approaches to web page tampering, whether
involving scrutinizing the modification time of web page files
or comparing data before and after alterations, predominantly
rely on anomaly analysis within the framework of temporal data.
Detection systems collect and look at old versions of target pages
or records of users accessing them. This creates chronological
patterns that show normal patterns of behavior. These temporal
patterns encompass variations spanning page structure, content,
style, and other dimensions. Once a web page undergoes abnormal tampering, deviating from normal behavioral patterns,
the detection system will trigger an alert or implement corresponding defensive measures. Consequently, unauthorized file
modifications, interface invocations, or changes to web page
content inherently manifest as outcomes of anomaly analysis
within a temporal context.
The core challenge in time-series AD (Anomaly Detection)
lies in precisely modeling the typical behavioral patterns of
web pages [36]. The dynamic and highly interactive nature
of web pages often engenders frequent alterations in structural
and content elements, thus complicating the modeling process.
Initial complexities emerge from the characteristics of web page
tampering, characterized by concealment and customization.
Certain covert and targeted tampering efforts prove difficult
to identify as anomalies, sometimes even infusing temporal
data to taint detection models. The diversification of web page
tampering introduces unpredictability in the types of anomalies,
exacerbating the challenge of identifying previously unknown
anomalies. Furthermore, the real-time aspect of web page tampering allows for continuous adjustments and refinements, progressively eluding conventional AD techniques.
It’s important to note that building detection models based on
the typical behaviors of genuine pages significantly increases

discerning genuine tampering instances amidst the noise [37].
Consequently, the central thrust of this research endeavor is to
effectively utilize time-series data to develop a high-precision
web page tampering detection model.
B. Graph Element Anomaly
It is common to convert a website into a graph for analysis [38]. In instances of aberrant alterations within the graph,
it is plausible that web pages have been tampered with. Such
anomalies predominantly encompass variations in node features
and modifications to the website’s structure. Fig. 2 shows the corresponding perturbation changes when different elements in the
webpage are tampered with. Our capability to detect tampering
on web pages is evident when deviations in node features are
present. Dynamic page alterations generally manifest as localized text changes. Tampering with textual content by attackers
induces drastic semantic shifts that result in perturbations within
the node feature vectors. Conversely, inserting malicious code
within a web page leads to structural changes in the DOM (Document Object Model) tree [39]. These alterations are absorbed
during information aggregation, leading to atypical disruptions
in structural features. Concurrently, associated statistical data
transforms when attackers tamper with web page elements.
This statistical data not only aids in analyzing web pages that
have suffered tampering but also facilitates unearthing attackers’
primary motives and methodologies in executing the tampering.
Structural changes within a website are observed from a broader
perspective. Attackers’ tampering is mobile, with adjacent pages
to the tampered web page susceptible to tampering. Analyzing
temporal web page tampering assists in confirming the trajectory
and direction of mobile tampering, consequently delving deeper
into concealed web page tampering. Additionally, the deletion
or addition of specific high-weight nodes within the time series
could indicate tampering activities undertaken by attackers.

The approach to web page tampering detection involves a

Definition 1. Website Structure Graph [40]: Within the
scholarly context of this research, a core concept is introduced,
denoted as the ”Website Structure Graph.” This graph is constructed within the comprehensive G = (V, E, X) framework,
where V signifies the node set and E embodies the edge set.

The feature mapping ensemble is encapsulated within X =
(Xv , Xe ), wherein Xv encompasses mappings of node features
and Xe encompasses mappings of edge features.
To capture the essence of website evolution, a meticulous
design and execution of the website structure graph, aligned
with the prescribed parameters, is carried out for each distinct
moment of website data acquisition. This intricate graph functions as a model, capturing the assimilated website information
at a precise juncture and effectively encapsulating its immediate
status within the broader temporal panorama. The static aspect
of this graph offers an enlightening perspective, unveiling the
structural arrangement of web pages and the intricate network of
linkages pertinent to a particular snapshot. Using careful comparison and analysis of website structure graphs from various
points in time, one can accurately follow the path of the website’s
evolution and spot oddities like the addition or removal of web
pages, changes to the website’s basic structure or content, and
other noticeable deviations.
Definition 2. Node and Edge [41]: Within the network structure graph G, nodes are denoted as V = {vi |0 < i < (N + 1)},
where N = |V |. The feature mapping ensemble Xv records the
feature vectors corresponding to each node vi , with the mapping
relationship represented by a bijective function f : V → Xv ,
where |V | = |Xv | = N . Given that the node type remains constant, each feature vector within Tv possesses identical dimensions. Meanwhile, edges are represented as E = {ei |0 < i <
(M + 1)}, where M = |E|. Each edge connects two nodes,
expressed as ei = (vi , vj ), with i, j ∈ [1, N ].

Within the website structure graph framework, we have curated three distinct features to serve as the node feature: content
features, structural features, and statistical features. Content
features encapsulate features that portray the textual information
within a web page, incorporating the contextual dependencies
and semantic facets of all textual components. Structural features
embody attributes delineating the source code structure within
a web page. These features are extracted using the DOM tree as
a foundational basis to capture the structural essence of the web
page. Statistical features encompass attributes that encapsulate
statistical data within a web page. These features primarily
include statistical information concerning text, images, links,
and keywords. We selected 12 statistical features, such as the
number of scripts, keyword density, and the number of original
tags, that closely relate to tampering behavior.
Each edge within the website structure graph bears directional
features, signifying the interlinking relationships between web
pages. While constructing the graph structure, we evaluate the
involvement of internal web pages and prune low-value leaf node
pages. Web pages can exist as isolated islands, devoid of any connections to other pages; such pages are deliberately omitted from
our consideration. The greater the number of edges attributed to
an internal web page node, the more significant its influence
within the website. This heightened influence corresponds to an
elevated likelihood of attacker access and tampering.

Q1: Select the DySAT+GATv2 as autoencoder: In generative

the training process.

D. Tampering Detection
Unearthing web page tampering within the dynamic realm of
constantly changing web pages presents a formidable challenge.
Our objective is centered on harnessing website temporal graphs
as a lens to observe whether there are evident disruptions in
graph structures and information during instances of tampering.
The tampering tends to bring about non-uniform alterations in
node features and graph structures, resulting in perturbations that
impact the characteristics of specific nodes. These perturbations
can be amplified by the pre-training, thereby aiding in identifying whether the intended page has undergone tampering. We
propose a web page tampering detection scheme, and its basic
process is shown in Fig. 5.
Website administrators, cybersecurity service providers, and
relevant government agencies are all potential beneficiaries of
this method. A major advantage of this method lies in its consistent approach of collecting website data from a third-party closed
box perspective for modeling, eliminating the need for access
to the website’s source code, directories, or databases. This
is particularly important for website operations that prioritize
foundational privacy protection. It also means that in practical
applications, this method can be directly integrated as a plugin or
functional module within conventional Web application firewall
software or deployed as a standalone system on servers to monitor multiple websites. This technology routinely gathers relevant
website data, automatically updates the website temporal graph,
and detects web page tampering activities. The specific steps of
the method are as follows:
Step 1. Crawling of web pages from the target Website:
We employ a browser-based crawler to collect all web pages
from the target website. This crawler is designed to collect the
URLs of web pages by strategically positioning hooks at crucial
points within the web page’s DOM rendering phase. Upon
initializing the network crawler, the robot and fuzz dictionaries
are integrated into the link pool to expand entry URLs. The
crawler automatically performs form population and submission
to comprehensively gather exposed entry points to the website,
thus complementing intelligent JavaScript event triggering.

Step 2. Filtering of collected web pages: The filtering module encompasses URL deduplication and pseudo-static URL
filtration. To enhance the quality of web page collection, we
introduce stringent rule mechanisms during the filtering process.
The filtering mechanism extracts data from various dimensions
such as request method, URL, value, and redirection for URL
deduplication, generating MD5 hashes to identify corresponding requests uniquely. Concerning the assessment of static resources, the filtering mechanism creates a mapping type marked
with common static resource suffixes. Subsequently, the URL’s
suffix serves as the key for this map. Finally, thresholds are
established based on the number of key parameters and paths,
and unique identifiers are allocated to web pages surpassing
these thresholds.
Step 3. Security Policy Review for Web pages: We assess
the legitimacy of websites through an initial security policy
review. These checks include indicators of secure browsing,
certificate signatures, resource cross-origin attributes, privacy
policies, and more. These tests allow us to confirm that the initial
status of the websites under monitoring is not malicious. This
effectively prevents the wastage of resources on web page tampering detection and also offers deployment recommendations to
administrators.
Step 4. Construction of the website temporal graph: Initially,
web page content features are computed using the Bert model.
As Bert employs an encoder to handle the semantics, it is adept
at capturing long-range dependencies and bidirectional textual
information within the web page text. Next, we use Doc2Vec [44]
to embed the DOM tree structure of web pages. Each tag on the
web page is assigned a unique identifier corresponding to a character. A depth-first traversal strategy is employed to traverse all
paths in the DOM tree, arranging the identifiers corresponding
to tags in the paths to form words. After all paths are converted,
a document composed of words is generated. We train Doc2Vec
on these path documents to generate corresponding embedding
vectors as structural features. After that, informational and statistical elements within web pages are extracted and normalized
into a vector format. These extracted features are included as
feature sets in the graph construction process.
All collected web pages within the website are transformed
into nodes. Each node’s features encompass content, structural,
and statistical features. By analyzing the linking relationships
on each page, vector edges are established between web pages
exhibiting navigational connections. Initiating with the current
time as the initial timestamp, the website structure graph is
preserved as the initial graph. Subsequently, the following fixed
time intervals, corresponding timestamps, and website structure
graphs are recorded. The collection of graph snapshots at all
timestamps forms the website temporal graph.
Step 5. Pretrain on the dynamic temporal graph: Set the sliding window length to w, and take the graph snapshots from the
past w timestamps in the website temporal graph to participate in
training. Apply masking to the dynamic temporal graph using
a temporal masking mechanism and input it into the DySAT
autoencoder for encoding. After re-masking the encoding results, reconstruct the node features through the DySAT decoder.
Calculate the reconstruction deviation using a loss function and

Step 6. Detect web page tampering using an anomaly detector: We have chosen various state-of-the-art anomaly detectors

A. Dataset
For data collection, we maintained a list of 600 authorized
websites, primarily concentrated in industries such as finance,
healthcare, and education. Websites in these sectors have high
tampering value due to their data sensitivity and public influence,
making them prime targets for hackers. Utilizing concurrency
mechanisms, we fully leverage the computational power of
multiple CPUs to process and collect nearly 600,000 pages
per hour. All 600 websites will be completely crawled within
5 hours, and the data collected will serve as the foundational
dataset for the current time slice. Subsequently, the data gathered
every 24 hours will be used for the next time slice. This process
will be continuously repeated until 21 time slices are generated.
In the course of data collection, we rigorously adhered to
the limitations prescribed by the Robots protocol file of each
website. Initially, our dataset encompassed over two million web
pages sourced from 600 distinct websites. Subsequent filtering
was executed based on several criteria: (a) Page Anomalies:
The task of automatically harvesting data from 600 diverse websites, each developed with different technological frameworks
across various sectors, presented substantial challenges. Not all
pages were viable; thus, we excluded any page that returned
response errors. (b) Pseudo-static Pages: Despite efforts to
exclude pseudo-static pages during the initial crawling phase,
numerous instances were overlooked. Two reviewers independently developed identification rules, resolved interpretation
differences through iterative discussion, and jointly applied the
unified criteria to manually remove pseudo-static pages. (c) Homogeneous Technology Stacks: Throughout the data cleaning
phase, we observed that several websites, likely developed by the
same entity, shared similar structural attributes. To enhance the
diversity of our dataset and manage the data volume effectively,
we retained only one representative website from each group
of structurally similar entities. (d) Websites with Insufficient
Pages: Websites that contained fewer than a predefined threshold
M , of pages within a single temporal segment were excluded.
This criterion was established because a minimal number of
pages could lead to an inadequately detailed representation in
our dataset analysis.
We also applied security policy review and valid page coverage testing to the web pages. After cleansing, we obtained a
dataset comprising over 204,000 clean web pages collected from
75 different websites. We referenced real web page tampering
cases from zone-h.org, manually simulating and restoring the

With authorization, we deployed a web page tampering monitoring system for a Chinese university and its sub-colleges. The
system, hosted on cloud servers as a third-party service, performs
real-time data collection and analysis of the university’s website.
The collection covers all pages under the official website, with
data re-collected and website temporal graph updated every
24 hours. On April 1, 2024, the monitoring system issued a
tampering alert, pinpointing the official website of a particular
college within the university. The college posted a notice for
master’s degree re-examination on the affected page, as depicted
in Fig. 11. The anomaly detector in our model indicated an
increase in the probability of page tampering from 2% to 98%
within two time intervals. After confirming the authenticity of
this web page tampering event, we conducted an in-depth analysis. The re-examination notice page contained an embedded
hidden link that pointed to an external website. The hidden link
was aimed at a graduate entrance examination service provider,
which we suspect may have employed hackers to conduct illegal
promotional activities. We have reported the tampering incident
to the relevant authorities and completed timely web page repair
and vulnerability self-checks. During subsequent continuous
monitoring of the same college site, neither our system nor
manual reports observed further tampering, suggesting that the
remediation and hardening steps reduced the likelihood of similar incidents.

J. Result Analysis
The WPT-Dataset faced significant variations in web page
content during the data collection, leading to dynamic changes
in the node sets for each snapshot. The results of comparative
experiments show that the DySAT and GraphMAE models are
not well-suited for web page tampering detection scenarios.
We suspect that GraphMAE cannot capture dynamic changes
in web pages over time, while DySAT may lack effective
guidance from a high-level learning framework. The SMGCN
underperforms on our dataset, which we attribute to the lack of
key technical expertise in replicating the model, as well as the
performance degradation resulting from the transformation
of multi-view graph convolution from semi-supervised to
self-supervised learning. In contrast, our approach combines
DySAT’s ability to capture spatiotemporal features with the reconstruction capability of the generative self-supervised framework. It additionally incorporates a dynamic attention mechanism to enhance its feature extraction capabilities and is complemented by a heuristic prediction error, ultimately achieving
competitive performance.
In the hyperparameter experiments, the number of encoder/decoder layers has a greater impact on the model’s performance. Deeper encoder/decoder structures can better capture data features and anomaly patterns. Choosing a deeper
encoder/decoder structure may improve AD performance in
practical applications. Furthermore, the final hyperparameter
selection should consider the interplay between the number of
encoder/decoder layers, attention heads, and dataset complexity.
Different datasets and tasks may require different combinations
of hyperparameters.
In the ablation experiments, the impact of key components
on the model is significant. Among them, the introduction of
DySAT has the most pronounced impact, providing a 21%
absolute gain in performance. It is because DySAT can aggregate
structural neighborhoods and temporal dynamics, allowing it to
learn data features from both temporal and spatial dimensions.
The dynamic graph attention mechanism, prediction error, and
generative autoencoder, respectively, provide gains of 12% to
19% . Such large gains are attributed to the effectiveness of
the various model components and the characteristics of the
WPT-Dataset, where each website has an average of only 21
snapshots, and the number of nodes in each snapshot is relatively
small, leading to larger fluctuations in the experimental results.
The selection and performance analysis of AD models guide
the practical application of our model. In the web page tampering
detection scenario, the LOF algorithm’s strong performance alleviates the difficulty of choosing among diverse AD algorithms.
Of course, we can also combine multiple AD algorithms to
provide a comprehensive conclusion if slightly lower efficiency
is acceptable. The superior performance allows our model to be
maintained on servers at a lower cost and complete tampering
detection for all web pages within a website in a short time (<10
minutes), replacing the need for global scans and comparisons.
The case study demonstrated that our model can detect web
tampering events in real-world college network scenarios, proving its practical value. Besides, our system has been operating

at scale since October 2023, continuously monitoring approximately 600 websites comprising about 150,000 pages, and has
identified more than 400 incidents of tampering or abnormal
activity across participating organizations. The university deployment described above represents one component of this
broader rollout. However, limitations remain, including a 24hour recrawl interval that may miss short-lived defacements,
monitoring restricted to public pages, manual confirmation requirements, and deployment within a single institution. Future
work will address these by increasing crawl frequency, expanding deployment to more sites, integrating multi-source telemetry,
and conducting red-team tests.

VII. CONCLUSION
In this paper, we propose a web page tamper detection based
on dynamic temporal graph pretraining, which improves the
effectiveness of web page tamper detection through pretraining
on dynamic temporal graphs. The paper provides an overview
of web page tampering and discusses web page tamper analysis
under temporal and graph. The proposed method is detailed,
covering website temporal graph construction, generative selfsupervised learning pretraining, and web page tamper detection under anomaly analysis. Experimental results demonstrate
that pre-trained node embedding vectors can better distinguish
anomalous web pages and perform excellently in various AD
classification tasks. The paper also tested the hyperparameter
sensitivity and performance of the proposed model, proving the
applicability of the proposed model in real-world scenarios.
