FusedBoostNet: A Lightweight Hybrid Model for
Consumer-Grade Intrusion Detection
Ankita Sharma

and Shalli Rani , Senior Member, IEEE

Abstract— The rapid accumulation of AI-enabled cyberattacks
poses a significant threat to the security of consumer applications
and smart devices. Traditional intrusion detection and prevention
systems (IDPS) often struggle to balance accuracy, efficiency,
and deployability in resource-constrained environments. FusedBoostNet, a novel hybrid framework that fuses Gradient Boosting
Machines (GBM) with an attention-augmented one-dimensional
Convolutional Neural Network (1D-CNN) has been proposed to
deliver accurate, robust, and lightweight threat detection. The
system leverages the interpretability and decision strength of
GBM on tabular network features while capturing temporal
patterns from sequential traffic using the 1D-CNN, enhanced
by a channel-level attention mechanism. A score-level fusion
strategy ensures optimal synergy between the models for final
classification. Extensive experiments on the CIC-IDS2018 dataset
demonstrate that FusedBoostNet outperforms classical machine
learning, deep learning, and ensemble-based techniques, achieving a detection accuracy of 96.8%, an F1-score of 96.0%, and
a false positive rate below 3%. The model is further validated
for edge deployment with a compact footprint (less than 5 MB)
and inference latency under 10 ms. In addition, robustness
testing against adversarial perturbations highlights the system’s
resilience to AI-enabled evasion attacks. FusedBoostNet offers
a practical and scalable solution for securing next-generation
consumer applications in an increasingly adversarial digital
landscape.

achieves a favorable balance between accuracy, speed, and
resource efficiency, outperforming several baseline models
including Random Forest, CNN, and LSTM in both adversarial
robustness and edge deployability.

packets or flows, we implement a sliding window technique
to aggregate session features over time. For tabular features
like connection flags, flow durations, and TCP window sizes,
we extract handcrafted statistics (mean, standard deviation,
entropy) which are well-suited for GBM. In parallel, sequential
features such as byte sequences and time-based changes in
packet length are preserved as ordered vectors, which are
input to the 1D-CNN module. This dual-feature preparation
ensures that both shallow and deep learning components
receive appropriately structured data.
B. Gradient Boosting Module for Static Detection
The first stage of detection is performed using a GBM,
specifically based on XGBoost due to its high efficiency and
support for tree pruning. GBM is ideal for capturing rulelike, categorical, and statistical patterns in structured network
flow data. These include fixed port scanning behavior, protocol
misuse, or sudden spikes in packet sizes. The GBM model is
trained on the preprocessed tabular feature set with labeled
attack categories. During training, we use early stopping
based on validation AUC to avoid overfitting and optimize
hyperparameters such as tree depth, learning rate, and number
of estimators.
C. Lightweight 1D-CNN With Feature Attention
The second detection stream processes sequential data using
a compact 1D-CNN, optimized for lightweight deployment
and temporal pattern recognition. The CNN takes as input
a fixed-length time-series vector, such as packet sizes or
inter-arrival times across a windowed session. To enhance the
model’s focus on critical patterns while maintaining a shallow
architecture, we incorporate a feature attention layer. This
mechanism assigns importance weights to different input channels (features), enabling the network to emphasize high-impact
attributes while suppressing irrelevant noise. The attention
layer operates on top of the first convolutional block and
outputs a weighted feature map that flows into subsequent
CNN layers. Our CNN configuration includes:
• Depthwise separable convolutions, reducing the number
of trainable parameters.
• Two convolutional layers with small kernel sizes (e.g.,
3 or 5).
• Global average pooling instead of dense layers to minimize model size.
• ReLU activation and dropout for regularization. This
design allows the CNN to capture bursty or stealthy
behaviors that evolve over short time windows, such as
distributed DoS packets, timing-based evasion, or adversarially perturbed flows. The CNN module also produces
a probability score indicating malicious activity.
D. Score-Level Fusion and Decision Layer
The outputs from the GBM and CNN modules are probability scores rather than hard labels, allowing for a score-level
fusion strategy. Specifically, we compute a weighted average
of both scores using a tunable fusion parameter α:
Final Score = α · GBM Score + (1 − α) · CNN Score (12)

1527

The value of α is selected based on validation set performance, typically in the range [0.4, 0.6], which provides a
balance between static and temporal detection streams.
The fusion weight α ∈ [0,1] controls the contribution of
the GBM and CNN outputs in the score-level fusion stage.
We performed a grid search over values 0.1, 0.2, . . . , 0.9 on the
validation set, with AUC as the primary selection criterion and
F1-score as a secondary tie-breaker. We conducted a controlled
study varying α while keeping all other hyperparameters fixed.
The results show that performance (AUC and F1-score) is
relatively stable in the range 0.4 ≤ α ≤ 0.6, but drops
noticeably when α is skewed heavily towards either GBM
(α ≥ 0.8) or CNN (α ≤ 0.2). This finding confirms that the
hybrid architecture benefits from a balanced contribution of
both models
E. Intrusion Prevention and Response Engine
Once an intrusion is detected, the system triggers the
response engine. Depending on the device type and policy,
this module can terminate or throttle the suspicious connection,
isolate the device from the network. Alert the user via mobile
notification or dashboard. Log the event for further analysis
or model retraining.
This architecture demonstrates that by smartly combining
the explainability and efficiency of tree-based ML models
with the temporal learning power of attention-augmented
CNNs, we can create a powerful yet lightweight hybrid system suitable for modern consumer environments under active
AI-driven threats.
IV. E XPERIMENTAL S ETUP AND E VALUATION
To rigorously evaluate the effectiveness, efficiency, and
deployment feasibility of the proposed FusedBoostNet model,
we conducted a series of experiments using a well established
intrusion detection dataset, implemented the full pipeline in
a controlled testbed, and benchmarked our model against
several baseline machine learning and deep learning models.
The experiments were designed to test the system ability to
detect a wide variety of attacks especially those generated by
adversarial techniques with high accuracy and low latency,
while ensuring suitability for resource-constrained consumer
devices.
A. Dataset Description
For the experiments, we utilized the CIC-IDS2018 dataset
https://www.kaggle.com/code/upam22/ids-2025-using-deeplearning, a widely recognized and comprehensive benchmark
for intrusion detection research. The dataset was collected
in a realistic testbed and contains both benign and malicious
traffic, simulating modern attack scenarios across multiple
days. It includes diverse attack types such as brute-force
SSH, DoS/DDoS, botnets, infiltration, web-based attacks, and
even heartbleed exploits. Each network flow contains over
80 features, including flow duration, packet length statistics,
byte rate, protocol type, and flag indicators. To focus on
realistic consumer-level scenarios, we extracted a subset of
the data representing traffic from smart home devices and

The increasing sophistication of AI-enabled cyber threats
targeting consumer applications underscores the urgent
need for next-generation intrusion detection and prevention
systems that are both intelligent and lightweight. In this work,
we presented FusedBoostNet, a novel hybrid model that
intelligently fuses the strengths of Gradient Boosting Machines
and attention-enhanced 1D Convolutional Neural Networks.
Designed specifically for resource-constrained consumer environments, the proposed system achieves high detection accuracy while maintaining low memory and latency requirements,
making it practical for real-time deployment on edge devices
such as smartphones, smart routers, and IoT hubs. Through
extensive evaluation on the CIC-IDS2018 dataset, FusedBoostNet demonstrated superior performance in terms of detection
accuracy, adversarial robustness, inference latency, and model

SHARMA AND RANI: FusedBoostNet: A LIGHTWEIGHT HYBRID MODEL

footprint compared to both classical and deep learning-based
baselines. It achieved over 96.8% accuracy, maintained a
false positive rate below 3%, and operated with a model size
under 5 MB all of which position it as a viable intrusion
defense solution for the modern consumer ecosystem.In the
context of deployment, future work can explore embedding the
model within secure hardware modules or network firmware,
enabling autonomous threat mitigation at the firmware or
chipset level. In conclusion, FusedBoostNet represents a
significant step forward in achieving intelligent, interpretable,
and deployable intrusion defense for everyday consumer platforms. Although FusedBoostNet demonstrates high detection
accuracy and real-time deployability, certain limitations must
be acknowledged. The model currently depends on labeled
datasets for supervised training and lacks mechanisms for
online or continual adaptation to evolving attack behaviors.
Future research will focus on integrating semi-supervised,
federated, and online learning strategies to overcome these
limitations and enable fully autonomous, continuously
adaptive intrusion detection in consumer IoT ecosystems.
