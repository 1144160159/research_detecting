ABSTRACT
Traffic identification has become a challenging task in recent years. Recently, deep learning
methods have been extensively studied for network traffic classification recently. Unfortunately,
these models require a large amount of training data. Another challenge with most traffic
classification methods is that the features must be extracted by an expert. In these methods,
finding the desired features that lead to a better classification is very tedious and timeconsuming. In this regard, an excellent solution to address this challenge is to use of deep
learning methods that automatically extract features. This paper is an attempt to address these
issues by using a combination of the convolutional neural network (CNN), the ant-lion metaheuristic algorithm (ALO), and the self-organizing map (SOM) to create a traffic classification
model that can accurately identify traffic types. The proposed method was able to identify
encrypted traffic and distinguish between VPN and non-VPN traffics. The model was evaluated
using the ‘‘ISCX VPN-non-VPN’’ dataset, and achieved 98% accuracy.

1. Introduction
Network traffic classification is a process for identifying different types of applications [1]. Traffic classification is used in various
applications, such as network management, network design, and network security. Network traffic classification is an essential and
challenging task for different reasons such as (a) the identification of some applications is complicated because of complex, and
dynamic protocols (e.g., P2P, online game, video streaming, etc.) [2,3]; (b) the use of dynamic ports and tunnels, which increases
the complexity of traffic identification; and (c) the use of encryption methods that can make it difficult to identify the traffic.
Therefore, the classification of encrypted network traffic has become a big challenge in modern networks. It should be noted that
many network traffic classification techniques like port number, payload based, statistical methods, and machine learning approaches
require patterns or extracted features. This process is time-consuming, error-prone, and expensive.
Network traffic classification using traditional machine learning techniques requires the manual involvement of human experts in
the feature extraction process. The manual process is prone to human error, which in recent years has emphasized the need for deep
learning-based methods for automatic feature extraction. However, these methods require a large amount of data in the training
phase. Since these models contain several hidden layers, the optimized adjustment of weights cannot be performed entirely and
correctly with a small amount of data. Researchers have shown that the optimal and desirable result cannot be achieved without
a sufficient data volume, and inadequate training data results in a model with poor performance.
However, the performance of traffic classification has been considerably improved by features that can be extracted and learned
through deep network models. The problems of robust feature selection and sufficient data availability for some traffics are still

• Preprocessing traffic data using entropy and entropy variance.

• Classification of new instances using a fuzzy-SOM based-clustering.

2. Related works
This section provides an overview of the main methods used to classify network traffic. In general, these methods can be
categorized into two main groups: (1) machine learning methods and (2) deep learning methods.
Machine learning methods: There are many studies on traditional machine learning techniques, some of which are briefly
described here. Shafiq et al. [10] used various machine learning classifiers such as C4.5 decision trees, Naïve Bayse, Support Vector
Machine (SVM), and Bayes Net classifiers for network traffic classification using a real-time Internet dataset. They showed that C4.5
gave a better result (78.9%) in comparison to other machine learning approaches. In [11], Soysal et al. employed three machine
learning classifiers, decision trees, Bayesian networks, and multi-layer perceptrons (MLP), using flow traces for traffic classification.
The dependence of the performance of network traffic classification systems on the amount of the training data show that machine
learning algorithms such as decision trees, and Bayesian networks are suitable for the classification of high-speed Internet traffic
flows. They also encompass applications with dynamic port number changing. These algorithms analyze the impact of mislabeled
data (training and testing) on the accuracy of machine learning algorithms.
Deep learning methods: Recently, researchers have tried to use deep learning for network traffic. Lixin, et al. [12] proposed a
new approach to train a CNN model by optimizing a new function, which emphasized on the learned features for network traffic
classification. They evaluated the proposed method on three traffic datasets. The experimental results showed that the method
improved the classification accuracy, and it can be well adapted to the challenges of class diversity and class similarity in network
traffic classification. Hong, et al. [13] proposed a method to improve network traffic classification performance using deep learning
methods. They presented a network applications classification model based on Deep Belief Network (DBN) and used the BP-based
model for comparison in the same conditions. The result showed that classifying network traffic based on DBN had a higher accuracy.
Gil et al. [14] used statistical features such as flow arrival time, the number of flows, Bytes per second, etc., to classify network
traffic. They also applied a decision tree and KNN algorithms and achieved 92% accuracy for recognizing six classes (chat, email,
FTP, etc.). Yamansavascilar et al. [15] considered the‘‘ ISCX VPN-non VPN’’ dataset and 111 flow features with 12 application classes
and used the KNN algorithm to achieve 94% accuracy. The main disadvantage of these methods is that an expert does the feature
extraction and selection processes. Therefore, such methods are prone to human error, time-consuming, and expensive. In [16],
Rezaei et al. presented a general framework to classify network traffic based on deep learning. Lotfollahi et al. [17] introduced a
model based on CNN and Stacked Auto-Encoder (SAE) for classifying encrypted traffic. The numbers of classes and data instances
in their work were close to those used in the present study. They obtained an accuracy of 94% in traffic classification by the CNN

3. Convolutional neural network and ant-lion optimization algorithm concepts
In this section, the concepts of the convolutional neural network (CNN) and the ant-lion optimization algorithm (ALO) are
described.

3.1. The concept of convolutional neural network
One of the most popular deep learning algorithms is the convolutional neural networks (CNNs). A CNN consists of an input
layer, an output layer, and several hidden layers. Mainly, a CNN is composed of three types of layers, namely, convolutional layers,
pooling layers, and fully connected layers. In general, CNNs are hierarchical neural networks, in which the convolutional layers and
pooling layers are placed alternately, and then multiple fully connected layers are arranged. Performing a convolution operation
has three merits [9] (1) using a weight sharing mechanism in every feature map considerably decreases the number of parameters,
(2) the local connection learns the relations between neighboring pixels, and (3) it leads to immutability and stability against object
replacement. A pooling layer is usually place after the convolutional layers and can be used to reduce the size of the feature map
and the number of network parameters. Then, fully connected layers allow to represent the network’s result as a vector with a
defined size. We believe that this method is an optimal option for network traffic classification. The results approved this claim and
showed that 1D-CNN performs well in terms of feature extraction from network traffic classification.

3.2. Ant-lion optimizer algorithm
In recent years, meta-heuristic algorithms have been used to obtain optimized solutions for optimization problems. Due to the
random nature of these algorithms, the probability of avoiding local optimums is high. If an evolutionary algorithm (EA) traps in a
local optimum, then the random operators make random changes in the solution and consequently depart from that local optimum.
The EAs use a general and common framework, in which a set of random solutions are created gradually or maybe iteratively. Some
of the most famous algorithms in the EA family include the Ant Colony Optimization (ACO), Emperor Penguins Colony algorithm,
Artificial Bee Colony optimization, Particle Swarm Optimization (PSO), and Genetic Algorithm (GA).
The ant-lion optimizer (ALO) algorithm was used in this study. The life cycle of an ant-lion consists of two main steps; larva
and adulthood. An ant-lion larva digs a cone-shaped hole with its hand by moving in a circular orbit and throws out the soil with
its jaw. Fig. 1(a) shows a tapered hole. After digging the trap, the larva hides beneath the cone and waits for insects (ideally ants)
to get trapped in the hole, like what is shown in Fig. 1(b) [19]. The edge of the cone is sharp enough so that ants easily fall into
the bottom of the trap. As soon as the ant-lion finds out about a miserable prey trapped in the hole, he tries to catch it. However,
insects are usually not easy to catch, while trying to fly out of the trap. In this condition, the ant-lion throws soil around the edge,
so that the prey slips downward. Once the larva captures the victim with his jaw, it pulls the hung under the soil. After that, the
ant-lion throws the rest of the ant’s body out of the hole and prepares the trap for another hunt.

4.2. Feature extraction
An important step in network traffic classification methods is feature extraction. Finding the desirable features that can leed to
high accuracy is difficult and time consuming. Therefore, it is important to extract the features efficiently. The CNN is one of the
most popular algorithms in deep learning for feature extraction. For this purpose, in the next step, the processed data are sent to a
CNN to extract features. In this phase, a CNN algorithm was used because this method performs less preprocessing tasks compared
to other feature extraction techniques. So, it needs data with similar sizes to map them into CNN. Therefore, a one-dimensional
array of remaining statistical features from the previous stage was provided as input for the convolutional network.
The optimization of hyperparameters is an essential part of deep learning. In many cases, the selection of hyperparameters is done
manually with trial and errors, which is a time-consuming method. Moreover, the correct selection of this type of parameters has a
significant impact on the accuracy. Therefore, a technique that shifts the feature extraction operation from a manual to an automatic
manner was proposed. The proposed method deals with an estimation model that uses the grid search algorithm to estimate the
number of neurons, the number of iterations for training the network, and other parameters of the CNN. Table 1 provides the values
of the hyperparameters obtained using the grid search algorithm.
This model was trained using the labels of the training data to recognize the class of each flow (the protocol generating the
flow) based on the different combinations of the features created in the intermediate layers. The CNN model in this study contains
two convolutional layers, two pooling layers, and five fully connected layers. The fully connected layers are the final classification
layers, where the output features are calculated by multiplying the fully connected weight matrix by the input feature vector.
The output of this phase is composed of several new combinational features that must be extracted from the hidden layers in the
convolutional network structure.

accuracy can be achieved for applications with less data available.

4.4. Traffic detection
To classify the traffic based on the optimized features, a combination of self-organized map (SOM) clustering and fuzzy logic
was used. Data might contain complex structures so that even extracting meaningful patterns using the best data mining techniques
can be a challenging task. Clustering refers to dividing a dissimilar pattern into several similar subsets or groups. A SOM is an
unsupervised neural network where neurons are organized in a standard network structure with a small number of parameters.
Each neuron has an n-dimensional weight vector. Weight vectors (synapses) connect the weight vectors of the input layer to the
output layer called the map or competition layer. The neurons are connected through a proximity function. Each input layer, based
on the most similarity, activates a neuron in the output layer, called the winner cell. The most crucial difference between the SOM
training algorithm and other vector measuring algorithms is that in addition to the single communication weight with the highest
adaptation (the winner cell), the weight of the neighbor cells of the winner cell is also updated.
First, based on the training set, the values of the extracted features are divided into 𝑘 clusters using clustering in the SOM

is collected by the TCP DUMP software and has an approximate size of 28 GB. Details about available classes are listed in Table 2.
This dataset contains 23 features for each flow instance. These 23 features are the statistical features on the packets of each flow,

of packets, etc.

5.3. Evaluation results
This section presents the results obtained by applying the proposed method to recognize, and classify the network traffic.
To perform a better comparison, along with evaluating the proposed method, a deep learning network with a dataset was also
evaluated. This deep learning network is a 1D-CNN with two convolutional layers, two pooling layers, and multiple fully connected
layers that performs feature extraction and traffic classification sequentially. In fact, the problem is to classify 12 classes of network
applications. These classes contain six normal classes, and six VPN classes.
The results of applying the proposed method and the CNN to the dataset for identification and classification of traffics are
provided in Table 3. The experiments were repeated several times, and the average accuracy of classifying the available classes and
instances in each class was calculated according to accuracy, precision, and recall criteria. It reached an average accuracy of 98% on
the dataset for a 12-classes problem. The CNN also achieved an average accuracy of 95% on the same dataset. Both methods have
excellent performance and accuracy. As shown in Table 3, amongst all classes, the accuracy for VPN-Streaming, Streaming, and Mail
classes is lower with the CNN method. This low accuracy for such applications is due to the availability of fewer training datasets
compared to other classes. Because of this, CNN could not learn sufficient features to recognize the data and, consequently, the
traffic. To yield successful results, artificial neural networks (ANNs) such as CNN depends on factors like the system architecture, the
training algorithm, and the features utilized in the training. These factors ensure the design an optimal ANN. The proposed method
used deep learning models to extract features automatically for network traffic classification and ant-lion meta-heuristic algorithm
to solve the problem of insufficient data availability and selecting optimal features. Such a method must be able to classify different
types of traffic with high accuracy and acceptable performance.
The proposed method achieved good accuracy even for the classes with fewer instances to train. This is due to the application of
an evolutionary algorithm and its combination with a deep learning network, resulting in an optimized solution. Another privilege
of the proposed method in traffic classification was the proper detection of applications like P2P and VoIP with high accuracy. The
P2P data are usually encrypted with dedicated protocols, and recognizing them is too hard. Nevertheless, the proposed method can
recognize such applications with high accuracy. In the best case, the method reached both the recall and the precision of 97% for

5.5. Discussion
In order to evaluate the proposed method as accurately as possible, a comparison with other related work was carried out. The
followings are some studies that have used the same dataset as this study (e.g., ISCX VPN-non VPN). Several papers have been
published to classify network traffic using machine learning methods. Two of the essential published papers that used the ‘‘ISCX
VPN-non VPN’’ dataset, focused on machine learning methods. Gil et al. [14] used temporal features like flow arrival time, the
number of flow Bytes per second, etc., for network traffic classification. They also applied a decision tree and the nearest neighbor
algorithm to classify the traffic. The authors achieved an accuracy of 92% in recognizing six classes, including chat, email, FTP, . . . ,
and normal classes by utilizing the decision tree algorithm. By comparing the results of this paper with the results obtained here,
the superiority of our method in classification becomes quite clear. Yamansavascilar et al. [15], achieved 94% accuracy with the
same dataset, 111 flow features with 12 application classes, and KNN algorithm. The main drawback of these methods is that an
expert is required to perform the feature extraction and selection processes. Therefore, such methods are prone to human error,
time-consuming, and expensive.
Recently, some studies have applied deep learning ideas to the ‘‘ISCX VPN-non VPN’’ dataset. In [16], Rezaei et al. introduced a
general framework to classify the network traffic based on deep learning. They also discussed the problems and challenges of their
proposed method. Lotfollahi et al. [17], introduced a model based on CNN and SAE for classifying encrypted traffic. The number
of classes and data instances in their work were almost the same as in the present study. They achieved an accuracy of 94% in
traffic classification by the CNN model, while our proposed method reached an accuracy above 95% for most applications and the
accuracy of 98% on average. Their proposed network could not achieve a good improvement in detecting different traffics like
streaming and mail. The average accuracy for these classes is about 87%, which is due to the lack of a sufficient training dataset for
these types of traffic. However, the proposed method reached an excellent accuracy of 95% by combining deep learning networks
and optimized evolutionary algorithms for traffics with insufficient training sets. Wang et al. [18], proposed classifying encrypted
traffic method using the one-dimensional convolutional neural network. This method combines feature extraction, feature selection,
and the classifier in a unified final framework for automated learning of the non-linear relation between row input and expected
output. The proposed method was applied to the ‘‘ISCX VPN-non VPN’’ dataset and obtained an accuracy of 92% for 12 classes.
As discussed earlier, one of the challenges in deep learning networks is the use of hyperparameters in a random and trial and
error manner. This challenge is due to the complexity of neural network configuration and the many parameters that need to be
adjusted. The correct and optimized selection of these parameters has a significant impact on increasing accuracy and reducing
execution time, especially for convolutional networks that are very sensitive to this factor. Therefore, to solve this problem, an
estimation or predictive model is used that workes on the grid search method and estimates several parameters like the number
of neurons, the number of iterations to train the network, the activation function, the cost function, etc. A general comparison
between the proposed method and other techniques focused on the ‘‘ISCX VPN-non VPN’’ dataset is presented in Table 6. The
proposed method reached a higher accuracy compared to both machine learning and deep learning methods. Since the feature
extraction is automatically performed in the deep learning network, many features might be extracted which might be ineffective
in the accuracy and even increase the computational cost and time.

6. Conclusions
A method based on the evolutionary algorithm and deep learning was proposed to automatically select features and accurately
classify network traffic. Several studies have recently focused on deep learning methods to extract features automatically. However,
deep learning models need massive training data that is not always available. Since these models are composed of multiple hidden
layers, the optimized weight adjustment cannot be done accurately and correctly with insufficient training data. Moreover, the
initial point for adjusting weight is essential. If the initial network settings are insufficient, there is a risk that the optimization
of the weights will stop at a local optimum. To address this problem, an evolutionary algorithm was used. This algorithm creates
one or more random solutions and searches for a global optimum in the search space. In addition, the cost of recruiting a human
expert for detecting and recognizing the traffic features was eliminated by using the automated feature extraction method. The
proposed method benefits from an evolutionary algorithm to find an optimal solution and select the appropriate features, reducing
the execution time and also the computational cost. This method is a combination of CNN, ALO, and SOM, and its purpose is to
classify network traffic as accurately as possible with any size of the training dataset. By combining an evolutionary algorithm and
neural networks, the proposed method can find an optimized training approach to classify network traffic with high accuracy. The
results showed that the suggested method outperformed all similar techniques on the ‘‘ISCX VPN-non-VPN’’ dataset.
