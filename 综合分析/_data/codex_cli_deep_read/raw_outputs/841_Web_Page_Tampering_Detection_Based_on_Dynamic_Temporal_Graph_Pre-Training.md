# [841] Web Page Tampering Detection Based on Dynamic Temporal Graph Pre-Training

- DOI：10.1109/TDSC.2025.3623257
- 主题定位：网页篡改检测、动态时间图、图预训练、自监督异常检测

## 2. 中文翻译与核心摘要
这篇论文要解决的是：动态网站中的正常更新与恶意篡改在表面上都表现为网页内容、DOM、链接和统计属性变化，传统基于快照比对、文本检测或单页特征阈值的方法很难稳定区分二者。作者将网站建模为随时间演化的动态图：网页是节点，网页之间的链接是边，每个时间点保存一个网站结构图，多个快照构成“网站时间图”。

方法核心是用增强版 DySAT 做动态时间图的自监督预训练。节点特征被部分遮蔽后，模型需要利用同一时间片的邻域结构和跨时间片的演化上下文重构网页特征；同时又加入“当前时间片预测误差”，迫使模型学习正常网页演化规律。预训练得到的节点嵌入再交给无监督异常检测器，判断哪些网页是篡改页。

论文的主张可以概括为：网页篡改不是单页静态异常，而是网站结构、网页内容和时间演化共同作用下的图时序异常；通过动态图预训练可以放大隐蔽篡改造成的小扰动，使后续异常检测更容易识别。

## 3. 论文解决的具体问题
论文针对三个具体难点展开：

1. 动态网页频繁变化  
现代网站中 JavaScript、AJAX、服务端脚本会持续更新内容，正常变化本身就很强，导致基于差异比对的方法误报高。

2. 网站结构复杂  
大型网站页面多、链接关系复杂，攻击者可能只篡改局部页面或通过邻接页面扩散，单页检测会丢失跨页面依赖。

3. 隐蔽篡改幅度小  
隐藏链接、SEO 黑链、轻微 DOM 注入、少量脚本植入等篡改不会造成大面积内容变化，但会在结构关系、统计属性和时间轨迹中留下异常。

作者因此把问题重新定义为：在动态时间图中识别节点级异常，即某个网页节点在内容、结构、统计特征及其邻域演化关系上偏离正常演化模式。

## 4. 创新点深度提炼
第一，提出面向网页篡改的 Website Temporal Graph。  
论文不是只看单个网页的历史版本，而是把网站整体结构纳入模型：节点为网页，边为站内跳转/链接，节点属性融合内容、DOM 结构和统计特征。这样可以捕获“攻击沿链接路径移动”“邻近页面风险升高”“高权重节点被增删”等现象。

第二，把生成式自监督预训练迁移到动态时间图。  
GraphMAE 一类方法主要处理静态图；DySAT 能处理动态图但缺少生成式预训练目标。论文将二者结合，用遮蔽重构任务训练时间图编码器，使模型在无标签条件下学习网页正常演化表征。

第三，用 GATv2 替换 DySAT 中的结构注意力。  
原 DySAT 的结构注意力使用 GAT，作者认为 GAT 的注意力排序不够动态，于是用 GATv2 在每个快照内聚合邻域信息，增强对不同查询节点、不同时间片结构变化的适应能力。

第四，设计时间遮蔽机制。  
遮蔽不是在整个动态图上一次性抽样，而是在每个时间片独立抽样，并且同一节点在不同时间片的遮蔽状态可以不同。这个设计让模型必须利用前后时间片信息推断缺失特征，更贴近网页篡改检测中的时序依赖。

第五，引入预测误差与重构误差联合训练。  
仅重构被遮蔽节点可能不足以服务“当前时刻是否异常”的检测目标。作者额外遮蔽当前时间片全部节点，用过去窗口预测当前节点特征，形成 Prediction Error，与 Reconstruction Error 加权相加，使预训练更偏向检测当前快照异常。

## 5. 科学问题与研究假设
科学问题可以表述为：  
在动态网页正常更新频繁、异常标签稀缺且篡改信号隐蔽的条件下，能否通过网站级动态图自监督预训练学习正常演化模式，并将篡改扰动放大为可被无监督异常检测器识别的节点嵌入异常？

论文隐含了几条研究假设：

- 网页篡改会改变节点特征，包括文本语义、DOM 结构和统计属性。
- 篡改不仅影响单个网页，还可能通过链接关系影响邻域聚合结果。
- 正常网页更新具有一定时间规律，而恶意篡改会破坏这种规律。
- 对动态时间图进行遮蔽重构和历史预测，可以学习正常演化分布。
- 预训练后的节点嵌入比原始网页特征更适合无监督异常检测。

## 6. 科学方法与技术路线
技术路线分为六步：

1. 网页采集  
使用浏览器式爬虫，从第三方黑盒视角抓取目标网站页面，通过 DOM 渲染阶段 hook、robots/fuzz 字典、表单填充和 JS 事件触发扩展入口。

2. 页面过滤  
进行 URL 去重、伪静态页面过滤、静态资源过滤、请求哈希标识、低价值页面筛除，提升图节点质量。

3. 特征构建  
内容特征用 BERT 表征网页文本语义；结构特征把 DOM 树路径转为“文档”，用 Doc2Vec 嵌入；统计特征包括脚本数量、关键词密度、标签数量等 12 类与篡改相关的统计量。

4. 时间图构建  
每个时间点构造一个 Website Structure Graph，固定间隔采集 21 个时间片，形成 Website Temporal Graph。

5. 动态图预训练  
用 DySAT+GATv2 编码时间图，采用时间遮蔽机制重构节点特征，并结合当前时间片预测误差优化模型。

6. 异常检测  
将预训练得到的网页节点嵌入输入无监督 AD 模型，包括 LOF、DeepSVDD、OCSVM、KNN、DAGMM、Isolation Forest 等，输出网页篡改风险。

## 7. 实验设计与实验步骤
可复核流程如下：

1. 数据  
作者维护 600 个授权网站，行业集中在金融、医疗、教育。每 24 小时采集一次，连续生成 21 个时间片。清洗后得到 75 个网站、约 204,000 个干净网页，并参考 zone-h.org 的真实篡改案例人工模拟篡改，形成 WPT-Dataset。

2. 预处理  
删除响应异常页面、伪静态页面、技术栈高度同质的网站、页面数过少的网站；进行安全策略初审；对涉及隐私的文本做不可逆哈希脱敏；最终公开的是向量化图数据而非原始网页文本。

3. 模型与基线  
本文方法：Website Temporal Graph + DySAT/GATv2 + 时间遮蔽 + 重构误差/预测误差 + 无监督 AD。  
基线包括 SMGCN、DySAT、EvolveGCN、GraphMAE。

4. 训练  
使用 PyTorch 2.0.1+cu118、Python 3.9.17、CogDL 和 PyOD，在双 RTX 3090 服务器上训练。先预训练动态图编码器，再生成节点嵌入，最后针对每个网站训练无监督异常检测模型。

5. 指标  
使用 AUC-ROC 和 AUC-PR。AUC-PR 尤其重要，因为正样本比例很低，论文提到正样本约 0.76%，类别极不平衡。

6. 消融与敏感性  
超参数实验考察编码器/解码器层数 1/2/3 与注意力头数 1/2/4。消融实验分别去掉 DySAT、GATv2、Prediction Error、MAE 训练框架。AD 选择实验比较 13 种异常检测器。

7. 结果核查  
比较 15 个随机网站上的基线性能；再在全部 75 个网站上测试本文模型；用 ROC 曲线、AD 排名热图、运行时间表和真实部署案例支撑结论。

## 8. 关键结果、结论与证据
主要结果有四类：

- 对 15 个随机网站，本文方法平均 AUC-ROC 为 0.9816，AUC-PR 为 0.9447，整体优于 SMGCN、DySAT、EvolveGCN、GraphMAE。
- 在全部 75 个网站上，AUC 均超过 0.8725，平均值为 0.9602，说明方法在不同网站结构上有较强适应性。
- 消融实验显示，去掉任一关键模块都会明显下降。DySAT 带来的收益最大，论文分析约有 21% 绝对性能增益；GATv2、预测误差、MAE 框架也分别带来 12% 到 19% 左右增益。
- AD 模型选择上，LOF 最常取得最优，适合局部离群篡改；DeepSVDD 稳定性较好；SOD、COF 等在不同篡改类型下表现有差异。论文结论是异常检测器应按网站和篡改分布选择，而不是固定一种。

真实案例也很有价值：作者在某中国高校及下属学院网站部署系统，2024 年 4 月 1 日检测到某学院复试通知页面存在隐藏外链，模型篡改概率从 2% 升至 98%，后经确认是指向考研服务商的隐蔽推广链接。

## 9. 局限性与待解决问题
论文自身暴露出几类局限：

- 采集周期为 24 小时，可能漏掉短时间存在、随后恢复的篡改。
- 只能覆盖公开可访问页面，登录后页面、内网页面、权限控制页面不在当前能力范围内。
- 数据集中的篡改样本包含人工模拟和恢复，虽然参考真实案例，但与真实攻击者行为仍可能存在分布差异。
- 异常检测结果仍需要人工确认，系统更像高质量预警器，而不是完全自动化定责工具。
- 每个网站需要选择合适 AD 模型，实际部署中存在模型管理和阈值维护成本。
- 数据集公开的是向量化图数据，不能复核原始网页语义与 DOM 细节，这保护隐私但降低了可解释复现实验的完整性。
- 本次正文包未截断，因此理解不受正文缺失影响；但若要做严格复现实验，仍需回到 PDF 核对表格数值、图中细节和数据下载说明。

## 10. 与本项目的关系
该论文与“时序、日志、KPI 与云原生异常检测”的关联在于：它把网页篡改看成时序实体的异常演化问题，而不是传统静态分类问题。这里的网页节点类似云原生系统中的服务、Pod、接口或主机；网页内容/DOM/统计特征类似日志、指标、调用结构；网站链接图类似服务依赖图。

对本项目最有借鉴价值的是：

- 用动态图快照建模系统状态演化，而不是只建单时间点图。
- 用自监督遮蔽重构学习正常模式，降低对异常标签的依赖。
- 将“重构当前状态”和“用历史预测当前状态”联合起来，更适合异常检测。
- 下游不强绑定某个分类器，而是把预训练嵌入交给多种 AD 算法比较。

但它的直接相关性是中等：研究对象是网页篡改，不是云原生日志/KPI；其特征工程依赖 BERT、DOM、Doc2Vec 和网页链接结构，不能直接迁移，需要替换为日志模板、调用链、指标窗口和服务拓扑特征。

## 12. 本篇精华
- 网页篡改检测的关键不只是“网页变了没有”，而是“网页是否偏离了网站整体结构和历史演化规律”。
- Website Temporal Graph 是本文核心抽象：网页为节点、链接为边、内容/DOM/统计为节点属性，多个时间快照构成动态图。
- 动态网页正常变化很强，传统差分和静态内容模型容易误报；动态图预训练通过学习正常演化模式来放大异常扰动。
- DySAT 解决时间图编码，GATv2 增强结构注意力，GraphMAE 式遮蔽重构提供自监督训练目标。
- 时间遮蔽机制是关键细节：每个时间片独立遮蔽，允许同一节点跨时间片遮蔽状态不同，从而逼迫模型利用时序上下文。
- 预测误差让模型不只会重构缺失特征，还要会用历史窗口预测当前网页状态，这更贴近篡改检测目标。
- 下游 AD 没有统一最优算法；LOF 适合局部离群，DeepSVDD 稳定，篡改类型和异常分布决定检测器选择。
- 真实高校案例表明，该方法对隐藏外链类隐蔽篡改有实际检测价值。
