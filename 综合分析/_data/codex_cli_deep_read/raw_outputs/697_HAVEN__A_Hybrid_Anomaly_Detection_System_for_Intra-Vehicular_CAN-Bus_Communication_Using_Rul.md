# [697] HAVEN: A Hybrid Anomaly Detection System for Intra-Vehicular CAN-Bus Communication Using Rule-Based and Neural Networks

## 1. 基本信息
- 论文题名：HAVEN：一种结合规则与神经网络的车内 CAN 总线混合异常检测系统
- 作者：Shaurya Purohit，Manimaran Govindarasu
- 年份与来源：2026，IEEE Transactions on Dependable and Secure Computing
- DOI：10.1109/TDSC.2026.3673151
- 本地 PDF：`paper/10.1109_TDSC.2026.3673151.pdf`
- 主题定位：车内 CAN 总线入侵检测，混合规则检测、机器学习、深度神经网络，覆盖 DoS、Fuzzy、Impersonation、Spoofing、Replay 等攻击。

## 2. 中文翻译与核心摘要
这篇论文提出 HAVEN，一个面向车内 CAN 总线通信的两阶段混合异常检测系统。它的核心思想不是单纯依赖深度学习或规则，而是先用轻量规则层快速筛掉明显异常，再让机器学习或神经网络层处理规则难以判断的复杂攻击。

论文实际提出了两个版本：第一版是“规则 + 树模型”，包括 DT、RF、XGBoost、CatBoost、LightGBM；第二版是“规则 + 深度神经网络”，同时支持二分类和多分类。作者认为第二版更强，因为神经网络对高维、非线性、非周期攻击模式的表达能力更好，尤其适合处理 Spoofing、Impersonation 这类不总是服从固定周期或固定序列的攻击。

## 3. 论文解决的具体问题
CAN 总线天然缺少认证、加密和发送者身份校验，任意接入总线的恶意节点都可能注入合法格式但语义恶意的报文。传统基于周期、频率、熵或时序的检测方法，对 DoS、Fuzzy 等明显扰动有效，但面对非周期、伪装性更强的 Spoofing 和 Impersonation 攻击时容易漏报。

论文要解决的是：在车载 CAN 场景中，如何同时实现较高检测率、较低假阴性、较低延迟，并覆盖多种真实或半真实攻击类型，而不是只在单一攻击或模拟数据上表现良好。

## 4. 创新点深度提炼
第一，HAVEN 把规则检测作为前置过滤器，而不是把规则和学习模型并列堆叠。这样可以把明显异常报文提前拦截，降低后续模型负载，也符合车载边缘环境对延迟的要求。

第二，论文比较了两类混合路线：规则 + 树模型，以及规则 + 神经网络。这个设计使论文不只是报告一个模型结果，而是在“传统高效机器学习”和“神经网络复杂模式学习”之间做了结构性对比。

第三，第二个模型同时做二分类和多分类。二分类回答“是否异常”，多分类回答“是哪类攻击”，这对实际安全运维和响应策略更有价值。

第四，实验覆盖三个公开 CAN 数据集，攻击类型比不少既有工作更完整，包括 DoS、Fuzzy、Impersonation、Spoofing、Replay。论文特别强调 Spoofing 和 Impersonation 中存在非周期样本，这是它区别于只依赖周期性检测方法的关键场景。

## 5. 科学问题与研究假设
科学问题可以概括为：车内 CAN 流量中，能否通过“确定性规则 + 学习模型”的分层结构，在保持低延迟的同时，提高复杂注入攻击的检测能力？

主要研究假设有三点：  
1. CAN 报文存在可被规则利用的稳定结构，如合法 ID、频率、序列关系和时间间隔。  
2. 规则层无法覆盖的异常模式，可以由 ML/DNN 从 CAN ID、DLC、payload 字节和时间差等特征中学习出来。  
3. 两阶段结构比单一规则或单一学习模型更适合车载部署，因为它同时降低计算负担和漏报风险。

## 6. 科学方法与技术路线
技术路线是典型的两阶段 ADS。第一阶段是规则检测，使用四类规则：合法 ID、消息频率、消息序列、时间间隔。违反规则的报文直接告警，未违反规则的报文进入第二阶段。

第二阶段分两条路线。Model 1 使用树模型，包括 DT、RF、XGBoost、CatBoost、LightGBM，重点利用这些模型的并行和多线程能力。Model 2 使用 DNN，包括二分类网络和多分类网络。二分类网络有两个 Dense 隐层，输出层使用 Sigmoid；多分类网络有三个 Dense 隐层，输出层使用 Softmax。

特征侧，论文使用 CAN ID、DLC、DATA[0] 到 DATA[7]、时间差等特征；十六进制转十进制，缺失字段用 -1 替代，使用归一化和 SMOTE 处理类别不平衡，并用信息增益和相关性分析辅助特征选择。

## 7. 实验设计与实验步骤
可复核流程如下：

1. 数据：Model 1 主要在 CAN Intrusion Dataset 上评估；Model 2 在 CAN Intrusion Dataset、Car Hacking Dataset、Automotive CAN Bus Intrusion Dataset 三个数据集上评估。攻击覆盖 DoS、Fuzzy、Impersonation、Spoofing、Replay。

2. 预处理：合并数据，清理缺失；将 CAN ID 和 payload 从十六进制转为十进制；空字段填 -1；提取 CAN ID、DLC、8 个数据字节、时间差；对数值特征做 min-max 归一化；对少数类使用 SMOTE 过采样。

3. 规则层：依次检查合法 ID、消息频率、消息序列、时间间隔。规则命中的异常直接拦截，剩余样本交给学习模型。

4. 模型与基线：Model 1 对比 DT、RF、XGBoost、CatBoost、LightGBM；Model 2 构建二分类 DNN 和多分类 DNN；还与 LCCDE 风格的 LightGBM/XGBoost/CatBoost 集成框架进行比较。

5. 训练：按时间顺序做 70%/30% 训练测试划分，避免未来数据进入训练；训练集内部做 10 折交叉验证；树模型用网格搜索调整树数量和深度；DNN 使用 Adam，学习率 0.01，二分类损失为 binary cross-entropy。

6. 指标：Accuracy、Precision、Recall、F1-score、执行时间。论文尤其关注 F1 和执行时间的平衡，因为车载检测不能只追求离线准确率。

7. 消融/敏感性：论文没有做严格意义上的规则消融或逐特征消融，但比较了规则 + ML 与规则 + DNN，并讨论了隐层数量、编码方式、dropout、学习率等超参数调节。

8. 结果核查：应重点核查各数据集类别分布、SMOTE 是否只在训练集使用、时间顺序划分是否贯穿所有实验、规则层和模型层的总延迟是否按同一口径统计。

## 8. 关键结果、结论与证据
规则 + ML 模型在 CAN Intrusion Dataset 上达到 90% 以上检测准确率，并保持较低执行时间。作者认为其优势来自规则层减少后端负载，以及树模型本身的并行训练和推理效率。

规则 + DNN 模型在三个数据集上二分类和多分类准确率均超过 95%，整体优于规则 + 树模型。论文结论是：神经网络更能捕获高维复杂模式，尤其对非周期的 Spoofing、Impersonation 攻击更有利。

与 LCCDE 风格集成方法比较时，LCCDE 在部分数据集上准确率略高，执行时间也可能更低；但 HAVEN 在 precision 和 F1-score 上更稳，作者据此强调其误报控制和多攻击适应性。

## 9. 局限性与待解决问题
第一，规则设计仍依赖 CAN 流量规律和车辆配置知识。不同车型、不同 DBC、不同 ECU 行为会影响合法 ID、频率和序列规则的迁移性。

第二，论文没有提供充分的线上实时部署实验。它报告了执行时间，但还需要在真实 CAN 总线速率、ECU 资源约束、连续流式输入和告警响应链路下验证。

第三，SMOTE 可能改变攻击样本分布，若处理不当会带来乐观估计。复现实验时必须确认过采样只发生在训练集，而不是在全数据划分前完成。

第四，规则层的具体阈值、规则学习方式、异常通过路径细节没有完全展开，这会影响可复现性。

第五，本次正文包标注为未截断，因此不存在基于截断文本造成的缺页问题；但若用于严肃复现，仍应回到 PDF 核查表格数值、图示和实验参数细节。

## 10. 与本项目的关系
该论文与“异常检测”项目高度相关，尤其适合作为车联网、工业互联网、边缘安全场景中“规则 + 学习”混合检测范式的代表文献。它的价值不在于提出特别复杂的网络结构，而在于把工程约束放进模型设计：先用便宜规则处理显性异常，再用学习模型处理隐性异常。

对本项目可借鉴的点包括：分层检测架构、低延迟指标纳入评价、多分类攻击识别、时间顺序划分避免泄漏、以及面向非周期攻击的模型能力讨论。

## 12. 本篇精华
- HAVEN 的核心不是“再训练一个检测器”，而是用两阶段结构平衡检测能力和车载实时性。
- 规则层负责快速拦截显性异常，学习层负责处理规则难以覆盖的非周期和伪装攻击。
- CAN 异常检测不能只看准确率，F1、假阴性和执行时间同样关键。
- 二分类适合实时告警，多分类适合后续响应和攻击溯源。
- 神经网络版本整体优于树模型版本，尤其在复杂攻击和多数据集泛化上更有优势。
- 论文覆盖三个公开 CAN 数据集，是其相对单数据集研究的重要增强。
- 最大复现风险在规则细节、SMOTE 使用口径和实时延迟评估，而不是 DNN 结构本身。
