# [561] ToCoAD: Two-Stage Contrastive Learning for Industrial Anomaly Detection

- 训练设定：训练阶段仅使用正常样本，测试阶段检测图像级异常并定位像素级缺陷区域

## 2. 中文翻译与核心摘要

这篇论文的核心问题是：现有工业异常检测方法普遍依赖 ImageNet 预训练且冻结的特征提取器，但工业图像与自然图像存在明显域差异，导致某些细粒度缺陷、纹理异常或结构异常在特征空间中不够可分。ToCoAD 试图通过“两阶段对比学习”让特征提取器从目标工业数据中重新适配，而不是只把预训练特征拿来做最近邻匹配或训练一个后端判别器。

方法分为两步。第一阶段使用 Perlin noise、纹理图像和正常样本合成伪异常，冻结预训练 WideResNet50 特征提取器，训练一个反向结构的判别网络，使其具备粗粒度异常定位能力。第二阶段固定这个判别网络，让它为特征提取器提供“负样本引导”；同时使用 SimSiam 式的正样本对比学习，让正常样本的不同增强视图在表征空间中保持一致。最终，微调后的特征提取器用于构建 PatchCore 式 memory bank，通过最近邻距离生成异常分数图。

论文报告的主要结果是：MVTec AD 上 image-level AUROC 99.10%、pixel-level AUROC 98.21%；VisA 上 95.35%/98.43%；BTAD 上 pixel-level AUROC 97.70%。结果说明，针对目标域微调特征提取器能提高异常定位性能，但也带来了两阶段训练和 memory bank 推理开销。

## 3. 论文解决的具体问题

论文不是简单提出一个新的异常分数，而是在处理工业异常检测中一个很实际的矛盾：预训练视觉模型泛化能力强，但它的特征空间并不是为工业缺陷设计的。

具体问题包括：

1. 冻结的 ImageNet 预训练特征与工业目标域存在域差异。工业图像常有固定背景、重复结构、微小纹理变化和局部形变，而 ImageNet 特征更偏向自然图像语义分类。

2. 现有特征嵌入类方法如 PatchCore、PaDiM、CFLOW-AD 多数直接使用冻结 backbone。它们在公开数据集上表现不错，但面对特定缺陷类型时，可能无法把正常局部和异常局部拉开。

3. 合成异常类方法能构造伪异常训练判别网络，但如果特征提取器仍然主要来自 ImageNet，判别器学到的异常边界不一定能反向改善底层特征。

4. 重建类方法虽然可以联合训练编码器和解码器，但可能重建大面积异常，且训练成本较高。

ToCoAD 要解决的是：在没有真实异常样本的前提下，如何利用正常样本和合成伪异常，使特征提取器更适应工业目标域，并且保持对异常区域的敏感性。

## 4. 创新点深度提炼

第一，论文把“训练异常判别器”和“微调特征提取器”拆成两个阶段。第一阶段不急于改变 backbone，而是先利用冻结预训练特征训练一个异常定位判别网络；第二阶段再让这个判别网络反过来约束 backbone。这个顺序比端到端一起训练更稳，因为判别网络先获得了一个粗异常边界。

第二，提出 negative-guided contrastive learning。它不是纯 SimSiam，因为纯正常样本增强只会学习正常样本内部不变性，缺少异常方向的约束；也不是普通二分类伪异常训练，因为它同时保留了正常样本增强视图之间的表征一致性。其损失由正常增强视图的对称余弦相似损失和伪异常 mask 的 focal loss 共同组成。

第三，论文把“正样本紧凑化”和“负样本边界引导”结合起来。正常样本的不同增强视图被拉近，伪异常通过判别网络提供排斥方向，从而让正常特征空间更紧致，异常特征更容易被最近邻距离识别。

第四，推理阶段没有直接使用判别网络输出作为最终异常图，而是使用微调后的特征提取器构建 memory bank。这说明论文真正想改进的是特征表征，而不是只训练一个 segmentation head。

第五，论文系统比较了异常生成策略、层级特征、损失函数、backbone 类型和两阶段训练的作用，消融较完整。Perlin noise 在该框架下效果最好，说明伪异常的形状和分布多样性对负引导学习很关键。

## 5. 科学问题与研究假设

核心科学问题可以概括为：

在无真实异常样本的工业检测任务中，能否通过合成异常和自监督对比学习，使 ImageNet 预训练特征向目标工业域适配，从而提升异常检测与定位能力？

论文隐含了几条研究假设：

1. 域差异是限制现有工业异常检测方法的重要原因。冻结 backbone 无法充分区分工业正常纹理与异常纹理。

2. 合成异常虽然不等同于真实异常，但可以作为正常分布外边界的近似信号，帮助模型学习“什么不像正常”。

3. 正常样本的增强视图对比学习可以提升目标域内的表征稳定性，使正常特征更紧凑。

4. 若只做正样本对比学习，模型可能缺少异常方向的区分能力；若只做伪异常判别，又可能过拟合合成异常。因此二者需要联合。

5. 微调后的特征提取器比冻结预训练特征更适合 memory bank 最近邻异常检测。

## 6. 科学方法与技术路线

ToCoAD 的技术路线如下：

1. 输入训练集只包含正常工业图像。

2. 第一阶段构造伪异常：
   - 对正常图像做随机小角度旋转和 0/90/180/270 度旋转；
   - 使用 Perlin noise 生成不规则 mask；
   - 从纹理数据集中取纹理图像，与 mask 结合形成异常区域；
   - 将异常区域贴回正常图像，得到合成异常图像和对应伪 mask。

3. 第一阶段训练判别网络：
   - 使用 ImageNet 预训练 WideResNet50 作为特征提取器 F，并冻结；
   - 使用与特征提取器近似对称的上采样判别网络 D；
   - D 输出与输入图像同尺寸的异常预测图；
   - 使用 focal loss 训练，以处理像素级正常/异常严重不均衡。

4. 第二阶段进行负引导对比学习：
   - 固定第一阶段训练好的 D；
   - 对正常图像做随机裁剪、Gaussian blur、水平翻转等增强，形成两个视图；
   - 使用 SimSiam 式 projector 和 predictor 学习正常视图之间的一致表征；
   - 同时用合成异常样本经过 D 得到负引导损失；
   - 总损失为 `L_ncl = λ L_sym + (1 - λ) L_neg`。

5. 推理阶段：
   - 使用微调后的 F 提取多层 patch feature；
   - 聚合浅层纹理和深层语义特征；
   - 使用 coreset subsampling 构建紧凑 memory bank；
   - 测试图像 patch 到 memory bank 最近邻的距离作为异常分数；
   - 图像级分数取 patch 异常分数最大值，像素级分数形成 anomaly map。

## 7. 实验设计与实验步骤

可复核流程如下。

数据：
- MVTec AD：15 类，包含 5 类纹理和 10 类物体，3629 张训练图像、1725 张测试图像。
- VisA：12 个子集，10821 张图像，其中正常 9621 张、异常 1200 张。
- BTAD：3 类工业产品，训练 1799 张、测试 1031 张。

预处理：
- 训练只使用正常图像。
- 合成异常使用 Perlin noise mask、外部纹理图像和正常样本融合。
- 对比学习阶段对正常图像使用随机裁剪、Gaussian blur、随机水平翻转等增强。
- memory bank 阶段使用特征层聚合，并进行 coreset 采样，比例为 0.1。

模型与基线：
- 主干：ImageNet 预训练 WideResNet50。
- 判别网络：inverse WideResNet50 风格，上采样、拼接、压缩维度后输出 mask。
- 对比学习网络：SimSiam 风格 projector 和 predictor。
- 对比方法包括 PatchCore、PaDiM、CFLOW-AD、PyramidFlow、DRAEM、FastFlow、DeSTSeg 等。

训练：
- 第一阶段 DNP：Adam，初始学习率 0.0001，冻结 F，训练 D。
- 第二阶段 NCL：SGD，weight decay 0.0001，momentum 0.9，cosine annealing 调整学习率。
- MVTec AD 和 VisA：第一阶段 100 epoch，第二阶段 100 epoch。
- BTAD：第二阶段训练 150 epoch。

指标：
- image-level AUROC：衡量图像级异常检测。
- pixel-level AUROC：衡量异常区域定位。

消融/敏感性：
- 层级特征选择：对比不同层参与 NCL 的效果，层 3+4 在相关消融中最好。
- 两阶段作用：只用 NCL 效果较差，DNP+NCL 更好。
- 损失函数：focal loss 优于 cross-entropy；`λ=0.5` 达到较好平衡。
- focal loss 参数：`α=0.5, γ=2` 表现最佳。
- 异常生成器：Perlin noise 优于 random patch 和 seamless patch。
- backbone：WideResNet50 最优，WideResNet101 接近但成本更高，ResNet50 略降但更轻量。

结果核查：
- 需同时看平均 AUROC 和类别级 AUROC。论文承认 cable、carpet、grid、pill、screw 等类别图像级结果略低于最优方法。
- 需结合可视化热图判断是否存在背景干扰。论文图中仍出现轻微背景响应。
- 对 VisA 的 Macaroni2 类，论文认为局部区域微调忽略了全局位置关系，导致位置变化可能被误判为异常。

## 8. 关键结果、结论与证据

主要结果：

- MVTec AD：image-level AUROC 99.10%，pixel-level AUROC 98.21%。
- VisA：image-level AUROC 95.35%，pixel-level AUROC 98.43%。
- BTAD：pixel-level AUROC 97.70%。

关键结论：

1. 两阶段训练确实优于只做正常样本对比学习。原因是纯 NCL 缺少明确的负样本边界，而 DNP 提供了伪异常引导。

2. Perlin noise 作为异常生成器效果最好。论文认为它提供了更多样的形状和空间分布，使判别网络学到更有效的粗定位能力。

3. focal loss 对像素级异常定位重要。工业异常 mask 通常只占图像很小区域，普通 CE 容易被正常像素主导。

4. ToCoAD 对结构和纹理异常较敏感，但对微弱颜色变化、全局位置关系异常仍不完美。这一点从 MVTec 某些类别和 VisA Macaroni2 的分析可以看出。

5. 方法的收益主要来自特征提取器适配，而不是单纯换一个检测头。最终仍使用 memory bank 最近邻距离，说明 fine-tuned feature 是核心资产。

## 9. 局限性与待解决问题

1. 训练成本增加。方法需要两个独立训练阶段，第一阶段训练判别网络，第二阶段再微调特征提取器和对比学习网络。

2. 推理仍依赖 memory bank 最近邻匹配。随着存储特征数量增加，推理速度和内存开销会变成问题，尤其不利于实时工业检测。

3. 背景干扰尚未完全消除。论文可视化中仍有轻微背景响应，说明模型并未彻底区分背景变化和真正缺陷。

4. 对全局位置异常不够敏感。论文在 VisA Macaroni2 上承认，局部区域微调可能忽略全局位置关系，导致位置变化被误判。

5. 对微弱颜色异常的敏感性可能下降。对比学习增强会鼓励某些外观变化下的不变性，这有助于泛化，但也可能削弱颜色细节异常检测。

6. 合成异常与真实异常之间仍有分布差距。Perlin noise 更有效，但它仍是人为构造的异常先验，不能覆盖所有真实工业缺陷。

## 10. 与本项目的关系

该论文与“入侵检测与网络异常检测”的相关性偏弱，因为对象是工业图像，不是网络流量、日志、主机行为或协议数据。但它对异常检测研究仍有可迁移启发：

1. 域适配思想有价值。网络安全中也常见预训练模型或通用表征与目标环境之间的域差异，例如不同企业网络、不同时间段流量、不同业务系统。

2. “合成异常 + 正常对比学习”可迁移到安全场景。可以考虑用规则扰动、流量字段扰动、时序片段替换等方式构造伪异常，再用正常样本增强学习稳定表征。

3. 两阶段设计适合无真实攻击样本场景。第一阶段用伪攻击训练粗判别器，第二阶段用该判别器引导 encoder 学到更紧凑的正常行为空间。

4. memory bank 最近邻检测与网络异常检测中的原型库、行为基线库相似。不过网络数据高维、动态、强时序，不能直接照搬图像 patch matching。

5. 需要警惕合成异常偏置。安全领域的攻击分布更复杂，如果伪异常生成过于简单，模型可能只学到伪造模式，而非真实攻击边界。

## 11. 代码对照分析

本地未发现该论文对应的开源代码包，因此无法做真实文件级映射。若复现 ToCoAD，代码通常应拆成以下模块：

- 数据预处理：应包含 MVTec AD、VisA、BTAD 的 dataset loader，以及正常样本读取、图像 resize、augmentation。
- 伪异常生成：应实现 Perlin noise mask、DTD 纹理融合、CutPaste/NSA 类替代生成器，对应论文中的 anomaly generator `G`。
- 模型定义：应包含 WideResNet50 feature extractor `F`、inverse WideResNet50 判别网络 `D`、SimSiam projector/predictor 对比学习网络 `C`。
- 第一阶段训练：应冻结 `F`，训练 `D`，损失为 focal loss。
- 第二阶段训练：应固定 `D`，联合训练 `F` 和 `C`，损失为 `λ L_sym + (1 - λ) L_neg`。
- memory bank：应实现多层特征抽取、layer 2/3 聚合、coreset subsampling。
- 推理与评估：应实现 patch 最近邻距离、anomaly map 上采样、image-level/pixel-level AUROC 计算。
- 配置文件：应包含数据集路径、backbone、异常生成器类型、训练 epoch、`λ`、focal loss 参数、coreset 比例等。

需要注意，论文中有两个层级使用点：NCL 消融中层 3+4 表现最好，而最终 memory bank 描述中聚合 layer 2 和 layer 3。复现时应分别核查“训练对比学习使用的层”和“推理 memory bank 使用的层”，不要混为一处。

## 12. 本篇精华

1. ToCoAD 的核心不是提出新的最近邻异常分数，而是让 ImageNet 预训练特征通过目标域无监督训练变得更适合工业缺陷检测。

2. 两阶段顺序很关键：先用合成异常训练判别网络获得粗异常边界，再用该判别网络反向引导特征提取器微调。

3. 正常样本对比学习解决“正常域内表征稳定性”，合成异常判别解决“异常方向边界”，二者互补。

4. Perlin noise 在该框架下优于 CutPaste/random seamless patch，说明伪异常的形状和分布多样性会直接影响负引导质量。

5. focal loss 是合理选择，因为像素级异常检测天然存在正常像素远多于异常像素的问题。

6. 方法在 MVTec AD、VisA、BTAD 上达到竞争性结果，但仍存在训练两阶段、推理 memory bank 慢、背景响应和全局位置异常不敏感等问题。

7. 对网络安全异常检测的启发是：可用伪异常构造负边界，用正常增强对比学习压缩正常行为空间，但必须谨慎设计伪异常生成机制。
