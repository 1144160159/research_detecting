# [432] Fed-RWM: A Robust Watermarking Approach for Federated Learning Model Ownership Protection

## 1. 基本信息

- 论文题名：Fed-RWM: A Robust Watermarking Approach for Federated Learning Model Ownership Protection
- 中文题名：Fed-RWM：一种用于联邦学习模型所有权保护的鲁棒水印方法
- 年份：2025
- 来源：IEEE Transactions on Network and Service Management, Vol. 22, No. 6
- DOI：10.1109/TNSM.2025.3596692
- 作者：Xin Tong, Shike Li, Ni Jin, Baojiang Cui
- 主题归类：联邦学习、模型水印、模型所有权验证、IoT/工业物联网安全
- 与异常检测方向关系：中相关。论文没有直接提出新的异常检测算法，但使用 WUSTL-IIOT-2021 工业物联网入侵检测数据集验证方法，关注联邦学习场景下安全模型的知识产权保护。

## 2. 中文翻译与核心摘要

这篇论文研究的是：在联邦学习中，虽然原始数据不离开边缘设备，但训练得到的全局模型或本地模型仍可能被云服务器、客户端或第三方非法复制、售卖和部署。Fed-RWM 的目标是给联邦学习模型嵌入一种鲁棒白盒水印，使模型被泄露后仍能证明所有权。

论文的核心做法是构造一个秘密网络 SNet，将 SNet 的一部分参数作为水印嵌入联邦学习模型，将另一部分参数作为验证密钥保存在任务发起者处。验证时，从可疑模型中按秘密位置提取参数，与密钥重新组成 SNet，并观察它在秘密数据集上的分类准确率 AS。如果 AS 超过阈值，则判定模型含有水印。

它的关键增强在于：水印信息只由联邦学习任务发起者掌握，服务器和客户端都无法知道水印位置和密钥；同时设计了水印恢复机制，用于抵抗参数缩放攻击和混合攻击。

## 3. 论文解决的具体问题

论文瞄准的是联邦学习模型泄露后的所有权证明问题，而不是训练过程中的数据隐私泄露问题。

传统联邦学习保护的是“数据不出本地”，但训练后的模型本身可能成为有价值资产。云服务器可能复制聚合后的全局模型，客户端可能复制本地模型或全局模型，第三方也可能部署被窃模型牟利。对于工业物联网、车联网、医疗、制造等协同训练场景，模型通常由多方数据和算力共同产生，一旦泄露，会带来知识产权和商业利益损失。

已有联邦学习水印方法主要有两类：

- 客户端侧嵌入：假设客户端可信，但论文认为现实中客户端也可能作恶。
- 服务器侧嵌入：假设服务器可信，但安全联邦学习中服务器常被视为半诚实甚至不可信。

因此，Fed-RWM 要解决的具体问题是：在服务器和客户端都可能不可信的联邦学习系统中，如何让可信任务发起者嵌入并验证模型水印，同时抵抗剪枝、微调、参数缩放、混合攻击和覆盖攻击。

## 4. 创新点深度提炼

第一，论文把水印训练权从服务器或客户端转移到任务发起者。  
这是 Fed-RWM 的系统层创新。服务器只做加密聚合，客户端只做本地训练，水印生成、位置选择、密钥更新和所有权验证全部由 initiator 完成。这样避免了服务器侧水印方案和客户端侧水印方案各自的信任假设漏洞。

第二，水印不是普通比特串，而是秘密网络 SNet 的一部分参数。  
Fed-RWM 将 SNet 参数拆成两部分：`wm` 作为嵌入到联邦模型中的水印，`wk` 作为本地保存的水印密钥。验证时两者重新拼接成完整 SNet，通过秘密测试集上的性能来判断所有权。这比单纯比较比特串或特定层参数更像“功能型白盒水印”。

第三，提出持续水印训练机制。  
第一轮嵌入水印，后续每轮从全局模型中提取当前水印参数，并冻结水印部分，只更新密钥部分，使 SNet 继续适配联邦训练过程中不断漂移的水印参数。这是为了缓解论文所说的 federated forgetting，即联邦训练会改变嵌入参数，使早期水印与密钥逐渐不匹配。

第四，设计了面向参数缩放和混合攻击的水印恢复。  
参数缩放攻击会放大某层、缩小下一层，使模型功能基本不变，但破坏参数水印。Fed-RWM 使用 SVD、迹比值、方向相似性估计每层缩放因子，再对可疑模型做恢复，然后重新验证水印。这是论文鲁棒性主张中最有辨识度的部分。

第五，水印嵌入位置跨层随机采样，不依赖 BN 层。  
FedTracker、FedIPR、FedMCT 等方法常依赖 BN 层或特定结构。Fed-RWM 随机选择除 softmax 层外的全模型参数位置，因此可以用于 CNN、RNN，以及没有 BN 层的小模型。

## 5. 科学问题与研究假设

核心科学问题可以概括为：

- 在不信任服务器和客户端的联邦学习系统中，能否设计一种只有任务发起者知道秘密的白盒模型水印？
- 该水印能否在不显著损害主任务性能的情况下嵌入全局模型和本地模型？
- 当攻击者知道模型结构和参数，并使用微调、剪枝、参数缩放、混合攻击或覆盖攻击时，水印验证是否仍然可靠？
- 一个秘密网络的“参数共享式水印”是否比传统比特串水印更适合复杂模型所有权验证？

论文隐含的主要假设包括：

- 任务发起者可信，并能安全保存水印位置、密钥和秘密数据集。
- 攻击者可获得模型结构和参数，但无法获得水印位置 `sp`、水印密钥 `wk` 和秘密数据集。
- 攻击者希望移除水印，同时保持主任务性能，因此不会完全重训或大幅破坏模型。
- 同态加密联邦学习框架可用于阻止服务器直接查看明文模型参数，但任务发起者仍能在每轮中执行水印嵌入或密钥更新。

## 6. 科学方法与技术路线

Fed-RWM 的技术路线可以分为五步。

1. 初始化联邦学习  
   发起者初始化待保护模型，并将加密后的初始全局模型上传至服务器。服务器选择部分客户端参与训练，客户端本地训练后上传加密模型。

2. 构造秘密网络 SNet  
   SNet 由四个卷积层和一个全连接层组成。前两层参数作为水印 `wm`，后续层参数作为密钥 `wk`。SNet 在秘密数据集 `Ds` 上预训练。

3. 随机生成嵌入位置  
   在待保护模型除 softmax 层外的参数空间中随机采样与 `wm` 等长的位置集合，并转换为各层 mask。这样水印分散嵌入多个层中。

4. 第一轮嵌入，后续轮更新密钥  
   第一轮将 `wm` 按秘密位置写入全局模型参数。之后每轮从当前全局模型提取水印参数，与上一轮密钥合并为 SNet，并冻结水印参数，仅训练密钥参数，使 SNet 重新适配当前水印状态。

5. 所有权验证与水印恢复  
   对可疑模型，先按秘密位置提取参数，与密钥组成 SNet，在秘密测试集上计算 AS。若 AS 低于阈值，再尝试恢复参数缩放或混合攻击导致的水印畸变，然后重新验证。

## 7. 实验设计与实验步骤

可复核流程如下。

1. 数据  
   主任务数据集包括 CIFAR-10、IMDB、WUSTL-IIOT-2021。MNIST 作为秘密数据集 `Ds` 和秘密测试集 `Dst`。WUSTL-IIOT-2021 用于模拟工业物联网入侵检测任务，包含 DoS、数据外泄、侦察等攻击类型。

2. 预处理与划分  
   CIFAR-10、IMDB、IIOT2021 按 8:2 划分训练集和测试集。训练集再按 IID 和 non-IID 两种方式分配给联邦客户端。MNIST 划分为秘密训练集和秘密验证集，用于训练和验证 SNet。

3. 模型与基线  
   主任务模型包括 ResNet18、DenseNet121、LSTM、CNN。ResNet18 和 DenseNet121 用于 CIFAR-10，LSTM 用于 IMDB，CNN 用于 IIOT2021。基线为无水印 FedAvg。对比方法包括 FedIPR、FedTracker、FedMCT、VPFL 等已有联邦水印方法。

4. 训练流程  
   先用 Fed-RWM 训练含水印联邦模型：第一轮嵌入水印，之后每轮联邦聚合后由发起者提取当前水印并更新密钥。同步训练过程中服务器执行加密聚合，客户端执行本地训练。

5. 指标  
   主任务性能使用分类准确率 Acc。水印验证性能使用 AS，即重构 SNet 在秘密测试集上的准确率。阈值设置为 `β = 0.6`，AS 高于阈值则判定为侵权模型。

6. 消融与敏感性  
   论文重点比较了不同场景下的水印有效性：主任务数据与秘密数据不同、主任务数据与秘密数据相同、使用错误嵌入位置。还测试 IID 与 non-IID、全局模型与本地模型、不同模型架构、不同攻击顺序。

7. 攻击与结果核查  
   攻击包括微调、剪枝、参数缩放、混合攻击和覆盖攻击。对参数缩放和混合攻击，先观察 AS 是否下降，再执行水印恢复，核查恢复后 AS 是否重新超过阈值，同时确认主任务 Acc 未严重下降。

## 8. 关键结果、结论与证据

有效性方面，受保护模型的 AS 通常超过 95%，未保护模型多数低于 20%。当使用错误水印位置时，AS 约在 10% 左右，无法通过阈值。这说明所有权验证依赖正确位置和密钥，攻击者较难伪造。

保真性方面，Fed-RWM 对主任务准确率影响低于 1%。例如水印模型和无水印模型在 CIFAR-10、IMDB、IIOT2021 上的差距很小。论文将原因归结为水印参数占比很低，并且只在第一轮直接嵌入，后续主要更新密钥。

鲁棒性方面，微调和剪枝对 AS 影响很小。剪枝率达到 70% 时，主任务性能已明显下降，但 AS 仍保持在 90% 以上。参数缩放会显著破坏直接验证，但经过恢复后，AS 可恢复到约 95% 以上。混合攻击中，恢复后的 AS 仍可维持在约 95% 到 98% 区间。

覆盖攻击方面，由于水印参数占模型总参数比例很低，例如 ResNet18 约 0.0850%、DenseNet121 约 0.0535%、LSTM 约 0.2254%、CNN 约 0.7417%，攻击者用同类方式重新嵌入水印时，覆盖原始水印的概率较低。

本地模型保护方面，论文观察到本地模型也能保留水印验证能力，因为本地训练本质上相当于在带水印全局模型上继续微调。

## 9. 局限性与待解决问题

第一，可信任务发起者是假设核心。Fed-RWM 避免了服务器和客户端获取水印秘密，但没有深入讨论发起者被攻陷、密钥泄露或秘密数据泄露后的补救机制。

第二，白盒验证要求访问可疑模型参数。若被盗模型仅提供 API 服务，Fed-RWM 的验证路径不如黑盒水印直接。

第三，水印恢复机制主要针对参数缩放及其混合攻击，依赖对原始水印模型与可疑模型逐层计算缩放关系。若攻击者采用结构变换、蒸馏、模型压缩、重参数化、量化或跨架构迁移，论文没有充分验证。

第四，实验规模仍偏基准化。虽然覆盖图像、文本和 IIoT 流量，但联邦客户端数量、异构设备约束、真实工业网络部署、长周期在线更新等方面仍需更贴近实际。

第五，安全联邦学习部分更多是框架适配说明，而不是完整系统实现评估。同态加密带来的计算和通信开销、密钥管理、发起者参与协议的安全边界，还需要更完整的系统实验。

## 10. 与本项目的关系

如果本项目关注异常检测、工业互联网或边缘安全，Fed-RWM 的价值不在于提升检测准确率，而在于保护“联邦训练出的检测模型”。

在工业物联网入侵检测中，不同工厂、边缘节点或组织可能联合训练 IDS 模型。模型一旦泄露，攻击者或竞争方可以直接复用检测能力。Fed-RWM 提供了一种模型归属证明机制，适合作为联邦异常检测系统的知识产权保护模块。

对综述写作而言，这篇论文可放在“联邦异常检测的安全与可信机制”部分，与隐私保护、投毒防御、鲁棒聚合、模型溯源并列讨论。它补足的是模型训练完成后的资产保护问题。

## 12. 本篇精华

- Fed-RWM 的核心贡献是把联邦模型水印从服务器/客户端侧移到可信任务发起者侧，直接回应“云和边都可能不诚实”的威胁模型。
- 它不是嵌入传统比特串，而是把秘密网络 SNet 的部分参数嵌入主模型，剩余参数作为密钥，用秘密数据集上的准确率完成所有权验证。
- 论文最有价值的技术点是持续水印训练：每轮从全局模型中提取当前水印，只更新密钥，使水印在联邦训练漂移中保持可验证。
- 参数缩放攻击是传统白盒参数水印的薄弱点，Fed-RWM 通过 SVD 估计层级缩放因子并恢复水印，是其鲁棒性实验的中心。
- 实验覆盖图像、文本和工业物联网流量，说明该方法不局限于 CNN 或 BN 层模型。
- 对异常检测研究而言，Fed-RWM 可作为联邦 IDS 模型的知识产权保护机制，而不是检测算法本身。
- 主要短板是依赖白盒访问和可信发起者，尚未充分覆盖蒸馏、量化、结构迁移等更强模型洗白攻击。

接着精读 Ownership Verification，尤其是水印恢复部分。这里是论文区别于普通联邦水印工作的关键，包括剪枝预处理、二维矩阵映射、SVD、缩放方向判断和恢复后验证。

最后读实验部分时，不要只看准确率表格。建议按“有效性、保真性、鲁棒性、本地模型保护、与已有方法比较、开销”六条线整理证据，重点核查参数缩放和混合攻击实验，因为这是 Fed-RWM 最核心的防御主张。
