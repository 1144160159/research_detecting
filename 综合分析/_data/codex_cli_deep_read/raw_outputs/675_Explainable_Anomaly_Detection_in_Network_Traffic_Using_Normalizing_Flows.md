# [675] Explainable Anomaly Detection in Network Traffic Using Normalizing Flows

## 2. 中文翻译与核心摘要

这篇论文的核心主张是：**只用正常网络流量训练 Normalizing Flow，用其精确似然估计能力给每条流打分；似然低的流量被视为异常；再把 Shapley 值作用在 NF 的概率输出上，用于特征选择和异常解释。**

它与很多生成式异常检测工作的差异在于，作者并不使用 GAN、VAE 或 NF 去“生成伪异常样本”，也不再训练一个监督分类器，而是直接把 NF 当作正常流量分布的显式密度模型。训练阶段只看正常流量，检测阶段计算新样本的 `log p(x)`，低于阈值即异常。

论文还强调可解释性：Shapley 值不是简单解释一个黑盒分类器的标签输出，而是解释某个特征如何改变 NF 对样本属于“正常分布”的似然判断。因此，作者认为 NF + Shapley 更接近“这个流量为什么在统计上不像正常流量”的解释。

## 3. 论文解决的具体问题

论文针对的是网络异常检测中几个非常现实的问题：

- 异常样本难以收集，攻击样本稀缺、变化快，监督学习依赖大量标注攻击流量并不现实。
- 类别极不均衡，尤其在真实网络中异常占比很低，监督模型容易被多数类牵引。
- 生成伪异常样本的方法存在真实性风险，合成异常未必覆盖真实攻击分布，且性能可能依赖正常/异常比例。
- 传统异常检测方法通常只给出异常分数，难以回答“哪些流量特征导致异常”。
- 无监督特征选择困难，加入冗余或伪相关特征会扰乱正常分布建模。

因此，本文的目标不是做一个普通二分类 IDS，而是构造一个**正常流量密度建模 + 低似然检测 + 可解释根因定位**的流程。

## 4. 创新点深度提炼

第一，论文把 NF 的优势放在“精确密度估计”而非“生成能力”上。它不生成伪攻击，不训练后续监督分类器，而是直接用正常流量的 log-likelihood 作为异常分数。

第二，作者提出了 Shapley 驱动的 wrapper 特征选择思路。特别重要的是，他们发现直接把已有强特征放进基础特征集，会让待测特征的 Shapley 值不可比；于是引入随机噪声 dummy feature 作为“中性基线”，逐个测试真实特征的边际贡献。

第三，论文区分了两种特征选择场景：Few-Shots 场景使用少量标注异常样本；Transductive 场景使用正常和异常混合但无标签的样本，通过平均绝对 Shapley 值寻找能拉开分布的特征。

第四，解释性部分不是停留在“画 SHAP 图”，而是用模拟样本和 CICIoT-2023 中构造的单特征偏离攻击样本验证：NF 的 Shapley 值更容易指向真正偏离正常分布的特征，而 XGBoost 可能只解释分类器学到的捷径。

第五，实验覆盖三类场景：IoT 大规模攻击 CICIoT-2023、IDS/DDoS 场景 CICIDS2017、加密流量 Tor/Non-Tor 场景 ISCXTor2016，说明方法不只针对单一数据集。

## 5. 科学问题与研究假设

核心科学问题可以概括为：

- 正常网络流量是否可以被 NF 学成一个足够有判别力的显式概率分布？
- 攻击流量、Tor 流量或其他异常流量是否会在该正常分布下表现为低似然样本？
- 在没有大量异常标签的情况下，能否通过 NF 的 log-likelihood 和 Shapley 值选择出判别性强的流量特征？
- NF 的概率输出是否能让 Shapley 解释更接近统计偏离原因，而不是仅解释黑盒分类器的决策边界？

对应假设是：正常流量在聚合流特征空间中存在可学习的稳定分布；异常流量相对该分布具有低似然；特征对 log-likelihood 的边际影响可以反映异常根因。

## 6. 科学方法与技术路线

论文把每条网络流表示为 `D` 维特征向量，特征来自流级头部统计，例如持续时间、包长统计、IAT、TCP flag count、窗口大小、上下行方向统计等。作者主动移除端口、IP 地址、绝对时间戳等可能带数据集环境痕迹的字段。

训练阶段只使用 `y=0` 的正常样本。NF 学习从简单基分布到复杂正常流量分布的可逆映射，并最大化正常样本 log-likelihood；等价地，最小化 negative log-likelihood。

检测阶段计算新流量的 `log pX(x)`。若 log-likelihood 高于阈值，则判为正常；若低于阈值，则判为异常。阈值在有验证集时通过 `TPR - FPR` 最大化选择；AUROC 评估则不依赖固定阈值。

可解释性路线是：把 NF 的 log-likelihood 输出作为待解释函数，对单个样本计算各特征 Shapley 值。负向贡献表示该特征降低正常似然，更可能是异常来源。

## 7. 实验设计与实验步骤

可复核流程如下：

1. 数据：使用 CICIoT-2023、ISCXTor2016、CICIDS2017；交叉泛化实验还引入 CICDDoS2019。
2. 预处理：保留流级统计特征；去掉 IP、端口、绝对时间戳；按训练正常样本拟合 z-score 标准化，再用于验证和测试。
3. 数据划分：将正常流量和异常流量分别汇总、打乱；训练集只取正常样本。论文描述中常用 10,000 正常样本训练，测试包含 10,000 正常和 10,000 异常；阈值指标另用独立验证集，含 1,000 正常和 1,000 异常。
4. 模型：使用 PZFlow 训练 NF，100 epochs，batch size 1024。
5. 检测：每个测试样本输出 log-likelihood，低似然为异常。
6. 基线：ISCXTor2016 对比 Dang et al. 汇总的多类 anomaly detection 方法和 Kitsune；CICIDS2017 对比 OCSVM、AE、MemAE、SparseMemAE、Kitsune；CICIoT-2023 对比监督方法 Adaboost、RF、DNN、LR，并自行训练 XGBoost。
7. 指标：重复 5 个随机种子，报告 mean AUROC；CICIoT-2023 还报告 Accuracy、Precision、Recall、F1。
8. 消融与敏感性：比较 Few-Shots 样本数 `k ∈ {10,20,50,100,200}`；比较 SHAP 与 LIME；比较随机噪声基线和强判别特征基线；做跨数据集泛化测试。
9. 结果核查：看 ROC/AUROC、直方图中正常/异常似然分布分离程度、特征组合 AUROC、Shapley 是否指向真实偏离特征。

## 8. 关键结果、结论与证据

CICIoT-2023 上，论文报告 NF 在只用正常流量训练的情况下达到 `0.9951` accuracy，接近或超过若干监督方法。这个结果是全文最强的论证点：正常分布建模在大规模 IoT 攻击数据上可以非常有效。

ISCXTor2016 上，论文报告 AUROC 为 `0.8731`，高于对比的异常检测方法。若使用与 Tor 类高度相关的 `Protocol Type`，AUROC 可达 `0.932`，但作者认为这有偏置风险，因此主结果排除了该特征。单个 NF 分类器最佳约 `0.851`，特征为 `Bwd IAT Std` 和 `Active Mean/Max` 一类时间活跃性特征；集成模型进一步提升效果。

CICIDS2017 上，针对 Wednesday DoS/DDoS 相关攻击子集，NF 达到约 `0.93` AUROC，优于 OCSVM、普通 AE、MemAE、SparseMemAE、Kitsune 等对比方法。最佳五个特征包括 `Bwd Packet Length Mean`、`Fwd Packets/s`、`ACK Flag Count`、`Total Length of Bwd Packets`、`Flow Duration`。

特征选择实验的关键结论是：用随机噪声作为基线时，少量样本上的 Shapley 分布统计量与完整测试集 AUROC 有显著相关；用强判别特征作基线时，特征交互会遮蔽待测特征贡献。

解释性实验显示：在二维模拟中，NF 的 Shapley 值能区分样本到底偏离 `F1` 还是 `F2`；OCSVM 和 XGBoost 的解释更容易受边界或监督捷径影响。在 CICIoT-2023 的单特征偏离攻击样本中，NF 更能指向 `Variance` 或 `fin count` 这类真实低似然特征。

## 9. 局限性与待解决问题

本文训练阶段是正常样本无监督，但阈值选择和 Few-Shots 特征选择仍可能使用少量异常样本；所以应区分“模型训练无需异常标签”和“完整部署流程完全无标签”这两件事。

测试集被下采样成较均衡的正常/异常比例，这有利于和已有工作比较，但真实网络中异常基率通常远低于 50%，实际误报率的运营影响需要单独验证。

NF 的似然异常检测在其他领域存在 typicality 问题，即 OOD 样本不一定总是低似然。论文在网络流特征上给出了强实验证据，但没有系统讨论该理论风险。

跨数据集实验显示性能会下降，说明正常流量分布具有环境依赖性。真实部署中，设备类型、采集点、业务时间段变化都会造成正常分布漂移。

Shapley wrapper 特征选择需要反复训练 NF，计算成本较高；Transductive 方法只在较小特征集合上展示，距离大规模自动特征筛选还有距离。

解释性验证主要依赖模拟和构造出的单特征偏离攻击子集，已经有说服力，但还不足以证明能稳定完成真实安全事件根因分析。

## 10. 与本项目的关系

这篇论文与“入侵检测与网络异常检测”强相关，尤其适合作为**一类学习 / 密度估计式 NIDS**的代表工作来引用。它不是传统监督 IDS，也不是 AE 重构误差路线，而是“正常流量显式概率建模”。

对本项目有三点直接价值：一是提供正常样本训练的技术路线；二是给出可解释异常检测的设计范式；三是覆盖加密流量 Tor/Non-Tor，可连接到“加密流量分类与应用识别”方向。

如果本项目关心跨域异常检测，这篇论文的跨数据集消融也很有参考意义：NF 能泛化一部分正常/攻击差异，但仍受分布漂移影响，后续可结合自监督预训练、域自适应或在线校准。

## 12. 本篇精华

- NF 在本文中不是用来生成攻击样本，而是用来学习正常流量的精确概率密度。
- 异常分数就是正常分布下的 log-likelihood，训练阶段完全不需要攻击样本。
- Shapley 值解释的是特征如何改变“正常似然”，因此比解释普通分类器标签更接近统计偏离原因。
- 随机噪声 dummy feature 是特征选择实验里的关键技巧，用于减少特征交互造成的 Shapley 不可比。
- Few-Shots 特征选择只需少量异常样本即可发现判别特征，但这也意味着完整流程不是绝对零标签。
- CICIoT-2023 上 `0.9951` accuracy 是本文最醒目的结果，说明正常建模可与监督 IDS 竞争。
- 最大开放问题是跨环境泛化、真实低基率误报控制，以及解释结果能否支撑实际安全响应。
