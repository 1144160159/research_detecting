# [242] Hierarchical-Instance Contrastive Learning for Minority Detection on Imbalanced Medical Datasets

## 2. 中文翻译与核心摘要
这篇论文的核心思想是：不要试图用极少、分布又复杂的恶性/罕见少数类样本去训练分类边界，而是只用多数类样本学习“多数类应该长什么样”，推理时把偏离多数类分布的样本判为少数类。

作者提出 HCLe，即层级实例对比学习方法。它由两个共享编码器的分支组成：一个是带 SSIM、GMS 和对抗损失约束的重建分支，用来保留图像级结构与纹理信息；另一个是层级实例对比学习分支，用多数类内部不同子类、患者或实例之间的样本作为对比输入，迫使多数类的表示更加一致。最终通过原图与重建图之间的 GMS 差异得到检测图和检测分数。

论文试图解决的不是一般长尾分类，而是医学中更棘手的一类场景：少数类往往是临床真正关心的恶性或罕见病，但样本少、形态多、标签不足，甚至某些机构完全没见过。因此作者把少数类检测转化成 majority-only 的分布学习问题。

## 3. 论文解决的具体问题
论文针对的是医学图像不平衡数据中的少数类检测，尤其是恶性或罕见疾病检测。传统重采样、重加权、Focal Loss 等方法仍依赖少数类样本参与监督训练，但医学少数类常常同时具有两个问题：数量极少，且内部形态差异大。

更具体地说，作者认为难点有三层：

第一，少数类样本对训练贡献有限。即使过采样，也只是重复已有少数病例，不能真正增加恶性病变的形态知识。

第二，少数类分布多样。比如黑色素瘤在形状、颜色、位置上差异很大，少量标签不足以学到稳定边界。

第三，多数类本身也不干净、不单一。医学中的“良性”或“非恶性”常包含多个子类，例如 ISIC 中 benign 内部有 nevus、solar lentigo、unknown 等。多数类内部差异过大时，普通一类重建模型会把多数类学得松散，异常检测边界也会变差。

## 4. 创新点深度提炼
最重要的创新是把不平衡分类转为只用多数类训练的 minority detection。它避开了少数类稀缺和高异质性带来的监督学习困难，思想上更接近医学异常检测，但任务目标仍是少数类分类。

第二个创新是双分支共享编码器。重建分支负责学习图像级可重建结构，对比学习分支负责压缩多数类内部表示差异。两者共享 encoder，使编码空间同时服务于“能重建多数类”和“多数类内部表示一致”这两个目标。

第三个创新是层级实例对比，而不是常规数据增强对比。普通 SimCLR/BYOL 式方法用同一图像的不同增强视图作为正样本；HCLe 用多数类内部不同实例，尤其是不同子类样本，构成对比关系。这更贴近医学数据：同属 benign 的不同病种虽然外观不同，但在本任务中应被压到同一多数类表征区域。

第四个创新是 diverse mini-batch 策略。若多数类有子类信息，每个 contrast mini-batch 尽量覆盖所有多数子类，并按训练集近似比例采样。这样每次优化都在拉近多数类多个子类之间的距离，缓解多数类内部不一致。

## 5. 科学问题与研究假设
科学问题可以概括为：在少数类样本稀缺甚至不可用、多数类内部又高度异质的医学图像场景中，能否仅依赖多数类训练出足够稳健的表示，从而检测恶性或罕见少数类？

论文隐含了几个关键假设：

1. 少数类相对多数类是分布外样本，至少在图像结构、纹理、边缘或局部梯度上存在可检测差异。
2. 多数类虽包含多个子类，但它们在任务语义上应被视为同一“正常/非恶性”集合。
3. 拉近多数类内部不同层级实例的表示，可以让模型形成更紧凑的多数类特征空间。
4. 重建误差，尤其是基于 GMS 的结构差异，能够反映少数类病变区域与多数类分布的偏离。
5. 多数类子类信息虽然不用于最终分类，但可用于设计更有效的对比采样。

## 6. 科学方法与技术路线
HCLe 的训练只使用多数类样本。输入图像先经过共享编码器 E 得到 embedding。

重建分支中，embedding 进入生成器 G，重建原图。作者不用单纯 L2，而是组合 SSIM、GMS 和 PatchGAN 对抗损失。SSIM 更关注亮度、对比度和结构；GMS 更关注局部梯度结构差异；对抗损失约束重建图更接近真实多数类图像分布。

层级实例对比学习分支中，raw network 处理输入 x，contrast network 处理另一个多数类层级实例 x′。二者通过 encoder 和 projector 得到归一化向量后，最小化双向均方距离。contrast network 类似 BYOL 思路，带 stop-gradient 和动量更新，使 raw network 向稳定目标回归。

推理时，只用 encoder + generator 得到重建图，然后计算 `1 - GMS(x, x_hat)` 作为异常图，并汇总成 detection score。分数越高，越可能是少数类恶性/罕见样本。

## 7. 实验设计与实验步骤
数据：ISIC 2020 用于黑色素瘤检测，训练设置包含 300:300、300:1000、300:2000、300:3000 等恶性:良性比例，测试集良恶性各 190 且患者不重叠；BRACS 使用 UDH、FEA、ADH 作为非恶性多数类，DCIS 作为恶性少数类；REFUGE 使用 360 个非青光眼样本训练，检测青光眼少数类。

预处理：所有输入图像调整到 224×224。论文未展开复杂预处理细节，重点在模型训练策略和损失设计。

模型/基线：监督不平衡方法包括重采样、Focal Loss、SEDC，骨干包括 ResNet-50、ResNet-101、VGG16、DenseNet169；异常检测基线包括 VAE-GAN、f-AnoGAN、RIAD。HCLe 和异常检测基线都只用多数类训练。

训练：PyTorch 实现，训练 800 epoch，Adam 优化器；前 200 epoch 学习率 0.001，之后降到 0.0002；batch size 为 48；ISIC 和 BRACS 的损失权重为 SSIM:GMS:adv:class = 0.5:1:1:0.5，REFUGE 为 1:1:1:0.5。

指标：AUC、Balanced Accuracy、F1-score。BACC 用于缓解类别不平衡下 accuracy 的误导性。

消融/敏感性：包括共享编码器是否有效、只用重建分支/只用对比分支/双分支不共享/双分支共享的比较；对比策略比较 augmentation、random HCLe、diverse HCLe；重建约束比较不同损失组合；ISIC 上额外考察不同不平衡比例。

结果核查：论文还做了 paired t-test，声称 HCLe 相比基线和替代策略的提升具有统计显著性；同时展示像素级异常图，说明模型能定位部分恶性区域，但也出现标记区域和边缘亮度变化被误判为异常的情况。

## 8. 关键结果、结论与证据
在 ISIC 2020 极不平衡设置下，HCLe 在 BACC、AUC、F1-score 上均优于监督不平衡方法和异常检测方法。论文报告其相对第二名分别提升约 6.64%、5.66%、6.95%，说明在多数类内部复杂、少数类恶性样本稀缺时，majority-only 策略有优势。

在 BRACS 上，HCLe 得到 76.57% BACC、82.63% AUC、77.16% F1-score，尤其在 BACC 和 F1 上超过第二名约 4 个百分点以上。这说明方法不只适用于皮肤照片，也能迁移到病理 ROI。

在 REFUGE 上，HCLe 达到 87.36% BACC、96.26% AUC、74.76% F1-score，并在 AUC 和 F1 上排名最高。这里多数类没有丰富子类，random 与 diverse 策略结果一致，也侧面说明 diverse mini-batch 的收益依赖多数类层级结构。

消融结果支持作者的设计逻辑：单独重建分支或单独对比分支性能有限，双分支共享编码器明显更好；层级实例对比优于普通数据增强对比；多约束重建优于单一约束。

## 9. 局限性与待解决问题
论文最核心的局限是“少数类等于多数类分布外”这一假设并不总成立。如果恶性或罕见病灶与良性组织在影像特征上高度相似，重建差异和特征距离可能不足以区分。

第二，diverse mini-batch 依赖多数类子类信息。论文说训练不需要少数类，但在多数类内部有层级标签或子类划分时，方法才能充分发挥。如果真实临床数据只有粗粒度 benign 标签，如何构造可靠层级实例仍是问题。

第三，异常图存在误报。论文可视化中提到临床标记区域、边缘亮度变化可能被当作异常，说明模型仍可能捕捉非病灶伪差。

第四，方法主要做 image-level minority detection，虽然能生成异常图，但并未以强标注分割任务系统验证病灶定位质量。

第五，本次正文包未截断，理解基于提供的完整正文文本；但若用于正式复现实验，仍建议回到 PDF 复核表格中的精确数值、图示细节和实现超参。

## 10. 与本项目的关系
这篇论文与“异常检测”项目有弱到中等关联。它不是网络安全异常检测论文，也不是典型视频/多媒体异常检测方法，但它提供了一个有价值的跨域思路：当异常类稀缺、异质、标注不可靠时，可以只学习正常/多数类，并通过表示一致性约束提高一类边界质量。

对网络安全异常检测的启发在于：正常流量或多数行为往往也不是单峰分布，而包含业务类型、用户群、时间段、协议族等层级子群。HCLe 的 diverse mini-batch 思想可以迁移为：在正常类内部按服务、主机、协议、时间窗口等层级采样，拉近正常子群的语义表示，同时保留重建或预测误差用于异常评分。

但也要谨慎：医学图像的 GMS/SSIM 重建差异不能直接迁移到网络流量。若用于安全数据，需要把“图像重建约束”替换为序列重建、图结构重建、时序预测误差或表征距离等更合适的信号。

## 11. 代码对照分析

若按论文方法复现，代码结构大概率应包含以下模块：

- 数据预处理：读取 ISIC、BRACS、REFUGE，筛选多数类训练样本，构造 224×224 输入，按多数类子类生成 diverse mini-batch sampler。
- 模型定义：共享 encoder、generator/decoder、PatchGAN discriminator、projection MLP、raw/contrast 两套对比网络参数。
- 损失函数：SSIM loss、GMS loss、adversarial loss、hierarchical-instance contrastive loss，以及总损失权重组合。
- 训练脚本：800 epoch、Adam、学习率分段下降、contrast network 的 stop-gradient 与动量更新。
- 推理评估：用 GMS map 生成异常图和检测分数，计算 AUC、BACC、F1，并做不同阈值评估。
- 消融脚本：单分支、共享/不共享 encoder、augmentation/random/diverse 对比策略、多损失组合、不同比例训练集。

运行线索上，最关键的不是模型骨干，而是 sampler：如果 diverse mini-batch 没有正确保证多数类子类覆盖，论文中的主要增益很可能复现不出来。

## 12. 本篇精华
1. HCLe 把医学不平衡分类改写为 majority-only minority detection，避免依赖稀缺且异质的少数类训练。
2. 论文真正处理的难点不只是少数类少，而是多数类也有高内部差异。
3. 双分支共享 encoder 是核心：重建分支学图像级结构，对比分支学多数类内部一致性。
4. 层级实例对比优于普通数据增强对比，因为正样本来自多数类内部不同实例/子类，而非同一图像扰动。
5. diverse mini-batch 是实践亮点：每个 batch 覆盖多数类多个子类，持续压缩多数类内部距离。
6. 异常评分使用 GMS 重建差异，适合医学图像结构变化，但跨到网络安全需换成领域合适的误差信号。
7. 方法成立依赖一个强假设：恶性/罕见少数类必须与多数类存在可学习的分布差异。
8. 论文的消融比较比较完整，能支撑“共享编码器 + 层级实例对比 + 多约束重建”三者缺一不可的结论。
