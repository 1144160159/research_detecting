# [779] RDSAD: Robust Threat Detection in Evolving Data Streams via Adaptive Latent Dynamics

## 2. 中文翻译与核心摘要

这篇论文的核心问题是：工业 CPS 的传感器和执行器数据不是静态分布，正常行为会随季节、工况、设备状态、环境扰动和业务流程变化而变化。传统异常检测模型通常在离线正常数据上训练，然后假设测试分布与训练分布一致；这种假设在真实工业环境中很脆弱，容易产生大量误报或漏报。

作者提出 RDSAD，一个无监督、流式、自适应的异常入侵检测方法。它把 CPS 高维时间序列压缩到低维潜在动力学空间，用深度状态空间模型学习正常行为，再用概率密度和动态阈值判断偏离。方法由两部分组成：

- DDR：Dynamic Deviation Recognition，用于学习系统潜在动力学并计算异常偏离。
- SMA：Shift-aware Model Adaptation，用于识别正常性漂移，并决定是否更新模型。

论文最有价值的地方不是单纯用了 VAE/SSM，而是把三个部署难点放在同一个框架里处理：时间依赖、数据不确定性、正常模式漂移。同时它避免了流式更新中的两个典型风险：把攻击样本学成正常行为的 self-poisoning，以及持续更新导致旧正常模式被遗忘的 catastrophic forgetting。

## 3. 论文解决的具体问题

论文解决的是工业 CPS 演化数据流中的无监督异常入侵检测问题。更具体地说，它面对三类困难：

1. 正常行为难以建模  
   CPS 数据通常是多传感器、多执行器、高维、时序相关且带噪声的。正常行为不是简单的点分布，而是受控制逻辑和物理过程共同约束的动态轨迹。

2. 正常性会漂移  
   水处理、水分配、气体传感、IoT 服务等系统会因为外部环境、原料质量、设备老化、工况切换而发生正常分布变化。静态模型可能把新正常状态误判为攻击，也可能在攻击分布靠近旧正常状态时漏报。

3. 流式自适应会引入新风险  
   直接在线更新模型并不一定更好。如果更新数据中混入攻击样本，模型会被自投毒；如果持续用新数据覆盖旧知识，模型会灾难性遗忘过去合法但暂时不常见的正常模式。

因此，论文目标不是“做一个更高 AUC 的异常检测器”这么简单，而是设计一个能在无监督、流式、分布变化条件下保持检测可靠性的 CPS 威胁检测框架。

## 4. 创新点深度提炼

第一，RDSAD 用深度状态空间模型表达 CPS 的潜在动力学。它不是直接在观测空间重构传感器值，而是引入连续潜在状态 h 和随机潜在状态 z：h 负责刻画长期时间演化，z 负责刻画随机性和不确定性。这比普通 AE/VAE/LSTM 更接近 CPS 的物理过程建模逻辑。

第二，DDR 中的 Temporal Embedding Network 使用 TCN 提取时间上下文。TCN 的膨胀卷积能扩大感受野，计算上也比传统 RNN 更适合流式序列处理。

第三，连续潜在状态使用 GRU-flow，而不是普通 GRU。作者希望通过 Neural Flow 思路近似连续时间动力学，避免标准 neural ODE 数值求解的高成本，同时保留对连续演化过程的建模能力。

第四，发射模型采用 Student-t 分布而非高斯分布。这个选择很关键：异常点往往是极端波动，高斯发射模型容易被极端值拉动，Student-t 的重尾特性使模型对噪声和异常污染更稳健。

第五，异常分数不是裸 log-likelihood，而是当前似然与近期正常似然移动平均的差值。这样做把“当前样本是否罕见”转化为“当前样本相对近期正常上下文是否明显偏离”，更适合非平稳流。

第六，SMA 在潜在空间识别漂移，而不是在原始高维观测空间直接做漂移检测。它用能量距离比较参考潜在窗口和当前潜在窗口，再用类似 CUSUM 的强度累积机制判断变化是否持续、显著。

第七，模型更新必须同时满足“检测到显著漂移”和“当前样本被判为正常”。这是一种简单但工程上很实用的鲁棒更新门控，目的在于阻断攻击样本进入更新过程。

第八，作者用贝叶斯在线学习式的自适应正则项约束参数更新，缓解灾难性遗忘。其思想是让上一阶段的后验成为下一阶段的先验，并通过指数遗忘因子平衡旧知识与新数据。

## 5. 科学问题与研究假设

核心科学问题可以概括为：

- 如何在无标签 CPS 数据流中学习可用于异常检测的低维正常动力学？
- 如何区分“真实攻击偏离”和“正常模式演化”？
- 如何在模型自适应时避免攻击污染和旧知识遗忘？
- 如何让检测方法既具备概率建模能力，又满足流式运行效率？

论文隐含或显式依赖以下研究假设：

- CPS 的高维观测背后存在较低维的潜在动力学结构。
- 正常性漂移会在潜在空间中表现为分布差异，因此可通过潜在窗口比较识别。
- 异常攻击相对正常行为具有较低生成似然，且在 Student-t 发射模型下更容易被稳健地区分。
- 若一个样本同时触发漂移但未通过正常性验证，就不应进入模型更新。
- 通过贝叶斯式正则约束，模型可以在适应新正常模式时保留旧正常知识。

这些假设大体合理，但也构成论文的边界：如果系统本身极度随机、潜在结构很弱，或者攻击者能伪装成平滑漂移，RDSAD 的判别逻辑会受到挑战。

## 6. 科学方法与技术路线

RDSAD 的技术路线可以按“表示学习、偏离检测、漂移识别、自适应更新”理解。

首先，输入是 CPS 连续数据流，系统用滑动窗口处理长度为 T 的观测序列。每个观测是多维传感器/执行器向量。

其次，TEN 使用 TCN 对输入序列做时间嵌入，得到适合推断模型使用的时间特征。

然后，推断模型学习近似后验 q(z_t | z_{t-1}, h_t, x_t)。连续状态 h_t 通过 GRU-flow 捕获时间演化，随机状态 z_t 则用高斯形式表达潜在不确定性。

接着，发射模型从 z_t 和 h_t 生成观测分布 p(x_t | z_t, h_t)，分布形式为动态参数化的 Student-t。模型通过最大化 ELBO 训练，包含重构似然项和 KL 正则项。

运行时，RDSAD 计算 log-likelihood，再与近期正常似然移动平均比较得到偏离分数 s_t。阈值由 EVT/POT 建模低尾极端偏离得到，低于阈值即报警。

同时，SMA 用参考潜在窗口和当前潜在窗口计算能量距离，得到变化分数，再用强度累积判断是否发生显著正常性漂移。只有当漂移显著且当前观测被认为正常时，才触发模型增量更新，并重新计算阈值。

## 7. 实验设计与实验步骤

可复核流程如下：

1. 数据  
   使用四个公开数据集：ToN_IoT、SWaT、WADI、GAS。前三者包含工业/IoT/CPS 攻击异常，GAS 中有害化学物质 Acetaldehyde 被视为威胁模式。异常只出现在测试数据中。

2. 预处理  
   正文没有展开详细预处理细节，称详细实现和基线参数在在线附录 A。主文可确认的是数据以滑动窗口进入模型，不同数据集窗口长度不同：GAS 为 50，SWaT/WADI 为 100，ToN_IoT 为 150。

3. 模型  
   RDSAD 使用 TCN 两个卷积块，每块两个时序卷积层，kernel size 为 3；推断模型和发射模型均为两层全连接结构；GRU-flow 为 64 单元；z-space 维度最终选为 4；使用 L2 正则 1e-6。

4. 基线  
   静态基线包括 DeepSVDD、Beta-VAE、DAGMM、LSTM-ED、LSTM-VAE，并在结果中还比较了 GDN、ADT、LATTICE。流式基线包括 STORM、HS-Tree、Online-RNN-AD、LODA、KitNET、SDOstream。

5. 训练  
   初始训练使用正常数据离线训练，优化 ELBO。优化器为 Adam，初始学习率 1e-3。随后运行时通过 SMA 进行选择性增量更新。

6. 指标  
   使用 Precision、Recall、F-score 和 AUC-ROC。论文每个数据集运行五次，报告均值和标准差。

7. 消融/敏感性  
   消融包括：TCN 替换为 RNN、GRU-flow 替换为普通 GRU、去掉自适应正则、Student-t 替换为高斯。敏感性分析包括 z 维度、窗口长度、漂移因子 κ。

8. 结果核查  
   主结果表明 RDSAD 在四个数据集 AUC 均最高：ToN_IoT 0.8112、SWaT 0.9006、WADI 0.8555、GAS 0.7861。SWaT 和 WADI 上尤其体现出 precision/recall 的平衡性，而不是靠极高 recall 牺牲误报。

## 8. 关键结果、结论与证据

最重要的结论是：RDSAD 在多种 CPS/IoT 数据集上比静态检测和普通流式检测更稳健，尤其在精确率与召回率之间更均衡。

在 SWaT 上，RDSAD 的 Precision 为 0.9175，Recall 为 0.8552，F-score 为 0.8851，AUC 为 0.9006。虽然 GDN 的 precision 高达 0.9935，但 recall 只有 0.6812，说明它更保守，漏检较多。

在 WADI 上，RDSAD precision 为 0.8316，虽然低于 LSTM-ED 的 0.9239，但 RDSAD 的 F-score 和 AUC 更优，说明整体判别能力更稳定。

在 ToN_IoT 和 GAS 上，RDSAD 也取得最高 AUC，说明方法不只适用于水处理场景，而具有一定跨 CPS/IoT 数据集泛化能力。

鲁棒更新实验显示，三种策略中“无更新”不适应漂移，“普通更新”容易被异常污染，而 RDSAD 的鲁棒更新门控效果最好。这个实验直接支撑了 SMA 的必要性。

污染与噪声实验进一步验证了稳健性：在 SWaT 训练集中注入 0%-20% 异常污染时，RDSAD 的 AUC 下降相对较小；在高斯噪声注入下，σ=0.05 时仍保持约 0.8782 AUC。证据指向 Student-t 发射模型、概率建模和选择性更新共同发挥作用。

消融实验说明每个组件都有贡献：TCN、GRU-flow、自适应正则、Student-t 发射模型缺一都会降低性能。其中 Student-t 和自适应正则对应的是鲁棒检测与持续学习能力，意义尤其明确。

## 9. 局限性与待解决问题

论文自己承认，RDSAD 依赖一个前提：正常行为能在潜在空间中被有效建模。如果系统高度随机、弱结构化，潜在动力学不稳定，RDSAD 的优势可能下降。

第二，深度模型在低功耗边缘设备上部署仍有压力。论文给出 SWaT 上 RDSAD 训练时间约 45 秒、内存约 750 MB，虽比部分深度基线更经济，但对嵌入式 PLC 边缘节点仍未必轻量。

第三，SMA 主要防范普通异常污染和灾难性遗忘，但对对抗攻击缺少防护。攻击者可能构造细微扰动操纵偏离分数，或者制造看似正常的漂移诱导模型错误更新。

第四，正常性漂移实验还不够贴近真实工业过程。作者也提到未来要用均值/方差渐变、潜在空间扰动等方式模拟更真实的领域演化。

第五，正文提到补充材料和 Appendix A 包含更详细实现设置，但本次正文包没有给出附录内容。因此，虽然正文包本身未截断，若要完全复现，还需要回到 PDF 补充材料核查基线参数、预处理细节和代码发布信息。

## 10. 与本项目的关系

对“恶意流量、暗网与攻击检测”项目而言，这篇论文的直接价值在于：它提供了处理演化攻击检测场景的系统化思路，而不仅是一个 CPS 专用模型。

如果项目面对的是网络流量、暗网行为日志或攻击事件流，正常模式同样会随时间变化。例如业务流量周期性变化、服务迁移、攻击基础设施切换、暗网市场活动波动，都会造成正常/异常边界漂移。RDSAD 的潜在空间漂移检测、鲁棒更新门控、异常污染防御都可以迁移为方法论。

尤其值得借鉴的是它对“在线学习”的谨慎态度：不是看到新数据就更新，而是先判断是否为正常性漂移，再判断是否安全可学。这对恶意流量检测很重要，因为攻击样本混入训练流几乎是常态。

## 12. 本篇精华

- RDSAD 把 CPS 异常检测从“静态重构误差问题”推进到“演化潜在动力学建模问题”。
- 方法核心是 DDR + SMA：前者学习正常动态并检测偏离，后者识别正常性漂移并控制模型更新。
- 连续潜在状态 h 建模时间演化，随机潜在状态 z 建模不确定性，两者共同服务于低维动态表示。
- Student-t 发射模型是鲁棒性的关键设计，能减弱极端异常值对生成模型的污染。
- SMA 的更新门控很实用：只有“漂移显著且样本正常”才更新，避免把攻击学成正常。
- 贝叶斯式自适应正则用于缓解灾难性遗忘，使模型在适应新工况时保留历史正常知识。
- 实验中 RDSAD 在 ToN_IoT、SWaT、WADI、GAS 四个数据集均取得最高 AUC，并在 SWaT/WADI 上表现出较好的 precision-recall 平衡。
- 局限在于对潜在结构假设、边缘部署成本和对抗性漂移攻击的防御仍未充分解决。
