# [834] Unified Anomaly Detection via Multi-Scale Contrasted Memory

## 1. 基本信息

- 题名：Unified Anomaly Detection via Multi-Scale Contrasted Memory
- 中文题名：基于多尺度对比记忆的统一异常检测
- 作者：Loïc Jézéquel、Jean Beaudet、Aymeric Histace、Ngoc-Son Vu
- 年份：2026
- 来源：IEEE Transactions on Image Processing, Vol. 35
- DOI：10.1109/TIP.2026.3663923
- 任务类型：图像异常检测、工业缺陷检测、人脸反欺骗、OOD 检测
- 关联到网络安全/异常检测：弱相关。它不是网络流量或入侵检测论文，但其“正常原型记忆 + 偏离度评分 + 少量异常样本统一建模”的思想可迁移到网络异常检测。

## 2. 中文翻译与核心摘要

这篇论文提出 AnoMem，一个面向无监督异常检测和少样本/类别极不平衡监督异常检测的统一框架。论文的核心判断是：现实异常检测往往从“只有正常样本”开始，随后逐步获得少量异常样本；如果每个阶段都要换一套算法、调一套超参，工程上并不合理。

AnoMem 的做法是两阶段：

第一阶段只围绕表征学习和正常原型记忆展开。模型用对比学习训练编码器，同时在多个特征尺度上通过可反向传播的 Hopfield memory 学习正常样本原型。这里的“记忆”不是简单保存训练样本，而是学习一组固定大小的正常模式原型。

第二阶段用输入特征与记忆原型之间的偏离来计算异常分数。无监督场景下，直接用特征与记忆恢复结果的 L2 差异作为异常分数；有少量异常样本时，则训练尺度级 MLP 检测器，对多尺度偏离图进行监督学习。

论文想证明的不是单一数据集上的性能提升，而是一个更强主张：同一套框架可以同时覆盖 UNS-AD 和 IMS-AD，并且能兼顾对象级异常、纹理/风格异常、局部细粒度异常、工业缺陷、人脸攻击以及 OOD 检测。

## 3. 论文解决的具体问题

论文针对的是视觉异常检测中的三个具体困难。

第一，异常样本稀缺且逐步出现。传统 UNS-AD 只用正常样本训练；IMS-AD 可以利用少量异常样本。但现有方法通常分属不同范式，不能从无监督自然切换到少样本监督。

第二，正常样本内部存在边界样本。模型如果只学习“平均正常模式”，容易把罕见但合法的正常样本误判为异常；如果记忆过强，又可能泛化到真正异常。论文把这个矛盾表述为：既要记住正常类的 edge-case，又不能削弱对异常的区分。

第三，异常尺度差异很大。对象级异常依赖高层语义，例如狗和猫；工业缺陷、人脸反欺骗中的纸张边缘、屏幕反光、面具纹理则可能是局部低层异常。很多方法偏向其中一类，缺少显式多尺度机制。

## 4. 创新点深度提炼

1. **把可学习记忆层嵌入对比学习，而不是训练后再聚类。**  
   常见两阶段方法先学表征，再用 k-means、最近邻或密度估计计算异常分数。AnoMem 在表征学习过程中就学习正常原型，使编码器的特征空间和正常记忆共同成形。

2. **用 Hopfield layer 作为正常原型记忆。**  
   它不是保存全部样本的 memory bank，也不是不可导的最近邻队列，而是一组可学习原型。这样推理时内存固定，不随训练集大小线性增长。

3. **只让正常样本进入记忆分支。**  
   论文用标签 y 控制 memory：正常样本经过 Hopfield 记忆，异常样本直接保留原特征。这是统一 UNS/IMS 的关键，因为第一阶段可以同时接收正常和少量异常，但记忆只服务于正常类建模。

4. **多尺度空间记忆。**  
   中间特征图不是直接展平成一个大向量，而是被视为多个空间位置上的局部特征向量，每个位置都可与 memory 交互。这使模型能捕捉局部纹理型正常模式。

5. **异常分数来自“记忆偏离图”。**  
   对每个尺度计算原特征和 memory recollection 的差值。这个差值天然表达“当前输入离正常原型有多远”，比直接分类更符合异常检测问题。

6. **UNS 与 IMS 只替换第二阶段。**  
   无监督时直接用偏离范数；有异常样本时训练小型 MLP 距离检测器。共享第一阶段，降低了从无监督部署到少样本监督升级的成本。

## 5. 科学问题与研究假设

论文背后的科学问题可以概括为：

- 是否存在一种异常检测表征，使其既能记忆正常类内部多样性，又能保持对未知异常的敏感性？
- 正常原型是否应当在表征学习过程中共同学习，而不是作为后处理步骤？
- 多尺度正常原型能否缓解对象级异常与局部纹理异常之间的检测冲突？
- 少量异常样本是否只需要改变异常打分器，而不必重构整套异常检测框架？

对应的研究假设是：

1. 可学习正常原型比 k-means 或最近邻样本库更能覆盖正常类的代表性结构。
2. 在对比学习中加入正常原型，会提升编码器表征质量。
3. 低层尺度更适合局部纹理异常，高层尺度更适合对象级/语义异常。
4. 异常检测中的少量异常样本应主要用于校准偏离度，而不是把问题退化成普通二分类。

## 6. 科学方法与技术路线

AnoMem 的技术路线分为两个阶段。

第一阶段是多尺度对比记忆学习。输入图像经过 ResNet 编码器，在若干中间层得到多尺度特征图。对于正常样本，特征先经过 Hopfield memory 得到记忆恢复后的原型特征，再与另一增强视图进行对比学习。异常样本如果存在，则不参与正常 memory 写入，只作为普通特征进入对比结构。论文还加入方差正则，避免训练早期所有记忆原型坍缩到同一点。

核心损失包括：

- 对比记忆损失：让同一图像不同增强视图接近，同时把正常样本的 memory-recalled 表征纳入对比。
- 方差正则：防止 memory 输出退化。
- 多尺度加权：不同尺度的损失用 λ 控制，论文采用随尺度增加的指数权重，更强调高层语义尺度。

第二阶段是基于偏离图的异常评分。对每个尺度，计算：

- 原始特征图 z
- Hopfield memory 恢复后的正常原型特征 HF(z)
- 偏离图 Δ = z - HF(z)

无监督时，异常分数就是各尺度 Δ 的 L2 范数加权和。有少量异常样本时，每个尺度训练一个平均池化加两层 MLP 的检测器，用 double-hinge distance loss 让正常样本距离小、异常样本距离大，但不把异常无限推远。

## 7. 实验设计与实验步骤

可复核流程如下。

**1. 数据设置**

- One-class novelty detection：CIFAR-10、CIFAR-100、CUB-200。每次指定一个类别为正常，其余类别为异常，最后对所有正常类别取平均。
- IMS 设置中调节训练异常比例 γ，例如 0、0.01、0.05、0.10 等；γ=0 即 UNS。
- 工业缺陷检测：MVTec-AD，包含 5 个纹理类和 10 个对象类。
- 人脸反欺骗：WMCA，采用跨攻击类型协议，一个攻击类型在测试时不可见。
- OOD 检测：以 CIFAR 为 ID，SVHN、LSUN 等为 OOD。

**2. 预处理**

- CIFAR-10/100 保持小图设置。
- 其他数据统一 resize 到 224×224。
- 增强使用 SimCLR 风格：随机裁剪缩放、水平翻转、亮度/对比度/饱和度扰动、高斯模糊和噪声。
- 作者强调没有使用 CSI 那类额外 shift augmentation。

**3. 模型**

- Backbone：ResNet-50，约 25M 参数。
- 两个 memory 尺度：第三 stage 后和最后 stage 后。
- memory 大小：低层尺度 512，高层尺度 256。
- Hopfield inverse temperature β=2。
- 空间采样比例：低层 r=0.3，高层 r=1。
- 尺度权重：λ(s)=2^(s-1)。
- 方差损失权重 λV=0.05。
- 对比学习温度 τ=0.1。
- IMS 距离损失 margin M=2。

**4. 训练**

- 优化器：SGD + Nesterov momentum。
- Batch size：1024。
- 学习率调度：cosine annealing。
- 第一阶段：训练编码器与多尺度 Hopfield memory。
- 第二阶段：UNS 不再训练；IMS 用少量异常样本训练尺度级 MLP 检测器。

**5. 对比基线**

- 无外部知识方法：重构式方法、知识蒸馏、pretext task、CSI 类对比学习方法、Deep SAD/距离式异常检测、普通二分类。
- 外部知识方法：使用 ImageNet 预训练或 CLIP/VLM 等额外知识的方法。
- 论文明确区分 EK 与 non-EK，因为使用大规模预训练数据会隐含异常先验。

**6. 指标**

- 主要指标：AUROC。
- 对 novelty detection：对所有 one-vs-all 正常类别取平均。
- 对 FAS：按未见攻击类型分别报告。
- 对 OOD：区分 ID/OOD 样本的 AUROC。

**7. 消融/敏感性**

- memory 对表征质量的影响：冻结编码器后做线性分类评估。
- Hopfield memory vs k-means 原型。
- 单尺度 vs 多尺度。
- memory size。
- 空间采样比例 r。
- 方差损失 λV。
- 尺度权重函数：线性 vs 指数。
- margin M 的选择讨论。

**8. 结果核查**

复现实验时应重点核查：

- 是否严格区分外部知识方法和从零训练方法。
- IMS 中异常比例 γ 是否与论文一致。
- CUB-200 每类样本较少，随机采样对结果影响可能更大，应多次重复。
- MVTec 本文只做 image-level AD，不做 localization 指标。
- FAS 是否采用 leave-one-attack-type-out，而不是普通随机划分。

## 8. 关键结果、结论与证据

论文的主要结论是：AnoMem 是第一个在 UNS 和 IMS 两种设置下都表现稳定的统一异常检测方法。

在 one-class novelty detection 中，普通监督二分类明显不如专用异常检测器，说明少量异常样本并不能简单把问题变成分类任务。AnoMem 在无外部知识方法中整体最强，并且随异常比例增加继续提升。

在工业缺陷检测中，UNS-AnoMem 不针对工业场景做特殊设计，却超过无外部知识方法中的 PatchCore、NSA、SPR 等。IMS-AnoMem 在加入少量异常样本后达到或接近 SOTA，即使与使用预训练模型的方法相比也很有竞争力。

在人脸反欺骗中，AnoMem 对纸张打印、屏幕重放、纸面具、柔性面具等攻击都表现强，尤其缩小了粗粒度攻击和细粒度攻击之间的性能差距。论文把这个归因于多尺度偏离检测。

在 OOD 检测中，AnoMem 与 CSI 接近，但内存更固定。CSI 需要保留大量训练样本特征，而 AnoMem 只保留固定大小的 memory 原型。

消融实验支持三个核心证据链：

- memory 加入对比学习后，编码器线性评估性能提升，说明它不只是异常评分模块，也改善表征。
- Hopfield memory 优于 k-means 原型，说明联合学习正常原型有效。
- 多尺度优于单尺度，说明不同异常尺度确实需要不同特征层共同建模。

## 9. 局限性与待解决问题

第一，本文主要是视觉异常检测，不是网络安全中的入侵检测或流量异常检测。它的方法论可迁移，但实验不能直接证明其在网络流量、日志、主机行为序列上的效果。

第二，异常定位不是本文重点。虽然偏离图看起来可以生成 heatmap，但论文明确说多尺度异常图分数范围和关注区域差异很大，如何融合成稳定定位图仍待研究。

第三，模型仍存在背景敏感性。CUB 鸟类图像中异常背景、WMCA 中异常服装都可能影响分数，说明模型没有完全剥离目标与背景因素。

第四，尺度不变性不足。论文失败案例显示，主体距离、局部异常尺寸过小都会影响检测。

第五，对极细微异常仍可能漏检。例如纸张边缘很薄、MVTec 中小缺陷过小，可能低于当前特征尺度分辨能力。

第六，超参数虽然做了消融，但 memory size、尺度选择、采样比例、margin M 仍依赖经验。论文也提到未来考虑动态调整 M。

第七，和 VLM/大规模预训练方法的比较存在范式差异。AnoMem 强调无外部知识，但实际工业系统未必禁止预训练；因此部署选择要看数据许可、计算预算和泛化需求。

## 10. 与本项目的关系

该论文与“入侵检测与网络异常检测”的直接相关性偏弱，因为其对象是图像。但它有几条值得借鉴的思想。

第一，正常行为原型记忆适合网络安全。网络流量、系统调用、用户行为、认证日志都存在“正常模式多样但异常稀缺”的特点。用可学习 memory 表示正常原型，比只用均值中心或最近邻样本库更灵活。

第二，UNS 到 IMS 的统一框架很契合安全场景。实际安全系统常常先只有正常数据，之后逐步积累攻击样本。AnoMem 的“共享表征和正常 memory，只替换监督检测头”是有工程价值的。

第三，多尺度思想可映射到网络数据的多粒度特征。例如包级、流级、会话级、主机级、时间窗口级，对应图像中的局部纹理到全局对象。

第四，偏离图可类比为偏离向量或偏离序列。对每个时间窗口或协议字段计算与正常原型的差异，可以用于解释异常来自哪些行为片段。

但要注意，网络安全数据往往是表格、序列或图结构，不是二维图像；Hopfield memory 与对比增强策略需要重新设计，不能直接照搬图像增强。

## 12. 本篇精华

1. AnoMem 的关键不是“加了 memory”，而是把正常原型 memory 放进对比学习过程，让表征和正常原型共同学习。

2. 它把异常检测统一成“输入相对正常原型的多尺度偏离”问题；UNS 用偏离范数，IMS 用少量异常样本校准偏离检测器。

3. Hopfield memory 使模型不必保存全部正常样本，推理内存固定，比最近邻队列更适合大规模部署。

4. 多尺度设计直接回应了异常检测中的尺度冲突：高层特征识别对象级异常，低层/中层特征识别纹理和局部异常。

5. 普通二分类在少量异常样本下表现差，说明异常检测不能简单等价为监督分类。

6. 外部知识方法和无外部知识方法必须分开比较；预训练模型可能隐含大量异常先验。

7. 论文的失败案例很有价值：背景敏感、尺度变化、极小异常仍是多尺度 memory 方法的薄弱点。

8. 对网络安全方向，最值得迁移的是“正常原型记忆 + 多粒度偏离评分 + 从无监督平滑升级到少样本监督”的框架思想。
