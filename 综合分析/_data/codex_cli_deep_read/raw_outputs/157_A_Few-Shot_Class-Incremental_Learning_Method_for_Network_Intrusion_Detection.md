# [157] A Few-Shot Class-Incremental Learning Method for Network Intrusion Detection

## 1. 基本信息

- 题名：A Few-Shot Class-Incremental Learning Method for Network Intrusion Detection
- 中文题名：面向网络入侵检测的少样本类增量学习方法
- 作者：Lei Du, Zhaoquan Gu, Ye Wang, Le Wang, Yan Jia
- 来源：IEEE Transactions on Network and Service Management
- 年份：2023，正式期刊卷期为 2024 年 4 月刊
- DOI：10.1109/TNSM.2023.3332284
- 本地 PDF：`paper/10.1109_TNSM.2023.3332284.pdf`
- 主题定位：入侵检测、少样本学习、类增量学习、原始流量表示、灾难性遗忘

## 2. 中文翻译与核心摘要

这篇论文研究的是：当新的攻击类型不断出现、但每类新攻击只有极少量样本时，入侵检测模型如何持续学习新类别，同时不忘记已经学过的攻击类别。

作者提出 BFS-NID，即基于分支融合策略的网络入侵检测方法。它把原始网络流量转换成灰度图，用自监督方式训练 ViT 特征提取器，再用按增量会话划分的分支分类器学习新类。核心思想不是简单微调整个模型，而是冻结一个较通用的特征提取器，通过每个会话自己的重投影层和原型分类器来维持新旧攻击类别之间的可分性。

实验在 CIC-IDS2017 和 CSE-CIC-IDS2018 上进行。结果表明，BFS-NID 在少样本类增量入侵检测任务上优于 finetune、iCaRL、FOSTER、IDFSCIL、LIMIT、C-FSCIL 等基线，但也暴露出 benign 流量误报偏高、相似攻击族混淆、推理开销较大等问题。

## 3. 论文解决的具体问题

论文针对的不是传统“已知类别监督分类”，也不是单纯“正常/异常二分类”，而是更贴近攻防演化的场景：

- 初始阶段有较多样本，可训练基础入侵检测模型。
- 后续不断出现新的攻击类别。
- 每个新攻击类别只有极少量标注样本，例如 5-shot。
- 增量阶段不能访问旧会话训练数据。
- 模型在学会新攻击类别后，还要能识别所有已经见过的类别。
- 不能因为学习新类而严重遗忘旧类。

这个问题在论文中被形式化为网络入侵检测场景下的 FSCIL：Few-Shot Class-Incremental Learning。它比普通少样本学习更难，因为少样本学习通常只关心新类识别；而这里还要求长期维护旧类能力。

## 4. 创新点深度提炼

第一，论文把网络入侵检测明确建模为 FSCIL 问题。已有 IDS 研究常见路线是规则检测、异常检测、细粒度监督分类、少样本分类，但这些方法大多不能持续吸收新攻击类别。本文把“新攻击少样本 + 旧攻击不遗忘”作为核心任务。

第二，作者提出一种原始流量灰度图表示。它以 bi-flow 为粒度，取前 16 个包、每包前 256 字节，填充或截断后把每个包重排为 `4 x 64`，再按到达时间堆叠成 `1 x 64 x 64` 灰度图。这比人工统计特征更少依赖专家规则，也比普通图像化方法更强调包序列关系。

第三，使用自监督 ViT 特征提取器。作者借鉴 MAE 思路，用 patch mask 重建任务训练特征提取器。这里的 patch 对应一个数据包，位置编码对应包之间的时序关系，因此 ViT 的结构和网络流量表示之间有较自然的对应关系。

第四，提出按会话的重投影机制。冻结特征提取器虽然能减少遗忘，但也可能导致不同攻击类在特征空间中过于接近。BFS-NID 为每个会话设置 projection layer，把特征重新映射到更适合该会话区分类别的空间。

第五，提出分支融合策略。每个会话有自己的分支分类器和投影层，推理时不是只依赖最后一个分类器，而是融合不同会话分支对各自类别原型的相似度，从而维护新旧类别之间的上下文关系。

## 5. 科学问题与研究假设

核心科学问题可以概括为：在没有旧类训练样本、只有极少新类样本的条件下，如何构造一个持续演化的细粒度入侵检测模型？

论文隐含了几组关键假设：

- 原始流量前若干包、前若干字节足以承载攻击类别的主要判别信息。
- 网络流量可以被转换成类图像结构，但不能完全忽略包级时序关系。
- 自监督预训练能学到比纯监督预训练更泛化的攻击行为表示。
- 冻结特征提取器可以缓解灾难性遗忘，但需要额外机制恢复类别可分性。
- 少量新类样本不足以训练完整模型，但足以更新原型和轻量投影层。
- 旧类原型可以替代旧类样本，参与新会话训练中的类别边界约束。

## 6. 科学方法与技术路线

技术路线分为三层。

第一层是流量表示。论文从 pcap 原始流量出发，用五元组提取 bi-flow，并允许源/目的 IP-port 对调。然后用 64 秒 timeout 和 120 秒 periodic reset 切分样本。每个样本取 `M=16` 个包、每包 `B=256` 字节，不足补 0，超出截断，并将 MAC/IP 地址置零以降低隐私泄露风险。

第二层是自监督特征学习。灰度图被送入 ViT-large 变体，patch 大小为 `4 x 64`，恰好对应一个包。模型采用类似 MAE 的 masked reconstruction 训练方式，mask ratio 为 75%。预训练目标不是分类，而是学习流量样本内部结构。

第三层是 BFS-NID 分类学习。基础会话中，模型微调特征提取器和基础投影层 `Proj0`，并计算各类别原型。增量会话中，冻结特征提取器，只训练当前会话投影层 `Proji`；`Proji` 由 `Proj0` 初始化。新类原型会加入原型矩阵，旧类原型保留。推理时，样本经过不同会话投影分支，与各会话类别原型计算余弦相似度，再融合得到最终类别。

## 7. 实验设计与实验步骤

可复核流程如下。

数据：使用 CIC-IDS2017 和 CSE-CIC-IDS2018 的原始 pcap，而不是 CICFlowMeter 统计特征。CIC-IDS2017 选 12 类，基础会话 8 类，后续 2 个增量会话各 2 类。CSE-CIC-IDS2018 选 14 类，基础会话 8 类，后续 2 个增量会话各 3 类。基础会话每类 2000 个训练样本，增量会话每个新类 5 个训练样本，测试阶段每类 100 个样本。

预处理：pcap 切分为 bi-flow；使用 timeout 和 periodic reset；匿名化 MAC/IP；取前 16 包、每包前 256 字节；转成 `1 x 64 x 64` 灰度图。

模型/基线：主模型为 BFS-NID。对比方法包括 finetune、iCaRL、FOSTER、IDFSCIL、LIMIT、C-FSCIL。还比较了标准监督预训练和自监督预训练的差异。

训练：ViT-large 作为骨干，特征维度改为 512，MAE decoder 维度为 384。优化器为 SGD。CIC-IDS2017 基础分支训练 40 epoch，学习率 0.05；CSE-CIC-IDS2018 基础分支训练 80 epoch，学习率 0.002。增量分支两个数据集均训练 100 epoch，学习率 0.0002，batch size 为 128。

指标：使用 Top-1 Accuracy 衡量分类准确率；使用 PD 衡量从基础会话到最后会话的性能下降，PD 越小越抗遗忘。还报告 precision、recall、F1、混淆矩阵、FLOPs、显存和推理速度。

消融/敏感性：逐步比较仅使用自监督特征提取器、加入重投影 REPROJ、再加入分支融合 BFS 的效果；用 t-SNE 观察特征空间和决策边界；用混淆矩阵分析误报和漏报；比较监督预训练与自监督预训练。

结果核查：重点检查最后一个增量会话的全类别测试结果，而不是只看新类；检查旧类是否被遗忘；检查 benign 被误判为攻击的比例；检查相似攻击族之间的混淆；检查模型复杂度是否适合实际部署。

## 8. 关键结果、结论与证据

自监督特征提取器本身已经有一定增量能力，但仍存在明显遗忘。论文报告仅使用 FE 时，最后会话 PD 在 CIC-IDS2017 和 CSE-CIC-IDS2018 上分别下降 11.21% 和 12.88%。

加入重投影后，两个数据集上的 PD 分别改善 4.13% 和 2.88%。这说明问题不只是“特征不够好”，还在于冻结特征空间下新旧类别边界需要重新校准。

加入分支融合后性能进一步提升。作者通过混淆矩阵说明，分支融合能减少旧类和新类之间的误判，尤其能缓解 benign 样本被多个攻击类吸走的问题。

自监督预训练整体优于标准监督预训练的抗遗忘能力。论文解释为：监督预训练容易过度贴合基础会话标签空间，而自监督重建任务更有利于学习对未见攻击类可迁移的结构表示。

与基线相比，BFS-NID 在两个数据集不同会话上取得最高准确率和最低 PD。论文还报告在最后会话的 precision、recall、F1 上优于对比方法。

但混淆矩阵也显示，BFS-NID 不是完美 IDS。CSE-CIC-IDS2018 中 benign 的误报可达到约 15%；Web-BruteForce、Web-XSS、DDoS-LOIC-HTTP、DDoS-LOIC-UDP 等相近攻击族之间仍有显著混淆。

## 9. 局限性与待解决问题

本次正文包未截断，因此整体理解不受正文缺页影响。不过提供的纯文本中部分表格的具体数值单元没有完整呈现，若需要逐项复现实验表格，仍建议回到 PDF 核对 Table II 到 Table V 的精确数值。

方法仍依赖少量已标注新攻击样本。它解决的是“新类出现后如何少样本增量学习”，不是“完全未知攻击在无标签条件下如何即时发现”。

实验会话是人为划分的，和真实网络中攻击按时间、组织、资产、漏洞链条混合出现的场景仍有距离。

benign 流量误报偏高。对真实 SOC 来说，15% 级别的 benign-to-attack 误判会带来较高告警分析成本。

相似攻击类型区分仍困难。论文中的 Web 攻击、DDoS 不同协议变体、暴力破解类攻击之间都有明显混淆，说明原始字节灰度图表示未必能充分捕获细粒度语义差异。

计算开销较大。BFS-NID 使用 ViT-large 和多分支结构，推理速度在对比方法中不占优。论文也指出可考虑轻量 ViT。

对加密流量尚未充分验证。作者在结论中把加密网络流量上的表示有效性列为未来工作。

## 10. 与本项目的关系

这篇论文与“异常检测/入侵检测”项目强相关，但它更偏向“细粒度新类增量识别”，不是传统无监督异常检测。

对本项目最有价值的启发有三点：第一，异常检测系统不能只判断 abnormal，还应尽量给出攻击类型级诊断；第二，新攻击样本稀缺是常态，应把 few-shot 与 incremental learning 纳入模型设计；第三，原始流量表示可以绕开人工统计特征，但必须谨慎处理隐私、加密、计算成本和误报。

如果本项目关注开放世界网络安全，BFS-NID 可作为一个重要基线：它适合比较“有少量新类标签后的持续学习能力”，但还需要和 open-set detection、unknown detection、active learning、告警聚类等模块结合，才能覆盖真实未知攻击发现链路。

## 12. 本篇精华

- 论文把入侵检测中的“新攻击少样本”问题推进为 FSCIL：学新类，同时不忘旧类。
- 原始流量被转换为 `64 x 64` 灰度图，每个 patch 对应一个包，保留了包级时间顺序。
- 自监督 ViT 比监督预训练更适合增量场景，因为它不强绑定基础会话标签空间。
- 冻结特征提取器只能缓解遗忘，不能自动保证新旧类可分；重投影层是关键补偿机制。
- 分支融合通过会话级投影和类别原型，把不同增量阶段的分类器关联起来。
- 实验显示 BFS-NID 在 CIC-IDS2017 和 CSE-CIC-IDS2018 上优于多种 CIL/FSCIL 基线。
- 方法的主要短板是误报、相似攻击混淆、计算开销和非真正开放世界检测。
