# [700] Hierarchical GNN Message Passing for Node-Level Anomaly Detection in Industrial Control Systems

- DOI：10.1109/TDSC.2025.3623299
- 主题：面向工业控制系统的节点级异常检测、层次化 GNN 消息传递、设备级状态推断

## 2. 中文翻译与核心摘要

这篇论文的核心意思是：传统 GNN 在工业控制系统异常检测中多采用“直接邻居聚合”，即节点从相邻节点收集信息来更新表示。但 ICS 天然是分层控制结构，传感器、执行器、PLC/控制器、上层监督节点之间有明确的上下级关系。普通邻居聚合容易过度偏向局部邻域，不能很好表达这种“监督-从属”的层次语义。

作者提出 Hierarchical Message Analyzer，简称 HMA。它不是只判断整个系统是否异常，而是为每个设备节点输出正常/异常标签。HMA 包含四部分：Preprocessor 将多变量时间序列压缩为节点初始特征；Adjacency Parser 根据 ICS 拓扑构造层次结构和层间邻接矩阵；Encoder 按“上行聚合、顶层交换、下行反馈”的路径进行层次化消息传递；Decoder 输出每个节点在每个时间点的状态。

论文主张：这种层次化消息传递能让节点嵌入既保留局部相关性，又吸收跨层级、跨工艺阶段的信息，从而比 GCN/GAT/TAGCN 等邻居聚合方法更适合 ICS 设备级异常检测。

## 3. 论文解决的具体问题

论文针对的是 ICS 中“异常发生在哪些设备上”的细粒度定位问题，而不是传统的系统级异常报警。

具体问题包括：

- 工业过程攻击会造成传感器读数、执行器状态、控制变量的异常偏离，需要及时识别。
- 只给出系统级异常标签不足以指导处置，因为停掉整个工业过程代价很高。
- 普通 GNN 的邻居聚合没有显式建模 ICS 的层次控制结构，节点表示容易被局部邻域主导。
- ICS 中同层设备之间的关系可能未知，但上下级监督关系通常可由工艺结构、控制回路或人工构造的 dummy 节点表达。

因此，论文要解决的是：如何设计一种符合 ICS 分层结构的 GNN 消息传递机制，使节点嵌入更适合设备级异常检测。

## 4. 创新点深度提炼

第一，任务层面从 graph-level 转向 node-level。论文强调输出每个设备的异常状态，而不是只判断整个系统是否异常。这一点对 ICS 响应很关键，因为安全人员需要定位到传感器、执行器或控制器。

第二，方法层面提出层次化消息传递。HMA 把消息路径改造成“底层设备向上汇报、顶层节点交换、再向下反馈”，对应 ICS 中现场层、控制层、监督层的结构逻辑。它改变的是消息流动路径，而不是简单做图池化或图级压缩。

第三，引入 meta-graph 组织 ICS 结构。单设备、控制回路、更大工艺阶段都可以被视为不同阶的 meta-graph，复杂 meta-graph 由监督节点和低阶 meta-graph 组成。这为构造层次消息通道提供了形式化基础。

第四，预处理不是直接喂原始时间序列，而是用 GEWA 加 PCA 得到压缩时间特征。GEWA 用指数衰减权重压缩滑动窗口，强调近期读数；PCA 进一步去冗余，实验中对性能影响明显。

第五，论文对鲁棒性、层数、消息步骤、迁移性和运行开销做了较系统的实验，不只给 baseline 表格。这使它比单纯刷指标的异常检测论文更完整。

## 5. 科学问题与研究假设

核心科学问题可以概括为：

- ICS 的层次监督关系是否应当显式进入 GNN 消息传递？
- 节点级异常检测是否需要比邻居聚合更“全局但有组织”的嵌入？
- 在设备关系不完全已知时，人工构造 dummy 层次节点是否仍能带来有效信息融合？

论文隐含的研究假设是：

- 设备异常不只体现在自身时间序列中，还体现在其与控制回路、工艺阶段和上层监督结构的关系中。
- 普通邻居聚合产生的节点嵌入过度局部化，难以表达 ICS 的纵向控制语义。
- 按层次路径调节消息传递，可以得到更平衡的 embedding composition，从而提升节点级检测性能。
- 过深的层次结构会带来过平滑，因此 2 到 3 层可能是更合适的折中。

## 6. 科学方法与技术路线

HMA 的技术路线是：

1. 输入为 `T x M` 的设备读数矩阵，M 表示设备或变量数量。
2. Preprocessor 对每个设备的时间序列做滑动窗口处理。窗口长度为 `n`，被划分为 `m` 段，每段用指数衰减权重做加权平均，形成 GEWA 特征。
3. 对 GEWA 输出做 arctan 归一化，避免不同量纲和幅值主导训练。
4. 使用 PCA 将特征压缩到维度 `gamma`，作为每个时间点、每个设备的初始节点向量。
5. Adjacency Parser 根据 meta-graph 和监督节点关系，把原图拆成若干层，并生成相邻层之间的邻接矩阵 `A(i)(i+1)`。
6. Encoder 先让底层消息逐层向上聚合，再在顶层进行消息交换，随后沿原路径逐层反馈到底层。
7. 对消息传递结果做线性变换和 ReLU，得到更新后的节点表示。
8. Decoder 使用 Log-Softmax 将每个节点表示映射为二分类状态：正常或异常。

其本质是把 GNN 的传播矩阵从单一邻接矩阵，改成一组受层次结构约束的传播矩阵序列。

## 7. 实验设计与实验步骤

可复核流程如下：

1. 数据：使用 SWaT、WADI、BATADAL、CISS 四个 ICS/水处理相关数据集，以及 CHD 车载 CAN 攻击数据集检验跨域泛化。
2. 标签：原始数据多提供系统级状态，论文将滑动窗口内包含异常状态的设备片段标为异常，用于节点级训练与测试。
3. 预处理：对每个设备流执行 GEWA、arctan 归一化、PCA，得到所有 baseline 和 HMA 共用的输入向量。
4. 图构造：现场设备连接到控制器；控制器之间可直接形成 2 层结构，也可连接到 CRP/dummy 节点形成 3 层或更深结构。
5. 模型：HMA 使用层次消息传递；对比 GAT、TAGCN、GLIN、AHGA、TPGraph、GSLCN、GAAL、LOF、AE、OCSVM、Isolation Forest。
6. 训练：PyTorch 1.7.1+cu110，服务器为 CentOS，32 处理器，约 125 GB 内存；输出为每个时间点每个设备的二分类状态。
7. 指标：F1、AUROC、AUPRC。
8. 消融：去掉 PCA；用普通 GCN 替代层次消息传递；改变结构层数 2 到 6；分别去掉聚合、顶层交换、反馈步骤。
9. 敏感性与鲁棒性：向邻接矩阵加噪声；随机删除结构边；改变异常样本比例；做跨数据集测试。
10. 结果核查：不仅比较精度，还检查运行时间、内存消耗、embedding composition，从性能、效率、解释性三方面验证 HMA。

## 8. 关键结果、结论与证据

论文报告 HMA 在五个数据集上总体优于 GNN 和非 GNN baseline。相对 GNN 类方法，平均 AUROC 提升分别为：SWaT 9.92%、WADI 18.92%、BATADAL 15.09%、CISS 15.47%、CHD 4.45%。

消融实验显示 PCA 对性能影响明显，说明初始时间特征质量对 HMA 很敏感。层次拆解加层次消息传递优于普通 GCN，支持作者关于“邻居聚合不足以表达 ICS 层次语义”的判断。

结构层数实验表明，2 层或 3 层通常效果最好；继续增加 dummy 层会使性能下降，作者将其归因于过平滑。消息步骤实验中，去掉聚合损失最大，其次是顶层交换，再是反馈，说明“先向上形成结构上下文”是 HMA 的关键。

鲁棒性实验显示，邻接噪声、少量结构边删除、异常比例变化对 AUROC 影响不大。但跨数据集迁移效果较差，说明模型学到的表示强依赖具体工艺变量空间和图结构。

## 9. 局限性与待解决问题

最重要的局限是节点级标签的真实性。论文说从系统级状态生成设备级标签：只要窗口内存在异常，该设备片段就被标为异常。这可能并不等价于真实“该设备异常”。如果攻击只影响少数设备，系统级标签扩展到所有设备会削弱节点级定位结论。

第二，HMA 依赖图结构和层次关系。对于真实工厂，控制回路、PLC 与现场设备映射、跨区域依赖未必完整可得；dummy 节点虽能补结构，但也引入人为假设。

第三，跨数据集迁移弱。论文已经承认 SWaT 训练的模型不能很好迁移到 WADI、BATADAL 或 CHD，未来需要 feature adaptation 和 graph adaptation。

第四，运行和内存成本高于普通 GCN。HMA 的等效邻接矩阵更稠密，训练/推理延迟更高；虽然单时间戳推理仍可满足秒级采样，但大规模 DCS/SCADA 部署还需要优化。

第五，解释性仍停留在 embedding composition 层面。它能说明哪些节点贡献了表示，但尚不能直接解释异常因果链、攻击阶段或物理约束违背。

## 10. 与本项目的关系

对“入侵检测与网络异常检测”综述而言，这篇论文的价值在于把 ICS 异常检测从多变量时间序列建模推进到“拓扑结构 + 设备级定位”。

它与图学习方向高度相关：不是学习自适应图，而是利用 ICS 层次拓扑重写消息传递路径。它也与知识图谱/威胁情报方向有连接，因为 meta-graph 本质上要求把设备角色、控制关系、工艺阶段结构化表达出来。

如果本项目关注工业异常检测，这篇可作为“结构先验增强 GNN”的代表；如果关注通用网络异常检测，它的启发是：网络节点角色和层级关系应进入传播机制，而不只是作为边或节点属性。

## 12. 本篇精华

- HMA 的核心不是“换一个 GNN 层”，而是把 ICS 的监督层次关系写进消息传递路径。
- 论文把异常检测目标设为设备级标签，试图解决系统级报警难定位的问题。
- GEWA + PCA 是重要前端，负责把每个设备的局部时间窗口压缩成可用于图传播的节点特征。
- 层次消息传递由上行聚合、顶层交换、下行反馈组成，分别对应信息汇报、跨阶段融合、上下文回传。
- 2 到 3 层结构效果最好，过深 dummy 层可能导致过平滑。
- 相比 GNN baseline，HMA 在 SWaT、WADI、BATADAL、CISS、CHD 上均报告 AUROC 提升。
- 最大疑点是节点级标签由系统级状态派生，可能不足以证明真实设备定位能力。
- 论文未来价值在于把工艺拓扑、控制语义和图表示学习结合，而不是单纯处理时间序列。
