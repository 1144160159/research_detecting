# [577] XIPHOS: Adaptive In-Vehicle Intrusion Detection via Unsupervised Graph Contrastive Learning

## 2. 中文翻译与核心摘要
这篇论文提出 XIPHOS，一个面向车载网络的无监督、自适应入侵检测框架。它不把 CAN 报文简单当作二维时间序列，而是把窗口内 CAN 流量转成图结构：用 TCG 捕捉 ID 转移与时序统计，用 CRG 捕捉连续报文和同 ID 报文之间的耦合关系。随后用图对比学习最大化两种增强视图之间的互信息，学习节点级和图级表示。最后，使用类似 Kitsune 的分层特征映射与集成自编码器，把正常样本的重构误差分布建模为单高斯模型，用显著性水平判断异常。

核心目标不是再做一个有监督分类器，而是在攻击标签稀缺、类别极不平衡、真实车载攻击更隐蔽的场景下，构造一种能从正常通信行为中学习结构规律的检测机制。

## 3. 论文解决的具体问题
论文针对 IVN/CAN 入侵检测中的四个具体痛点：

1. 原始 CAN 数据多被当作时间序列或矩阵处理，难以表达 CAN ID 之间的周期性、转移关系和耦合结构。
2. 有监督模型依赖高质量攻击标签，但真实车载环境中攻击样本少、标注昂贵、类别不平衡严重。
3. 无监督模型虽能摆脱标签依赖，但容易受噪声和初始分布影响，结果不稳定，尤其在小样本和隐蔽攻击下表现弱。
4. 现有方法常忽略车端实时部署约束，缺少车云协同下的推理延迟与资源可行性验证。

## 4. 创新点深度提炼
第一，论文把 CAN 入侵检测明确建模为图表示学习问题。TCG 提取窗口级时序统计特征，CRG 建立报文级邻接关系，使 CAN ID 的传输规律和同 ID 消息的上下文关系都进入模型。

第二，XIPHOS 的图对比学习不是只做图-图或节点-图对比，而是同时最大化节点-节点与图-图增强视图之间的互信息。这让模型既能学习局部报文级变化，也能保留窗口级全局结构。

第三，检测端没有直接用普通聚类器，而是用分层特征聚类映射加集成自编码器，再对多个 RMSE 误差信号做单高斯建模。这比单一重构误差阈值更能表达不同特征子空间的异常偏移。

第四，论文把“自适应”落在两个层面：模型可以用不同阶段的正常样本重新训练以适应数据漂移；同时支持图级检测和节点级检测两种粒度。

## 5. 科学问题与研究假设
科学问题可以概括为：在没有攻击标签、攻击样本稀缺且车载通信模式随时间变化的条件下，能否通过图结构化建模和互信息最大化学习到足够稳定的正常行为表示，从而检测伪造和伪装类攻击？

论文隐含的研究假设包括：

- CAN 报文流中存在稳定的结构不变量，例如 ID 转移模式、同 ID 报文耦合关系、窗口级统计结构。
- 攻击即使不明显改变时间频率，也会在图表示空间或特征组合重构误差上产生偏移。
- 图对比学习能在无标签条件下提取比普通时序模型更有判别力的表示。
- 用正常样本学习误差分布，比依赖少量攻击标签训练分类边界更适合真实车载 IDS。

## 6. 科学方法与技术路线
技术路线是“三段式”。

第一段，图结构化生成。将 CAN 流按窗口大小 `W` 切分。TCG 中每个不同 CAN ID 是节点，ID 转移形成有向边，并提取节点数、边数、最大度等统计量补充到报文特征。CRG 中每条 CAN 报文是节点，边包括相邻报文连接和同 ID 报文连接。最终得到图 `G=(X,A)`。

第二段，图对比表示学习。对邻接矩阵做边扰动，形成两个增强视图；用两个 GNN 编码器得到节点级表示和图级表示；用 MLP 投影头映射到对比空间；通过 JS 互信息下界训练判别器，同时优化节点-节点和图-图互信息。

第三段，自适应异常分类。将图级或节点级 embedding 输入分层聚类映射，按特征相关距离把维度划分为多个小组；每组送入集成层自编码器，输出层再学习 RMSE 模式；最终把集成层和输出层的多个 RMSE 作为高维误差信号，用单高斯模型和显著性水平 `α` 判定异常。

## 7. 实验设计与实验步骤
可复核流程如下：

1. 数据：使用 Car Hacking 和 ROAD。前者包含 DoS、Fuzzy、Gear spoofing、RPM spoofing 等伪造类攻击；后者包含真实车辆上的 masquerade 攻击，更隐蔽。
2. 预处理：将十六进制 CAN ID 与 payload 转十进制；ROAD 先用 CAN-D 生成标注，再按 CAN ID 和时间戳对齐原始日志；统一整理为 ID、8 字节数据和标签格式。
3. 图构造：按窗口切分 CAN 流；构造 TCG 提取窗口统计特征；构造 CRG 生成邻接矩阵；形成图集合。
4. 模型/基线：XIPHOS 与 RF、MLP、LSTM、EfficientNet、MobileNetV3、CANet、DAGMM、MSFlow、MTGFlow、G-IDCS 等比较。
5. 训练：GCL 阶段不使用攻击标签；AHC 阶段只采样正常样本学习正常行为的误差分布。
6. 指标：Accuracy、Precision、Recall、F1-score、AUC、FPR，并额外比较车端和云端推理时间。
7. 消融/敏感性：考察 GNN hidden size、batch size、边扰动比例 `ρ`、SGM 显著性水平 `α`、AHC 正常样本数 `nt`；同时替换上游图表示方法和下游无监督分类器。
8. 结果核查：重点看 ROAD 上的 F1、AUC 与 FPR，因为 ROAD 的伪装攻击更接近真实威胁；同时核查 Jetson Orin Nano 上是否满足毫秒级实时推理。

## 8. 关键结果、结论与证据
在 Car Hacking 上，XIPHOS 几乎达到完美检测，原因是伪造攻击会明显改变周期性或造成消息冲突，图结构很容易捕捉这种异常。

在 ROAD 上，平均 F1-score 为 74.97%，AUC 为 75.15%。绝对值不算夸张，但在无攻击标签条件下已经优于论文比较的无监督方法，并接近部分有监督模型。更关键的是，XIPHOS 在两个数据集上的 FPR 分别只有 0.19% 和 0.32%，说明它不是靠大量误报换召回。

消融实验表明，上游 GCL 和下游 AHC 都不可替代。用 InfoGraph、CMVRLG 替换 GCL 会损失特征表达；用 K-means、FCM、GMM 替换 AHC 则会暴露普通聚类对初始分布和噪声敏感的问题。

## 9. 局限性与待解决问题
本次正文包未截断，因此理解不受缺页影响；但本地未提供代码包，源码实现细节仍需回到作者仓库复核。

方法层面的局限主要有四点。第一，ROAD 上 F1 和 AUC 仍有限，说明面对只改 payload、不改时序的高级伪装攻击，图结构表示并不能完全解决问题。第二，AHC 对正常训练样本质量敏感，若正常样本覆盖不足，误报可能上升。第三，显著性水平 `α` 等阈值仍需要数据集级调参，跨车型泛化还没有被充分证明。第四，若攻击者了解 XIPHOS 的图构造和 GNN 表示机制，可能构造针对图结构或 embedding 的规避攻击。

## 12. 本篇精华
- XIPHOS 的核心不是“换一个分类器”，而是把 CAN 异常检测前移到结构表示学习：先把 CAN 流转成图，再做无监督检测。
- TCG 负责长期时序统计，CRG 负责短期报文耦合，两种图视角共同弥补普通时间序列建模的结构盲区。
- 节点-节点加图-图互信息最大化，是论文相对 InfoGraph 类方法的重要增强。
- AHC 的价值在于把 embedding 的不同特征子空间分开重构，再用多个 RMSE 信号联合判定异常。
- ROAD 上性能明显低于 Car Hacking，说明高级 masquerade 攻击仍是车载 IDS 的核心难题。
- 极低 FPR 是论文最有部署意义的结果，因为车载 IDS 不能靠频繁误报换取高召回。
- 论文把车端 Jetson 推理延迟纳入验证，比只在服务器上报告精度更接近工程落地。
