Abstract—Encrypted malicious trafﬁc detection aims at identifying malicious activities without decrypting network trafﬁc,
which is essential for cybersecurity. Existing methods have shown
effective performance in encrypted malicious trafﬁc detection,
but their heavy reliance on labeled datasets presents a challenge. This paper presents CoMDet, a contrastive multimodal
pre-training approach, to detect encrypted malicious trafﬁc.
CoMDet leverages three independent Transformer encoders to
learn multimodal feature representations from encrypted trafﬁc
based on unlabeled data in the pre-training phase. Meanwhile,
we introduce a novel inter-modal contrastive learning method
to enhance feature representation by maximizing the mutual
information among the modalities. Subsequently, we ﬁne-tune
the pre-trained model using limited labeled data. Experimental
results demonstrate that CoMDet outperforms the existing semisupervised learning methods and achieves comparable performance with existing supervised learning methods. It obtains an
average ACC of 92% and an average macro-F1 of 86% with
only 80 labeled samples in each malicious category. We conduct
an investigation on the ﬁne-tuning dataset size and discover that
as the dataset size increases, the performance of CoMDet is
increasingly comparable to existing supervised learning methods.
Index Terms—Encrypted malicious trafﬁc detection, Contrastive multimodal pre-training, Model ﬁne-tuning, Transformer encoder

I. INTRODUCTION
Nowadays, the extensive use of network trafﬁc encryption
plays a crucial role in ensuring the security of data transmission. As of January 2023, encrypted trafﬁc using Hypertext
Transfer Protocol Secure (HTTPS) accounted for 94% of all
trafﬁc in the products and services offered by Google [1].
Nevertheless, trafﬁc encryption is double-edged, as malicious
users may exploit it to conceal illegal activities, including
network attacks within encrypted channels (such as scanning,
brute-force attacks, and data exﬁltration), encrypted trafﬁc
generated by malware (such as cryptocurrency mining), and
illicit encryption applications, for instance, The Onion Router
(TOR) and unauthorized Virtual Private Network (VPN).
According to the latest threat research report released by
Zscaler [2], attacks based on encrypted channels have shown
a continuous upward trend, rising from 57% in 2020 to 85%
in 2022. The disparity between encrypted malicious trafﬁc
and benign trafﬁc undermines the effectiveness of existing
detection methods, since more existing methods are primarily

Methods for detecting encrypted malicious trafﬁc can
be roughly divided into two categories: machine learningbased and deep learning-based methods. Most early machine learning-based detection methods often relied on prior

contrastive multimodal pre-training phase and ﬁne-tuning
phase. As for the ﬁrst phase, we pre-train three Transformer
encoders to learn general feature representations from unlabeled data. Initially, we transform each trafﬁc session into
embeddings using three modalities: SSL/TLS handshake payload bytes, packet length sequences, and packet arrival-time
interval sequences. Subsequently, we employ three individual
Transformer encoders to encode each modality. Transformer
encoders are capable of generating accurate representations
of encrypted trafﬁc by maximizing the mutual information
among modalities in the same latent space. As for the second
phase, CoMDet introduces a new ﬁne-tuning scheme based on
limited labeled samples to achieve comparable performance
with existing methods.

II. RELATED WORK
A. Encrypted Malicious Trafﬁc Detection
Non-encrypted network trafﬁc takes on completely different
forms after encryption. It renders existing malicious trafﬁc
detection methods, which typically rely on analyzing plaintext features, ineffective. With the advancement of machine
learning, researchers adopt various machine learning methods
to detect encrypted malicious trafﬁc such as K-Nearest Neighbors (K-NN) [5], Decision Tree (DT) [6], Random Forest
(RF) [7]. For instance, MaMPF [8] leverages packet types
and packet arrival-time interval sequences to train a Markov
model, and achieves 96.4% TPR and 0.2% FPR performance
on a real-world dataset from campus network. MEMTD [9]
extracts modalities features from encrypted trafﬁc to enhance
detection performance, and outperforms other single-modal
deep learning methods. Most machine learning-based methods
rely on manually-crafted features that require prior domain
knowledge to distinguish between malicious and benign trafﬁc
[10].
Deep learning-based methods have emerged in recent years.
These methods automatically extract deep features from raw
network trafﬁc. This enables an end-to-end detection of encrypted malicious trafﬁc. ET-BERT [11] pre-trains deep contextualized datagram-level representations from large-scale
unlabeled data, and achieves remarkable performance after
ﬁne-tuning with task-speciﬁc labeled data. FC-Net [12] enhances performance under conditions with limited samples
using meta-learning techniques. It is not conﬁned to speciﬁc
datasets or attack types. Rezaei et al. [13] employ a 1D-CNN
(1Dimension-Convolutional Neural Network) model that takes
packet arrival-time interval sequences and packet arrival-time
interval sequences as input, and achieves almost the same
accuracy as supervised methods based on only 20 samples in
each class. Although deep learning-based methods outperform
machine learning-based methods in detection performance,
they heavily rely on labeled data. Collecting and labeling
encrypted malicious network trafﬁc in a real-world network
environment presents an exceptionally daunting challenge.

III. C O MD ET
In this section, we present CoMDet which includes two
phases: (1) contrastive multimodal pre-training, and (2) ﬁnetuning by limited data.
In the contrastive multimodal pre-training phase, we initialize three individual Transformer encoders to map SSL/TLS
handshake payload bytes, packet length sequences, and packet
arrival-time interval sequences to the same latent space. We
propose an inter-modal contrastive learning method to optimize the feature representation of multiple modalities. It enhances the mutual information among modalities and reduces
noise information by using contrastive learning among multimodal feature vectors. As a result, the Transformer encoders
learn a better representation that preserves the latent shared information among modalities while removing modality-speciﬁc
noise.
In the ﬁne-tuning phase, we ﬁne-tune the pre-trained model
based on limited labeled data. Additionally, we classify the
encrypted trafﬁc categories by a fully connected layer, which
receives multimodal features in latent space as input. CoMDet
is capable of efﬁciently ﬁne-tuning with limited data, capitalizing on its well-learned representations. The overview of
CoMDet is shown in Fig 1.

Table II summarizes the detection performance and the

the detection performance of CoMDet, but this improvement
slows down as the dataset size increases. It can be seen
from Table II, the ACCavg of CoMDet improved by 8.70%
when the number of samples increased from 10 to 20 in

4.12% when the number of samples increases from 40 to 80.

distinguishable encrypted trafﬁc samples can be captured with
20 to 40 samples, and additional encrypted trafﬁc capture
provides relatively limited classiﬁcation information.
The 1D-CNN method only uses packet arrival-time interval
sequences and packet sequences to detect encrypted malicious
trafﬁc, which performs worse than the FC-Net which uses
encrypted trafﬁc payloads as input. This illustrates that encrypted trafﬁc payloads are more suitable than ﬂow statistical
features in training with limited data. FC-Net learns a pair of
feature maps from a pair of encrypted trafﬁc samples based
on meta-learning. However, FC-Net falls short in conducting
a comprehensive fusion analysis of diverse features, resulting
in an inferior performance to CoMDet. CoMDet outperforms
others with training on limited data since learning the mutual
information among multiple modalities during the contrastive
multimodal pre-training phase.
