Self-Supervised Deep Clustering Method for
Detecting Abnormal Data of Wastewater
Treatment Process
Honggui Han , Senior Member, IEEE, Meiting Sun, Fangyu Li , Zezhong Liu, and Chen Wang

Abstract—In wastewater treatment process (WWTP),
abnormal data seriously reduce data quality rendering the
application techniques impractical. The implementation of
abnormal data detection is challenging due to the nonlinear
nature of WWTP. Typically, constructing an accurate
anomaly detector requires large amounts of labeled data,
which is difficult in practice. Thus, a self-supervised
memory enhanced deep clustering method (SMEL) is
proposed to detect abnormal data without using any labels.
First, a self-supervised deep clustering network, combining
stacked autoencoders and the clustering algorithm,
leverages unlabeled data to extract nonlinear features and
capture the normal pattern. Second, an adaptive weight
objective function, jointly optimizing the reconstruct error
and clustering error, is designed to obtain a robust clustering structure. Third, double memory enhanced modules,
consisting of a centroid memory and a score memory,
are presented to enhance training stability and detection
accuracy. Finally, experiments on three WWTP datasets
show that SMEL achieves the highest detection accuracy.
Index Terms—Abnormal data detection, adaptive weight
objective function, double memory enhanced modules,
self-supervised deep clustering network, wastewater treatment process (WWTP).

I. INTRODUCTION
ASTEWATER treatment process (WWTP) plays an essential role in removing the organic wastes and producing the renewable water source [1]. With recent progress in
advanced techniques, WWTP has been equipped with various
sensors and transmission equipment for collecting, transmitting,
and storing time series. These time series, implying the operation
status of WWTP, have strong nonlinearity and time-varying
characteristic. To improve effluent quality and guarantee stable
operation, it is necessary to analyze the data generated by the
treatment process and obtain the relevant information about its
operation status [2].
Abnormal data of WWTP, which are caused by various reasons, have been an inevitable problem [3]. Specifically, abnormal
data are caused by working condition faults or transmission
faults, among which working condition faults have been widely
studied. Abnormal data in WWTP caused by transmission faults
are rarely mentioned. The article mainly focuses on the transmission faults, such as the disturbance of unstable current,
sensor faults, communication losses, and changed environment.
Abnormal data are significantly different from or inconsistent
with the normal existing data. The existence of abnormal data
makes the distribution of training data deviate, which results
in the model unable to extract normal features [4]. Moreover,
as WWTP demands stability and reliability, maintainers need to
detect abnormal operations and implement specific maintenance
operations [5]. Thus, to detect abnormal data, one straightforward idea is that abnormal data detection method is used.
In the past few decades, the existing abnormal data detection
studies can be broadly divided into three categories: statisticalbased, model-based, and clustering-based approaches. The
statistical-based method assumes that the data follow a predetermined distribution or probability model and identifies abnormal
values that deviate from such distribution or are in the region
of low probability [6], [7], [8]. These statistical-based methods always assume the normal data follow a certain of data
distribution. Nevertheless, we cannot always have this kind of
prior data distribution knowledge in practice, especially for high
dimensional real data sets. For clustering-based methods, these
methods calculate the corresponding anomaly scores based on
the density information of the data point and its neighboring
data and finally compare the value with a preset threshold to
determine whether the data are abnormal [9], [10], [11]. The

clustering-based methods have two main limitations. First, these
methods assume that the shape and form of the clusters are
considered. Second, as the number of dimensions of the data
increases, the detection performances of these methods decrease.
As a promising method, the model-based methods, which use
a predictive model to characterize the normal data and then
detect abnormal values as deviations from the model, have been
studied in recent years [12], [13]. Shakiba et al. [14] addressed
fault diagnosis for transmission lines using the convolutional
neural network. The data used in [14] were generated due to
device faults. However, the abnormal data studied in this article
are caused by transmission faults due to the unstable working
environment. Although the above model-based methods have
achieved good results in abnormal data detection, these methods
rely too much on manually setting of attribute relationship.
Human intervention is more serious, limiting its robustness and
generalization ability. In addition, these methods are shallowly
structured, limiting their learning and classification capabilities.
Since WWTP data are complex with nonlinearity and timevarying characteristic, these methods may not be flexible and
accurate enough.
As a part of model-based methods, deep learning methods
with the strong ability in nonlinear extraction and data modeling have obtained great achievements in the field of abnormal
data detection. Patnaik et al. [15] combined the convolutional
network and the long short-term memory network to construct a
supervised data extraction system for detecting automated web
page. Pan et al. [16] proposed a multiscale analysis method for
rolling bearing fault diagnosis by integrating the inner product
for capturing feature and the kernels with different sizes for
generating better performances. Yu et al. [17] presented a novel
deep common spatial pattern model to transform data into another mapping with data of different categories. These categories
have maximal differences in their measures of dispersion. However, the performance of feature extraction was not satisfactory.
Luo et al. [18] adopted stacked recurrent neural networks to
detect anomalies by iteratively updating the spare coefficients.
However, it demanded a robust mechanism to generate large
reconstruction error on the anomalies. Wang et al. [19] presented
a stacked autoencoders (SAE) model for fault classification
to address the problem of deep features contain information
unrelated to faults. Hu et al. [20] utilized a stacked sparse
autoencoders model to learn generic driving behavior features
and introduced the dropout technology to avoid overfitting. In
[21], a convolutional deep neural network was presented for
one-class classification. In the method, the labeled data from an
unrelated task were utilized to perform feature learning. Though
much progress has been done for abnormal data detection, most
of the existing works always assume that training data are labeled
for building the abnormal data detection model or classifier.
However, it is difficult and time-consuming to obtain a great
quantity of labeled data required in the training process.
To detect abnormal data without using any labels, the integration of clustering-based and deep learning method has
been considered as a promising solution. Lu and Hanjalic [22]
presented a context-dependent scaling factors based spectral
clustering method that was utilized to detect acoustic events

from audio streams. Lin et al. [23] proposed a density clustering
algorithm employed on pretrained deep features to detect unconstrained face images. Although the detection performances were
improved in [22] and [23], they performed feature extraction,
independent of the clustering task. The feature distribution in
the extracted feature space cannot be well clustered to detect
abnormal data. To conquer the problem, Xie et al. [24] integrated
a deep neural network with clustering method, instead of only
using the deep network to detect abnormal data. Yang et al.
[25] designed an joint objective function including a network
reconstruction loss and a clustering loss to perform clustering
and network training simultaneously. Similarity, Song et al. [26]
took advantage of the coupling nature of clustering and outlier
detection to design a deep clustering based fair outlier detection
method. However, these deep clustering methods have two main
drawbacks. First, the centroid of the clustering layer is randomly
initialized before each iteration, resulting in training instability.
Second, the threshold of anomaly score is manually set, making
it unable to adapt to the change of data distribution.
Motivated by the above analysis, the article proposes a selfsupervised memory enhanced deep clustering method (SMEL)
to detect abnormal data of WWTP. The proposed SMEL combines the advantages of clustering methods and deep learning
methods. Compared with the traditional clustering-based methods, the proposed SMEL does not require the assumption of
the shape of the clusters and can capture the nonlinear characteristic of WWTP data through nonlinear dimension reduction.
Compared with the deep learning-based methods, the proposed
SMEL is a self-supervised method, which does not require a
great quantity of labeled data in the training process. The main
contributions are summarized as follows.
1) A self-supervised deep clustering network is proposed
for efficiently capturing nonlinear representations and
automatically detecting abnormal data without using any
labels.
2) An adaptive weight objective function is developed to obtain a robust clustering structure by adopting the adaptive
weight mechanism.
3) Double memory enhanced modules are designed to enhance training stability and detection accuracy by addressing the problems of initial centroid randomization
and abnormal score threshold presetting.
The rest of this article is organized as follows. The problem
formulation is presented in Section II. The proposed SMEL is
designed in details in Section III. The proposed SMEL is tested
on two benchmark datasets and a real WWTP dataset to manifest
its performances in Section IV. Finally, Section V concludes this
article.

III. METHOD
A. Architecture of the Proposed SMEL
The overall architecture of the proposed SMEL is presented
in Fig. 1 and is composed of three parts: a self-supervised deep
clustering network; an adaptive weight objective function; and
double enhanced memory modules.
Specifically, original data X with the shape of RT ×N are
collected though N sensors installed in WWTP and are fed into
the deep clustering network along the temporal dimension. The
self-supervised deep clustering network includes an encoder

layer, a clustering layer, and a decoder layer. The instance xi
is fed into the encoder layer to extract the nonlinear feature
representation. The clustering layer captures the robust normal
pattern through several iterations. The decoder layer is applied
to reconstruct input instance. To optimize the parameters of the
self-supervised deep clustering network, the adaptive weight
objective function is designed by integrating the reconstruction error and the clustering error. The function is utilized to
realize the constraint of feature learning making the clustering
structure more suitable for anomaly detection. Meanwhile, to
enhance training stability and detection accuracy, double memory enhanced modules, consisting of a centroid memory and
a score memory, are proposed through building up recurrent
connections with the clustering layer and caching the cluster
centroids and feature representations, respectively. The centroid
memory module generates a centroid before each iteration by
calculating historical clustering centroid. The score memory
module is applied to calculate anomaly score thresholds and
assign anomaly labels.

D. Double Memory Enhanced Modules

memory enhanced modules, consisting of a centroid memory
and a score memory, are developed. The centroid memory module stores the cluster centroid of each iteration process, while the
score memory module stores feature points and pseudo-labels

updated alternately during uninterrupted iterations. A memory

the memory block Mb with the input feature If during training

V. CONCLUSION
In this article, a self-supervised memory enhanced deep clustering method (SMEL), including a self-supervised deep clustering network, an adaptive weight objective function, and double
memory enhanced modules, was proposed for detecting abnormal data in WWTP without using any labels. The self-supervised
deep clustering network with the adaptive weight objective
function projected time series into a latent subspace to extract
nonlinear structure and iteratively updated the clustering layer
to obtain the normal pattern by taking into the negative impact
of noise account. Furthermore, the double memory enhanced
modules were used to produce the centroids before each iteration
for enhancing training stability and provide pseudo-labels for
updating the parameters of encoders and decoders. Experimental
results demonstrated that the proposed SMEL achieved superior
anomaly detection accuracy over eight competitors under three
WWTP datasets, and obtained an acceptable running time that
was much less than the specific interval, facilitating the promotion of online abnormal detection scenarios. In the future, we
plan to extend our work in two directions. First, we will extend
the deep clustering algorithm to online scenarios for WWTP.
Second, an optimization strategy will be designed to improve
detection efficiency.
