# [497] Multimodal VAD: Visual Anomaly Detection in Intelligent Monitoring System via Audio-Vision-Language

## 1. 基本信息

论文发表于 IEEE Transactions on Instrumentation and Measurement，2025 年，DOI 为 `10.1109/TIM.2025.3578702`。作者来自天津大学与兰州交通大学。

研究对象是弱监督视频异常检测，核心场景是智能监控系统中的异常事件识别。论文将视觉、音频、文本三种模态共同用于 VAD，提出一个粗粒度与细粒度协同的双流网络。正文包完整，未截断；本地代码包状态为“未发现”。

## 2. 中文翻译与核心摘要

这篇论文的核心问题可以概括为：传统视频异常检测大多依赖视觉单模态，或者只把光流、深度图、语义图等视觉派生信号当作补充，表达能力有限；而真实监控中的异常事件往往同时伴随声音线索和语义类别线索，例如打斗、爆炸、枪击、交通事故等。作者希望把视频、音频和文本先验统一到一个弱监督 VAD 框架中。

论文提出 Multimodal VAD，一个双流结构。粗粒度流负责将时序建模后的视觉特征与音频特征融合，并用对比约束增强正常与异常片段之间的判别边界。细粒度流则通过异常感知上下文提示 ACP，把异常类别知识和视觉信息注入文本提示，再与视觉特征做图文匹配，从而细化异常类别和时间位置判断。最终模型在 UCF-Crime 和 XD-Violence 两个大规模异常检测数据集上取得优于多数现有方法的结果。

## 3. 论文解决的具体问题

论文针对的是弱监督视频异常检测中的三个具体痛点。

第一，视觉单模态不足。许多异常事件在画面上并不总是显著，例如远距离冲突、遮挡下的暴力行为、突发声响对应的危险事件，仅依靠 RGB 或视觉派生特征容易漏检。

第二，弱监督标签粗糙。训练阶段只有视频级标签，模型知道一个视频是否含异常，却不知道异常发生在哪些帧、属于哪个具体片段。传统 MIL 方法容易把背景、上下文偏置或共现物体当作异常证据。

第三，视觉语言模型虽有语义能力，但直接迁移到 VAD 不够充分。已有 VadCLIP、TPWNG、PEL4VAD 等工作主要利用视觉-文本关系，本文进一步加入音频，并设计“粗粒度支持细粒度”的信息流，使音视频融合结果反过来指导文本提示和细粒度定位。

## 4. 创新点深度提炼

论文最重要的创新不是简单“多模态拼接”，而是把三种模态分配到不同检测粒度中。音频与视频在粗粒度阶段融合，用来判断视频片段是否异常；文本在细粒度阶段作为异常类别语义锚点，用来增强类别级和时间边界级判别。

第二个创新是 ACP，即 abnormal-aware context prompt。它不是只写一个固定文本模板，而是把类别标签、可学习上下文参数、由视觉异常信息动态对齐得到的提示向量结合起来，使文本提示携带异常相关视觉上下文。

第三个创新是 coarse-support-fine 策略。粗粒度流输出的异常置信度不仅用于粗分类，还作为权重参与细粒度图文对齐，相当于先用音视频定位潜在异常区域，再用文本语义判断异常类型和细节。

第四个创新是对比约束。作者基于粗粒度异常分数，把异常视频和正常视频分别划分为高分、低分 mini-bag，通过 InfoNCE 拉近异常视频中高低置信片段的相关性，同时与正常片段区分，试图处理弱监督中的模糊片段和困难样本。

## 5. 科学问题与研究假设

论文背后的科学问题是：在只有视频级弱标签的条件下，音频、视觉和文本三种异构信息能否互补，从而提升异常事件的时间定位、类别识别和鲁棒性？

主要研究假设有四个。第一，音频信号携带与异常事件相关的环境线索，能够补充视觉遮挡、低分辨率和远景监控的不足。第二，CLIP 类视觉语言预训练模型中的语义空间可以迁移到 VAD，使异常类别标签不只是分类名，而是可对齐的语义原型。第三，粗粒度异常置信度可以为细粒度检测提供可靠注意力，使图文对齐聚焦于更可能异常的片段。第四，可学习且异常感知的 prompt 比固定 prompt 更适合复杂监控异常场景。

## 6. 科学方法与技术路线

输入是一段未裁剪音视频序列，训练标签是视频级正常/异常标签。视频被切成若干 segment，每个 segment 分别提取视觉特征和音频特征。

视觉侧使用 CLIP ViT-B/16 提取帧级或片段级视觉特征，然后通过受限窗口 Transformer 编码器和轻量 GCN 做时序建模，得到包含全局与局部时间关系的视觉表示。音频侧使用 VGGish 提取音频特征。粗粒度流将音频特征与时序视觉特征做跨模态融合，再通过二分类器得到异常置信度。

细粒度流围绕文本提示构造展开。异常类别标签经过 tokenizer 得到文本嵌入，再与可学习上下文参数拼接。随后，模型用视觉异常信息动态调整 prompt，形成 ACP。最后计算视觉特征与类别文本嵌入之间的相似度矩阵，通过 top-k MIL 机制得到类别级预测。

总体损失由四部分组成：粗粒度二分类 BCE、细粒度 BCE、InfoNCE 对比损失、文本嵌入约束损失。最终异常分数取粗粒度流和细粒度流输出中的较大值。

## 7. 实验设计与实验步骤

数据：使用 UCF-Crime 和 XD-Violence。UCF-Crime 包含 1900 个真实监控视频、13 类异常，训练集约 810 个异常视频和 800 个正常视频。XD-Violence 包含 4854 个带音频视频、约 217 小时、6 类异常，训练集约 1905 个异常视频和 2049 个正常视频。

预处理：将未裁剪视频划分为固定数量 segment；视觉用 CLIP ViT-B/16 提取特征，音频用 VGGish 提取特征；音频和视觉特征在粗粒度层面对齐。

模型/基线：与无监督 VAD、传统 MIL 弱监督方法、I3D/VideoSwin 特征方法、音视频方法、视觉语言方法比较，包括 AVVD、UR-DMU、MGFN、VadCLIP、TPWNG、PEL4VAD 等。

训练：PyTorch 实现，NVIDIA RTX 3090 训练。UCF-Crime 与 XD-Violence 的 batch size 分别设为 64 和 128，epoch 分别为 40 和 60。优化器为 Adam。损失权重中，`lambda1` 分别取 0.1/0.15，`lambda2` 分别取 `1e-1`/`2e-4`。

指标：XD-Violence 使用 frame-level AP；UCF-Crime 使用 frame-level AUC 和 AUCno-n。细粒度实验还报告不同 IoU 阈值下的 mAP 以及平均 mAP。

消融/敏感性：论文分别验证输入模态组合、时序单元、ACP、对比约束、损失项、loss 权重、可学习 prompt 数量、视频 segment 数量、batch size 对性能的影响。

结果核查：需要同时看粗粒度表格、细粒度表格和定性曲线。作者强调该方法粗粒度未必在所有指标上压倒 VadCLIP，但细粒度定位和类别级表现更强，说明文本 prompt 与粗粒度异常权重确实改善了异常边界与类别对齐。

## 8. 关键结果、结论与证据

在 UCF-Crime 上，论文报告该方法在粗粒度检测中超过多种无监督和弱监督方法，并与 VadCLIP 接近；在细粒度比较中优于当前对比方法。这个现象很关键：它说明方法的强项不是单纯提高视频级异常判断，而是更好地对齐异常发生时间和异常类别。

在 XD-Violence 上，方法的优势更明显。与 TPWNG、VadCLIP、PEL4VAD 相比，AP 分别提升约 2.64%、1.81%、0.73%。由于 XD-Violence 有音频，三模态方法在该数据集上更能发挥作用。

消融表明，视频+文本的提升通常大于视频+音频，说明文本语义对异常类别判断更直接；但视频+音频+文本整体最优，说明音频仍能补充视觉中的事件强度和环境线索。ACP 加入后，异常边界更清楚，正常与异常分数曲线分离更明显。

## 9. 局限性与待解决问题

第一，方法依赖预提取特征，尤其是 CLIP 和 VGGish。论文没有深入讨论当监控场景与预训练数据分布差异很大时，视觉语言语义和音频特征是否会失效。

第二，音频并非所有监控场景都可用。很多城市摄像头、工业摄像头没有高质量音频，或者存在隐私与噪声问题。模型在纯视觉退化场景下的可靠性仍需进一步验证。

第三，ACP 依赖异常类别文本标签，因此更适合已知异常类别或半开放集合。面对未知异常、跨领域异常、网络安全日志类异常时，需要重新设计“异常语义”的表达方式。

第四，论文主要证明检测性能，解释性仍偏弱。虽然引入文本，但没有充分展示模型生成可读原因、因果链或自然语言解释的能力。

第五，代码未公开或本地未发现，复现仍有不确定性，特别是 segment 划分、top-k 设置、音视频对齐细节、prompt 参数数量等实现细节需要回到作者代码或 PDF 表格进一步核查。

## 10. 与本项目的关系

该论文与网络安全异常检测不是直接同域，但方法论上有中等相关性。它提供了一个“多源信号 + 弱标签 + 语义先验”的异常检测范式，可迁移到多源安全监测场景。

对网络安全来说，视觉、音频、文本可类比为流量统计特征、主机/进程行为日志、告警文本/规则描述/攻击技战术知识。ACP 的思想可以对应为“攻击感知 prompt”或“异常类型上下文嵌入”，把 ATT&CK 技术、告警名称、漏洞描述等先验注入模型。coarse-support-fine 也适合安全场景：先用粗粒度模型筛选可疑时间窗，再用语义或规则知识做细粒度攻击阶段定位。

需要谨慎的是，视频异常具有连续帧结构和视觉语义，而网络安全数据常是异步、多粒度、强噪声事件流，不能直接搬用 CLIP 式图文相似度，需要重新设计跨模态编码器与时间对齐机制。

## 12. 本篇精华

1. 论文把 VAD 从“视觉特征分类”推进到“音频-视觉-文本协同判别”，尤其强调文本语义和音频事件线索的互补性。

2. 双流结构的关键是分工：粗粒度流用音视频融合判断异常置信度，细粒度流用 ACP 和图文对齐细化异常类别与时间边界。

3. ACP 是本文最有迁移价值的设计：它把异常类别文本、可学习 prompt、视觉异常上下文结合起来，使 prompt 不再是静态模板。

4. coarse-support-fine 策略解决了弱监督 VAD 的核心难点：没有帧级标签时，用粗粒度异常分数引导细粒度对齐。

5. 消融结果表明文本模态贡献通常大于音频模态，但三模态联合最优，说明异常检测需要语义方向和感知证据同时存在。

6. 方法在 XD-Violence 上优势更明显，因为该数据集天然包含音频，能体现三模态融合价值。

7. 对网络安全异常检测的启发是：可以把多源日志、流量、告警文本、威胁情报组织成类似的多模态弱监督框架。
