# [127] Darknet traffic classification and adversarial attacks using machine learning

## 1. 基本信息

- 题名：Darknet traffic classification and adversarial attacks using machine learning
- 中文题名：使用机器学习进行暗网流量分类与对抗攻击研究

- 年份：2023
- 来源：Computers & Security 127: 103098
- DOI：10.1016/j.cose.2023.103098
- 数据集：CIC-Darknet2020
- 任务类型：暗网/明网流量分类、应用类型识别、对抗混淆与鲁棒性分析
- 本地代码状态：未发现该论文对应开源代码包

## 2. 中文翻译与核心摘要

这篇论文的核心意思是：暗网的匿名性常被用于非法活动，因此需要自动化识别 Tor、VPN 等暗网相关流量，并进一步识别其背后的应用类型。作者在 CIC-Darknet2020 数据集上系统比较了传统机器学习、深度学习、图像化流量表示和数据增强方法，发现 Random Forest 在四类流量识别和八类应用识别上都最强。

论文不止停留在“分类准确率”层面，而是进一步问：如果攻击者知道分类器依赖的统计特征，能否通过修改应用层流量统计特征来逃避检测？作者构造了一种基于类别特征概率分布的混淆方法，把某些应用类别伪装成其他类别，验证 Random Forest 虽然正常情况下效果最好，但在对抗混淆下会明显退化。不过，如果训练集中包含一定比例的混淆样本，模型又能恢复较高识别能力。

一句话概括：这篇论文把 CIC-Darknet2020 上的暗网流量分类从“谁的 F1 更高”推进到“高 F1 模型在统计特征被操纵时是否可靠”。

## 3. 论文解决的具体问题

论文实际解决了三个层次的问题。

第一，暗网流量能否被稳定分类。作者不是只做 binary darknet vs clearnet，而是做四类流量分类：Tor、non-Tor、VPN、non-VPN。这比简单二分类更细，因为 Tor 和 VPN 都属于匿名通信技术，但统计特征并不完全相同。

第二，暗网或加密流量背后的应用类型能否识别。应用类别包括 Audio-Streaming、Browsing、Chat、Email、File Transfer、P2P、Video-Streaming、VOIP。这个任务更接近实际安全分析：监管或检测系统往往不只关心“是不是暗网”，还关心“里面在做什么”。

第三，分类器是否能抵抗对抗性流量伪装。作者假设攻击者可能修改应用层流量特征，例如包数量、间隔、端口、长度等，使 P2P、Email、Chat 等流量更像其他应用类别。论文用统计分布映射构造三类攻击场景：只混淆验证集、只污染训练集、训练和验证都存在混淆样本。

## 4. 创新点深度提炼

1. 从单纯分类性能扩展到对抗鲁棒性。  
   既比较模型，也验证最佳模型在特征分布被操纵时是否会失效，这是本文比许多 CIC-Darknet2020 分类论文更有价值的部分。

2. Random Forest 被证明是强基线，而不是复杂深度模型。  
   作者比较了 GBDT、XGBoost、k-NN、MLP、SVM、RF、CNN、AC-GAN，结果 RF 在流量分类和应用分类上都最优。这说明 CICFlowMeter 生成的统计特征本身高度结构化，树模型比把表格特征硬转成图像更适合。

3. 保留 IP 信息的处理很关键。  
   以往研究通常删除 Source IP 和 Destination IP。本文删除 Flow Id、Timestamp，但把源/目的 IP 拆成 octet 特征保留，最终形成 72 维特征。作者称初步实验显示保留 IP octet 会提升分类器表现。

4. 对 2D 图像化表示做了细粒度检查。  
   作者把 72 个特征填充成 9×9 灰度图，比较原始顺序、按 RF 特征重要性排序、按重要性中心化三种排列。CNN 在“重要特征中心化”下略好，但 AC-GAN 反而在原始排列下更好，说明表格特征图像化并不天然合理。

5. AC-GAN 数据增强的负结果有启发。  
   作者尝试用 AC-GAN 生成少数类样本，但生成样本能被 CNN 以 99%-100% 准确率识别为假样本，因此不适合增强。这是一个重要负结果：对网络流量统计特征，GAN 生成“看起来像”的图像不等于生成了统计上可用的流量样本。

6. 提出可逆的统计分布混淆方法。  
   作者用每个类别、每个特征的 100-bin 概率直方图计算类别间距离，再根据类别分布差异把一个类别的特征值映射到另一个类别更可能出现的区间。这不是标准 adversarial example 梯度攻击，而是面向流量统计特征的分布级混淆。

## 5. 科学问题与研究假设

核心科学问题可以拆成四个。

1. 在 CIC-Darknet2020 上，传统机器学习是否比深度学习更适合暗网流量统计特征分类？
   论文隐含假设：表格型流量统计特征具有强可分性，RF、SVM、XGBoost 等模型可能比 CNN/AC-GAN 更有效。

2. 类别不平衡是否是性能瓶颈？
   CIC-Darknet2020 中 Tor 样本极少，应用类别也明显不均衡。作者假设 SMOTE 或生成式增强可能改善少数类识别。

3. 将流量特征转为 2D 图像是否能受益于 CNN 的局部卷积？
   作者假设如果把重要特征放在相邻或中心位置，CNN 可能更好学习局部结构。

4. 高性能分类器是否会被统计特征混淆攻击击穿？
   作者假设攻击者只要掌握足够的流量统计知识，就能把某类应用流量伪装成另一类，降低 RF 的检测效果；反过来，防御者若在训练时见过部分混淆样本，也能恢复模型能力。

## 6. 科学方法与技术路线

论文技术路线是典型的“数据清洗-模型比较-增强实验-对抗分析”。

数据来自 CIC-Darknet2020，它融合 ISCXTor2016 和 ISCXVPN2016，原始流量由 Wireshark、TCPdump 捕获，再由 CICFlowMeter 提取流量特征。标签是层级式的：上层是 Tor、non-Tor、VPN、non-VPN，下层是八类应用。

预处理包括：删除 NaN 样本；删除 Flow Id 和 Timestamp；保留 Source IP 和 Destination IP，并拆成 octet 特征；所有特征做 min-max 归一化；最终使用 72 个特征。

模型比较包括两条线：一条是直接处理 1D 表格特征的 SVM、RF、GBDT、XGBoost、k-NN、MLP；另一条是将特征转成 9×9 灰度图后使用 CNN 和 AC-GAN 判别器。

数据增强包括两种：SMOTE 按 0%、20%、40%、60%、80%、100% 不同比例过采样少数类；AC-GAN 作为生成器尝试生成少数类样本，但最后被证明不实用。

对抗部分以 RF 为目标模型。作者先计算应用类别之间的统计距离，选出三组混淆关系：Audio-Streaming→P2P、Email→VOIP、Chat→Email。然后构造三种场景：验证集被混淆的逃逸攻击、训练集被混淆的数据投毒、训练和验证都含混淆样本的防御适应实验。

## 7. 实验设计与实验步骤

1. 数据  
   使用 CIC-Darknet2020。论文称原始数据集包含 158,659 个样本；清洗后表中流量类别样本数约为 141k 量级，其中 Tor 仅 1,393 条，类别极不均衡。应用类别中 P2P 最多，VOIP 最少。

2. 预处理  
   删除包含 NaN 的样本。删除 Flow Id、Timestamp。与部分前人不同，作者没有完全删除 IP 地址，而是把源 IP 和目的 IP 拆为多个 octet 特征。所有特征做 min-max normalization。应用分类使用 8 类标签，流量分类使用 4 类标签。

3. 模型/基线  
   表格模型包括 GBDT、XGBoost、k-NN、MLP、SVM、RF。深度模型包括 CNN 和 AC-GAN。CNN/AC-GAN 输入为 9×9 灰度图，即 72 个特征加零填充。主要对比前人包括 Lashkari 等的 CNN、Sarwar 等的 CNN-LSTM/CNN-GRU、Iliadis 和 Kaifas 的 RF 等。

4. 训练  
   使用 Python，主要库包括 scikit-learn、imblearn、TensorFlow/Keras、SciPy、Matplotlib、Seaborn。论文提到使用 StratifiedKFold 做 5-fold cross validation。SVM 使用 RBF kernel；k-NN 取 k=5；GBDT 使用 log loss、learning rate 0.1、100 estimators；XGBoost learning rate 0.3、max depth 6；RF 使用 scikit-learn 默认参数。

5. 指标  
   使用 Accuracy 和 F1-score。由于类别不均衡，F1-score 比 accuracy 更有解释价值。论文报告的核心比较主要看 F1-score。

6. 消融/敏感性  
   包括 SMOTE 比例敏感性、CNN 输入特征排列方式、CNN cutout 正则化、AC-GAN 生成样本可用性、对抗混淆类别选择和训练暴露比例。

7. 结果核查  
   对正常分类，重点看表 11、表 12、表 13。对对抗攻击，重点看表 8 的类别统计距离、图 11/12 的混淆矩阵、表 14 的整体准确率和被攻击类别准确率。尤其要检查：攻击后 overall accuracy 下降是否来自目标类别被严重误判，而不是所有类别均匀退化。

## 8. 关键结果、结论与证据

最重要结果是 RF 最强。流量四分类上，RF F1-score 达到 0.998；应用八分类上，RF F1-score 达到 0.922。相比前人，流量分类优于 Iliadis 和 Kaifas 的 RF 结果，应用分类优于 Sarwar 等 CNN-LSTM 的 0.890。

CNN 表现不差，但不是最优。CNN 在应用分类上约 0.888 F1，接近 CNN-LSTM，但仍低于 RF。按 RF 特征重要性重新排列并中心化图像后，CNN 略有提升，但幅度很小，说明“图像化”不是决定性因素。

AC-GAN 作为分类器在流量分类上尚可，最高约 0.987 F1；但在应用分类上明显弱，最高约 0.768 F1。作为数据增强工具也失败，因为生成样本很容易被 CNN 分辨真假。

SMOTE 的收益有限。大多数模型在不同 SMOTE 水平下只变化 1%-2%。RF 在不使用 SMOTE 时已经达到最好或接近最好。论文的结论不是“SMOTE 解决了类别不平衡”，而是“SMOTE 可用于微调，但不是主要性能来源”。

对抗攻击证明 RF 并非天然鲁棒。正常情况下 RF 应用分类 accuracy 约 92.3%。当只混淆验证集时，Audio-Streaming→P2P、Chat→Email、Email→VOIP 三种攻击使 overall accuracy 分别降到约 80.8%、85.4%、88.7%。目标类别准确率更惨：class 0 降到 0.100，class 2 降到 0.006，class 3 降到 0。

训练集投毒也有效。当训练集中某一类被完全混淆，而验证集保持原始分布时，RF 几乎不再预测该原始类别，目标类准确率为 0。说明如果训练数据采集链路被污染，高性能模型会学到错误边界。

防御实验说明“见过攻击样本”很重要。当训练集中包含 20% 混淆暴露样本，同时验证集全部混淆时，RF 对目标类的识别能力基本恢复，三组攻击下目标类准确率接近 0.998、0.993、0.997。这说明对抗样本纳入训练可以显著提升鲁棒性。

## 9. 局限性与待解决问题

正文包未截断，因此本次理解没有受到文本缺失影响。

第一，数据集单一。所有主要实验都围绕 CIC-Darknet2020 展开，没有跨数据集验证。CIC-Darknet2020 本身由较早的 Tor/VPN 数据组合而来，真实部署中的应用、协议、VPN 服务、Tor 行为都可能发生漂移。

第二，保留 IP octet 虽然提升性能，但可能引入数据集偏置。IP 地址往往携带采集环境、实验拓扑、生成脚本或数据源痕迹。RF 很可能利用这些非因果特征获得高分，但在新网络环境中泛化变差。对安全检测而言，这一点尤其需要复核。

第三，归一化和交叉验证细节仍需更严格说明。论文说做了 min-max normalization 和 5-fold StratifiedKFold，但如果归一化参数在全数据上拟合，再划分训练/验证，会带来轻微信息泄漏。正文没有足够细节排除这种可能。

第四，对抗攻击偏“理想攻击者”。作者允许攻击者独立修改大量 CICFlowMeter 特征，没有严格约束这些修改是否能由真实网络协议、操作系统栈或应用行为实现。真实攻击中，包长、间隔、端口、连接方向、流持续时间之间存在依赖关系，不可能任意独立变换。

第五，混淆算法没有建模特征依赖。它按单个特征的一维概率分布做 bin 映射，没有处理多特征联合分布。因此出现了一个有意思现象：有些样本没有被误判成预期目标类，而是被 RF 判到第三类。

第六，只对 RF 做了系统对抗实验。RF 是最佳分类器，但不代表其他模型更脆弱或更鲁棒。后续应比较 SVM、XGBoost、CNN 在同样混淆下的鲁棒性差异。

## 10. 与本项目的关系

这篇论文与“加密流量分类与应用识别”“恶意流量、暗网与攻击检测”“AI 安全与跨域异常检测”高度相关。

对本项目最直接的价值是提供了一个强基线：在 CICFlowMeter 这类统计特征上，RF 仍然非常有竞争力。若本项目要做异常检测或加密流量识别，不能只用深度模型作为基线，必须纳入 RF、XGBoost、SVM 等传统模型。

第二个价值是提醒特征泄漏问题。保留 IP octet 能提高分数，但这类特征可能不具备跨环境泛化能力。本项目如果追求真实部署，应分别报告“含 IP 特征”和“不含 IP 特征”的结果。

第三个价值是对抗视角。异常检测系统面对的不是静态分布，而是有动机规避检测的攻击者。本文的 obfuscation 实验可以转化为本项目的鲁棒性评估模块：不仅测试 clean F1，还测试混淆、投毒、训练暴露后的性能恢复。

第四个价值是负结果。AC-GAN 生成样本无法有效增强，说明在网络流量表格特征上，不应轻易假设 GAN 增强有效。更合理的方向可能是基于流生成机制、协议约束或联合分布建模的数据增强。

## 12. 本篇精华

- CIC-Darknet2020 上，Random Forest 是比复杂深度模型更强的基线：流量四分类 F1=0.998，应用八分类 F1=0.922。
- 该数据集的统计特征高度可分，但也可能包含环境性偏置；保留 IP octet 提升性能，同时带来泛化风险。
- 把表格流量特征转成 9×9 图像对 CNN 有一定作用，但不是根本优势，特征排列只带来很小收益。
- SMOTE 对大多数模型只是微调级提升，不是性能跃迁来源。
- AC-GAN 生成样本不适合本文数据增强，因为 fake samples 被 CNN 几乎完美识别。
- 对抗混淆能显著击穿 RF：只混淆验证集时，目标类识别率可接近 0。
- 训练集中加入足够混淆样本能恢复检测能力，说明鲁棒流量分类需要把攻击分布纳入训练和评估。
