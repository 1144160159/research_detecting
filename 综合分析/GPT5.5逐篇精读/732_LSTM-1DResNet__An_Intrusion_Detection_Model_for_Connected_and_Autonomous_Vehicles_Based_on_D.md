# [732] LSTM-1DResNet: An Intrusion Detection Model for Connected and Autonomous Vehicles Based on Deep Learning

## 2. 中文翻译与核心摘要

这篇论文关注联网自动驾驶车辆的网络入侵检测问题。CAVs 与车、路、人、云以及互联网持续交互，带来自动驾驶、交通管理和个性化服务能力，但也扩大了攻击面。作者认为，传统机器学习方法在高维网络流量上依赖人工特征，难以充分抽取复杂攻击模式；单一深度模型又存在局部空间特征和长程序列依赖难以兼顾的问题。

论文提出 LSTM-1DResNet 模型。整体思想是先用 LSTM 捕获网络流量字段之间的长程依赖，再用一维卷积残差网络提取更深层的局部空间/字段组合特征，最后通过 MLP 分类器输出正常或异常。作者特别强调“先序列、后空间”的结构顺序，认为这样可以保留原始字段序列关系，避免一开始卷积破坏协议层之间的动态逻辑。

实验使用 NSL-KDD 和 CICIDS2017 两个公开数据集。模型在 NSL-KDD 上达到 94.38% accuracy，在 CICIDS2017 上达到 97.98% accuracy、98.11% precision、约 97.98% recall。论文进一步用消融实验比较 LSTM-1DResNet、1DResNet-LSTM 和 LSTM-1DCNN，证明 LSTM 前置和残差模块都对性能和训练稳定性有贡献。

## 3. 论文解决的具体问题

论文解决的是 CAVs 场景下高维网络流量的异常/入侵检测问题，而不是车内 CAN 总线信号异常检测。它将 CAV 安全问题抽象为网络流量二分类：输入经过预处理后的流量特征，输出正常或攻击。

具体痛点包括：

1. CAVs 网络环境攻击后果严重。攻击不仅影响服务质量，还可能进一步影响车辆控制、安全驾驶和隐私。
2. 基于签名的 IDS 难以识别未知攻击，依赖特征库更新，适应性不足。
3. 传统机器学习方法在高维网络流量中需要人工特征工程，面对复杂非线性攻击模式时容易检测率不足或误报偏高。
4. 单独 CNN 擅长局部模式但弱于长程字段依赖；单独 LSTM 能建模序列关系但在高维递归传播中可能出现特征退化。
5. CAVs 对实时性有要求，复杂深度模型即使准确率高，也可能因计算开销过大而不适合部署在车载或边缘设备上。

## 4. 创新点深度提炼

第一，论文不是简单堆叠 CNN 与 LSTM，而是明确提出“LSTM 先行、1DResNet 后接”的特征抽取顺序。这个顺序背后的假设是：网络流量字段虽然不是自然语言时间序列，但字段之间存在协议逻辑、统计依赖和跨层关系，先由 LSTM 建模字段序列依赖，再进行卷积式深层局部组合，比先卷积再 LSTM 更适合保留结构信息。

第二，论文将 ResNet 思路迁移到一维网络流量特征处理上。它用 Conv1D 替代传统图像场景中的 Conv2D，并在 shortcut 分支使用 1x1 Conv1D 对齐通道数。这一设计兼顾深层特征提取和梯度稳定，目标是避免普通深层 CNN 在训练中退化。

第三，论文把性能与部署开销一起讨论。相比某些复杂 LSTM-CNN 架构，LSTM-1DResNet 在 NSL-KDD 上准确率略低于最高对照模型，但 FLOPS 明显更少。作者报告其计算量为 27.8M FLOPS、单样本平均推理延迟约 0.0242 ms，用以支撑车载实时部署可行性。

第四，论文用双数据集验证。NSL-KDD 是经典 IDS 数据集，CICIDS2017 更接近现代网络攻击流量。两者共同使用，可以说明模型不只是适配单一旧数据集。

## 5. 科学问题与研究假设

核心科学问题可以概括为：在 CAVs 相关高维网络流量中，如何同时捕获长程字段依赖与深层局部特征，并在可部署计算开销内提升入侵检测性能？

论文隐含了几个研究假设：

1. 网络流量特征字段之间存在可被 LSTM 捕获的序列依赖，且这种依赖有助于区分攻击与正常行为。
2. LSTM 输出后的特征仍包含可进一步通过 Conv1D 深层抽取的局部组合模式。
3. 残差连接能提升深层一维卷积模块的训练稳定性，减少梯度消失和模型退化。
4. “先 LSTM 后 1DResNet”优于“先 1DResNet 后 LSTM”，因为前者更能保留原始字段结构。
5. 在 CAVs IDS 中，模型不仅要追求准确率，还要控制 FLOPS、参数量和推理延迟。

## 6. 科学方法与技术路线

论文技术路线是典型的深度学习式 IDS 流程：

1. 数据输入：使用 NSL-KDD 和 CICIDS2017 的流量级特征。
2. 数据预处理：字符型特征独热编码，数值特征标准化，递归特征消除 RFE 做特征选择。
3. 序列建模：将输入调整为 LSTM 可接受的三维结构，使用 LSTM 捕获字段之间的长程依赖。
4. 深层特征提取：将 LSTM 输出重塑后送入两个 Conv1D 残差模块。第一个残差模块将通道扩展到 32，并经过一维最大池化；第二个模块进一步扩展到 64。
5. 分类：Flatten 后进入倒金字塔式 MLP，先压缩到 32 维，再压缩到 16 维，最后用 Sigmoid 输出二分类概率。
6. 评估：用 Accuracy、Precision、Recall、F1 和混淆矩阵评估检测性能。
7. 消融：比较完整模型、顺序反转模型 1DResNet-LSTM、去残差模型 LSTM-1DCNN。

需要注意的是，论文称模型包含 autoencoder 和 classifier，但正文结构更像“特征提取器 + MLP 分类器”，没有清晰描述 decoder 或重构损失。因此“autoencoder”这一表述在当前正文中不够严谨。

## 7. 实验设计与实验步骤

可复核流程如下：

1. 数据  
   使用 NSL-KDD 和 CICIDS2017。NSL-KDD 训练集 125,973 条，测试集约 22,545 条，原始特征 41 个，攻击类型包括 DoS、Probe、R2L、U2R。CICIDS2017 使用 MachineLearningCSV 切分，包含 benign 与 DDoS、DoS、PortScan、Bot、Web Attack、Infiltration、Patator 等多类流量，但实验最终转为正常/异常二分类。

2. 预处理  
   对字符型特征进行独热编码；对数值特征标准化；使用递归特征消除 RFE 去除冗余特征；训练集再按 7:3 划分为训练集和验证集。

3. 模型与基线  
   主模型为 LSTM-1DResNet。对照模型包括 SVM、1DCNN、LSTM、CNN-GRU、JAYA-LSTM、CNN-LSTM、LSTM-CNN 等。消融模型包括 1DResNet-LSTM 和 LSTM-1DCNN。

4. 训练  
   框架为 PyTorch，系统为 Ubuntu，硬件为 16GB RAM 和 NVIDIA GTX3060 GPU。激活函数使用 ReLU，学习率 0.0001，每次训练 100 epochs。

5. 指标  
   使用 Accuracy、Precision、Recall、F1-score。异常样本标记为 1，正常样本标记为 0，并基于 TP、TN、FP、FN 计算指标。

6. 消融/敏感性  
   消融主要验证两个问题：LSTM 放在前面是否优于 1DResNet 放在前面；残差模块是否优于普通 1D CNN。论文没有系统给出学习率、层数、通道数、池化大小等超参数敏感性实验。

7. 结果核查  
   需要核查表 IV 中 NSL-KDD 的 F1 数值。表中 LSTM-1DResNet 的 precision 为 0.9262、recall 为 0.9047，但 F1 写为 0.8675，按公式直觉上不太匹配。摘要中 CICIDS2017 F1 写 96.90%，而表 IV 写 0.9800，正文也出现不一致。这些数值应回到正式 PDF 或作者代码复核。

## 8. 关键结果、结论与证据

在 NSL-KDD 上，LSTM-1DResNet accuracy 为 94.38%，高于 SVM 的 75.38%、1DCNN 的 81.41%、LSTM 的 82.48%，说明级联结构相对单一模型有明显提升。与 CNN-GRU、JAYA-LSTM、CNN-LSTM 相比也有竞争力，但低于文中引用的 LSTM-CNN 95.70%。

在 CICIDS2017 上，LSTM-1DResNet accuracy 为 97.98%、precision 为 98.11%、recall 约 97.97%、F1 表中为 98.00%。相比 SVM、1DCNN、LSTM、CNN-GRU、JAYA-LSTM 均更高，说明它在更现代的流量数据上表现更强。

消融实验支持两个关键结论：

1. LSTM-1DResNet 优于 1DResNet-LSTM。NSL-KDD 上完整模型 accuracy 为 94.38%，反向结构为 92.938%；CICIDS2017 上完整模型为 97.98%，反向结构为 97.88%。差距在 NSL-KDD 上更明显。
2. LSTM-1DResNet 优于 LSTM-1DCNN。说明残差结构不仅提升分类结果，也改善训练曲线稳定性。

作者还强调部署效率：LSTM-1DResNet 为 27.8M FLOPS，平均单样本延迟约 24.23 微秒；相较文中提到的复杂 LSTM-CNN 447.10M FLOPS，计算量低很多。

## 9. 局限性与待解决问题

第一，CAV 场景论证和数据集之间存在距离。NSL-KDD 和 CICIDS2017 都是通用网络 IDS 数据集，并非真实车联网、车载以太网、CAN、V2X 或 CAV 边缘通信测试床数据。论文将 CICIDS2017 视为更接近 CAV 网络环境，但这仍是间接验证。

第二，二分类设定简化了实际防御需求。实际车联网 IDS 不仅要判断是否异常，还要识别攻击类型、风险等级、传播路径和响应策略。论文结论中也承认未来要发展多分类 IDS。

第三，类别不平衡问题没有充分解决。NSL-KDD 中 U2R、R2L 等少数类极少，转为二分类后会掩盖稀有攻击识别能力。作者提出未来使用 focal loss 和 GAN 增强少数类，但本文尚未实现。

第四，部分实验数值存在不一致。摘要、表格和结论中 CICIDS2017 F1 的表述不完全一致；NSL-KDD 的 precision/recall/F1 也需要重新计算确认。

第五，模型参数量“220 parameters”的说法值得怀疑。按 LSTM、Conv1D 残差块和 MLP 的结构描述，220 个参数似乎过低，可能是单位、统计方式或排版问题。部署效率结论需要源码或完整配置支撑。

第六，缺少真实在线检测流程。论文报告单样本推理延迟，但没有说明流量采集、窗口构造、特征计算、归一化和模型推理的端到端延迟。

这篇论文与“异常检测/网络异常检测”项目强相关。它提供了一个可直接纳入综述的代表性方向：面向车联网或 CAV 的轻量级深度混合 IDS。

对本项目有三点参考价值：

1. 架构思路可复用：LSTM 捕获字段依赖，Conv1D/ResNet 提取局部组合特征，MLP 分类，可作为网络流量异常检测基线。
2. 实验设计可借鉴：双数据集验证、传统 ML 与深度模型对照、顺序结构和残差模块消融，适合写入方法对比章节。

## 12. 本篇精华

1. 论文核心贡献不是提出全新神经元，而是给出“LSTM 先建模字段依赖，1DResNet 再抽取深层局部特征”的轻量级混合 IDS 架构。
2. 它把 CAVs 网络流量的难点定义为高维、序列依赖、细粒度特征耦合，以及实时部署约束。
3. 消融实验表明，LSTM 前置比 Conv1D 残差前置更稳，支持“先序列、后空间”的设计假设。
4. 残差连接在一维流量特征上有实际收益，既提升准确率，也改善训练损失曲线稳定性。
5. CICIDS2017 上 97.98% accuracy 和 98.11% precision 是论文最有说服力的结果，优于多数对照基线。
6. 论文最大短板是 CAV 场景验证不足，使用的是通用 IDS 数据集，而非真实车联网或车载通信数据。
7. 实验表格存在若干数值疑点，尤其 F1 与 precision/recall 的一致性，正式引用前应复核。
8. 对综述写作而言，这篇可归为“面向车联网的轻量级时空深度特征融合 IDS”。
