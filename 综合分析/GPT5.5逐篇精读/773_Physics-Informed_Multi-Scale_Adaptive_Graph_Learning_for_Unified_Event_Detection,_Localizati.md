# [773] Physics-Informed Multi-Scale Adaptive Graph Learning for Unified Event Detection, Localization, and Classification in Power System

## 1. 基本信息

论文发表于/录用于 2026 年 IEEE Transactions on Industrial Informatics，DOI 为 `10.1109/tii.2026.3682628`。作者来自重庆大学，研究对象是现代电力系统中单源、多源、时空耦合事件的检测、定位与分类，即 ED-L-C。

本文与“异常检测”相关性中等偏高：它不是传统网络流量或主机安全异常检测，而是面向电力信息物理系统的图时序异常分析；其统一输出结构、多源事件建模、物理先验融合方法，对工业控制安全、跨域异常检测和资产图异常定位有借鉴意义。

## 2. 中文翻译与核心摘要

本文提出 PI-MSA，即物理信息引导的多尺度自适应图神经网络，用于电力系统事件检测、定位和分类。作者认为，过去很多方法把检测、定位、分类拆成多个子任务，容易产生误差传递，也不擅长处理多个事件源同时发生、波形叠加、节点事件和边事件并存的场景。

核心做法是把 ED-L-C 改写成一个统一的一阶段回归问题。模型输出一个 `[N, N, 1+M]` 三维张量：对角线表示节点事件，非对角线表示线路/边事件，第一个通道是异常置信度，后续通道是事件类别概率。这样，事件位置由张量索引表达，事件类别由对应位置的类别通道表达。

模型侧，PI-MSA 用三条并行图路径学习空间依赖：真实电网拓扑、自适应特征相关图、基于最短路径导纳编码的物理图。再通过时序门控卷积和多头注意力融合多尺度特征。实验在 5 个不同规模和电压等级的系统上验证，报告了超过 75% 的 mAP、约 90% 以上定位准确率，并在 225 FPS 左右实现实时推理。

## 3. 论文解决的具体问题

论文要解决的不是“某一种故障分类”，而是更复杂的统一事件分析问题：在一个观测窗口内，事件源数量未知、位置未知、类别未知，且事件可能发生在节点或线路上。

具体难点有四个。第一，多源事件数量变化，模型不能预设只有一个异常。第二，事件在时间上重叠，多个波形叠加后不再呈现单一事件模板。第三，事件会沿电网传播，测点看到的是源事件与传播扰动混合后的信号。第四，同类事件可能在不同地点同时出现，例如多个 C-G 接地故障，模型必须把它们识别为不同源，而不是合并为一个类别判断。

因此，本文真正关注的是：如何在图结构工业系统中，把异常检测、空间定位、类别识别、多源分离和实时推理合成一个可训练、可部署的统一框架。

## 4. 创新点深度提炼

第一，最重要的创新是空间感知的三维输出张量。它把“位置”嵌入输出索引，把“检测”和“分类”放在同一位置的不同通道里，从结构上耦合任务，而不是先检测再定位再分类。

第二，本文避免了多事件组合类别爆炸。传统做法如果想识别“故障 A + 负荷切换 B + 线路跳闸 C”的组合，可能需要定义新的组合类；本文只在空间张量上分别激活多个事件源，因此天然支持多源事件。

第三，图学习不是只用邻接矩阵。PI-MSA 同时使用二值物理拓扑、数据驱动自适应图、最短路径导纳编码图，使模型既能学习统计相关性，又不完全脱离电气连接规律。

第四，物理信息注入方式比较具体：作者用线路距离求最短路径，再用正序/零序电阻电抗编码路径阻抗，取倒数形成导纳表示，并让它门控自适应邻接。这比简单把邻接矩阵喂给 GCN 更接近电力系统中的扰动传播机制。

第五，本文把节点事件和边事件放进同一个输出结构中。对角线负责节点，非对角线负责边，解决了很多方法只能处理节点分类或只能处理线路故障的限制。

## 5. 科学问题与研究假设

本文的科学问题可以概括为三类。

第一，ED-L-C 是否可以从多个串行分类任务转化为一个结构化回归任务，并因此减少误差累积？作者的假设是，事件源在图上是稀疏的，位置和类别可以共同编码在一个空间张量中。

第二，物理电网先验是否能提升多源异常识别的泛化性和鲁棒性？作者的假设是，真实扰动传播同时受拓扑、电气距离和动态运行状态影响，因此三种图关系的融合优于单一邻接关系。

第三，一个模型能否同时满足复杂多源分析和实时监测？作者的假设是，用轻量化时序卷积、一阶图卷积近似和并行多尺度路径，可以在保持精度的同时达到 30-120 Hz D-PMU/H-PMU 报告速率下的在线推理。

## 6. 科学方法与技术路线

输入是电力系统图 `G=(V,E,A)` 和图时序信号 `X ∈ R^{N×C×T}`。特征包括三相电压幅值、电流幅值、功率因数，采样/上报频率为 120 Hz。扩展实验中还假设 H-PMU 可测基波、三次和五次谐波，并将它们拼接为更高维输入。

模型主体是 STMS-Block，即时间-空间-时间结构。时间部分使用因果卷积和门控单元，捕获事件开始、持续、叠加和消退过程。空间部分使用一阶 Chebyshev 图卷积近似，降低大规模图上的计算负担。

三条图路径分别是：

- 物理拓扑图：只允许直接相连节点传播信息。
- 自适应图：用节点特征余弦相似度和可学习参数动态生成连接强度。
- 物理信息自适应图：用最短路径、电气阻抗和导纳编码约束自适应图，使强连接同时满足数据相关和电气耦合。

三路输出拼接后进入多头注意力，最后由线性预测头输出 ED-L-C 三维张量。训练损失分别平衡异常检测正负样本和分类正负样本，推理时先用检测通道阈值过滤候选位置，再在候选位置上取最大类别概率。

## 7. 实验设计与实验步骤

数据：作者在 IEEE 34 节点、IEEE 123 节点、欧洲 906 节点、New England 39 节点输电系统、含 RES 的改造 IEEE 33 节点系统上实验。事件覆盖故障、谐波负荷切换、可再生能源相关事件和输电系统事件，编号为 E1-E19。

预处理：每个样本是 1 秒滑动窗口图时序数据，未观测节点或缺相位置用 0 填充。标签按 `[N,N,1+M]` 构造，对角线标节点事件，非对角线标边事件。

数据生成：用 Monte Carlo 随机生成多源事件。每个窗口随机采样 1-8 个事件源，906 节点系统扩展到最多 16 个；随机选位置、线路内位置比例、事件类别、故障电阻、触发时刻和持续时间。每个系统包含约 4000-8000 个事件样本和 400-1000 个正常样本。

模型/基线：基线包括 LSTM、MLP、NBeats、STGCN、DCRNN、Graph WaveNet、AGCRN、PatchTST、iTransformer、TimesNet、Crossformer。所有基线只加统一 ED-L-C 输出头，避免人为增强。

训练：按时间顺序划分 70% 训练、10% 验证、20% 测试，训练前打乱训练样本。PI-MSA 使用 2 个 STMS-Block，时间卷积核数 64，空间图卷积核数 16，3 头 MHA。优化器为 Adam，初始学习率 0.002，100 epoch，batch size 64，dropout 0.5，梯度裁剪 3.0。

指标：使用 CorLoc、AP、mAP，并区分节点事件 mAPN、边事件 mAPE、一跳容忍 mAPOH。严格 AP 要求类别正确且位置精确匹配。

消融/敏感性：作者测试了事件源数量、传感器覆盖率、拓扑变化、测量缺失和延迟、谐波输入、单尺度/双尺度/去除 MHA/替换损失等设置。

结果核查：重点看 mAP、CorLoc、边事件 mAPE、复杂多源场景下的性能下降幅度，以及大规模 906 节点系统上的 FPS 和内存。

## 8. 关键结果、结论与证据

在 34 节点和 123 节点系统上，PI-MSA 分别达到 81.21% 和 84.62% mAP，比最佳基线高 5.02% 和 4.4%。这说明统一输出和物理多尺度图结构确实带来稳定增益。

在 1-8 个事件源场景中，模型在八源事件下仍保持 79% 以上 mAP，CorLoc 约 92%。123 节点系统在多源复杂场景中反而优于 34 节点系统，作者解释为更大的空间范围有利于分离传播模式。

在 906 节点系统上，最多 16 个事件源，整体 mAP 达到 96.42%，CorLoc 达到 98.79%。已见位置和未见位置 mAP 只差 0.23%，这是本文支撑“空间泛化”的最强证据之一。

在观测率降到 12% 时，PI-MSA 仍有 54.45% mAP 和 73.13% CorLoc，而依赖静态拓扑的基线退化超过 40%。在拓扑动态变化时，PI-MSA 比最佳基线高 6.5% 以上 mAP，CorLoc 超过 91%。

在缺失和延迟测量下，906 节点系统中 30% 缺失只导致 mAP 从 96.42% 降到 93.76%；20% 缺失加 20% 延迟时仍有 89.76% mAP 和 93% 以上 CorLoc。

消融结果显示，自适应单尺度最强，物理尺度优于纯物理拓扑；Adaptive+Physics 是最强双尺度组合，完整三尺度模型达到 84.62% mAP。加入三次和五次谐波后，PI-MSA 在 123 节点系统上额外提升 1.6% mAP。

## 9. 局限性与待解决问题

第一，论文主要依赖仿真和标准测试系统，真实现场事件、真实通信异常、真实传感器漂移和标注噪声尚未充分验证。

第二，作者明确承认，当事件空间上相邻且时间上高度耦合时，性能会下降。这恰好是多源事件最难的情况，也说明当前 `[N,N]` 输出分辨率对紧邻密集事件仍可能不足。

第三，H-PMU 谐波测量被作为假设引入，实际部署中硬件覆盖率、同步误差、谐波测量可靠性都会影响模型可用性。

第四，plain text 正文中表格 III 的 E1-E19 具体类别内容没有完整展开，虽然正文说明了类别范围，但若要严格复现实验，仍需回到 PDF 表格核对每个事件编号的精确定义。

第五，阈值 `τ`、损失权重、正负样本不均衡处理对最终 AP 可能很敏感，论文给出经验参数，但没有充分展开参数搜索边界。

第六，当前工作把 cyber layer 作为未来方向，尚未真正处理通信攻击、虚假数据注入、网络链路故障等网络安全事件。

## 10. 与本项目的关系

如果本项目关注“AI 安全与跨域异常检测”，这篇论文的价值不在于电力故障类别本身，而在于它提供了一个图结构系统中多源异常统一建模范式。

可迁移点包括：用空间张量同时表达异常存在、位置和类别；把节点异常与边异常统一处理；把领域知识作为图学习的约束而不是后处理规则；在多源重叠异常下避免组合类别爆炸。

对网络安全场景，可以把电网节点替换为主机、服务、传感器、工控设备，把边替换为通信链路、调用关系或物理依赖；把导纳/阻抗先验替换为网络拓扑距离、业务依赖强度、协议路径、攻击图可达性或资产风险权重。

本地代码包状态为“未发现；无”，因此不能列出真实源码目录或关键文件。论文只给出了实现线索：PyTorch、PyG、EasyTorch，NVIDIA A40 48GB，训练 100 epoch，batch size 64。

若复现，代码应至少拆成以下模块：

- 数据生成：Monte Carlo 多源事件采样，负责事件数量、位置、类别、故障电阻、触发时间、持续时间。
- 数据预处理：构造 `X ∈ R^{N×C×T}`，零填充未观测节点，生成基础邻接、线路距离矩阵、阻抗/导纳参数矩阵。
- 标签构造：生成 `[N,N,1+M]` 目标张量，区分对角线节点事件和非对角线边事件。
- 模型：实现 TGC、Chebyshev 一阶图卷积、三尺度邻接路径、最短路径导纳编码、MHA 融合、ED-L-C 输出头。
- 训练：实现加权 MSE 风格的检测/分类正负样本损失，Adam、MultiStepLR、dropout、梯度裁剪。
- 评估：实现 CorLoc、AP、mAP、mAPN、mAPE、mAPOH，以及一跳容忍定位评价。
- 鲁棒性脚本：传感器覆盖率下降、拓扑切换、测量缺失、延迟恢复、谐波输入开关。

运行线索最关键的是：先复现 34/123 节点小系统，再扩展 906 节点；先只用基波 D-PMU 特征，再加入三次和五次谐波；先验证完整观测，再做低观测率和拓扑变化实验。

## 12. 本篇精华

- 本文把检测、定位、分类统一成 `[N,N,1+M]` 张量回归，是整篇论文最值得借鉴的设计。
- 对角线表示节点事件，非对角线表示边事件，使节点级和线路级异常可以同框架处理。
- PI-MSA 的三尺度图不是简单堆模型，而是分别对应物理拓扑、动态统计相关、电气距离先验。
- 最短路径导纳编码把电力系统物理规律变成图学习中的可学习门控，增强了可解释性和泛化性。
- 多源事件不需要定义组合类别，模型只需在多个空间位置同时输出高置信度。
- 906 节点、最多 16 源、未见位置性能几乎不降，是论文最强的规模化和泛化证据。
- 局限集中在真实数据缺失、密集相邻事件退化、H-PMU 部署假设和网络攻击层尚未覆盖。
