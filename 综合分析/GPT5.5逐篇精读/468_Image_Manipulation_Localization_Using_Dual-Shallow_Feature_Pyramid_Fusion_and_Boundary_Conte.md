# [468] Image Manipulation Localization Using Dual-Shallow Feature Pyramid Fusion and Boundary Contextual Incoherence Enhancement

## 2. 中文翻译与核心摘要

这篇论文研究的是图像被拼接、复制移动、移除等内容级篡改后，如何精确定位篡改区域。作者认为，现有深度模型常有两个关键短板：一是编码解码结构中的跳连多来自局部层级，缺少融合后的全局伪造线索；二是篡改边界通常很细、形态不规则，普通分割解码器对边缘上下文不一致不够敏感。

论文提出一个端到端 IML 网络，由 DFPF 特征融合模块、Transformer 编码器和 BCIE 解码器组成。DFPF 用两条浅层 Hybrid ResNet50 分支分别提取 RGB 语义特征金字塔和局部纹理特征金字塔，再通过自顶向下路径融合。局部纹理分支前面加入 CSHC 或 PMSC 预处理块，用可学习高频/残差卷积增强篡改痕迹。编码器使用 ViT 式 Transformer 处理深层 RGB 特征以获得全局依赖。解码器使用级联 BCIE 块，通过局部窗口内像素余弦相似度刻画边界上下文不一致，从粗到细恢复篡改掩码。

核心结论是：同时利用浅层纹理痕迹、RGB 语义结构、Transformer 全局关系和边界上下文不一致，比单纯 CNN/Transformer 或只做边缘监督的方法更适合篡改定位，尤其对 copy-move、小目标篡改和边界模糊场景更有效。

## 3. 论文解决的具体问题

论文要解决的不是“图像是否被篡改”的分类问题，而是“哪里被篡改”的像素级定位问题。难点在于：

1. 篡改区域没有固定语义类别，可能是一块背景、一段物体边缘或很小的局部纹理，不能直接套用语义分割思路。
2. 拼接和移除会留下边界不一致、纹理残差、压缩/模糊差异；copy-move 来自同一图像，语义和颜色更一致，传统残差方法更容易失效。
3. 篡改区域尺度跨度大，可能是大面积区域，也可能是很小的局部补丁。
4. 现有编码解码网络的跳连常只传递对应层的局部特征，缺少融合后的全局金字塔线索。
5. 边界监督方法在低维高分辨率特征上有效，但进入高层低分辨率表示后，边界异常容易被稀释。

## 4. 创新点深度提炼

第一，DFPF 把“RGB 语义金字塔”和“局部纹理金字塔”作为同等重要的两类证据融合。RGB 分支负责保留场景结构与语义上下文，LTFP 分支专门放大篡改痕迹、残差和高频纹理。相比只用 RGB 层级融合的方法，它更贴近图像取证任务的本质：篡改区域未必语义异常，但经常统计痕迹异常。

第二，论文强调“浅层、高分辨率”的特征金字塔。Hybrid ResNet50 保留 stem 输出作为第一层特征，并调整后续层级，使金字塔更适合边界和细节定位。这一点比直接拿标准 ResNet 深层特征更合理，因为图像伪造痕迹往往是局部纹理和边缘细节。

第三，CSHC 与 PMSC 是面向取证的预处理块。CSHC 按 RGB 通道分别做高频/残差卷积，增强通道间异常；PMSC 用 3×3、5×5、近似 7×7 的多尺度卷积分支扩大感受野。它们不是固定滤波器，而是以 TFP 和 PR 作为初始化/约束思路，再由训练调整。

第四，BCIE 把边界问题从“额外边缘监督”转为“解码过程中的局部上下文不一致增强”。SWS-Head 计算每个像素与邻域像素的平均余弦相似度，边界处前景/背景混合导致相似性变化，从而帮助解码器突出篡改边缘。

第五，论文还提出用 Photoshop Scripting 自动合成 IML-MUST 数据集，覆盖 copy-move、splicing、removal，并加入旋转、缩放、模糊、光照调整等后处理，缓解 IML 标注数据不足的问题。

## 5. 科学问题与研究假设

科学问题可以概括为：在语义类别不稳定、篡改区域形态不规则、边界痕迹微弱的图像取证任务中，如何同时利用全局上下文、浅层纹理残差和边界局部不一致，实现可靠的像素级定位？

论文隐含的研究假设有三条：

1. 篡改定位不能只依赖 RGB 语义特征，必须显式引入纹理/残差/高频证据。
2. 篡改痕迹在多尺度浅层特征中更容易保留，因此高分辨率特征金字塔比单一深层表示更有效。
3. 篡改边界附近的局部相似性分布不同于自然边界，利用邻域余弦相似度可以增强前景与背景的不一致。

## 6. 科学方法与技术路线

整体流程是：输入图像统一缩放到 256×256，先经过 DFPF 得到融合金字塔，再用 Transformer 编码深层 RGB 表示，最后通过级联 BCIE 解码得到二值 mask。

DFPF 中有两条 Hybrid ResNet50。RGBFP 分支直接提取 RGB 层级特征；LTFP 分支先经过 CSHC 或 PMSC 预处理，再提取纹理特征。两条分支输出对应尺度后，在反向路径中从低分辨率深层开始融合，并逐层上采样，与相邻尺度的 RGB/纹理特征相加，形成 Skip1、Skip2、Skip3 等解码跳连。

Encoder 使用 ViT 思路，把 16×16 空间特征展平成 256 个 patch token，每个 token 维度为 768，加入位置编码后输入 12 层 Transformer。这里 Transformer 的作用不是替代全部 CNN，而是补足 CNN 对远距离依赖建模不足的问题。

Decoder 先把 Transformer 输出恢复为空间特征，然后级联上采样。每一级 BCIE 块都融合 DFPF 的 skip 特征，并用 SWS-Head 在 3×3 局部窗口中计算像素与邻居的平均余弦相似度，将相似度矩阵加回特征图，从而突出边界不一致。

## 7. 实验设计与实验步骤

可复核流程如下：

1. 数据准备：使用 CASIA、Coverage、NIST2016、Columbia、IMD2020、DEFACTO，以及作者合成的 IML-MUST。CASIA v1.0 用作测试，CASIA v2.0 子集用于训练；Coverage 按 75/25 切分；NIST2016 为 414/150；Columbia 为 130/50；IMD2020 为 70/5/25；DEFACTO 抽样 80000 张按 8/1/1 切分；IML-MUST 为 125500 张，90% 训练、10% 验证。
2. 预处理：所有图像缩放到 256×256，以匹配 ViT patch 设置；训练标签为像素级二值掩码。
3. 合成数据：用 PS-Scripting 自动生成 copy-move、splicing、removal 样本，对前景区域做畸变、旋转、缩放、模糊、光照调整等。
4. 模型训练：先在 IML-MUST 或 DEFACTO 上预训练，再在五个 benchmark 的组合训练集上微调。
5. 初始化：Hybrid ResNet50 和 ViT 使用 ImageNet 预训练权重。
6. 优化设置：PyTorch，3 张 RTX 3090，Adam，初始学习率 1e-4，线性衰减，batch size 21，训练 70 epochs。
7. 损失函数：Binary Cross-Entropy 与 Dice Loss 等权组合。
8. 指标：像素级 F1 和 AUC；F1 默认阈值固定为 0.5，以便与多数公开方法比较。
9. 消融：分别验证 DFPF、RGBFP、LTFP、不同预处理块、BCIE/SWS-Head、CBAM 替代方案。
10. 鲁棒性：在 NIST2016 上加入 LinearResize、GaussianBlur、GaussianNoise、JPEGCompress 攻击，比较 AUC。
11. 结果核查：除表格指标外，用预测 mask、Grad-CAM 和计算复杂度共同检查定位质量、边界响应和实用性。

## 8. 关键结果、结论与证据

DFPF 消融显示，只有 Encoder+Decoder 的 baseline 明显不足；加入 RGBFP、LTFP 后逐步提升，完整 DFPF 平均 F1 相比 baseline 提升约 22.7%。这支持了作者的核心判断：双流浅层金字塔融合比单一路径编码更适合 IML。

预处理块实验中，普通 Conv2D、CW-HPF、Bayar 都有一定帮助，但提升有限；CSHC 和 PMSC 更强，其中 PMSC 由于多尺度卷积对不同大小篡改区域更友好，整体表现更突出。

BCIE 消融显示，SWS-Head 优于简单级联上采样，也比加入 CBAM 更贴近任务需求。它提升的不是一般注意力，而是边界邻域的不一致响应，因此在 Columbia 和 NIST2016 等边界明显或复杂的场景中收益较大。

与 ManTraNet、MVSS-Net、TDA-Net、SATFL、EMT-Net、Li et al.、SAPS-Net、NCL-IML、UP-Net、PCL 等方法比较时，论文方法在多个数据集的平均 F1/AUC 上领先；在 Columbia 和 IMD2020 上尤其强。NIST2016 上它不是绝对第一，但接近最优。Coverage 上对 copy-move 的可视化效果也被作者重点强调。

鲁棒性方面，在 NIST2016 遭受缩放、模糊、噪声、JPEG 压缩攻击后，方法的 AUC 仍高于 SPAN 和 NCL-IML，说明 DFPF 与 BCIE 不只是拟合干净数据，也能保留一定抗扰能力。

## 9. 局限性与待解决问题

论文自己承认模型对伪造痕迹敏感：当训练集和测试集包含相同或相近的篡改技术时效果最好，面对未见过的篡改方式会下降。这是图像取证模型的典型泛化问题。

第二，模型复杂度并不低。双 Hybrid ResNet50、ViT 编码器、级联 BCIE 共同带来较高计算开销。论文认为约 115.3 ms/图仍可接受，但在实时取证、移动端或大规模内容审核中仍需压缩。

第三，合成数据虽然缓解了样本不足，但 Photoshop 脚本生成的篡改分布仍可能与真实社交媒体、生成式 AI 编辑、复杂多轮压缩链路存在差距。

第四，论文主要围绕传统图像编辑型篡改，对扩散模型局部重绘、AIGC 混合编辑、跨平台传播后的取证痕迹没有展开系统验证。

第五，本次正文包未截断，因此上述理解覆盖了提供文本中的方法、实验和结论；但若后续用于正式引用，仍建议回到 PDF 复核表格具体数值、图注和版面细节。

## 12. 本篇精华

1. IML 的核心不是语义分割，而是定位“语义可能正常但统计痕迹异常”的区域。
2. DFPF 的价值在于把 RGB 语义和局部纹理残差做多尺度双流融合，解决单分支特征证据不足。
3. 浅层高分辨率特征对篡改边界和微弱痕迹非常关键，不能只依赖深层低分辨率语义。
4. PMSC 比单一高通滤波更灵活，因为不同尺度卷积能覆盖不同大小的篡改区域。
5. BCIE 用局部余弦相似度增强边界上下文不一致，是比泛化注意力更贴近图像取证的设计。
6. 合成数据 IML-MUST 是性能提升的重要支撑，但也带来合成分布与真实篡改分布不一致的问题。
7. 论文强项在 Columbia、IMD2020、copy-move 可视化和鲁棒性测试；短板是未见篡改泛化与计算复杂度。
8. 对异常检测综述而言，这篇可归为“视觉局部异常定位中的多尺度残差-边界增强范式”。
