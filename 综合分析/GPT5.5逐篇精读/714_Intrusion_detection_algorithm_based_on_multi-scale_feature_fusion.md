# [714] Intrusion detection algorithm based on multi-scale feature fusion

## 1. 基本信息

- 题名：Intrusion detection algorithm based on multi-scale feature fusion
- 作者：Jinxian Zhao, Haidong Hou, Liang Chang
- 来源：Computers & Security, 161, 104783
- DOI：10.1016/j.cose.2025.104783
- 时间信息：2025-11-21 接收，2025-11-22 在线发表；期刊卷期标注为 2026
- 主题：基于深度学习的网络入侵检测，重点是表格流量特征图像化、多尺度特征融合、类别不平衡处理
- 主要模型：FLSPPMRXt，基于 ResNeXt50，融合改进卷积、SPPM 多尺度模块、Soft Pool 和 Focal Loss
- 数据集：UNSW-NB15 为主，NSL-KDD 作为补充验证
- 代码状态：本地未发现该论文对应开源代码包

## 2. 中文翻译与核心摘要

这篇论文的核心思路是：把网络流量的表格特征先转换成二维灰度图，再用改造后的 ResNeXt50 做二分类入侵检测。作者认为，传统深度学习 IDS 方法通常直接把单条流量记录看作一维特征向量，虽然能学习非线性关系，但很难显式捕捉非相邻特征之间的潜在关联。为此，论文引入一种基于特征距离排序和像素距离排序匹配的数据图像化方法，让相似特征在图像中尽可能成为邻近像素。

在模型侧，论文基于 ResNeXt50 做了三处主要改造：第一，把原始 7×7 初始卷积替换为 5×5 加两个 3×3 的组合卷积；第二，在早期特征提取后加入 SPPM，即融合 Soft Pool 的 Pyramid Pooling Module，用 1、3、5、7 等尺度聚合上下文；第三，用 Focal Loss 缓解正常样本与攻击样本、易分类样本与难分类样本之间的不均衡影响。

实验显示，在 UNSW-NB15 上，FLSPPMRXt 达到 93.3% overall accuracy 和 95.2% F1；在 NSL-KDD 上也优于若干对比方法。论文试图证明两个判断：网络流量表格特征图像化是可行的；多尺度融合和软池化能增强图像化流量样本的判别特征。

## 3. 论文解决的具体问题

论文针对的是网络入侵检测中的二分类问题：判断一条网络流量记录是 normal 还是 attack。它并不是重点解决多攻击类型细粒度分类，而是围绕异常/攻击检测的总体识别能力展开。

具体问题有三层：

第一，传统机器学习 IDS 依赖人工特征工程，面对攻击变种和复杂流量时泛化能力不足。深度学习虽然能自动学习特征，但很多方法仍把网络流量当作一维向量处理，没有充分利用特征之间的结构关系。

第二，已有图像化方法要么过于简单，只按原始特征顺序填充像素，忽略特征相关性；要么过于复杂，例如依赖自编码器、KNN、聚类、DeepInsight 或 GAN 增广，计算成本较高，不利于轻量部署。

第三，入侵检测数据普遍类别不均衡。普通交叉熵容易被多数类或易分类样本主导，导致模型对少数攻击样本、边界样本的学习不充分。

## 4. 创新点深度提炼

论文最有价值的创新不是单个模块本身，而是把“表格流量图像化”和“面向图像的多尺度 CNN 结构”接在一起，形成一条完整的 IDS 建模路线。

第一个创新是改进数据图像化方法。作者借鉴 Image Generator for Tabular Data，将每个特征映射为一个像素，通过最小化特征距离排序矩阵与像素距离排序矩阵之间的误差，使相似特征在图像中靠近。论文进一步把距离度量从普通欧氏距离扩展并比较为 Euclidean、Cosine 和 Standardized Euclidean，最终选择标准化欧氏距离，因为它能减弱不同特征量纲差异对距离计算的干扰。

第二个创新是把 Soft Pool 引入多尺度池化模块。普通 PPM 中的平均池化会压缩并损失局部激活信息；Soft Pool 按指数权重聚合激活值，使高响应区域贡献更大，同时不是只保留最大值。对入侵检测图像来说，这相当于在多尺度上下文汇聚时尽量保留细粒度异常模式。

第三个创新是对 ResNeXt50 输入端做小尺度图像适配。论文生成的是 14×14 或 11×11 这样的小图，直接沿用 ImageNet 风格的 7×7 初始卷积并不一定合适。作者通过消融实验选择 5×5、3×3、3×3 的组合卷积，并使初始输出特征图为 9×9。

第四个创新是把 Focal Loss 放在图像化 IDS 框架中处理不均衡。它不是简单重采样，而是在损失层面降低易分类样本权重，使训练更关注难分类流量。

## 5. 科学问题与研究假设

论文背后的科学问题可以概括为：

网络流量表格特征之间是否存在可被“空间邻近关系”表达的结构？如果存在，把它们转换为二维图像后，CNN 是否能比一维向量模型更有效地学习攻击模式？

论文隐含了四个研究假设：

1. 流量特征之间的统计相似性可以通过距离矩阵描述，且相似特征在二维图像中相邻有利于卷积核捕获局部关联。
2. 标准化欧氏距离比普通欧氏距离、余弦距离更适合此类异质网络流量特征，因为它能处理不同属性尺度差异。
3. 多尺度上下文对入侵检测有用，因为攻击行为可能同时体现在局部特征组合和全局流量模式中。
4. 类别不均衡会明显影响 IDS 分类边界，Focal Loss 可以提升模型对攻击样本和难样本的关注。

## 6. 科学方法与技术路线

技术路线是：原始流量表格数据 → 类别特征编码 → 归一化 → 特征相似性排序 → 二维灰度图生成 → FLSPPMRXt 分类。

数据预处理包括三类操作：字符型特征使用 one-hot encoding，标签特征使用 label encoding，数值特征保持数值形式，然后进行 min-max 归一化。

数据图像化的关键是构造两个 M×M 矩阵：一个是特征距离排序矩阵 F，一个是图像像素距离排序矩阵 I。算法通过不断交换特征到像素的位置，降低 F 与 I 的排序误差。最终，每个样本的一维特征向量被填入固定大小图像。UNSW-NB15 被处理为 14×14，NSL-KDD 被处理为 11×11。

模型结构以 ResNeXt50(32×4d) 为主干，利用分组卷积和残差结构提高表达能力。初始卷积被改为 5×5 卷积加两个 3×3 卷积；之后加入 SPPM 模块，分别用不同尺度池化获得上下文特征，再经 1×1 卷积、上采样和通道拼接形成多尺度融合特征。最后经过 ResNeXt 分组残差块、全局平均池化、全连接层和 sigmoid 输出分类结果。

损失函数使用 Focal Loss，设置 γ=2、α=0.25。

## 7. 实验设计与实验步骤

可复核流程如下：

1. 数据  
   使用 UNSW-NB15 和 NSL-KDD。UNSW-NB15 含 44 个属性，其中 3 个字符特征、40 个数值特征、1 个标签；NSL-KDD 含 42 个特征，其中 3 个字符特征、36 个数值特征、1 个标签。论文主要报告 normal 与 attack 二分类。

2. 预处理  
   对协议、服务等字符特征做 one-hot encoding；对标签做 label encoding；对数值列做归一化。随后基于特征距离生成图像。UNSW-NB15 转为 14×14 灰度图，NSL-KDD 转为 11×11 灰度图。

3. 图像化方法比较  
   比较 Euclidean、Cosine、Standardized Euclidean 三种距离度量。评价包括矩阵误差、图像生成耗时，以及用简单 2D-CNN 分类后的 OA、Recall、F1。论文结论是标准化欧氏距离误差更低、耗时更少、分类效果更好。

4. 模型/基线  
   图像分类模型包括 simple 2D-CNN、ResNet50、ResNeXt50 和最终 FLSPPMRXt。外部对比包括 1D-CNN、RNN/LSTM、DNN、GAN 增广方法、随机森林、MLP、若干 2D-CNN IDS 方法等。

5. 训练设置  
   GPU 为 NVIDIA GeForce RTX 3050Ti，环境提到 TensorFlow 1.14 和 PyTorch 1.10。优化器为 Adam，学习率主要选择 1e-4，batch size 主要选择 64。训练集再按 7:3 划分训练/验证。

6. 指标  
   使用 OA、Recall、Precision、F1。论文公式按二分类定义 TP、TN、FP、FN，其中 attack 被视为正类。

7. 消融/敏感性  
   消融包括初始卷积结构比较、不同 feature map size 比较、Focal Loss 与 BCE 比较、PPM 与 SPPM 比较、PPM/SPPM 与 Focal Loss 的组合比较。敏感性实验包括 batch size 和 learning rate 组合：batch size 32、64、128，learning rate 1e-4、1e-3。

8. 结果核查  
   核心结果需要检查三类证据是否一致：图像化误差和耗时是否支持标准化欧氏距离；消融实验是否支持 SPPM 和 Focal Loss 的贡献；最终对比表是否在相同数据集、相同二分类设置下比较。

## 8. 关键结果、结论与证据

最关键结果是 UNSW-NB15 上 OA=93.3%、F1=95.2%、Recall=96.3%、Precision=94.0%。这说明模型在攻击识别召回上较强，同时 F1 也较高，论文据此认为漏报和误报之间取得了较好平衡。

数据图像化部分，标准化欧氏距离优于普通欧氏距离和余弦距离。论文给出的证据包括更低的矩阵排序误差、更短的图像生成时间，以及在 simple 2D-CNN 上更好的 OA、Recall、F1。

与 DeepInsight 相比，论文方法在 NSL-KDD 上 OA 从 77.47% 提升到 81.2%，F1 从 77.56% 到 81.4%；在 UNSW-NB15 上 OA 从 68.29% 提升到 89.2%，F1 从 81.10% 到 91.5%。这部分结果支撑作者的观点：不依赖 t-SNE 投影的特征-像素排序匹配方法，在该任务上更合适。

消融实验显示，SPPM+Focal Loss 是 UNSW-NB15 上最优组合。单独使用 PPM 或 SPPM 已能提升性能，而 SPPM 比 PPM 更好，说明 Soft Pool 对多尺度特征保留有帮助。Focal Loss 能降低验证集 accuracy 和 loss 的震荡，并改善最终分类表现。

初始卷积实验中，5×5 卷积加两个 3×3 卷积、输出 9×9 特征图的设置效果最好，OA=90.6%、F1=92.8%，略优于原始 7×7 初始卷积。

## 9. 局限性与待解决问题

第一，论文主要是二分类检测，未充分展开多攻击类型分类。真实 IDS 通常不仅要判断是否异常，还要区分 DoS、Probe、Exploits、Fuzzers、Backdoor 等攻击类型，这会显著增加类别不均衡和混淆难度。

第二，图像化方法虽然比 DeepInsight 简洁，但仍引入了额外的特征排序和迭代交换过程。论文报告了生成耗时对比，但没有充分分析在大规模在线流量场景中的端到端吞吐、延迟和内存消耗。

第三，UNSW-NB15 和 NSL-KDD 都是常用基准，但与真实生产网络仍有差距。作者也承认未来需要覆盖更真实流量的数据集，并考虑实时监控对模型速度的要求。

第四，论文对统计显著性、重复实验方差、置信区间没有展开。很多对比表来自不同文献，训练划分、预处理、二分类/多分类设定可能并不完全一致，因此横向比较只能作为参考。

第五，模型融合了多项改造：图像化、组合卷积、ResNeXt、SPPM、Soft Pool、Focal Loss。虽然做了消融，但仍可以进一步隔离每个环节的贡献，例如只改变距离度量但保持模型固定、只改变损失但保持采样策略固定。

第六，正文包未截断，本次理解基于完整提供文本；但如果用于正式引用或复现实验，仍建议回到 PDF 核对图表、公式排版和表格细节，尤其是 Table 5 中数据集训练/测试样本数的表述存在容易混淆之处。

## 10. 与本项目的关系

这篇论文与“入侵检测与网络异常检测”方向中等偏高相关。它适合放在“表格流量特征图像化 + CNN 入侵检测”这一条线中，而不是传统时序流量建模或无监督异常检测主线。

对本项目有三点参考价值：

第一，提供了一种把网络流量 tabular data 转成 image representation 的可复用思路。若项目中已有 NetFlow、CICFlowMeter 或 UNSW 类特征，可以尝试类似的特征邻近映射。

第二，说明小尺寸流量图像不应盲目套用 ImageNet CNN。初始卷积核、池化尺度、特征图大小都需要按 11×11、14×14 这类输入重新调试。

第三，Focal Loss 适合本项目中攻击样本稀缺、类别长尾明显的场景。但如果项目目标是未知攻击检测，还需要结合无监督、半监督或开放集识别方法。

## 12. 本篇精华

1. 论文核心不是“又一个 ResNeXt IDS”，而是把网络流量特征重排成保留邻近关系的二维图像，再用 CNN 学习非相邻特征关系。
2. 标准化欧氏距离是图像化阶段的关键选择，它比普通欧氏距离更适合量纲差异明显的网络流量特征。
3. 生成图像后，UNSW-NB15 被表示为 14×14，NSL-KDD 为 11×11，说明这是面向小尺寸特征图的 CNN 任务。
4. SPPM 的价值在于多尺度上下文聚合，Soft Pool 的价值在于比平均池化保留更多激活细节。
5. Focal Loss 主要服务类别不均衡和难样本学习，在攻击召回率上有直接意义。
6. 最终模型在 UNSW-NB15 上达到 OA 93.3%、F1 95.2%、Recall 96.3%，是论文最重要的实验主张。
7. 最大局限是缺少真实在线部署评估、多分类攻击识别不足、跨文献对比条件未完全统一。
8. 这篇适合综述中归入“基于图像化表征的深度入侵检测”和“多尺度 CNN IDS”两个小节。

## 13. 建议精读路线

建议先读第 3.3 节数据图像化方法，这是论文真正区别于普通 CNN IDS 的部分。重点看 F、I 两个排序矩阵、误差函数、特征交换优化，以及为什么标准化欧氏距离更合理。

第二步读第 3.4 节 SPPM。需要把它和 PSPNet 的 PPM、SoftPool 原始思想联系起来理解：论文不是发明多尺度池化，而是把软池化嵌入 IDS 图像分类场景。

第三步读第 4.4 节和 Fig. 7、Fig. 8。这里验证图像化方法本身是否有效，不能只看最终模型结果。

第四步读第 4.6 节消融实验。重点判断每个模块是否真的贡献明显，尤其是 SPPM+Focal Loss 是否稳定优于 PPM、BCE 和原始 ResNeXt。
