# [844] When Unknown Threat Meets Label Noise: A Self-Correcting Framework

## 2. 中文翻译与核心摘要

这篇论文的核心命题是：真实 NIDS 不只是“训练标签有噪声”或“部署后遇到未知攻击”这两个问题之一，而是二者会互相放大。未知攻击被误判为已知类后，如果又进入后续训练数据，就会变成新的标签噪声；标签噪声又会扭曲已知类特征空间，使未知样本更容易贴近错误边界，形成“噪声-误检-更多噪声”的循环。

AEGIS-Net 的回答是一个共享编码器上的双模块框架：训练阶段用密度差异驱动的多原型机制纠正噪声标签，使已知类特征更紧凑；检测阶段不用假设流量服从高斯、EVT 或其他特定分布，而是基于 KNN/ANN 的邻近距离判断未知攻击。论文最有价值的地方不是单独提出一个标签纠错器或一个开集检测器，而是把“标签纠错改善特征空间”和“稳定特征空间支撑未知检测”连接成闭环。

## 3. 论文解决的具体问题

论文把弱先验知识下的 NIDS 拆成两个强耦合任务：

- T1：在训练标签可能错误的情况下，仍要准确分类已知恶意攻击。
- T2：部署环境中出现训练集没有覆盖的攻击类别时，仍要把它们识别为未知攻击，而不是强行归入某个已知类。

作者认为既有方法的问题在于分治：标签噪声研究多默认类别闭集，未知攻击检测研究多默认训练标签可靠。现实中这两个假设都不稳。特别是加密流量、混淆流量、自动标注工具误差、人工标注经验差异，会让“已知类边界”和“未知类拒识边界”同时变差。

## 4. 创新点深度提炼

1. 多原型标签纠错：不是为每个类别找一个中心，而是承认网络流量类内天然多簇。例如同为 benign，可能包含浏览、邮件、传输等多种行为；同为 DDoS，也可能有洪泛、放大、应用层等模式。单原型会抹平这些差异，多原型更符合流量结构。

2. 密度差异驱动：作者观察到干净样本在其标注类别的特征空间里更容易形成高密度区域，噪声样本则更像离群簇或低密度点。因此先根据相似度矩阵计算密度 `ρ`，再用相似性度量 `η`避免多个原型都落在同一个子簇。

3. 标签纠错不是离线清洗，而是训练中循环发生：先预训练得到初步表征，再每个 epoch 重新选原型、投票生成纠正标签，并把原标签与纠正标签共同用于损失函数。

4. 未知检测采用模型无关的 KNN 范式：检测模块不训练参数，只依赖归一化特征空间中测试样本到已知训练样本的第 `k` 近邻距离。这样它可以挂接到不同编码器后面。

5. 理论主张集中在“特征空间稳定性”：如果标签纠错与对比学习能让噪声训练下的特征分布接近无噪声情形，则 KNN 距离分布和阈值随噪声率变化有限，未知检测性能不应随标签噪声明显退化。

## 5. 科学问题与研究假设

科学问题可以概括为：在没有未知类训练样本、且已知类标签本身不可靠时，能否同时控制闭集经验风险与开放空间风险？

论文隐含并显式使用了几条关键假设：

- 干净样本与噪声样本在深度特征空间中存在密度差异。
- 已知流量类别不是单峰分布，而是多子簇分布，因此需要多个原型。
- 纠正后的标签能提升类内紧凑性和类间可分性。
- 未知攻击虽然可能与已知类局部重叠，但总体上在 KNN 距离分布上可与已知类区分。
- 如果特征空间稳定，即噪声情形下编码器 `E` 与理想无噪声编码器 `E*` 的输出偏移足够小，那么基于距离分位数的未知检测阈值对噪声率不敏感。

## 6. 科学方法与技术路线

整体技术路线是三段式：

1. 流量预处理：原始网络流按五元组切分为双向流，用 CICFlowMeter 等工具提取统计特征；删除 Flow ID、源/目的 IP、端口、时间戳等容易造成记忆化的字段，只保留数值特征。

2. 已知类训练与标签纠错：CNN/ResNet 编码器先用噪声标签预训练 `Npre=20` 个 epoch。之后提取每类样本特征，构造余弦相似度矩阵，计算密度 `ρ` 与相似度指标 `η`，为每类选 `p` 个原型。样本对所有类别原型求平均余弦相似度，得分最高者作为纠正标签 `ŷ`。总损失为原标签交叉熵、纠正标签交叉熵和 InfoNCE 对比损失的加权和。

3. 未知攻击检测：训练完成后冻结编码器，提取归一化特征。对测试样本计算其到已知训练样本特征集合的第 `k` 近邻距离，用已知训练样本距离分布的分位数设阈值。距离过大判为未知，否则进入已知类判别。

## 7. 实验设计与实验步骤

可复核流程如下：

1. 数据：已知类数据使用 Mal_TLS2023、CICIDS2017、CICIDS2018；未知类数据使用 CICDarknet2020。Mal_TLS2023 含 23 类、92,034 条 TLS 恶意流，特征维度 117；CICIDS2017 含 benign 加 14 类攻击；CICIDS2018 选 2018-03-02 与 2018-02-16 两天，转为二分类；CICDarknet2020 含 Tor/VPN 派生的 8 类 darknet 流量。

2. 预处理：删除类别型标识字段，保留数值统计特征；对类别不平衡数据做欠采样；训练/测试按 7:3 划分；构造对称噪声和非对称噪声，噪声率覆盖 0.1 到 0.5。

3. 模型与基线：AEGIS-Net 主干是多层残差 CNN。标签噪声处理基线包括 Co-teaching、MCRe、RAPIER；未知检测基线包括 RoFi、Trident、RFG-HELAD。

4. 训练：SGD，学习率 0.001，50 epochs，前 20 epochs 预训练，batch size 128 或按数据集调整，`α=0.1`，`β=0.5`，对比损失温度参数用于稳定特征空间。

5. 未知检测：取倒数层或中间层归一化特征，KNN 设置 `k=50`；工程实现中用 ANN/FAISS 加速近邻检索；阈值按训练集中已知样本距离分布设定，目标是保证较高比例已知流量通过。

6. 指标：已知类分类看 Accuracy、Precision、Recall、F1；未知检测看 Accuracy、AUC/AUROC、FPR、AUIN 等。

7. 消融与敏感性：测试原型数 `p`、近邻数 `k`、采样数 `m`、截断密度分位数 `Sc`、损失权重 `α/β`、是否使用对比损失、是否预训练、是否启用标签纠错。

8. 结果核查：用理论噪声上界、纠错后纯净样本比例、异常分数分布图、倒数层特征可视化共同验证，而不是只报告单个表格结果。

## 8. 关键结果、结论与证据

闭集已知攻击分类方面，AEGIS-Net 在高噪声下优势明显。Mal_TLS2023 对称 10% 噪声时，Accuracy 为 96.69%，F1 为 96.37%；非对称 50% 噪声时仍达到约 89% 级别，而 Co-teaching 的 F1 降到 64.98%。CICIDS2017 非对称 50% 下 AEGIS-Net 仍有 81.32% Accuracy；CICIDS2018 二分类场景下高噪声仍接近 99.7%。

未知攻击检测方面，作者最强调的是性能几乎不随噪声率下降。Mal_TLS2023 对称 50% 噪声下，AEGIS-Net 未知检测 Accuracy 为 98.76%，而 RoFi、Trident、RFG-HELAD 分别约为 74.19%、55.18%、62.59%。CICIDS2017 非对称 50% 下，AEGIS-Net AUC 为 98.60%，远高于 RFG-HELAD 的 55.45%。

可视化证据也支撑方法动机：已知类在特征空间中呈多簇结构，未知 darknet 流量多分布在已知簇边界或外部；异常分数分布中，已知与未知样本重叠很少。消融实验显示，预训练是必要的；无标签纠错时性能明显不足；对比损失主要提升已知类鲁棒分类，对未知检测影响较小。

## 9. 局限性与待解决问题

论文自己承认三点：第一，正常流量分布随时间漂移时，当前方法可能失效，需要引入概念漂移检测；第二，若对抗样本被故意构造成“更接近错误类别”，会干扰基于密度和原型的纠错；第三，效率上还需要研究哪些环节可并行化。

我认为还应补充几项研究风险。其一，理论证明依赖特征空间稳定性，但这更像经验可满足条件，不是任意噪声模式下的保证。其二，未知类使用 CICDarknet2020，与已知数据集之间可能存在较强数据源差异，未知检测任务可能比同源新型攻击更容易。其三，非对称噪声规则是人工设定的，未必覆盖真实 SOC 标注错误。其四，KNN/ANN 需要保存训练特征库，在线部署时有内存、更新和延迟问题。正文包未截断，但若用于严格复现，仍建议回 PDF 核对图表、附录证明和表格排版细节。

## 10. 与本项目的关系

这篇论文与“入侵检测与网络异常检测”高度相关，尤其适合放在综述中“弱监督/弱先验 NIDS”“开放集入侵检测”“加密恶意流量检测”“标签噪声鲁棒学习”几个位置。

对本项目最可借鉴的是：不要把未知攻击检测只写成 OOD 后处理，也不要把标签噪声只写成数据清洗。AEGIS-Net 提供了一个更完整的问题框架：训练数据不干净会污染特征空间，特征空间不稳会削弱未知检测，因此需要联合考虑。若本项目有真实告警闭环或持续学习场景，这个“误检样本回流形成新噪声”的论点非常适合作为问题动机。

## 11. 代码对照分析

本地代码主线与 README 一致：先训练，再抽取特征，最后做未知检测。README 给出的顺序是 `training.py -> extract_features.py -> Unknown_detection.py`，见 [README.md](<F:\泉城实验室\二期\论文\异常检测\source\AEGIS-Net\README.md:1>)。

- 数据加载与预处理入口在 [util/datasets.py](<F:\泉城实验室\二期\论文\异常检测\source\AEGIS-Net\util\datasets.py:8>)。它实现了 `load_malicious_TLS`、`load_IDS_2017`、`load_IDS_2018_friday`、`load_Darknet2020`，使用 `LabelEncoder`、`MinMaxScaler`、`train_test_split`，并对 CICIDS 做欠采样。本地 `dataset` 目录实际只有 `label_encodered_malicious_TLS-1.csv` 和 `cleaned_data.csv`，缺少 README 提到的 CICIDS2017/2018 CSV。

- 噪声注入和训练入口在 [training.py](<F:\泉城实验室\二期\论文\异常检测\source\AEGIS-Net\training.py:12>)。`symmetric_noise` 与 `asymmetric_noise` 对应论文的对称/非对称噪声实验；主程序加载数据、生成噪声标签、调用 `DeepResNet.fit`，最后保存模型并输出分类指标。

- 模型定义在 [Network.py](<F:\泉城实验室\二期\论文\异常检测\source\AEGIS-Net\Network.py:36>)。`DeepResNet` 是 1D CNN 残差网络，通道从 64 扩展到 1024，经全局平均池化得到 1024 维特征；`info_nce_loss` 对应论文中的对比学习；`fit` 中前 20 epoch 预训练，之后调用标签纠错并混合原标签损失、伪标签损失和对比损失。

- 标签纠错在 [label_correction.py](<F:\泉城实验室\二期\论文\异常检测\source\AEGIS-Net\label_correction.py:3>)。这里实现余弦相似度矩阵、密度 `rho`、原型选择、平均原型相似度投票生成伪标签，和论文 IV-B 的多原型纠错机制对应。

- 特征缓存入口在 [extract_features.py](<F:\泉城实验室\二期\论文\异常检测\source\AEGIS-Net\extract_features.py:69>)。它加载已训练模型，调用 `feature_list` 抽取四个残差块的池化特征并拼接成 1920 维，然后缓存训练集、验证集和 Darknet2020 的 `features.npy`。

- 未知检测在 [Unknown_detection.py](<F:\泉城实验室\二期\论文\异常检测\source\AEGIS-Net\Unknown_detection.py:22>)。它默认使用 `malicious_TLS` 作为已知集、`Darknet2020` 作为 OOD，截取拼接特征最后 128 维，L2 归一化后用 FAISS `IndexIVFFlat` 做 ANN 检索，`k=50`，以第 k 近邻距离的相反数作为分数。

- 指标和阈值逻辑在 [util/metrics.py](<F:\泉城实验室\二期\论文\异常检测\source\AEGIS-Net\util\metrics.py:45>)。代码用训练分数的低分位阈值保证约 95% 已知样本通过；由于分数取的是负距离，所以“已知”是分数高，“未知”是分数低，这与论文公式中的距离阈值方向相反但语义一致。

需要注意几处实现与论文叙述并不完全一致。`Network.py` 中调用 `produce_pseudo_labels(z, y.numpy(), self.classes, epoch)`，把 `epoch` 传给了原型数 `p`，而论文实验固定选择 `p=14`；`label_correction.py` 中原型选择也没有显式实现论文描述的 `η < 0.95` 筛选。未知检测脚本截取的是 1920 维拼接特征的最后 128 维，而论文主文更强调倒数第二层归一化特征。`requirements.txt` 还包含若干本地 wheel 路径和与本项目无关的包，环境复现需要清理。

## 12. 本篇精华

1. 论文真正的问题意识是“未知攻击”和“标签噪声”的耦合，而不是单点优化。
2. 多原型机制抓住了网络流量类内多簇这一事实，比单中心原型更符合 IDS 数据结构。
3. 标签纠错的作用不只是提高闭集分类准确率，更重要的是修复未知检测依赖的特征几何。
4. KNN/ANN 未知检测的优势在于不假设特征分布，适合加密和混淆流量这类难建模对象。
5. 理论证明的核心前提是特征空间稳定；这是方法成立的关键，也是不足之处。
6. 实验中未知检测几乎不随噪声率退化，是论文最强的结果叙事。
7. 代码实现提供了完整运行链路，但与论文细节存在若干差异，复现表格前必须逐项核对超参数和特征选择。
