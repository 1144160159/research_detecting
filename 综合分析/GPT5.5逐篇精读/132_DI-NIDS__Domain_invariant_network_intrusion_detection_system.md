# [132] DI-NIDS: Domain invariant network intrusion detection system

## 1. 基本信息

论文发表于 *Knowledge-Based Systems* 273，2023，DOI：`10.1016/j.knosys.2023.110626`。作者为 Siamak Layeghy、Mahsa Baktashmotlagh、Marius Portmann，来自 The University of Queensland。

主题属于入侵检测与网络异常检测，核心关键词是对抗域适应、跨域 NIDS、域不变异常检测、One-Class SVM。正文包标注未截断，本次阅读基于完整正文文本。代码包状态为未发现本地对应开源实现；我在本地工作区也未发现 DI-NIDS 官方代码目录，仅看到代码检索记录中有一个未验证的同名 GitHub 候选，不能视为论文配套代码。

## 2. 中文翻译与核心摘要

题名可译为：**DI-NIDS：域不变网络入侵检测系统**。

这篇论文针对一个很实际的问题：用公开基准数据集训练的机器学习 NIDS，一旦部署到特征分布明显不同的网络环境，性能会严重下降。作者认为，普通域适应方法在入侵检测中效果有限，一个重要原因是 NIDS 数据高度类别不平衡，攻击流量是少数类，而多数域适应方法更接近监督分类范式，天然偏向类分布较均衡的任务。

DI-NIDS 的思路是先用 DANN 学习源域与目标域共享的域不变特征，再把这些特征交给 One-Class SVM 做异常检测。换言之，它不是直接让 DANN 完成最终分类，而是把 DANN 当作跨域表征投影器，把 OSVM 当作面向少数异常的检测器。

## 3. 论文解决的具体问题

论文解决的是 **NIDS 跨数据集、跨网络环境部署时的分布偏移问题**。训练域与测试域可能来自不同网络、不同采集工具、不同攻击集合、不同背景流量，导致特征分布差异很大。传统 ML 模型在同域测试中 F1 很高，但跨域测试会崩溃，例如 Random Forest、Extra Tree、LSTM、MLP 在两组跨域实验中的平均 F1 都明显偏低。

作者特别强调：入侵检测里的“异常”不是稳定、均衡、可充分标注的类别，而是稀有事件。直接把计算机视觉里的域适应分类器搬到 NIDS 上，容易被类别不平衡和攻击类别差异拖垮。

## 4. 创新点深度提炼

第一，论文把 **域不变表征学习** 与 **一类异常检测** 串联起来。DANN 解决“源域和目标域特征空间不一致”，OSVM 解决“攻击样本稀少、不宜完全依赖监督分类”的问题。

第二，实验采用了更严格的双向跨域评估：既做 NFv2-CIC-2018 → NFv2-UNSW-NB15，也做 NFv2-UNSW-NB15 → NFv2-CIC-2018。论文指出单向跨域结果可能误导，因为方向不同，性能可以高度不对称。

第三，作者没有只报同域性能，而是把同域 F1 与跨域 F1 的退化幅度作为核心证据。这比单纯追求高 F1 更接近真实部署问题。

第四，论文用 DANN、OSVM 以及 DI-NIDS 三者分别实验，相当于做了组件级对照：单独 DANN 不稳定，单独 OSVM 跨域仍受分布偏移影响，两者组合才形成主要增益。

## 5. 科学问题与研究假设

科学问题可以概括为：**能否在没有目标域类别标签的条件下，学习一种既保留攻击/正常可分性、又消除网络域差异的流量表示，从而提升 NIDS 跨域泛化能力？**

核心假设有三条。第一，源域和目标域虽分布不同，但存在可学习的共享隐空间。第二，DANN 的梯度反转机制可以削弱域可判别性，同时保留源域上的类别可判别性。第三，在域不变空间中，正常流量分布更稳定，OSVM 能比普通二分类器更适合处理稀有异常。

这里也隐含一个部署假设：训练时可以获得目标网络的未标注流量。DI-NIDS 是无监督域适应，不是完全不看目标域数据的域泛化。

## 6. 科学方法与技术路线

技术路线是两阶段。

第一阶段训练 DANN。模型包含特征提取器 `Gf`、标签分类器 `GC`、域分类器 `GD`。源域样本有攻击/正常标签，目标域样本没有类别标签，但源域和目标域都有域标签。训练目标一方面让 `GC` 在源域上能区分 Benign/Attack，另一方面通过梯度反转层让 `GD` 难以判断样本来自哪个域。

第二阶段使用训练好的 `Gf` 提取 10 维域不变特征，再训练 OSVM。OSVM 的角色是学习正常样本的密度边界，把明显偏离正常分布的样本判为异常。

论文表 1 给出 DANN 结构：`Gf` 两个隐藏层，每层 10 节点，输出 10 维；`GC` 输出 2 类；`GD` 有一个 10 节点隐藏层并输出 2 类。正文同时提到 NetFlow 输入为 43 个字段，而表 1 写 `Gf` 输入节点为 39，这一点可能来自预处理删字段或编码差异，但正文没有充分解释。

## 7. 实验设计与实验步骤

1. 数据：使用 NFv2-UNSW-NB15 与 NFv2-CIC-2018。前者约 239 万条流，Benign 占 96.02%，9 类攻击聚合为 Attack；后者约 1889 万条流，Benign 占 88.05%，14 类攻击聚合为 Attack。

2. 预处理：使用 NetFlow v9 统一特征空间，避免原始 UNSW-NB15 与 CIC-2018 特征集合不同导致不可比。多类攻击统一合并为二分类 Benign/Attack。

3. 模型：主模型为 DANN + OSVM。基线包括 Random Forest、Extra Tree、LSTM、Feed Forward MLP、AutoEncoder、Isolation Forest、单独 OSVM、单独 DANN。

4. 训练：同域实验分别在同一数据集上训练和测试；跨域实验做两个方向，CIC-2018 训练、UNSW-NB15 测试，以及反方向训练测试。DANN 训练使用源域标签和目标域未标注样本。

5. 指标：主要报告 F1-Score，并计算跨域性能相对同域性能的退化幅度。

6. 消融/敏感性：论文的主要消融是拆开 DI-NIDS 的两个组件，比较 DANN、OSVM、DANN+OSVM；同时用结构相近的 MLP 观察域分类器分支的作用。但没有充分做 `lambda`、OSVM `nu`、目标域样本比例、特征维度等敏感性分析。

7. 结果核查：除表格外，论文用 Isomap 可视化原始特征与 DANN 投影后特征，观察两个数据集是否靠近、Attack/Benign 是否更可分。

## 8. 关键结果、结论与证据

同域实验中，DI-NIDS 表现已经很强：NFv2-CIC-2018 上 F1 为 93.23%，NFv2-UNSW-NB15 上 F1 为 98.68%，平均同域表现最高，接近或超过 OSVM、DANN 等组件模型。

跨域实验是论文最关键的证据。CIC-2018 → UNSW-NB15 时，DI-NIDS F1 为 85.79%，退化 7.44%；UNSW-NB15 → CIC-2018 时，DI-NIDS F1 为 93.29%，退化 5.39%。两向平均跨域 F1 为 89.54%。

相比之下，传统监督模型跨域几乎失效：Random Forest、Extra Tree、LSTM、MLP、Isolation Forest 的平均跨域 F1 均不超过约 29.88%。单独 OSVM 和 AutoEncoder 在某一方向可以较好，但方向敏感；单独 DANN 在一个方向达到 61.94%，另一个方向只有 17.31%。这说明 DI-NIDS 的优势不只是来自 DANN 或 OSVM 单组件，而是来自“先对齐、再做一类检测”的组合。

与 Pontes 等人的 EFC 方法相比，DI-NIDS 平均跨域退化为 6.42%，对方为 19.3%。虽然数据集不同，绝对 F1 不宜直接比较，但退化幅度说明 DI-NIDS 跨域稳定性更好。

## 9. 局限性与待解决问题

第一，DI-NIDS 需要目标域未标注数据参与训练，因此更准确地说是无监督域适应，而不是无需目标域数据的域泛化。真实部署中，目标网络流量窗口如何采样、是否包含攻击污染，会影响稳定性。

第二，实验只覆盖两个 NetFlow 化公开基准数据集，尚未证明在真实生产网络、长期概念漂移、加密流量占比变化、设备拓扑变化下仍稳定。

第三，攻击类别全部聚合为 Attack，掩盖了不同攻击族之间的差异。模型证明了二分类异常检测能力，但没有证明多攻击类型识别、未知攻击归因或细粒度告警能力。

第四，正文没有给出足够完整的复现细节，例如 OSVM 核函数与关键超参数、训练样本采样策略、目标域未标注样本使用范围，以及 43 个 NetFlow 字段与表 1 中 39 输入节点之间的差异。

第五，指标以 F1 为主，对 NIDS 工程部署仍不够。高类别不平衡环境下还应报告误报率、漏报率、PR-AUC、告警量、阈值敏感性和在线检测开销。

第六，DANN 主要做边缘分布对齐，若源域和目标域的类别条件分布不一致，可能发生类条件错配或负迁移。论文用可视化说明投影后更接近，但还没有充分量化类条件对齐质量。

## 10. 与本项目的关系

这篇论文与异常检测项目强相关，尤其适合作为“跨域泛化 NIDS”或“域对抗异常检测”的基础参考。它直接支持一个判断：只在单一数据集上做高精度入侵检测并不可靠，真正有价值的是跨网络环境的性能保持能力。

如果本项目关注跨园区、跨设备、跨采集环境或跨数据集的异常检测，DI-NIDS 可以作为基线思路：用 GRL/域判别器学习域不变表征，再接异常检测器。若本项目进一步做动态图、少样本、开放集或多模态流量检测，则可把 DI-NIDS 作为静态表征对齐基线，再扩展到时序关系、图结构和未知类别检测。

## 12. 本篇精华

- NIDS 的核心部署难题不是同域精度，而是训练网络和目标网络的特征分布偏移。
- 传统域适应分类器在 NIDS 上不理想，原因之一是攻击样本极少，类别不平衡严重。
- DI-NIDS 的关键组合是：DANN 学域不变空间，OSVM 在该空间做一类异常检测。
- 双向跨域评估很重要；只做 A→B 不做 B→A，可能误判方法稳定性。
- DI-NIDS 两向跨域 F1 分别为 85.79% 和 93.29%，平均 89.54%，明显优于普通 ML 基线。
- 单独 DANN 或单独 OSVM 都不足以稳定跨域，组合后才显著降低性能退化。
- 论文仍停留在二分类公开基准验证，真实网络、细粒度攻击、在线漂移和误报成本仍待研究。
