# [545] SENTINEL: Insider Threat Detection Based on Multi-Timescale User Behavior Interaction Graph Learning

## 2. 中文翻译与核心摘要

这篇论文的核心思想是：不要把每条日志都建成图节点，而是把内网中的主机、用户或系统实体作为节点，把用户跨主机、跨服务的操作行为作为边。这样构造出的行为交互图 BIG 既保留了用户在网络拓扑中的移动轨迹，也避免了“日志即节点”导致的巨大图规模。

SENTINEL 进一步认为，内部威胁不是单一时间点的异常，而是用户行为在位置、时间和操作属性上的联合偏离。它用边特征注意力学习不同日志字段的重要性，用 GCN+GRU 学习空间拓扑依赖和时间演化，再把日、周、月三个时间尺度的状态融合起来，以同时捕捉突发型威胁和慢速潜伏型威胁。训练阶段只使用正常日志，通过负采样构造“伪异常边”，最终对每条日志级行为边输出异常分数。

## 3. 论文解决的具体问题

论文面对的是组织内网中的内部威胁检测：攻击者可能是恶意员工，也可能是被攻陷账号背后的外部攻击者。他们通常已经拥有合法凭据，能绕过边界防护和常规认证，因此传统 IDS/IPS、防火墙、基于权限的信任管理很难直接拦截。

具体困难有四类：第一，恶意样本极少，监督学习难以获得足够标签；第二，攻击步骤分散在认证、DNS、网络流、文件、设备等多源日志中；第三，横向移动会造成跨主机、跨账号、跨服务的碎片化轨迹；第四，攻击可能既有短时突发行为，也有长期缓慢演化，单一时间窗口容易漏报或误报。

## 4. 创新点深度提炼

第一，BIG 的建模粒度抓得比较准。论文没有延续 Log2vec 等方法把日志作为节点，而是把日志行为作为边，节点数量由内网实体数量决定，而不是由日志量决定。这一点同时服务了建模语义和计算效率。

第二，论文强调“边特征比节点特征更关键”。内部威胁的异常往往体现在一次登录协议、文件路径、认证方式、设备使用、访问目标等操作属性变化上，而不是主机本身属性变化。因此 SENTINEL 用 EGAT 式的边特征注意力，把多字段日志属性聚合进节点表示。

第三，多时间尺度融合不是简单跑多个模型，而是在同一检测框架里融合日、周、月周期的图嵌入。这个设计针对内部威胁的两面性：短窗口更容易发现突然越权或异常登录，长窗口更容易发现持续性偏移。

第四，论文把检测目标落到 log-entry-level。每条行为边都有异常分数，这比只输出“某用户异常”更利于安全运营人员回溯具体证据。

## 5. 科学问题与研究假设

核心科学问题是：内部威胁是否可以被表述为用户行为交互图中边属性、空间路径和时间规律的联合异常。

主要研究假设包括：正常用户在特定时间和网络位置上具有稳定的操作规律；恶意内部行为会造成访问路径、交互对象或操作属性偏离历史基线；边上的日志字段包含比节点静态属性更强的威胁信号；同时观察多个时间尺度能比单尺度更稳健地区分偶发正常操作与持续恶意行为；在缺少真实攻击标签时，基于负采样的边判别训练能近似学习正常边与异常边的边界。

## 6. 科学方法与技术路线

技术路线可以概括为：日志解析 → BIG 快照构建 → 边特征增强 → 时空依赖学习 → 多尺度融合 → 边级异常评分。

原始日志被统一成包含 K 个字段的格式。数值字段直接保留，离散文本字段做序数编码，文件路径或资源描述等连续文本用 Word2Vec 转向量；缺失字段用 0 填充。若用户在节点 i 和 j 之间产生交互，就形成带特征向量 Fij 的有向边。

模型先用多通道边注意力计算不同字段对邻居聚合的影响，再用 GCN 学习同一图快照内的空间拓扑模式；随后用历史窗口上的层次上下文注意力提取时间依赖，并通过 GRU 融合当前空间表示和历史时间表示。最后分别构造日、周、月尺度的滑动窗口，用门控/线性权重融合三个尺度的节点嵌入。异常分数由源节点表示、目标节点表示和边特征共同决定。

## 7. 实验设计与实验步骤

数据：论文使用 LANL、CERT r6.2 和 TWOS。LANL 选认证、DNS、网络流，含 504 个用户、7825 个主机、约 593 万事件和 698 个恶意事件；CERT 使用登录、可移动设备、文件操作，含 30 个用户、4400 主机、40051 事件和 161 个异常事件；TWOS 使用登录、鼠标、键盘记录，含 1433094 事件和 1892 个恶意事件。

预处理：按固定时间切分图快照。LANL 用前 40 小时正常行为训练，1 小时一个快照；CERT 用前 200 天正常行为训练，半天一个快照，并区分 7:00-19:00 与 19:00-次日 7:00；TWOS 用第一天正常行为训练，1 小时一个快照。所有日志字段被编码为统一边特征。

模型/基线：SENTINEL 对比 LODA、LOF、LSTM 语言模型、AddGraph、EGAT、Log2vec、LMTracker。SENTINEL 设置时间窗口为 3，GCN 层数为 3，隐藏维度 512，dropout 0.2，学习率 0.001，margin γ=0.7，TensorFlow 2.11 实现。

训练：训练集只含正常边。每条正常边通过替换源或目标节点生成负样本，替换概率与端点度相关。损失函数采用边级 pairwise margin loss，使正常边分数低于负采样边，并加 L2 正则。

指标：使用 Accuracy、ROC、AUC、TPR、FPR；论文也报告不同威胁场景下的 TPR/FNR。由于内部威胁严重类别不平衡，AUC 比 accuracy 更有解释力。

消融/敏感性：论文测试快照长度、时间尺度组合、关键模块移除、训练集比例、检测阈值选择。结果核查重点包括：多源日志是否优于单源日志，边特征增强是否关键，多尺度融合是否真有增益，以及不同威胁场景是否稳定。

## 8. 关键结果、结论与证据

多源日志场景下，SENTINEL 在三个数据集上取得最高 AUC：LANL 为 0.980，CERT 为 0.960，TWOS 为 0.956。相比单源日志，三个数据集 AUC 分别提升 0.008、0.040、0.035，说明多源行为证据确实补足了单一日志视角。

多时间尺度实验中，CERT 上半天快照优于更长快照，AUC 从月级窗口的 0.677 提升到半天窗口的 0.941；日+周+月融合达到 0.960，优于任一单尺度。这支持作者关于突发威胁和持久威胁需要同时建模的判断。

消融实验中，去掉边特征增强导致 AUC 下降 0.084，是最明显的性能损失；去掉空间依赖学习比去掉时间依赖学习伤害更大，说明内部威胁在访问拓扑和交互对象上的偏移非常关键；去掉多尺度融合 AUC 下降 0.019，增益存在但不是唯一主因。

场景分析很有价值：SENTINEL 在 CERT 的 S1、S2、S4 上平均 TPR 约 98%，但在 S3 管理员滥用场景中漏掉约 42% 恶意行为。这说明模型擅长发现“偏离日常习惯”的行为，却难以识别“形式上像正常职责、内容上恶意”的行为。

## 9. 局限性与待解决问题

本次正文包未截断，因此这里主要讨论方法和复现层面的局限。

最关键的局限是语义意图不足。S3 场景失败说明，如果管理员本来就经常登录多台机器，单靠交互对象、时间和协议特征很难判断这次登录是否恶意。论文未来工作提到引入心理健康或社交记录，但这会带来隐私、合规和伦理问题；更可行的方向可能是命令内容、文件敏感级别、审批上下文和任务工单关联。

第二，阈值选择存在现实部署问题。论文通过测试集 ROC 上最大化 TPR-FPR 来选阈值，但真实无标签部署时无法这样调参。后续应给出无标签阈值校准、少量告警反馈校准或风险预算下的阈值策略。

第三，负采样只近似异常。替换端点生成的边不一定是真异常，尤其在大型企业里“未见过访问”可能只是新业务流程。pairwise loss 能缓解但不能消除这种伪标签噪声。

第四，日志字段编码仍偏粗糙。离散字段用序数编码可能引入不存在的大小关系，Word2Vec 对文件路径、命令行、URL 这类安全文本的语义表达也有限。更强的字段级嵌入和类型感知编码可能提高可解释性与泛化能力。

## 10. 与本项目的关系

这篇论文与你的“异常检测、图学习、知识图谱与威胁情报”方向中相关，相关性分数 8 是合理的。它不是典型恶意流量分类论文，也不是暗网检测论文，但它提供了一个很适合迁移到网络安全多源日志融合的图建模范式。

对本项目最有启发的是“边即事件”的思想。若迁移到恶意流量或攻击检测，可以把 IP、主机、账号、域名、服务作为节点，把流量会话、DNS 查询、认证、文件访问作为边；边特征可以放入流量统计、协议、SNI、JA3、URL token、认证类型、时间段等。这样能把流量检测从单条流特征提升为行为路径检测。

它也能服务威胁情报生成：SENTINEL 的边级异常分数天然对应具体证据，进一步聚合后可以形成“账号-主机-文件-外联域名”的攻击链视图，比单纯给出异常标签更接近安全运营需求。

## 12. 本篇精华

- SENTINEL 的核心不是“用了 GNN”，而是把内部威胁检测重新表述为内网实体之间的边级行为异常检测。
- 把日志作为边而不是节点，是同时降低图规模和保留行为语义的关键设计。
- 内部威胁的强信号往往在边属性：认证协议变化、登录类型变化、文件/设备/流量行为变化，比主机静态属性更敏感。
- 多时间尺度融合解决的是“短期异常”和“长期潜伏”之间的检测张力，实验中日+周+月优于单尺度。
- 只用正常数据训练是部署优势，但负采样异常与真实攻击之间仍有语义差距。
- 模型对偏离习惯的恶意行为很强，对“管理员滥用正常权限”这类近似日常职责的恶意行为明显不足。
- 论文的可复现风险主要在数据预处理、阈值选择和缺少官方代码，而不是模型公式本身。
- 对安全运营最有价值的输出是日志级异常边，可进一步汇聚为攻击路径和威胁情报证据链。
