# [750] Multi-Dimensional Cross-Granularity Open-Set Network Intrusion Detection

## 1. 基本信息

- 题名：Multi-Dimensional Cross-Granularity Open-Set Network Intrusion Detection
- 中文可译：多维跨粒度开放集网络入侵检测
- 年份：2026
- 来源：IEEE Transactions on Network and Service Management, Vol. 23, 2026
- DOI：10.1109/TNSM.2026.3693141
- 作者：Minh-Thuyen Thi, Mohan Gurusamy
- 主题归属：入侵检测、开放集检测、异常检测、半监督学习、最优传输、多粒度流量表征
- 与异常检测相关性：强。论文核心就是在未知攻击/OOD攻击条件下，用仅良性训练样本加少量带标签验证样本做开放集入侵检测。

## 2. 中文翻译与核心摘要

这篇论文提出 MDCG-IDS，一个面向开放集网络入侵检测的半监督异常检测框架。它不把入侵检测看成传统的闭集多分类问题，而是把真实网络中不断出现的新攻击、未知攻击、训练分布外攻击看成 OOD 检测问题：训练阶段主要只依赖良性流量，验证阶段用少量带标签样本校准参数，推理阶段判断新样本与良性参考分布之间的偏离程度。

论文的核心思想是：单一视角的流量特征容易留下检测盲区，因此要从三个互补维度刻画网络行为：流量统计维度、时间序列维度、空间/主机交互维度；每个维度再分成多个粒度，例如包、流、会话，短时间窗、长时间窗，会话级、主机级。作者把这些特征统一编码成 MDCG 张量，再用最优传输距离度量待测样本与良性训练分布之间的分布差异。数值型流量特征使用 Sinkhorn-Wasserstein 距离，符号型时间/空间特征使用 Gromov-Wasserstein 距离。

实验覆盖 CIC-IDS-2017、UNSW-NB15、TON-IoT、5GAD 四个数据集。MDCG-IDS 在整体 AUROC 上达到 0.948、0.962、0.954、0.956，优于多个闭集与开放集基线。论文特别强调：只用 3% 的验证标签时，模型已经接近完整验证集性能；在训练良性集被攻击样本污染 15% 时，AUROC 退化仍小于 6.7%。

## 3. 论文解决的具体问题

论文瞄准的不是普通监督式 NIDS，而是真实部署中更棘手的开放集场景：

1. 攻击类别不断扩展，训练集不可能覆盖所有攻击。传统闭集分类器会把未知攻击强行归入已知类别，无法可靠拒识。
2. 高质量攻击标签昂贵且不完整。安全数据有隐私、专有、误标和对抗规避问题，导致依赖大量攻击标签的监督学习很难落地。
3. 单一特征视角存在盲区。例如某些 APT 在包级统计上可能近似正常，但在跨流会话模式、协议序列或主机通信集合上异常。
4. 传统距离度量难以刻画分布结构。均值、方差、欧氏距离可能忽略“概率质量如何分布”的几何差异。
5. 部署上还要求少标签、可跨数据集、可抗污染、吞吐量不能过低。

因此，论文的问题可以概括为：如何在开放集 NIDS 中，用很少标签和主要良性流量，构建能跨维度、跨粒度捕捉未知攻击结构的异常评分方法。

## 4. 创新点深度提炼

第一，MDCG 特征表征。论文把网络样本拆成流量统计、时间序列、空间属性三个维度，并在每个维度上做多粒度分析。这比常见的“流级统计特征 + 分类器”更接近真实攻击的多尺度行为结构。

第二，统一张量编码。作者设计 `D × Gmax × Fmax` 的 MDCG 张量，把不同维度、不同粒度、不同数据类型的特征放进统一结构中。这个设计不是单纯为了形式化，而是为了后续批量计算不同粒度上的距离。

第三，把最优传输引入 NIDS。论文声称这是最优传输理论首次用于网络入侵检测。其关键意义在于：异常不是只看点到点距离，而是看待测样本与良性参考分布之间“分布质量搬运”的代价。

第四，数值特征与符号特征分别建模。流量统计维度使用 Sinkhorn-Wasserstein；时间和空间维度中的协议、端口集合、TCP flag 序列等符号信息使用 Gromov-Wasserstein，避免把符号类别粗暴当作连续数值。

第五，半监督开放集优化。训练参考分布只用良性样本，少量验证标签仅用于优化粒度权重、维度权重、正则项、sigmoid 参数和阈值相关行为。它降低了对攻击标签的依赖。

第六，实验不只做常规准确率。论文检查了 OOD-1/OOD-2、跨数据集迁移、标签量敏感性、训练集污染鲁棒性、计算吞吐和消融，比较全面地服务“能否部署”的论证。

## 5. 科学问题与研究假设

核心科学问题是：未知攻击与良性流量之间的差异，是否可以通过多维跨粒度分布偏移稳定地表现出来，并被最优传输距离可靠捕捉？

论文隐含了几个研究假设：

- 攻击即使在单一维度上伪装正常，也很难在流量统计、时间顺序、空间通信集合三个维度及多个粒度上同时保持正常。
- 良性流量可以形成相对稳定的参考分布；未知攻击相对于这个分布会产生可度量的结构性偏移。
- Wasserstein/Gromov-Wasserstein 距离比 KL、JS、欧氏距离更适合描述网络行为分布的几何差异。
- 少量带标签验证数据足以校准各维度、各粒度的重要性，而不需要完整攻击标签训练集。
- 多粒度时间窗对不同网络环境有差异，但多尺度组合比单一时间窗更稳健。

## 6. 科学方法与技术路线

技术路线可以分成五步。

1. 样本重构  
   以网络会话为主要样本单位，从原始包或流记录重构 flow/session。flow 基于五元组，session 基于双向流和 TCP FIN/RST 状态；UDP/ICMP 用端点和协议近似聚合。

2. MDCG 特征构造  
   流量维度提取包级、流级、会话级数值统计；时间维度提取不同时间窗下的符号序列；空间维度提取会话级和主机级的无序符号集合。

3. 张量编码  
   每个样本编码为统一张量 `z_i ∈ R^{D×Gmax×Fmax}`。数值特征做训练集均值方差归一化，符号序列用类别嵌入和位置嵌入，空间符号集合用类别嵌入和平均聚合。

4. 最优传输距离  
   对待测样本和良性训练分布，在每个维度、每个粒度上计算距离。数值特征用 Sinkhorn-Wasserstein，符号结构用 Gromov-Wasserstein。

5. 异常评分与参数优化  
   每个粒度距离先经过 sigmoid 映射，再按粒度权重合成维度分数，最后按维度权重得到总 OOD 分数。参数用验证集 AUROC 的可微近似目标优化。

## 7. 实验设计与实验步骤

可复核流程如下：

1. 数据  
   使用 CIC17、UNSW-NB15、TON-IoT、5GAD。CIC17/NB15 代表通用企业网络，TON 代表 IoT，5GAD 代表 5G 控制面攻击。每个数据集按 60%/20%/20% 划分，训练集只含良性流量，验证和测试集含正常与攻击样本。

2. 预处理  
   从原始捕获中恢复 IP、flow 和 session。flow 用五元组、10 秒 inactive timeout、30 秒 active timeout。session 用双向流和 TCP 状态划分；非 TCP 按端点、协议和 60 秒 inactivity 近似聚合。时间粒度默认使用 0.5s、10s、60s。

3. 特征  
   所有模型使用同一组 MDCG 特征。应用层协议在 5GAD 中因 TLS 不可用，因此为一致性从所有数据集中排除；消融中还测试了用目的端口近似应用协议的代理方案。

4. 模型与基线  
   闭集基线包括 SVM、Random Forest、TCG-IDS、LS-GRU、AHDM。开放集基线包括 Isolation Forest、One-Class SVM、FOSS、S-NIDS、CVAE-EVT。另有 FOSS-mg、S-NIDS-mg、CVAE-EVT-ot 等增强变体。

5. 训练  
   MDCG-IDS 用良性训练样本建立参考分布，用验证集优化权重、正则项和 sigmoid 参数。实现环境为 Python、PyTorch 2.1、POT，优化器 Adam，学习率 0.001，验证 AUROC early stopping。

6. 指标  
   主指标是 AUROC；在 Youden 指数确定的操作点上报告 FPR 和 F1。结果为 5 个随机种子的均值和标准差。

7. 消融/敏感性  
   检查单维度、双维度、无 MDCG、无 OT、欧氏距离、等权重、KL/JS 替代、不同时间窗、不同验证标签比例、训练污染比例、跨数据集迁移和计算效率。

8. 结果核查  
   论文用 t-SNE 和簇分离指标验证特征可分性，用优化曲线验证收敛，用 OOD-1/OOD-2 分解验证未知攻击检测能力，用吞吐/内存/延迟验证部署成本。

## 8. 关键结果、结论与证据

整体性能上，MDCG-IDS 在四个数据集 AUROC 分别为 CIC17 0.948、NB15 0.962、TON 0.954、5GAD 0.956，超过最强竞争方法约 3% 到 7%。

特征质量上，MDCG 表征在 CIC17 的 t-SNE 中比互信息筛选的 flat features 更能分开良性、ID 攻击和 OOD 攻击；簇间分离和簇内紧致性也明显提升。

消融结果支持三个判断：多维度优于单维度，流量+时间通常是最强双维组合，最优传输优于欧氏、KL、JS 等替代距离。5GAD 上时间维度单独就很强，说明控制面调用序列对 5G 攻击尤其关键。

标签效率是论文最有用的结果之一。只用 3% 完整验证集标签时，MDCG-IDS 已达到完整验证集性能的约 99.4% 到 99.5%，说明标签主要用于校准，而不是学习攻击类别本身。

鲁棒性方面，在良性训练集混入最多 15% 攻击样本时，CIC17 上 AUROC 退化小于 6.7%，明显好于传统无监督方法和其他开放集模型。

跨数据集方面，MDCG-IDS 平均性能下降 6.2%，小于基线的 11.8% 到 21.2%。TON 与 5GAD 互迁移表现较好，企业网到 5G 的迁移最难。

效率方面，CIC17 上吞吐约 12,500 packets/s，内存约 634 MB，每 1000 包约 80 ms。它慢于 Isolation Forest/OSVM，但与先进深度基线处于可比较范围，并换来明显更高的检测性能。

## 9. 局限性与待解决问题

第一，正文包标注未截断，因此本次理解不受文本截断影响；但图表的视觉细节、表格排版和公式符号仍建议回到 PDF 复核，尤其是 Table IV/V/VI/VII/IX/X 与 Fig. 7-10 的具体数值。

第二，论文没有给出可直接复现实验的代码包。预处理涉及 CICFlowMeter、Payload-Byte、nProbe、原始 pcap 重构和重新标注，实际复现门槛较高。

第三，方法依赖“足够干净的良性参考分布”。虽然污染实验显示 15% 污染下仍可用，但真实网络中良性基线漂移、业务周期变化、攻击长期潜伏会更复杂。

第四，符号特征的嵌入和 Gromov-Wasserstein 建模细节仍可追问。例如协议、端口、flag 的关系结构如何初始化，是否会受数据集偏置影响，论文没有完全展开工程细节。

第五，计算复杂度仍是部署瓶颈。Sinkhorn 近似降低了 OT 成本，但多维多粒度张量和参考集距离计算对高吞吐骨干链路仍偏重。

第六，OOD-1/OOD-2 的划分虽然有意义，但仍是人为 hold-out。真实零日攻击与数据集内攻击族的关系可能更模糊。

第七，时间窗口默认固定为 0.5s/10s/60s。论文做了敏感性分析，但自适应粒度选择仍是未来工作。

## 10. 与本项目的关系

如果本项目关注“异常检测”或“开放环境下的入侵检测”，这篇论文价值很高。它提供了一个从闭集分类转向开放集异常评分的完整范式：只用良性样本建模，用少量标签校准，目标不是识别具体攻击名，而是发现偏离良性分布的未知行为。

对综述写作来说，它可以放在“开放集 NIDS”“半监督/一类学习”“多粒度流量表征”“最优传输异常检测”几个交叉位置。相比普通深度分类 NIDS，这篇更适合支撑以下论点：未来 NIDS 的关键不只是更强分类器，而是更好的行为表征、更少标签依赖和更强 OOD 拒识能力。

对后续研究来说，可以沿三个方向延伸：自适应粒度选择、面向加密流量的代理特征设计、结合联邦学习的跨组织良性分布建模。

- 数据预处理：应包含 pcap 到 flow/session 的重构逻辑，对应五元组 flow 切分、inactive/active timeout、TCP FIN/RST session 划分、UDP/ICMP 近似聚合、CIC17/NB15/TON/5GAD 标签回填。

## 12. 本篇精华

1. 论文把开放集 NIDS 的核心矛盾定义为：未知攻击不可穷举，攻击标签稀缺，闭集分类天然不适合真实部署。
2. MDCG 的价值在于让攻击必须同时“骗过”流量统计、时间序列和空间通信结构，降低单视角特征盲区。
3. 最优传输不是装饰性工具，它承担了比较“样本分布形状”与良性参考分布的关键角色。
4. 数值特征用 Sinkhorn-Wasserstein，符号结构用 Gromov-Wasserstein，是论文方法设计中最值得借鉴的异构特征处理思路。
5. 只用良性训练样本、少量验证标签校准，是比全监督攻击分类更贴近真实安全运营的设定。
6. 四数据集、OOD 分层、跨数据集、污染、标签量和效率实验共同支撑了“可部署开放集检测”的主张。
7. 主要短板在复现工程复杂、良性参考分布依赖、符号关系建模细节不足和高吞吐场景成本。
8. 对异常检测研究，本文适合作为“多视角表征 + 分布距离 + 半监督开放集”的代表性近期工作。
