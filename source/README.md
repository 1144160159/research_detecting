# source 开源代码库

本目录保存与论文相关的开源代码、数据集和复现项目。

## 主入口

- [开源代码汇总报告](开源代码汇总报告.md)

## 使用口径

- 本目录用于保存代码仓库原始内容，不直接作为论文报告主入口。
- 与论文相关的代码可在专题报告中引用，但代码本身保持原仓库结构。
- 若新增代码仓库，建议在 `开源代码汇总报告.md` 中补充来源、论文题名、仓库地址、下载状态和用途。

## 与专题目录的关系

- `多模态开放集加密恶意流量检测/` 主要引用本目录中的加密流量、开放集、图关系、LLM 相关开源项目。
- `AI驱动的网络流量检测分析系统/` 可引用 DIDS-MFL、TrafficLLM、E-GraphSAGE、DA-FDIDS 相关代码或远程代码分析结果。
