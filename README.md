# 异常检测论文项目空间

本工作区用于异常检测、网络入侵检测、加密恶意流量检测等方向的论文筛选、证据抽取、综述撰写、代码调研和选题沉淀。

当前主线有两条：

1. **多模态开放集加密恶意流量检测**：以 `paper/` 下 858 篇 PDF 为全量文献库，当前主线已升级为 Evidence-OpenEMTD 可信开放集检测。
2. **AI驱动的网络流量检测分析系统 / DA-FDIDS**：围绕 DA-FDIDS 模型方向判定、相关论文补充、综述部分和补充论文并入记录展开。

## 维护口径

- `paper/` 保留 PDF 原件，不在专题目录中复制 PDF。
- 专题目录只放分析、证据、索引、报告和图表产物。
- 主线分析以专题目录中的 README 为入口；根目录早期报告保留溯源，不作为最新主入口。
- 旧版、重复版、过程文件应进入对应专题下的 `99_归档_旧版重复/`，避免与主版本并列。
