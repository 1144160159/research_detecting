## 目录结构

- `01_综合报告/`：面向论文选题和汇报的总览、统计、精读清单。
- `02_逐篇详报/`：55 篇主线逐篇详报，按 A-E 相关性分层。
- `03_全文证据/`：全文证据筛选、严格相关判定、全文证据版逐篇分析。
- `04_原始解析与缓存/`：654 篇解析缓存、首页摘要解析、精选全文 txt 与结构化 JSON。
- `05_PPT与图表/`：PPT、图表、PPT QA 截图、生成脚本与图片资源。
- `99_归档_旧版重复/`：旧版通用详报和合并版，保留溯源但不作为主分析入口。

## 去重口径

1. 同一篇论文的主线分析只保留在 `02_逐篇详报/` 的 A-E 子目录中。
2. 合并版逐篇详报和通用旧版详报已归档，避免与主线逐篇文件重复。
3. 报告中的 PDF 链接仍指向工作区上级 `paper/` 目录；图表链接已调整到 `05_PPT与图表/assets/`。
