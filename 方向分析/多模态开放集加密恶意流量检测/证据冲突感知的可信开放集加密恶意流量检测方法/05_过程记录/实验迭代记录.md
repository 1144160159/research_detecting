## 1. 固定记录字段

每次实验必须记录：实验编号、日期、方案版本、代码版本、数据集及文件摘要、留出未知类别、已知类别、采样规则、数据划分随机种子、模型随机种子、超参数、风险权重、阈值标定方式、硬件环境、输出目录、指标、观察、结论和下一步动作。

实验状态使用：`计划`、`运行中`、`完成`、`失败`、`作废`。只有代码错误或数据泄漏导致的结果可标记为作废；性能不佳的有效实验必须保留为完成或失败。

|---|---|

| 方案版本 | v1.0 |
| 状态 | 完成 |

| 数据集 | `NF-UNSW-NB15-v2.csv`，约 441 MB |
| 未知类别 | Backdoor，仅进入测试集 |
| 采样 | 每类最多 1000 条，Worms 实际 164 条 |
| 划分规模 | train=5714，validation=1225，test=2225，其中未知测试样本 1000 条 |
| 模型 | M3 完整实现，3 个 MLP 代理视图 |
| 随机种子 | 7 |
| 核心参数 | epochs=3，batch=512，hidden=128，embedding=64，corruption=0.20 |
| 风险权重 | uncertainty=0.25，conflict=0.30，distance=0.30，energy=0.15 |
| 阈值标定 | 已知验证风险 95% 分位数 |
| 环境 | RTX A6000；PyTorch 2.1.2+cu121；Conda `py3.9` |
| 原始结果 | [results/01_基础与闭集验证/G-SMOKE-001](../results/01_基础与闭集验证/G-SMOKE-001) |

主要结果：

| 指标 | 结果 |
|---|---:|
| Known Accuracy | 0.4376 |
| Known Macro-F1 | 0.3637 |
| Unknown AUROC | 0.3517 |
| Unknown AUPR | 0.3834 |
| FPR@95TPR | 0.8988 |
| Unknown-F1 | 0.1324 |
| OSCR | 0.2096 |
| ECE | 0.2666 |
| Known Acceptance Rate | 0.9527 |
| Unknown Rejection Rate | 0.0750 |

诊断结果：已知平均风险为 0.4710，Backdoor 平均风险为 0.4175；已知平均冲突为 0.0888，Backdoor 平均冲突为 0.0864。风险方向和冲突方向均未形成未知分离。由于仅训练 3 轮且已知 Macro-F1 仍低，本轮不能区分“表征尚未收敛”和“冲突机制无效”，也不能据此调整风险权重。

实现事件：首次运行在混合精度环境中因 sigmoid 后的可靠度使用普通 BCE 而失败。代码已改为输出可靠度 logits，并使用 `binary_cross_entropy_with_logits`；本地和服务器 5 项单元测试通过，保持同一数据与参数重跑后完成。该修复属于数值稳定性修复，不改变方案结构。

下一步动作：先补充每个风险分量的均值与单项 AUROC，再运行收敛性基线。若已知分类收敛后 Backdoor 风险仍低于已知样本，则进入视图划分与冲突独立性诊断，而不是提高冲突权重。

主要结果：

| 指标 | G-SMOKE-001 | G-CONV-001 |
|---|---:|---:|
| Known Accuracy | 0.4376 | 0.6442 |
| Known Macro-F1 | 0.3637 | 0.5622 |
| Unknown AUROC | 0.3517 | 0.3948 |

| FPR@95TPR | 0.8988 | 0.8454 |

风险分量诊断：

| 分量 | 单项 AUROC | 已知均值 | 未知均值 | 判断 |
|---|---:|---:|---:|---|
| 融合不确定性 | 0.7440 | 0.6069 | 0.8050 | 方向正确 |
| 能量 | 0.7440 | -1.6845 | -0.7480 | 与不确定性排序近似重复 |
| 最大信念反值 | 0.6912 | 0.6711 | 0.8813 | 方向正确但与不确定性相关 |
| 正常类原型距离 | 0.6551 | 2.8850 | 3.3721 | 具有一定恶意倾向判别能力 |
| 最近类别原型距离 | 0.2903 | 0.1563 | 0.0890 | 方向相反，Backdoor 靠近某已知攻击原型 |
| 有效冲突 | 0.2072 | 0.0082 | 0.0036 | 方向相反 |
| 原始冲突 | 0.1981 | 0.0083 | 0.0037 | 方向相反 |

结论：训练增加后已知分类持续改善，但复合未知风险仍被最近类别原型距离和冲突项拖累。现有冲突定义的分子由双方信念质量乘积决定；Backdoor 的不确定性更高、已承诺信念质量更小，因此即使不同视图意见比例不一致，冲突绝对量仍会变小。该结果触发单一结构候选改动：用双方已承诺信念质量乘积归一化冲突，得到条件冲突。能量与不确定性的重复计权问题保留到下一轮风险消融处理，不在同一实验中同时修改。
