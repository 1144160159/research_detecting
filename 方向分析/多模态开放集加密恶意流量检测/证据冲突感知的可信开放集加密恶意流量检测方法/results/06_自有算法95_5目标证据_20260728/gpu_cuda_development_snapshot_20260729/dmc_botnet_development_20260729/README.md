更新时间：2026-07-29

本目录保存 DMC-CAEOS、统计模态消融、修正纯序列对照及 PSF-DMC 互补性诊断的本地只读副本。本地只做汇总；训练均来自远端 A6000，正式效果仍属于 seed29 开发结果，不是 fresh 确认。

## 结论边界

DMC 的已知类聚类和误报控制有效，但没有形成可迁移到 Botnet 的共享恶意边界。统计特征捷径是主要原因之一，却不是全部原因；清除统计捷径后仍比 PSF 低 4.39 个百分点。下一分支应使用“轮流留出一个已知恶意家族”的元训练外循环，显式要求内循环未见家族仍被判为恶意，不再增加静态对比损失或简单分数融合。
