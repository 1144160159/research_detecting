# strict-v4 D1-D7 冲突度量专项报告

> 完成时间：2026-07-20  
> 范围：七数据集、102 个 seed7 冻结开发场景  
> 性质：机制统计分析，不参与模型或阈值选择

## 1. 结论

条件归一化冲突 D6 获得跨套件支持：平均 Unknown AUROC `0.714025`，比原始 DS 冲突 D5 高 `0.143181`。该差值的 10,000 次 bootstrap 95% CI 为 `[0.083157,0.203062]`，单侧配对 Wilcoxon `p=1.4689e-6`，七个数据集套件的平均差均为正。

可靠度加权条件冲突 D7 的平均 AUROC 略高至 `0.722043`，但相对 D6 只在 50% 场景改善，不能声明为稳定的额外未知检测增益。最终算法应保留条件归一化，把可靠度用于污染鲁棒融合，而不是全局提高冲突风险。

## 4. 机制取舍

1. D5 受已承诺证据总量影响，低证据会把真实方向分歧压低；条件归一化修复了这一结构性问题。
2. D6 在平均意义和多数场景中有效，但最差 AUROC 仅 `0.032653`，不能作为全局单一风险。
3. D7 相对 D6 的平均差为 `+0.008018`，但正增益率只有 `0.50`，可靠度权重不构成独立未知检测创新。
4. 自有算法继续采用“域安全路由 + 条件冲突局部使用”；可靠度保留在模态污染、缺失和折扣融合路径。
