## 五条精读主线

1. 开放集加密恶意流量：已知攻击分类、未知攻击拒识、未知簇发现。
2. 证据冲突与不确定性：Dirichlet 证据、主观逻辑、Dempster-Shafer、折扣信念融合。
3. 多模态表征：字节载荷、流统计、时序/交互图，以及真正多视图与伪多模态的区分。
4. 开放集指标与校准：Known Macro-F1、Balanced Accuracy、AUROC、AUPR-Out、FPR@95TPR、OSCR、ECE、Brier。
5. 强表征与基线：ET-BERT、YaTC、Energy、OpenMax、Open-Detect、RoNeTC、ECNet 等。

## 证据门

1. 没有 Zotero Item、Citation Key 和中文证据卡，不进入 `08_论文写作` 正文。
2. 论文自报指标只用于理解方法，不自动视为同协议 SOTA 证据。
3. 使用辅助 unknown、随机挑选 unknown、在测试集调阈值或仅报联合 F1 的工作，与 strict-v4 分开报告。
4. 中文证据卡中的“采纳”只表示进入候选实验，不代表已经验证有效。
