## 2. 摘要缩译

异常型网络入侵检测系统对网络安全很重要，但实际部署面临两项不足：其一，系统通常只能区分正常与异常，不能把此前未见的攻击进一步分成可操作的细粒度新类别；其二，业务变化会产生新的合法流量，固定的正常模型容易把它们误报为攻击。作者提出三条设计原则：划分数据分布的超平面而不是直接切分样本；利用“隔离”而不是距离或密度发现局部异常；通过增长与退役支持增量更新。FOSS 以隔离树为骨架，采用 Monte Carlo 特征选择、树级异常投票、未知路径编码聚类以及节点增长/退役机制。公共数据与 ISP 部署结果表明，FOSS 能检测并细分未知攻击，同时适应正常流量变化。

## 3. 引言与问题动机

签名型方法依赖已知攻击指纹，面对零日攻击失效；异常型方法可以检测偏离正常分布的样本，却通常只输出“异常”。运营人员真正需要的是“已知攻击 1、已知攻击 2、未知攻击 1、未知攻击 2”等细粒度结果，因为不同攻击需要不同的缓解措施。另一方面，仅用良性流量训练的一类检测器会把新的正常应用协议或业务形态误判为攻击，因此模型必须能吸收新增正常流量，也能遗忘已经退出的旧业务。

论文把两项能力合并为一个开放世界流程：先在已有良性与已知攻击上建立树模型；部署后把短路径且偏离叶节点数据云的样本判为未知；再根据它们在森林中的路径编码形成新的未知簇；经过人工核验后，新正常类或新攻击类可增量写回模型。这里的“细粒度未知标签”首先是模型生成的代号，并不等同于 Heartbleed、NTP Reflection 等语义名称，最终语义仍需安全人员或威胁情报确认。

## 4. 威胁模型与任务形式化

训练集由良性流量 B 与 n 个已知攻击类 {A₁ᵏ,…,Aₙᵏ} 构成。测试流除这些已知类别外，还含数量事先未知的攻击类 {A₁ᵘ,…,Aₘᵘ}。模型目标不是只输出一个 unknown，而是输出：

ŷ ∈ {B,A₁ᵏ,…,Aₙᵏ,A₁ᵘ,…,Aₘᵘ}

其中 m 在训练时未知。业务变化时，原始正常集合 {L₁ᵒ,…,Lₛᵒ} 还会增加 {L₁ⁿ,…,Lqⁿ}；模型需要通过树增长直接吸收新正常样本，并在旧业务退出后通过节点退役减少过时分支。

攻击者可以使用训练期污染以及测试期插入/规避手段；作者假设受害方事前拿不到未知攻击数据，也不依赖外部 IP 黑名单，但在业务变化时能够提供一部分经确认的新正常样本。研究聚焦加密流量，不读取 TCP payload 语义，而以包头字段和流级统计刻画行为。

## 5. 三条设计原则

### 5.1 划分超平面

监督分类器按现有标签切分样本，可能把空间中从未被训练数据覆盖的区域仍归给已知类；一类模型又只建立正常边界。FOSS 递归划分整个特征超平面，使未知样本也能落入一条可比较的树路径。这样做的核心不是宣称所有开放空间都已被建模，而是为“是否容易被隔离”和“不同未知是否经过相似路径”提供统一表示。

### 5.2 使用隔离而非全向量距离

若两个 d 维向量只在第 j 维不同，全向量距离可能稀释这一局部差异。FOSS 让每个节点只考察一个维度，异常若在少数维度显著偏离，就可能用更短路径被隔离。该设计对局部异常有合理直觉，但性能仍依赖原始 106 维特征是否包含攻击差异。

### 5.3 增长与退役

新增样本到达已有叶节点后，只对满足条件的叶节点继续分裂，不重训既有结构；旧样本不再需要时合并或删除相应分支。增量机制既可吸收新正常业务，也可把经确认的未知攻击纳入已知库。

## 6. 输入与特征工程

样本单位为双向五元组流：源/目的 IP、源/目的端口和协议。每流提取 106 维手工特征：1 维协议编码；33 维二、三、四层标志计数，分别统计正向、反向和双向；72 维时序、流量体积及 TTL、窗口大小等字段在三个方向上的最大值、最小值、均值和标准差。特征均为整数或浮点数。

这是一条单源统计特征路线，不是 CAEOS 所定义的包字节、包序列、流统计三分支多模态。它适合作为表格型强基线或风险分支，却不能证明多模态融合有效。论文还承认应用层字段缺失会把 HTTP GET Flood 与 POST Flood 合并，说明“加密友好”与“细粒度语义可分”之间存在信息上限。

## 7. FOSS 方法缩译

### 7.1 单树构建与 Monte Carlo 维度选择

每个节点从当前样本集 S 选择维度 q，再在以下区间均匀随机产生切分点：

p ∼ U[min S⁽q⁾, max S⁽q⁾]

把样本分为 Sₗ = {x | x⁽q⁾ < p} 与 Sᵣ = {x | x⁽q⁾ ≥ p}。达到最大深度 hₘₐₓ、节点样本数不大于 Sₘᵢₙ 或样本完全相同时停止。论文采用 hₘₐₓ = ⌈log₂ ψ⌉，其中 ψ 为每棵树的子采样规模。

与完全随机选择维度不同，FOSS 每次先随机抽取 nₛₐₘ 个候选维度，再按“取值离均值分散且概率分布不混杂”的加权熵选择。若维度 q 的不同取值为 xᵢ、经验概率为 pᵢ，其期望为：

E(S⁽q⁾) = ∑ᵢ₌₁ᵏ xᵢpᵢ

加权熵写为

Hq = ∑ᵢ₌₁ᵏ {−pᵢlog₂pᵢ ÷ |xᵢ − E(S⁽q⁾)|}

选择较小 Hq 的候选维度。该策略是随机搜索与确定性特征选择之间的折中，但分母接近零时的数值处理、归一化和并列规则需要依赖代码核验。

### 7.2 森林、异常检测与已知分类

森林由 Nₜᵣₑₑ 棵并行构建的树组成，每棵树从训练集独立子采样。测试样本要同时满足两项条件才在该树上被标记为未知：第一，根到叶的路径异常短；第二，它偏离落入叶节点的数据云中心。

每棵树把训练叶路径长度排序为 L，选择断点 ℓ，使断点两侧路径长度标准差之差最小：

L* = arg minℓ∈{1,…,max(L)} |σ(Lₗ) − σ(Lᵣ)|

若样本同时满足短路径和叶内偏离，则该树投票为 UnknownClass，否则投票为叶节点已知标签。森林输出多数票：

ŷ = arg maxy∈{c₁,…,cₙ,UnknownClass} F[y]

这里的阈值来自训练树自身的路径与叶节点分布，并未在正文中看到用目标未知验证集选择拒识阈值，因此其静态拒识部分可作为 P0 候选；但是聚类参数与整体超参数如何选定、是否观察过测试未知仍需代码和实验脚本核验。

### 7.3 未知类别细分

所有被拒识的样本进入缓冲区。对样本 x，记录其在 Nₜᵣₑₑ 棵树上的二进制路径编码：

P(x) = ⟨C₁(x),…,Cₙₜᵣₑₑ(x)⟩

两个样本的相似度由各树路径的最长公共前缀计算，再跨树聚合。若相似度达到邻接阈值 Aᵈ，就在未知样本图上连边；连通/密集程度达到最小类规模 M꜀ 后形成一个新未知类别。这样无需预先给出未知类数，但 Aᵈ 和 M꜀ 实际控制聚类粒度，仍是任务先验。

### 7.4 模型更新

经过确认的新正常或攻击样本可触发叶节点增长；各树独立更新。退役机制根据旧业务样本的消失合并不再需要的分支，限制模型规模和过时知识。动态评估中，增长只处理新增部分，因此比全量重训快；然而如果自动把错误伪标签写回，误差会沿树结构累积，论文主要依靠专家抽查与退役缓解，并没有给出严格的错误传播界。

## 8. 实验设置

公开实验使用 CICIDS2017 和 ISCX VPN-nonVPN 2016。前者约 51 GB，包含 8 类攻击；后者约 28 GB，提供 7 类正常应用。默认训练/测试比例为 6:4，每组随机划分与实验执行 10 次。FOSS 设置为 nₛₐₘ = 10、Nₜᵣₑₑ = 200、采样率 ψ = 60%、Sₘᵢₙ = 10、未知聚类参数 Aᵈ = 30、M꜀ = 300。

二分类对比包括 Whisper、Diff-RF、Kitsune；细粒度对比包括 K-means、DBSCAN、FARE、Cls-Anomaly 和 SENC。指标分两组：正常/攻击二分类使用 FPR、FNR、Precision、Recall、F1；细粒度新类发现使用 clustering accuracy（ACC）与 adjusted mutual information（AMI）。

协议上，攻击类按已知/未知比例 Nₖ:Nᵤ 划分，并多次随机抽类；这比固定单一 unknown 组合更稳健。但论文主指标 ACC/AMI 把已知分类、未知拒识和未知聚类合在一起，不能替代 CAEOS 的三层指标，也无法从中恢复 FPR@95TPR 或 OSCR。训练/测试为随机流划分，正文未说明按 capture/fingerprint 分组，存在同源泄漏风险。

## 9. 主要结果缩译

### 9.1 二分类与细粒度识别

四个二分类方法的准确率均超过 92%；FOSS 达到超过 98% 的 ACC、低于 1.2% 的 FPR 和超过 98% 的 F1。逐项表格数值在当前文本抽取中未恢复，正式引用前必须从 PDF 表 V 图像核对。

细粒度实验设置五组：全已知 8:0、全未知 0:8，以及三组随机选择攻击类型的 4:4。FOSS 在五组中均达到 ACC 超过 92%、AMI 超过 91%；DBSCAN 固定为 ACC 63.01%、AMI 62.78%。当未知类数从 0 增至 8 时，FOSS 总体优于 FARE、Cls-Anomaly 和 SENC；即使全部攻击均未知，ACC 与 AMI 仍超过 86%，十次实验标准差约 1%。

这些结果证明路径编码可用于未知簇发现，但不是严格 OSR 的同口径胜负：FARE 被告知真实类数，FOSS 使用固定最小簇规模；不同方法获得的先验不同。ACC 还依赖未知簇与真实标签的最优映射，不能直接解释为 unknown detection recall。

### 9.2 动态业务实验

作者按 CICIDS2017 的星期时间线设计 7 个阶段：第 1 阶段只用周一正常流训练；第 2、3、5、6 阶段依次出现 2、1、3、2 类攻击并触发更新；第 4 阶段加入 VPN2016 正常流量，第 7 阶段移除它们并触发退役。各阶段整体 ACC/AMI 大体超过 92%。初始训练耗时 296 s，后续五次增长分别为 27、17、75、43、46 s，退役为 25 s。该实验展示增量效率，但同一时间线上的后续阶段已吸收前阶段标签，因此不能与“未知永不用于训练”的静态 P0 主表混合。

### 9.3 鲁棒性与部署

训练污染实验说明子采样对污染有缓冲作用。测试期插入/规避比例各取 5%、10%、20%；最坏组合使 ACC/AMI 下降小于 7%。在 Nₖ:Nᵤ = 8:0 且扰动比 20% 时，规避与插入对应的 AMI 分别降至 90.42% 和 92.17%。这些扰动是否保持真实攻击语义主要依据构造规则，尚不等同自适应白盒攻击。

真实 ISP 测试覆盖 2020-2021 年、超过 20 万活跃主机。作者按周训练 8 个模型，并采取“8 个模型均报异常才接受”的保守规则。一次事件中，现有过滤器报告 27 类，FOSS 形成 49 类；人工分析确认两者重合 25 类，FOSS 额外发现若干基于 TCP 标志组合和 SSL/TLS 行为的簇。由于没有完整真值，这属于案例验证，不能作为准确率或漏报率的无偏估计。

## 10. 论文结论与局限缩译

作者认为 FOSS 通过超平面划分、隔离式局部异常感知和增量树更新，实现了已知/未知攻击的细粒度识别以及动态正常流量适应。论文明确列出五项局限：Monte Carlo 搜索仍会采到大量无效维度；不同客户需要不同检测粒度；特征提取和参数选择需要自动化；组合型强攻击仍未充分研究；形式化验证、可扩展性与解释性仍需加强。

此外，真实部署暴露了更直接的信息局限：未使用应用层细节时，模型不能区分 HTTP GET 与 POST Flood；作者也观察到部分加密协议版本差异和目标型攻击无法由当前特征充分刻画。这意味着未知簇的“细粒度”是表征空间中的可分性，而不是攻击语义的天然保证。

## 11. 独立方法评价

FOSS 的真正贡献是把异常拒识、未知聚类和增量更新连成开放世界流程，并用树路径把“为何是异常”与“属于哪个新簇”复用起来。它尤其适合 CAEOS 的两条交付线分工：静态论文主线可借鉴隔离风险；工程扩展线可研究经人工确认后的类增量更新。

但它不是 CAEOS 的直接同协议 SOTA。第一，FOSS 报告 ACC/AMI，而 CAEOS 的核心是 Known Macro-F1、Balanced Accuracy、Unknown AUROC/AUPR、FPR@95TPR 与 OSCR；第二，FOSS 的 unknown 聚类利用测试批次缓冲区，属于 transductive/batch discovery，而 CAEOS 的拒识需要逐流在线得分；第三，随机流划分可能高估跨 capture 泛化；第四，FOSS 使用手工统计单视图，没有证据校准、模态缺失或冲突处理。

从 95%/5% 安全验收看，论文只有二分类 FPR 小于 1.2% 和 F1 大于 98% 的汇总陈述，不能推出开放集的已知恶意分类超过 95%且良性误报低于 5%，更不能推出 FPR@95TPR 小于 5%。相关门槛必须在 CAEOS strict-v4 上重新测量。

## 12. 对 CAEOS-EMTD 的可执行映射

1. 增加 `FOSS-stat` 强基线：只使用统一预处理数据中的流统计与包头统计，不接触 payload 语义；在完全相同的 grouped split 和 unknown family 场景运行。
2. 将隔离风险作为独立组件：在融合嵌入或统计分支上训练 Isolation Forest/FOSS 风格树，输出 rᵢₛₒ，与 energy、distance、support、conflict 分别报告单项 AUROC。
3. 不把未知聚类结果并入主表。另设“未知发现扩展表”，报告 unknown detection 后的 NMI/ARI/ACC、簇纯度及人工核验成本。
4. 增加良性漂移场景：训练期只含原始良性，测试引入新正常应用，单独报告 Benign FAR；随后只用已确认的新良性更新，报告恢复速度与遗忘。
5. 复现时固定 Nₖ:Nᵤ 的类别清单、10 个抽类种子与 capture-grouped 划分；所有阈值和聚类参数只能在允许的 validation 数据上确定。
6. 做同预算消融：random dimension、deterministic dimension、Monte Carlo weighted entropy；同时报告树数、推理吞吐、峰值内存与参数敏感性。
7. 把 FOSS 的 8 模型全体一致规则视为 selective prediction 候选，并测 known acceptance、unknown rejection 与 coverage-risk 曲线，而不是只引用案例。

## 14. 一句话结论

FOSS 是“未知攻击拒识后继续细分并增量吸收”的重要开放世界基线，但其单视图手工特征、批式未知聚类和 ACC/AMI 指标不能直接替代 CAEOS 的多模态可信拒识；最有价值的迁移是隔离风险分支、良性漂移实验和未知发现扩展线。
