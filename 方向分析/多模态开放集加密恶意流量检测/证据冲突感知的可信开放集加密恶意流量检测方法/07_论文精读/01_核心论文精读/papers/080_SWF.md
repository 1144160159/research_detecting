论文关注的不是 unknown attack rejection，而是加密恶意流量二分类在“弱信息”条件下的可靠性。弱信息包括图连接断裂、节点特征缺失和训练标签稀缺。作者提出 TrustWI：先从同一受损交互图产生三个互补视图，再把各视图输出转换为 Dirichlet 证据意见，以 Dempster-Shafer 规则融合。三个数据集的实验显示，在合成的弱信息与极弱信息条件下，TrustWI 通常优于所选图模型和流量检测模型；摘要所称的 85.45% 到 89.57% 是 DoHBrw 极弱信息场景下 AUC 的相对最强基线比较，不是未知攻击 AUROC。

## 2. 引言缩译

加密协议保护隐私，也让攻击者可以隐藏载荷和行为。图神经网络能够利用主机交互关系，但实际部署无法保证图与特征完整：丢包、NAT、VPN 和动态地址会破坏连接；端口共享与流量复用会削弱流语义；专家标注成本又造成标签稀缺。

既有特征补全方法多依赖短程传播以避免过平滑，因此无法补偿远距离连接丢失。既有边补全方法通常在传播前根据原始、残缺特征建边，容易同时产生假边和漏边。多数工作只处理一种缺失，未联合建模结构、特征与标签不足。

TrustWI 的三项主要设计是：

1. View-L 通过带重启的长程扩散扩大信息传播范围。
2. View-S 在语义传播之后依据更新表征补边，减少由残缺原始特征造成的错误连接。
3. View-P 再次传播 View-S，并与 View-L 拼接，显式表示语义增强与结构修复之间的交互。

每个视图输出证据与不确定性，最终以 Dempster-Shafer 规则动态融合。作者强调这里的权重是样本级可靠性，而不是固定权重或只依赖表示的注意力。

## 3. 相关工作缩译

加密恶意流量检测从载荷规则转向统计学习、深度序列和交互图。Kitsune 使用在线自编码器；ST-Graph 建模时空关系；ContraMTD 以对比学习联合局部行为和主机图。弱信息研究包括数据补全、鲁棒图学习和低质量标签修正，但通常没有同时覆盖连接、特征与标签不足。

多视图学习希望利用共享信息和视图特异结构。MI-GNN 用多任务方式构造补充视图，ECNet 融合内容与模式特征，但 ECNet 的融合门控没有显式建模各视图的不确定性，标量置信度也与融合过程分离。

不确定性学习方面，MC Dropout 和深度集成需要多次前向推理；高斯方差可能把重构难度与模型不确定性混在一起。证据深度学习将非负证据映射为 Dirichlet 分布，能同时表示分类信念和整体无知。TrustWI 采用这一表达并用主观逻辑与 Dempster-Shafer 规则融合多视图意见。

## 4. 问题定义缩译

原始交互图表示为：

G = (V, E, A, H)

V 是主机节点集合，节点以 IP 地址标识；若两主机之间存在网络流，则在 E 中建立边。A 是邻接矩阵，H 是 d 维流统计特征矩阵。论文称流由源/目的 IP 与源/目的端口组成的四元组标识，没有把传输层协议纳入流键。

半监督任务给出少量有标签节点，学习映射：

ŷₜ = TrustWI(A, H, vₜ ∣ Θ)

弱信息通过二值掩码 Ωᴬ 与 Ωᴴ 模拟：

Ḡ = (V, E, A ⊙ Ωᴬ, H ⊙ Ωᴴ)

其中 Ωᴬ 删除边，Ωᴴ 把部分节点特征置零。目标是在受损图 Ḡ 上预测正常或恶意标签。这里没有 known family 标签空间、unknown 类或拒识动作。

## 5. 三视图表示学习缩译

### 5.1 View-L：长程传播

作者采用带重启的扩散：

H⁽ᵗ⁺¹⁾ = (1 − α) ÃH⁽ᵗ⁾ + αH⁽⁰⁾

Ã 是行归一化邻接矩阵，α 是重启概率。第一项聚合邻居，第二项在每轮注入原始特征，防止深层传播把节点表示完全抹平。经过 T 次迭代得到 H̄ = H⁽ᵀ⁾。实验把传播深度扩展到 12-20 步，明显长于常见的 2-3 层 GNN。

### 5.2 View-S：传播后结构增强

作者不直接使用残缺的 H 建边，而是用 View-L 的 H̄ 计算余弦相似度。对节点 i、j，若二者相似度同时达到各自的自适应近邻阈值，则添加边：

Âᵢⱼ = 1，若 s(H̄ᵢ, H̄ⱼ) ≥ min[τ(H̄ᵢ, c), τ(H̄ⱼ, c)]；否则 Âᵢⱼ = Aᵢⱼ

τ(H̄ᵢ, c) 是节点 i 与第 c 个最相似节点的相似度，c = max(|Nᵢ|, |Nⱼ|)。该阈值沿用原图局部度数，试图在漏边和假边之间取得平衡。

### 5.3 View-P：视图交互

对 Â 和 H̄ 再做一次扩散得到 H′，再拼接 H̄ 与 H′ 形成 View-P。它不是独立采集模态，而是从 View-L 与 View-S 派生的伪视图，用来刻画“增强语义如何影响补边、补边又如何改变传播”。

因此，TrustWI 的“多视图”是同一图数据的算法派生视图，不等于 CAEOS 所要求的统计、载荷字节、时序/交互结构三种观测模态。

## 6. 证据学习与不确定性感知融合缩译

### 6.1 Dirichlet 意见

每个视图的变分网络输出非负类别证据 eₖ，并令：

αₖ = eₖ + 1

总证据强度、类别信念和整体不确定性为：

S = ∑ₖ₌₁ᴷ αₖ

bₖ = eₖ / S

u = K / S

u + ∑ₖ₌₁ᴷ bₖ = 1

证据越多，u 越小；所有类别证据为零时，u = 1。该不确定性反映模型缺少支持，而不是独立校准后的错误概率。

### 6.2 证据损失

对样本 i，期望交叉熵写为：

Lᵢ = ∑ₖ₌₁ᴷ yᵢₖ[ψ(Sᵢ) − ψ(αᵢₖ)]

为抑制错误类别证据，作者将真类对应 Dirichlet 参数替换为 1，得到 α̃，并加入指向均匀 Dirichlet 的 KL 正则：

Lᴿ = KL[Dir(p ∣ α̃) ∥ Dir(p ∣ 1, …, 1)]

单视图目标为：

L = ∑ᵢ₌₁ᴺᴸ Lᵢ + λₑLᴿ

λₑ 从 0.01 开始，每个 epoch 增加 0.01，最大为 1。该退火让模型先学习可分性，再逐渐强化错误证据惩罚。

### 6.3 Dempster-Shafer 融合

两个视图 a、b 的冲突质量为：

C = ∑ᵢ≠ⱼ bᵢᵃbⱼᵇ

融合后的类别信念与不确定性为：

bₖ = [bₖᵃbₖᵇ + bₖᵃuᵇ + bₖᵇuᵃ] / (1 − C)

u = uᵃuᵇ / (1 − C)

三个视图依次融合得到 View-F。论文声称高不确定性视图不会显著损害结果，并能把输入不确定性传到输出；但当 C 接近 1 时分母很小，经典 Dempster 归一化仍可能放大极端冲突，论文没有在开放集或分布外样本上专门验证这一风险。

总训练目标是四个意见损失之和：

Lᵃˡˡ = Lᴸ + Lˢ + Lᴾ + Lᶠ

其中前三项约束单视图，最后一项约束融合意见。

### 9.2 标签稀缺、标签噪声与对抗边

在结构和特征均缺失 50% 时，标注比例为 0.5%、1%、5%，TONIoT 的 TrustWI AUC 分别为 82.35%、83.90%、88.42%，均高于 GCN、Pro-GNN、MI-GNN。

训练标签随机翻转 50% 时，TrustWI 的 ACC 为 TONIoT 78.5%、DoHBrw 95.8%、CICIDS 88.3%；相对 clean 分别下降 12.6、2.7、4.8 个百分点。TONIoT 对标签噪声仍较敏感，只是比 GCN/GAT 下降更缓。

TONIoT 测试图随机注入正常与异常节点间的假边。当注入率从 0% 增至 20%，TrustWI 从 93.72 降至 88.47；简单融合从 87.12 降至 67.30，传播前增强从 90.85 降至 73.95。该实验支持传播后增强比两种对照更稳，但它是随机边注入，不是自适应白盒攻击。

### 9.3 定性不确定性

预测分布图显示正常与恶意概率集中在两端。向测试特征注入高斯噪声后，预测不确定性随噪声强度上升。DoHBrw 的融合视图保持接近最佳单视图的准确率，同时不确定性中位数从约 18%-20% 降至约 3%-4%。这说明融合后的数值更“确定”，但论文没有用 ECE、Brier、NLL、risk-coverage 或 error-detection AUROC 验证这种确定性是否校准。

## 10. 消融、敏感性和效率缩译

表 VII 显示完整 TrustWI 的 AUC 为 TONIoT 93.72%、DoHBrw 87.75%、CICIDS 97.37%。只保留 View-L、View-S 或 View-P 时，TONIoT AUC 仅 81.25%、82.77%、85.26%；简单融合与注意力融合约为 86.90%-87.52%。传播前结构增强为 90.85%，仍低于传播后完整模型。

不同基图下，完整模型在 TONIoT 的 AUC 为 93.2%-93.7%；去除 View-L 或 View-S 会下降约 9.5-13.1 个百分点。该结果说明后续增强组件的贡献大于初始构图启发式。

传播深度在 12-20 附近较优；α = 0 会过平滑，过大的 α 又削弱长程信息。自适应近邻阈值的假边率为 12.5%、AUC 93.7%；c = 5 虽把假边率降至 7.8%，AUC 只有 91.2%；c = 20 的假边率升至 24.6%、AUC 90.1%。余弦相似度在表 IX 中优于欧氏距离和 Pearson 相关。

复杂度为：

O(dT · |E| + dK · |V|)

## 11. 结论与未来工作缩译

TrustWI 以长程传播修补信息不足，以传播后结构增强降低假边，以交互伪视图表示两者协同，再用证据融合输出预测和不确定性。实验表明其在多种合成弱信息条件下通常优于所选对照。

作者承认未来仍需处理强目标图攻击；View-P 较轻量，可能遗漏更丰富的结构和时间线索；后续可用图注意力或协同训练建模更复杂的跨视图依赖。

# 第二部分：独立技术分析

## A. 任务边界与可比性

TrustWI 是半监督、transductive 倾向的正常/恶意图节点二分类器。它没有攻击家族分类、unknown 留出、拒识阈值、unknown 标签或 OSCR。因此：

- 对 CAEOS 安全检测线：只能作为 closed-set/恶意二分类及图鲁棒性组件基线。
- 对 CAEOS 未知发现线：没有聚类、命名、人工检查或增量学习，不能直接支持。
- 对开放集主表：不能把其二分类 AUC 写成 Unknown AUROC，也不能把其普通误报率写成 FPR@95TPR。

协议记为 `P?-closed-set-transductive/hyperparameter-selection-unclear`，可比性记为 `C1-component-only`。

## B. “多视图”与 CAEOS 三模态的区别

TrustWI 的三个视图共享同一交互图和同一流统计特征，View-S、View-P 还是由 View-L 计算结果派生。它属于同源图多视图，不是独立观测模态。CAEOS 的三模态至少要求：

1. 流统计特征；
2. payload/header 字节序列；
3. 包长/方向/时间序列或跨流交互图。

TrustWI 可贡献第 3 模态的图分支和冲突融合机制，但不能作为“CAEOS 已实现三模态”的证据。

## C. 协议风险

1. 随机 3:1 split 未按 capture、时间、设备或五元组组隔离，容易共享会话指纹和拓扑邻居。
2. 单图半监督传播可能在训练时使用测试节点特征与邻接关系，属于 transductive information exposure。
3. 50% 删边、50% 置零是人工随机缺失，不能代表 NAT、VPN、丢包与采集盲区的真实机制。
4. 非图基线不承受边缺失，各方法受损条件不完全一致。
5. 网格搜索没有给出独立 validation、选择目标和种子，存在 test-tuned 风险。
6. 论文未报告五种子均值、标准差、显著性或效应量。
7. DoHBrw 特征数正文 28、表 I 29，不一致。
8. 四元组流键忽略协议；与 CAEOS 统一五元组和官方标签对齐协议不一致。

## D. 对证据冲突机制的启示与限制

可采纳的组件：带重启长程传播、传播后补边、自适应近邻阈值、单视图辅助监督、样本级 Dirichlet 意见和噪声强度－不确定性曲线。

不能直接采纳的结论：融合不确定性降低不等于校准更好；普通二分类 AUC 提升不等于 unknown rejection 提升；Dempster 归一化在高冲突 C → 1 时仍可能不稳定；派生视图间高度相关，不满足经典证据独立性假设。

CAEOS 应新增显式的高冲突保护：在 C 接近 1、证据总量过低或模态缺失时，优先 abstain，而不是强制归一化到 known 类。

## E. 三层指标与 95%/5% 判断

| 层级 | TrustWI 报告 | CAEOS 必补 |
|---|---|---|
| 已知识别 | ACC、Precision、Recall、F1、二分类 AUC | Known Macro-F1、Balanced Accuracy、逐类 Recall、Benign FAR |
| 未知检测 | 无 | Unknown AUROC、AUPR、FPR@95TPR、Unknown-F1 |
| 联合开放集 | 无 | OSCR、Known Acceptance、Unknown Rejection |
| 校准/选择性 | 不确定性分布图 | ECE、Brier、NLL、risk-coverage、error AUROC |

TrustWI 无法接受 CAEOS 的 95%/5% 安全门验收。其 TONIoT 弱信息 ACC 77.17%、极弱信息 ACC 63.70%，CICIDS 弱信息 ACC 91.64%，均低于 95%；DoHBrw ACC 97.44% 虽超过 95%，但没有 Benign FAR、FPR@95TPR 或 unknown rejection，不能证明误报率低于 5%。

## F. CAEOS-EMTD 可执行实验

1. `E-TRUSTWI-CLOSED`：同一 grouped split 上复现 TrustWI closed-set 二分类，确认图分支是否真有增益。
2. `E-TRUSTWI-INDUCTIVE`：严格断开 train/validation/test 节点与 capture，比较 transductive 与 inductive 差距。
3. `E-REAL-MISSING`：按真实缺失机制构造整模态缺失、连续丢包、局部拓扑断裂和设备离线，而非只随机置零。
4. `E-GRAPH-ORDER`：传播前补边、传播后补边与不补边三组消融。
5. `E-FUSION`：平均、注意力、经典 DS、冲突折扣 DS、CAEOS 冲突感知融合，在同一三模态输入上比较。
6. `E-CONFLICT-STRESS`：跨攻击家族交换单一模态，扫描冲突 C 与错误率、unknown risk、校准误差的关系。
7. `E-MISSING-MODALITY`：分别缺失统计、字节、时序/图模态，报告性能与拒识覆盖率。
8. `E-OSR`：把 known family 留一为 unknown，报告三层指标，阈值只由 known-only validation 选择。
9. `E-CALIBRATION`：补 ECE、Brier、NLL、risk-coverage 和 error AUROC，核验“低不确定性”是否可信。
10. `E-STAT`：至少五种子，按场景×种子做 paired Wilcoxon、Holm 和 scenario-block bootstrap CI。

## H. 一句话结论

TrustWI 是 CAEOS 图分支、证据融合和弱模态鲁棒性的重要组件来源，但它只是同源图多视图的半监督二分类方法；其随机 3:1 单图协议、未说明的调参来源及缺失开放集指标决定了它不能直接进入 CAEOS 的 strict OSR 主表。
