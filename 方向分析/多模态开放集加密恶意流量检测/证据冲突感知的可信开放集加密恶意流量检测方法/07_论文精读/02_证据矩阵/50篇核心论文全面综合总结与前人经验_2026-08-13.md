## 1. 对研究问题的统一认识

### 1.1 已知识别、未知拒识、未知发现和开放世界更新是四个连续但不等价的任务

前人工作的第一个共同教训是，开放环境中的“检测”至少包含四个决策阶段。已知识别回答样本属于哪个已知攻击家族，依赖类内紧致与类间分离；未知拒识回答样本是否超出已知类别集合，依赖已知支持域边界；未知发现对被拒样本进行聚类、解释或命名；开放世界更新在人工确认后吸收新类别并控制遗忘。Good-Closed、OpenAUC 和 OSCR 相关工作说明强闭集表征通常有利于开放集排序，但这种相关性不构成任务等价。ORI 与 FOSS 进一步说明拒识、聚类和增量更新可以共享表征，却必须采用不同的数据权限与指标。

这一区分对 CAEOS 至关重要。安全检测线必须保持目标 unknown 对训练、模型选择、风险权重和阈值不可见；未知发现线可以在拒识之后引入人工标注和批次聚类，但其结果不得回填成初始拒识的无泄漏证据。论文若把目标 unknown 无标签池用于训练，如 SS-EMTD、M3S-UPD，或者用目标 unknown 标签选择阈值、超参数和候选标签，如 RoNeTC、MDCG-IDS、TAO-Net、SOFA、NF-AD 和 DUEMT，则解决的是 P1/P2/P3 条件下的不同任务，而非 strict P0。

### 1.2 OOD、异常、零日和开放集只是部分重叠

Energy、NF-AD、CAIDS、DUEMT 和 MVAD 提供了通用异常或 OOD 风险，但未知恶意家族通常与已知攻击共享协议、工具链、基础设施行为和统计结构，其难度远高于低层分布明显不同的图像 OOD。相反，新的良性设备、QUIC 服务或跨数据集采集域可能比未知攻击更偏离训练分布。因而“离已知分布远”不自动等价于“恶意”，低置信也不自动等价于“未知攻击”。

适用于 CAEOS 的操作性定义应是：已知空间包含 benign 和训练可见的恶意家族；unknown-positive 仅指训练未见的目标攻击家族；新良性域单独作为 benign-OOD 安全压力测试。系统最终应区分“已知类别输出”“未知攻击拒识”“低质量或信息不足弃权”和“新良性误拒”，而不是把所有低置信样本统一改写为 malicious。

### 1.3 开放集难度由语义接近程度决定，不由 unknown 数量决定

Good-Closed 的语义偏移观点、Open-Detect 的原型距离、ORI 的局部支持、FOSS 的局部隔离和 OS-ETF 的类条件距离共同说明：未知类与已知类在表征空间的接近程度比未知类数量更关键。跨数据集 unknown 往往混合语义开放与域偏移，可能因为采集环境不同而“虚假容易”；同一攻击大类下的相邻细类或共享工具链的家族才是 hard unknown。

因此，CAEOS 的 unknown 场景需要同时包含 leave-fine-class-out、leave-family-out 和跨数据集三组，并把 easy、hard 与 domain-shift 分层报告。不能只随机抽若干类别，也不能把 Tor、VPN 或新服务类别一概解释为未知恶意攻击。

## 2. 数据、标签与拆分的前人经验

### 2.1 数据协议通常比模型结构更决定结果可信度

50 篇材料中最普遍的风险不是网络结构薄弱，而是随机流或随机包拆分、全图传导、目标未知调参和身份字段捷径。ET-BERT 的 packet 级随机拆分可能让同一 flow 的包进入训练与测试；IntraInter、TrustWI、RAGN 和部分图方法可能在全图上先构图再划分，测试节点由训练节点传播信息；EncryptoVision 的 SNI、IP、ASN、port 与单日交叉验证容易记忆服务身份；若 CIC 良性与攻击来自不同来源，模型甚至只需学习数据集身份。

可迁移的经验是：拆分必须先于任何会拟合数据分布或建立跨样本关系的操作。每个场景都要按 capture、flow fingerprint、设备、日期或实验批次分组；标准化、特征选择、PCA、原型、密度、图结构和阈值只能在训练或允许的 known validation 上拟合；验证和测试图不得向训练图发送消息；预训练语料必须审计数据集、时间、设备、应用和攻击家族重叠。

### 2.2 官方标签是基准，标签清洗只能作为训练鲁棒性实验

Normality-Labels 与 MCRe 说明标签并非天然可靠：恶意流中含有大量正常协议结构，流级二元标签不能使所有字段都成为恶意证据；官方标签也可能存在错配、边界误差和类内噪声。然而，自动清洗结果不能覆盖官方 ground truth 后再用自身结果评价自身。正确做法是将官方标签及其来源、时间、五元组和删除原因保持不可变，在训练副本中注入可复现噪声或生成 suspect list，并使用官方标签评价清洗 purity、coverage、correction precision/recall 以及对三层指标的传播影响。

对于 PCAP 处理，不能以“没有 payload”或“不是 TCP/UDP”为统一删除理由。扫描、DoS、ICMP 攻击、DNS 隧道和握手失败本身可能具有安全语义。只有官方标签范围明确不包含、五元组缺失、协议无法形成项目规定样本或具备已批准原因时才可删除，并记录流量、包数和字节比例。

### 2.3 良性流量不是背景噪声，而是安全边界的一半

CESNET-QUIC22、Normality-Labels、FOSS 和 CAIDS 表明，良性流量随服务、设备、时间和协议版本显著多峰。只用单一 benign 原型或平衡测试集得到的高 F1，往往无法维持真实低恶意基率下的误报。新良性可能同时表现为低支持、高距离、高 energy 和高 vacuity，如果风险头没有语义分解，就会把正常域漂移拒为未知攻击。

CAEOS 应建立三类良性评估：同域 known benign、同数据集但训练未见的 benign service/device、跨数据集或跨时间 benign。三者分别报告 malicious FAR、unknown rejection rate、known/benign acceptance 和 calibration shift。CESNET-QUIC22 适合用作外部良性 QUIC 和时间漂移测试，但没有恶意标签、payload bytes 或 PCAP，不能计入三模态恶意数据集。

### 2.4 统一基础数据要信息保真，实验视图再裁剪

YaTC、ET-BERT、DM-IDS、FlowPayload-NIDS、ECNet 和多种图方法使用不同包数、字节数与字段组合。前人的共同经验不是选择一个永久裁剪规则，而是保留能够重建这些视图的基础数据：五元组、方向、包时间、包边界、header/payload 边界、原始或脱敏字节、包长/IAT/标志序列、全流统计、标签层级及质量信息。前 5 包、前 32 字节、四包随机采样、BURST 或 MFR 都应是 dataloader 层的可复现实验视图，不能不可逆覆盖统一基础 CSV。

## 3. 多模态与表征学习的经验

### 3.1 多字段、多尺度、多视图和多模态必须分开命名

精读材料中“多模态”的使用非常不一致。ET-BERT 与 YaTC 是单源字节的不同编码；EncryptoVision 的 RGB channel 和 flatten sequence 是同一前三包输入的多视图；MTRF 的时域与频域是同源变换；TrustWI 的多个图视图由同一图和统计派生；Edge-Aware MMIDS 更严重地把不同数据集上的不对齐分支称作模态融合。只有样本级对齐且具有不同信息生成机制的视图，才有资格用于证据一致性与冲突推断。

对当前数据条件，最稳妥的表述是“三路同流对齐的异构观测”或“同源多视图多模态”：原始字节/脱敏 L4 载荷，包序列与方向/IAT，流统计；若加入严格时间可用的跨流图，则图上下文作为第四候选模态。每条流的所有模态必须共享 sample ID、标签和时间边界，并携带 missingness、截断、解析错误、payload 可见性和包数等质量变量。

### 3.2 强编码器是开放集方法的必要控制变量

Good-Closed 的核心经验是，许多开放集收益来自更强的闭集表征，而非复杂拒识公式。ET-BERT、YaTC、Pretrain-Robust、PCL-NovDet 和 M3S-UPD 说明无标签预训练、掩码重建、方向连续 BURST、包/流层级注意力和对比学习可以显著提高流量表征。但这些论文多数没有严格 OSR 指标，且常伴随目标域预训练或 grouped split 不清。

因此，CAEOS 必须先锁定统一训练配方和至少一个强字节/序列编码器，再比较风险与融合。必要对照包括弱训练 MLS、强训练 MLS、强训练 Energy、强训练单原型/多原型距离和强训练 CAEOS。只有在相同 encoder、优化预算和 split 下，自有风险头相对这些低成本分数仍有稳定增益，才能把收益归因于冲突感知而非表征强度。

### 3.3 字节表征必须防止环境和身份捷径

加密并不意味着没有可学习信号。ET-BERT 和 YaTC 说明密文字节、协议头结构、包边界、长度和方向序列仍能支持高质量分类。然而，这些信号也包含 TLS 版本、TCP options、TTL、padding、固定栈实现和 capture 工具指纹。IP、port、SNI、ASN、绝对时间以及可逆服务标识更可能成为直接捷径。

正式实验需要 full、去 IP/port/SNI/ASN、header-only、payload-only、序列-only、随机化端点、跨 capture 与跨时间对照。反捷径处理应作为可审计视图而非永久删除原始数据。字节模型的高闭集准确率必须经过跨数据集与协议版本压力测试，才能解释为攻击语义表征。

### 3.4 图模态有价值，但传导泄漏和部署因果性风险最高

RAGN、DUEMT、MAGNN、RETRIAL、Graph-Malware、IntraInter 和 TrustWI 说明跨流关系可以捕获扫描、C2、共享基础设施、服务交互和局部异常。这些信号常能弥补单流可见信息不足。但图模型最容易利用未来邻居、测试节点、IP/domain 身份和连通分量标签捷径。

CAEOS 若采用图模态，必须同时报告 inductive 与 transductive 两种协议；论文主线只能使用决策时点之前的邻居，并在 split 内独立构图。应做随机边、端点置换、去协议、degree-only、component-only 和时间反转消融。如果 graph-only 已经解决问题，复杂证据融合必须证明额外价值；如果增益只在全图传导中存在，则不能用于在线部署主张。

### 3.5 多模态常不优于最佳单模态，简单平均是必须打败的强基线

MVAD 的系统研究是重要负面证据：更多视图、对齐损失和复杂融合并不稳定优于最佳单视图。FlowPayload-NIDS 的两个随机森林加 soft voting、TMC 的 DS、ECML 的平均证据以及普通 late-average 都构成低成本强基线。复杂融合的合理验收不是“完整模型最高”，而是同时满足：跨场景不劣于最佳单模态；显著超过简单平均或 soft voting；在缺失、损坏和矛盾模态下退化更慢；新增计算成本与收益匹配。

为此，完整消融必须包含三个单模态、三个两模态、三模态全模型、事后最佳单模态 oracle、concat、mean、soft voting、late-average、gating、TMC、ECML、DBF 和 CAEOS。缺少这个正交矩阵，无法把提升归因于“多模态”或“冲突机制”。

## 4. 开放集风险与决策边界的经验

### 4.1 MSP、MLS 和 Energy 是最低成本而非弱基线

MSP 衡量最大 Softmax 概率，MLS 直接使用最大 logit，Energy 汇总全部 logit mass。这三者无需另训复杂生成模型，且在强编码器上经常形成难以击败的基线。Energy 的优势是利用全类别 logit，但受共同 logit 偏移、温度和类别尺度影响；global threshold 容易对不同类别产生接收偏差。MLS 则直接检验复杂风险是否只是重现分类 margin。

CAEOS 应固定 risk 越大越 unknown 的方向，T=1 作为 Energy 主设置，阈值仅取 known validation 分位数。每个 score 同时比较 global 与 class-conditional/Mondrian calibration。Energy-OE 或其他外部异常暴露必须标 P1，不能与 posthoc P0 混表。

### 4.2 距离、原型和局部支持刻画的是不同几何性质

OpenMax、Open-Detect、OS-ETF、ORI 和 FOSS 分别从极值尾部、生成式高斯原型、类条件邻域距离、局部支持和隔离路径刻画已知域。它们的共同经验是类条件边界优于单一全局阈值，尤其适合类别尺度和密度不同的攻击家族。其共同限制是单原型难以表示多峰 benign/attack，距离会被高维尺度和编码器范数影响，局部支持参数容易在目标 unknown 上调优，密度低也可能只是合法少数类。

因此，CAEOS 的几何基线应覆盖单原型、多原型、Mahalanobis、k-LND、ORI-support 和 Isolation/FOSS risk。原型与归一化只由 known training 拟合；阈值由 known validation 冻结；逐类报告 known rejection，防止少数类被全局阈值牺牲。若 support-only 或 distance-only 已达到同等 OSCR，自有组合应被简化。

### 4.3 密度和重构风险适合作为补充，不能把异常等同于未知攻击

NF-AD、CAIDS 和 Open-Detect 说明 normalizing flow、autoencoder 和 VAE 能提供密度或重构风险。它们对正常域建模和可解释性有价值，但高维 likelihood 存在 typicality failure，重构良好不保证属于已知类，重构差也可能来自新良性。生成模型还增加训练不稳定、解码开销和分布假设。

可接受的用法是将 NLL、reconstruction、ELBO 或 prototype KL 作为独立 risk 分量，与 Energy、distance、support、vacuity 和 conflict 计算 rank correlation、条件错误率和增量 AUROC。所有阈值仍只用 known validation。P2 的异常标签阈值可作为乐观对照，但不能进入 strict 主结论。

### 4.4 阈值选择是开放集协议的核心，不是实现细节

大量论文的主要风险来自 Youden J、optimal F-score、目标 unknown TPR/FPR 或测试图曲线选阈值。阈值一旦读取目标 unknown，就改变了研究问题。即使模型只用 known 训练，目标 unknown 调阈值仍属于 P2/P3。相反，仅报告 AUROC 也不足以说明部署工作点达到 95%/5%。

CAEOS 的正式阈值应由 known-only validation 的目标 known acceptance 分位数确定，例如 95% 或 99%。风险组合权重、温度、类别条件校准和退火策略同样不得读取 outer unknown。论文式 test-optimal 阈值可放附表，用于量化协议乐观偏差，而不能混入主表。

## 5. 证据、不确定性、冲突与融合的经验

### 5.1 证据总量不足不等于跨模态冲突

EDL 将非负证据映射为 Dirichlet 参数 α=e+1，并以 u=K/S 表示 vacuity。它适合表达“模型没有积累足够证据”，但两个模态各自以高证据支持不同类别时，总证据仍然很高，u 可能很低。把 u 直接称为 conflict 会掩盖最危险的高置信分歧。

适用于 CAEOS 的风险分解至少包括：vacuity，表示证据不足；dissonance/conflict，表示高证据类别或模态分歧；distributional risk，表示样本偏离已知支持域；quality/missingness，表示解析、截断和模态可用性。四者可以相关，但不能从一个标量名称上视为同义。

### 5.2 TMC、ECML、DBF 与 RoNeTC 已覆盖通用证据融合，创新必须收窄

TMC 建立逐视图 Dirichlet 意见并用缩减 DS 融合，低证据视图通过 u 被隐式弱化；ECML 用类别分歧乘确定性定义冲突，并采用平均证据避免 DS 把不确定性机械压低；DBF 从跨视图 agreement 估计样本级可靠度，把不可靠 belief 折扣到 uncertainty 后融合；RoNeTC 已将三视图 EDL 与 Dempster 融合用于开放集流量分类。

因此，“采用 EDL”“计算冲突”“折扣不可靠模态”或“用 DS 融合”均不能单独成为 CAEOS 的创新。可论证的差异必须落在严格 unknown-free 的安全问题上：利用流统计、包序列和字节模态的质量变量，区分共同无知与高置信矛盾；在同源依赖条件下进行可靠性折扣；把冲突作为错误与 unknown 的风险证据；并在 known 分类、unknown 拒识、OSCR 和校准上共同验收。

### 5.3 DS 高冲突归一化必须设置保护，而不是强制给出 known 类

经典 Dempster 组合含 1/(1-C) 归一。当 C 接近 1 时，数值不稳定与反直觉过置信风险增大。更重要的是，同一 PCAP 派生的三个视图不满足独立证据源假设，重复证据可能被多次计权。TMC 和 RoNeTC 的结果不能证明高冲突流量下安全；DBF 的多数一致可靠度也可能在多数模态共同错误时惩罚唯一正确模态。

CAEOS 必须预先规定高冲突保护：C 接近 1、全模态低证据、模态缺失或质量低于门限时优先 abstain；比较经典 DS、平均意见、TMC、ECML、DBF、quality gating 与 conflict-aware abstention；对同源复制、两个错误对一个正确、三模态分别支持三个 known 类等反事实做单调性与数值测试。

### 5.4 冲突分数必须证明增量信息，而不是只与人工噪声相关

现有多视图证据论文常用高斯噪声、随机错配或缺失视图评价冲突。这些实验只能说明分数对预设扰动敏感，不能证明它能识别真实未知攻击或已知分类错误。CAEOS 的 conflict 必须同时报告 unknown AUROC、known-error AUROC、在 distance/energy/support 条件下的增量，以及 risk calibration。若冲突与已有风险高度共线且不能改善 OSCR/FPR95，就不应保留复杂融合。

真实压力测试至少覆盖随机模态替换、同一攻击家族内错配、跨家族交换、连续丢包、乱序、截断、payload 缺失、图边断裂、同源视图复制和对抗性高证据错误。所有污染强度形成曲线，模型训练与阈值保持不变。

### 5.5 可信度不是未经校准的门值或总证据

ECNet 的 confidence head、RoNeTC/EDL 的 u、TrustWI 的融合不确定性和 DBF 的可靠度各自表达不同量。它们若没有 ECE、Brier、NLL、risk-coverage 和错误条件可靠性验证，就不能被直接称为“可信概率”。融合后 u 下降也不意味着预测更可靠，可能只是证据相加造成的机械结果。

合理的校准流程是分别校准单模态类别概率、单模态证据尺度、可靠性分数和最终风险；检查每个攻击家族、良性域和缺失模式下的 reliability；比较 global 与 class-conditional calibration；对 rejected known 保持在分类错误分母内，不通过静默删样本改善准确率。

## 6. 指标、统计与安全验收经验

### 6.1 三层指标不可压成单一 Accuracy

前人指标混用造成了大量不可比较结论。联合 Macro-F1 可能把 known 分类、unknown 路由和 target unknown 命名混在一起；二分类 FPR 可能是按类平均而非 benign FAR；论文式 ID-positive FPR95 与 unknown-positive FPR@95TPR 方向不同；AUROC 是排序面积，不代表任何固定阈值通过安全门。

CAEOS 主表保留六项：Known Macro-F1、Balanced Accuracy、Unknown AUROC、Unknown AUPR-Out、明确正类的 FPR@95TPR、OSCR。附表报告逐类 Recall、Benign FAR、Unknown-F1、Known Acceptance Rate、Unknown Rejection Rate、OpenAUC、ECE、Brier、NLL 和各单项 risk AUROC。所有表头必须标明正类、阈值来源和 rejected known 的处理。

### 6.2 OSCR 与 OpenAUC是联合评价，不替代两端验收

OSCR 评价“正确分类的已知被接收”与“未知被拒识”的联合关系；OpenAUC 从已知正确分类与 known-unknown 排序对构建联合面积。它们比 Accuracy+AUROC 简单相加更符合开放集决策，但仍是跨阈值面积，不能取代固定工作点的已知接收、未知拒识和良性误报。

最合理的报告逻辑是三层并列：第一层证明分类器能识别 known；第二层证明风险能区分 unknown；第三层证明二者在同一流和同一阈值排序下协同。任何一层改善都不能自动推出另外两层改善。

### 6.3 95%/5% 安全门必须基于冻结工作点和置信界

论文中大量高于 95% 的 Accuracy/F1 不能自动填写 CAEOS 安全表。需要分别定义：Known Macro-F1 或攻击识别 Recall 的下界达到 95%；Benign FAR 的上界不超过 5%；在指定 known acceptance 或 unknown recall 下的错误率不超过 5%；同时报告 OSCR 与覆盖率。不同 FPR 不得混名。

验收不能只看点估计。正式实验至少 5 个种子，以场景×种子为配对单元，报告均值、标准差和 scenario-block bootstrap 置信区间；方法比较使用 paired Wilcoxon 与 Holm 校正并给出效应量。类别样本极少或误报率接近 0 时，应报告二项置信上界，避免“测试中未观察到误报”被解释为真实误报为零。

### 6.4 真实类别先验与覆盖率必须保留

平衡采样可用于训练稳定，但测试若同样平衡会掩盖低恶意基率下的告警负担。选择性模型也可能通过拒绝大量困难 known 获得高准确率。主实验应同时报告研究均衡集和真实先验集，至少给出 precision、Benign FAR、每百万流告警量、coverage、known acceptance 和 risk-coverage 曲线。所有删除、采样和拒识比例必须显式记录。

## 7. 前人方法的主要失败模式

### 7.1 协议性失败

最常见的失败是目标 unknown 参与阈值、超参数、模型选择、特征选择或候选标签提示。其次是随机包/流拆分、目标域全量无标签预训练、全图传导和 test-optimal 指标。这些做法不一定使论文无价值，但改变了可回答的问题。正确处理不是删除这些论文，而是标 P1/P2/P3、构建 strict adapter，并用双版本量化乐观偏差。

### 7.2 构念性失败

第二类失败是名称与测量对象不一致：把低置信称为恶意，把 vacuity 称为 conflict，把多字段称为多模态，把异常二分类称为开放集家族识别，把应用类别 OOD 称为未知攻击，把联合 F1 称为 unknown detection。解决办法是用操作性定义和三层指标重写问题，不沿用论文标题中的宽泛术语。

### 7.3 表征捷径与跨域失败

IP、端口、SNI、ASN、时间、设备、capture 和协议版本能够带来很高同域分数，却在跨时间、跨设备和跨数据集时崩溃。预训练模型还可能通过语料重叠获得隐性优势。每个强表征都需要 identity ablation、grouped split、cross-domain 与 pretraining manifest，而不能只比较论文自报最高值。

### 7.4 融合性失败

复杂融合可能不如简单平均；相关视图会重复计证据；高冲突 DS 会过置信；一致性损失会压制真正互补的少数视图；多数错误的可靠性估计会排斥唯一正确视图；缺失模态训练与真实缺失机制不一致。融合模块必须在 clean 与 corrupted 条件下同时比较最佳单模态、平均、gating、证据融合和 abstention，并报告最坏场景而非只报告平均。

### 7.5 评价性失败

单次运行、最好结果、无方差、不同平均方式的 F1、未注明正类的 FPR95、跨协议 SOTA 排名和忽略 rejected known 都会造成结论膨胀。可靠的改进必须跨场景和种子稳定，差值大于运行方差，并能通过配对统计与置信区间。

### 7.6 部署性失败

许多方法依赖离线全批次、目标 unknown 缓冲区、未来邻居、LLM 候选标签或推理时不可得字段。它们可以服务未知发现或分析员辅助，但不能直接作为逐流实时拒识。论文必须分别报告离线、PCAP 回放和在线流式路径的吞吐、P50/P95/P99 延迟、峰值内存、显存和模型更新成本。

## 8. 对 CAEOS-EMTD 方法框架的综合结论

### 8.1 可以成立的科学问题

经过横向综合，CAEOS 不应再把创新概括为“多模态证据融合”。更准确的科学问题是：在目标未知家族对训练、模型选择和阈值不可见的条件下，同一加密流的异构观测可能同时出现信息不足、质量下降和高置信语义矛盾；如何区分这些状态，对不可靠模态进行受约束折扣，并在不牺牲 known 分类与 benign 安全边界的前提下改善未知攻击拒识和联合开放集性能？

这一问题与前人工作的差异不在单个算子，而在四项联合约束：严格 P0 协议；同流三路观测及质量变量；vacuity、conflict、distributional risk 的显式分解；以三层指标、校准和 95%/5% 门共同验收。

### 8.2 推荐的模块化框架

输入层保留字节、包序列/时序和流统计三个严格对齐分支，图上下文作为可选扩展。每个分支输出类别表示、Dirichlet 证据、质量向量和 missingness mask。强 encoder 与风险头解耦，使闭集表征改进不会被误写为融合贡献。

单模态层分别形成类别概率、vacuity 和可校准可靠度。跨模态层计算高置信分歧 conflict，同时根据 payload 可见性、包数、截断、解析状态和历史校准误差估计折扣。折扣后的意见采用数值稳定融合；当冲突或缺失超过预注册范围时允许 abstain，不强制归一化到已知类。

风险层不预设所有分数都有用，而是候选集合：MLS/Energy、prototype or Mahalanobis distance、ORI/local support、vacuity、conflict、quality。每个分量单独报告 unknown AUROC 和 error AUROC，再通过 known-only validation 学习或预注册组合。若某分量无条件增量，则删除而非保留叙事性复杂度。

决策层先输出 known family classifier，再以 frozen threshold 决定 accept/reject。对 reject 样本的聚类、LLM 命名和人工检查属于第二交付线，其标签不可用于回溯调整第一阶段结果。

### 8.3 必须保留的负向假设

自有方法可能失败于以下情况：强 encoder 加 MLS 已足够；support 或 distance 单项已经覆盖 conflict；三个模态高度相关，折扣反而重复惩罚；benign 多峰使所有域外分数误报；一致性学习压低细粒度 known 分离；高冲突主要来自预处理错位而非真实攻击；复杂融合在 clean 场景提高不确定性却降低 Known Macro-F1。每一项都应形成预注册否决实验，而不是只寻找支持性结果。

## 9. 实验优先级与闭环路径

### 9.1 第一阶段：协议和基础表征闭环

固定数据清单、统一基础 CSV、官方标签、sample ID、三模态字段、质量字段、capture/fingerprint grouped split、leave-family-out 场景和 known-only threshold。先比较统计树模型、当前 encoder、YaTC、ET-BERT 或 packet-sequence Transformer，并锁定公共强训练配方。该阶段只解决 Known Macro-F1、Balanced Accuracy、逐类 Recall 和 Benign FAR；若 known 端未达到合理水平，不继续堆叠风险组件。

### 9.2 第二阶段：低成本风险基线闭环

在同一 frozen encoder 上比较 MSP、MLS、Energy、OpenMax、prototype/Mahalanobis、k-LND、ORI-support、AE/NF 和 Open-Detect。所有 score 使用同一方向、同一 known validation 和同一测试流。目标不是马上证明 CAEOS 最优，而是识别未知检测瓶颈属于全局 margin、类条件几何、局部支持还是密度。

### 9.3 第三阶段：证据与冲突组件闭环

加入 Vanilla EDL、TMC、ECML、DBF、RoNeTC-strict，并在同 encoder 下比较。依次消融 evidence parameterization、vacuity、conflict、quality discount、fusion 和 abstention。只有当 conflict 对 error/unknown 有增量并改善 OSCR/FPR95，才进入正式方法。

### 9.4 第四阶段：多模态和鲁棒性闭环

运行三个单模态、三个两模态、完整三模态与最佳单模态 oracle；比较 mean、concat、soft voting、gating、DS、DBF 和 CAEOS。随后执行缺失、截断、错位、替换、对抗高证据、丢包、乱序、图边断裂与跨域良性压力测试，报告 clean、absolute drop、worst-case 与 calibration shift。

### 9.5 第五阶段：正式统计和安全门

所有确认实验运行至少 5 个种子。主指标采用场景×种子的 paired Wilcoxon、Holm 和 scenario-block bootstrap；安全表同时填 Known Macro-F1/Recall 下界、Benign FAR 上界、Unknown 指标、OSCR 和 coverage。不能通过置信界的组件只能标为探索性结果。

### 9.6 第六阶段：未知发现扩展线

在第一阶段冻结后，对已拒识样本进行 FOSS/ORI 风格聚类、代表样本选择和人工检查，报告 NMI、ARI、簇纯度、标注成本、发现延迟和增量更新遗忘。该线独立发表或放扩展实验，不用于改善初始 strict 指标。

## 10. 可形成的论文主张与不可形成的主张

在完成同协议实验前，可以成立的文献级判断是：开放集流量检测需要分离 known 分类与 unknown 拒识；强闭集表征、类条件几何和局部支持是必须控制的强基线；EDL vacuity 不能表达高证据跨模态冲突；同源多视图融合存在依赖、重复计证据和高冲突不稳定风险；阈值必须避免目标 unknown 泄漏；三层指标和校准比单一 Accuracy 更完整。

当前不能成立的主张包括：CAEOS 已达到 SOTA；三模态必然优于单模态；冲突分数必然优于 Energy 或 distance；论文中超过 95% 的 F1 证明本项目通过安全门；低 uncertainty 等于可信；所有跨数据集 unknown 提升都来自语义泛化；50 篇精读已可直接用于正式引用。以上主张必须等待同协议实验和 G10 引用门。

| SS-EMTD | 多种流量特征与半监督训练可用未标注数据 | 目标留出攻击进入无标签训练 | P2 半监督附表，不作 strict 证据 |
| RAGN | 动态关系图有助于未知恶意二分类 | 合成未知、二分类而非 OSR | 图异常支线与鲁棒性基线 |
| ORI | 局部 known support、拒识和人工检查分阶段 | k 参数在目标开放测试确定，跨源身份捷径 | ORI-support-strict 与独立发现线 |
| YaTC | MFR、包/流注意力与 MAE 是强字节表征 | 闭集、预训练边界和 split 不可审计 | strict grouped 强 encoder 基线 |
| Ext-UQ | Relative Mahalanobis、KDE 尾部和 known-only 校准 | 随机 window 拆分、单应用评估 | 类条件 distance/KDE 强 P0 候选 |
| IntraInter | 字节、统计、关系图三分支最接近项目结构 | 全流图传导、IP捷径、split 缺失 | 采纳结构，完全重写 inductive 协议 |
| ET-BERT | BURST、MBM、SBP 支持强字节预训练 | 目标域预训练与 packet/flow 泄漏 | 语料审计后作为强 encoder |
| EncryptoVision | spatial/sequence 双 encoder 与动态融合 | 同源视图、SNI/IP捷径、random CV | 组件基线与 identity ablation |
| Energy-OOD | Energy 是无额外训练的强风险基线 | score 方向、温度、类尺度和 OE 协议易混 | posthoc P0 与 OE P1 分表 |
| OS-ETF | 类条件 k-LND 与 known quantile 拒识 | 指纹 unknown 非恶意家族，阈值接收率不足 | k-LND/Mondrian 风险基线 |
| EDL | Dirichlet 证据和 vacuity 可单次前向计算 | vacuity 不等于 conflict，证据尺度和 KL 有偏 | Vanilla EDL 基线，显式分解三类风险 |
| NF-AD | normal-only flow density与解释可作异常基线 | target anomaly 阈值/特征选择、typicality failure | strict NF 与 P2 原协议双版本 |
| MM-LLM | 流量到语言的解释与分析员辅助值得探索 | 合成参考循环监督、随机 split、非三路流量模态 | 只进未知发现/解释线，不进安全主判决 |
| Graph-Malware | 异构 host/domain/IP 关系图能捕获恶意基础设施 | 良性随机拆分与 infrastructure shortcut | 关系模态基线和端点随机化消融 |
| SWF/TrustWI | 图视图、Dirichlet 和弱信息实验适合鲁棒对照 | 同源派生视图、单图传导、DS高冲突 | 图证据基线、真实缺失与 inductive 对照 |
| Pretrain-Robust | clean accuracy 不代表丢包/乱序下性能 | 闭集 PA-area 不等于 OSR，语料/split 不清 | 标准 packet 扰动与 calibration shift |
| pVoxel | 告警批次密度可降低运营误报 | transductive 后处理，不是逐流 strict OSR | 第二阶段告警后处理与吞吐评估 |
| HDA-IoT | 异构域几何对齐和伪标签适合跨域 | 共享类、目标标签和全量无标签参与训练 | P1/P2 域适应附表，不处理 unknown |
| DUEMT/HyperVision | 跨流图、低内存与流式系统设计有价值 | 用目标攻击 validation 调参，异常二分类 | strict 图异常基线与在线性能表 |
| MVAD | 多视图常不优于最佳单视图，平均是强基线 | 非流量一类任务、随机 split | 完整融合 taxonomy 与 best-single oracle |
| TAO-Net | PCA residual 和层间平滑是可移植 OOD score | 目标 OOD validation、标签 prompt 暴露、无真正拒识 | detector-strict 组件；LLM只作分析员建议 |
| MCRe | 标签噪声鲁棒与类核心约束可作压力测试 | 闭集合成噪声，不是 unknown；不可覆盖官方标签 | 训练副本噪声附表和 suspect list |
| CAIDS | normal AE 与 known-only 95%重构阈值是简单基线 | 目标测试独立 PCA、跨阶段均值不等于 OSCR | 修复预处理后的二阶段低复杂度基线 |
| CESNET-QUIC22 | 长时间良性 QUIC、PPI+统计与采样权重 | 无恶意、无 payload bytes/PCAP，SNI是标签源 | 外部良性 FAR、跨周校准与双视图支线 |

## 12. 最终判断

前人经验并未否定 CAEOS-EMTD 的自有算法探索，但显著抬高了创新门槛。证据学习、冲突度量、可靠性折扣、DS 融合、多视图流量表示和通用 OOD 风险均已有直接先例。项目的合理研究空间不是再叠加一个风险分数，而是把严格无未知泄漏、同流异构观测、质量感知折扣、冲突与无知分解、类条件开放集校准和安全工作点验收连成一条可验证链路。

这条链路能否成立，最终不由方法名称决定，而由一组负向对照决定：能否超过强 encoder+MLS/Energy，能否超过 support/distance，能否超过简单平均和 DBF，能否在模态矛盾与新良性域中保持低误报，能否在五种子多场景下通过 OSCR、FPR95、校准与 95%/5% 置信门。任何一项不成立，都应缩减主张或删减组件。这样的结论比在异构论文表格中追求表面最高分更接近可投稿、可复现的科研闭环。
