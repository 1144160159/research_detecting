## 维护规则

1. 两条交付线共享数据身份、known/unknown定义、指标实现和泄漏约束，但分别验收。
2. 三层指标不能合并成单个Accuracy；95%/5%绝对门不能被相对SOTA排名替代。
3. 正式训练只在GPU，本地只做pytest、代码冒烟、汇总和文档。
4. 新结果必须先通过机器合同，再更新路线图和证据索引；历史流水不再追加到本README。
5. 基线正文主表固定为XGBoost、MSP、Energy、OpenMax、Mahalanobis++、Open-Detect、RoNeTC，新增方法必须有预注册必要性。
6. 未知测试标签参与候选或阈值选择的结果永久标为development，不进入confirmation。
7. 论文写作执行 Zotero 证据硬门：无 Zotero Item、Citation Key、中文证据卡和页码/表号定位，不写入正文。
