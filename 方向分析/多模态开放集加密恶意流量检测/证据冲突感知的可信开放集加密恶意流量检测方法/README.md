## 维护规则

1. 稳定结论只写入 `01_当前稳定方案`，未经验证的想法只进入 `02_候选升级`。
2. 新实验必须先定义假设、对照、成功判据和数据泄漏边界，再启动运行。
3. 报告只保存核对后的汇总；原始大结果留在 GPU 服务器，本地只同步轻量摘要。
4. 任何算法升级都必须同时满足无未知标签泄漏、多种子增益、主要家族无系统退化和既有数据集无明显回退。
