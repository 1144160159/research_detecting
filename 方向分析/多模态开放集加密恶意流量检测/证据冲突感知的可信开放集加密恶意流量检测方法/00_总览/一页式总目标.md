# 一页式总目标

## 1. 一句话目标

构建一种**不解密流量载荷、能够准确识别已知恶意类别、能够拒识训练阶段未见攻击、能够解释多模态证据冲突并抵抗单模态污染**的可信开放集加密恶意流量检测方法。

## 2. 最终要解决的问题

传统恶意流量多分类假设训练类与测试类一致，面对新型攻击时容易把未知流量高置信地归入某个已知类。简单置信度或距离阈值又无法说明判断来自哪个模态，也无法区分“各模态均缺少已知类支持”和“不同模态给出相互矛盾意见”。本研究要把一个闭集多分类模型演进为具有未知拒识、冲突解释和污染鲁棒性的开放集检测系统。

## 3. 三个核心科学问题

1. **证据可信性**：如何让包序列、时序统计、协议字段和流级统计等模态独立形成类别证据、可靠度与不确定性。
2. **冲突与未知的关系**：如何区分高冲突未知、低支持未知以及多模态一致但错误的未知，避免把“冲突”等同于“未知”。
3. **无未知标签选择**：如何只利用已知训练集和已知验证集选择风险函数、门控路径与拒识阈值，保证真实未知类只用于最终测试。

## 4. 总体算法链路

`侧信道多模态特征 -> 已知类多分类主干 -> 每模态独立证据意见 -> 可靠度与不确定性估计 -> 模态冲突矩阵 -> 冲突驱动折扣融合 -> 支持/冲突层级风险选择 -> 开放集拒识 -> 可审计证据包`

其中，已知类多分类负责回答“属于哪个已知类别”；独立证据与冲突建模负责回答“哪些模态支持、哪些模态不足或矛盾”；层级开放集风险负责回答“是否应拒识为未知候选”。

## 5. 最终交付

- 一套无真实未知标签泄漏的训练、验证和测试协议。
- 一个同时输出已知类别、未知风险和逐模态证据的算法实现。
- 一组覆盖闭集分类、开放集拒识、模态污染和跨数据集泛化的实验。
- 一套与简单分数、距离方法、神经开放集方法及安全领域强基线的同协议比较。
- 一个不包含测试真值、可独立校验的结构化证据包。

## 6. 成功判据

方法不能只追求单个数据集的最高 AUROC。最终验收同时要求：已知类 Macro-F1 稳定；未知 AUROC、AUPR、OSCR 和 Unknown-F1 有竞争力；FPR95 与已知误拒可控；模态污染下退化较小；跨数据集、多未知家族和多随机种子结果稳定；所有模型选择与阈值校准均不接触真实未知标签。

## 7. 当前阶段

论文冻结版本为 `v1.4.4-paper-freeze`，主算法为 `CAEOS-Pairwise`（`caeos_pairwise`）。三新种子 102 场景确认已证明其相对 OpenDetect 的 Known F1、AUROC、AUPR 和 OSCR 总体优势，但 FPR95 和部分套件仍回退。当前重点是效率、污染鲁棒性、真实异构模态、跨域泛化以及受预注册约束的自有算法探索，不再以继续增加基线数量替代关键证据。总体论文主张保持为“证据冲突感知的开放集风险选择”，在多维证据闭环前不宣称全面 SOTA。

基线补充采用“覆盖缺口优先”而非数量优先：WDiscOOD 作为第 31 个候选补齐 WLDA 判别/残差双子空间路线，先经过 14 场景预注册门，只有通过才进入 full102。自有算法优先级不因此下降，执行顺序保持主论文闭环、LCB Tail-aware、Mal_TLS2023 异构编码器、WDiscOOD CPU 试点。
