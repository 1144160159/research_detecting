# 总目标与研究路线

## 1. 总目标

本研究的总目标是构建一种**不依赖载荷解密、能够识别已知恶意类别并拒识未知恶意类别、能够解释多模态证据冲突且对模态污染具有鲁棒性**的可信开放集加密恶意流量检测方法。研究对象不是单纯的闭集多分类器，也不是只依靠一个置信度阈值的未知检测器，而是一套从多粒度侧信道特征、已知类识别、独立模态证据、显式冲突建模到开放集风险判定的完整算法。

最终方法应同时回答三个问题：已知恶意流量属于哪一类；当前判断由哪些模态证据支持或反对；当样本不符合任何已知类时，系统能否在不使用真实未知标签调参的前提下将其判为未知候选。

## 2. 核心科学问题

### 2.1 多模态证据何时可信

加密流量的载荷不可见，只能利用包长、方向、时序、协议字段、统计量和关系特征等侧信道。不同模态的信息量和污染程度并不一致，需要让每个模态独立形成类别证据、可靠度和不确定性，而不是一次性拼接后进行黑箱分类。

### 2.2 证据冲突是否等价于未知性

已有实验已经证明，未知攻击不一定产生高模态冲突。部分未知类别会在多个模态上形成一致但错误的已知类意见。因此，研究重点不是证明“冲突越高越未知”，而是判断在什么已知类内结构下，冲突风险、缺少已知类支持的风险或两者联合更适合作为未知线索。

### 2.3 如何在没有真实未知标签时选择风险路径

真实部署无法预先获得未来未知攻击。风险分数、组合权重和门控路径必须只用已知训练集与独立已知验证集确定。当前采用已知攻击类内层留一构造伪未知任务，并以平均 AUROC 与最小 AUROC 等权的稳健目标选择风险路径。

## 3. 当前算法主线

1. 从加密流量中构造多个具有明确语义的侧信道模态，并排除地址、端口组合、采集编号等直接标识字段。
2. 使用 MC7 多样性树集成建立稳定的已知恶意流量多分类主干。
3. 每个模态独立输出类别意见、证据量、可靠度和不确定性，并计算模态间证据冲突。
4. 在模态污染场景下，使用 MC8-v2 根据局部冲突对受污染模态进行折扣和保守路由。
5. 开放集一级门在“双支持风险”与“冲突证据风险”之间进行已知类内层留一选择。
6. 一级门选择支持路径时，使用预注册锚定模态进行低权重补偿；选择冲突路径时，仅在四因素联合风险的内层稳健增益超过 `0.055` 时升级。
7. 所有开放集阈值由独立已知验证集校准，真实未知样本只进入最终测试。

## 4. 分阶段目标

| 阶段 | 目标 | 当前状态 |

## 5. 当前证据

- HIKARI、DoH 和 Mal_TLS 的65次留一实验表明，支持/冲突一级门能够根据已知类内层结构选择互补风险；v1.4.3 平均 AUROC 为 `0.931747`。
- NF-UNSW 的54次无泄漏留一实验表明，冲突分支的受控四因素联合可以将平均 AUROC 从 `0.715697` 提高到 `0.726718`，10胜43平1负，Wilcoxon `p=0.002930`。
- NF-UNSW 的独立全规模确认使用9个新种子、每类最多5000条和150棵树，共54次运行；AUROC从 v1.4.3 的 `0.747583` 提升至 v1.4.4 的 `0.763173`，12胜41平1负，精确 Wilcoxon `p=0.001709`。Unknown AUPR、OSCR和Unknown F1分别提高 `0.016455`、`0.010294` 和 `0.021770`，FPR95下降 `0.004725`。
- 神经开放集同协议39次对比中，原层级门控平均 AUROC 为 `0.929520`，高于最强固定神经评分 KNN 的 `0.883127`。
- 外部网络入侵开放集强基线CLOSR已按官方200轮配置完成同协议39次适配。CAEOS门控AUROC为 `0.932796`，CLOSR为 `0.767187`，33胜6负，Wilcoxon `p=2.40e-08`；CAEOS的Known Macro-F1、AUPR、FPR95和OSCR均值也更优。CLOSR在HIKARI/Bruteforce-XML三次和Probing两次留出中获胜，说明对比表示仍具有场景优势。
- 安全概念漂移强基线CADE已按官方结构、损失和250轮配置完成同一39次适配。CADE AUROC为`0.630395`，CAEOS为`0.932796`，39胜0负，Wilcoxon `p=3.64e-12`；统一95%校准与官方MAD=3.5阈值均已报告。
- Open-Detect和RoNeTC已完成同协议39次适配。AUROC分别为`0.792297`和`0.656010`，CAEOS为`0.932796`，对应32胜7负和38胜1负。Open-Detect在7个任务上具有互补优势，但已知类内专家门和四种固定秩融合均未通过稳定升级条件。
- FOSS论文公式重实现已完成同协议39次适配，AUROC为`0.675517`，CAEOS为`0.932796`，对应34胜5负。FOSS在HIKARI/XMRIGCC三个种子均占优，但已知类内专家门无法预测该优势；61维、8维和支撑作用域结构消融均未同时改善AUROC与OSCR。含零回退的结构支撑联合门在HIKARI 12次确认中AUROC和OSCR又分别下降`0.006056`和`0.005274`，因此稳定版本保持v1.4.4。
- Sieve已保留官方DeepResNet、样本筛选、置信扩展、对比损失和类条件Mahalanobis机制完成同协议39次适配。Sieve AUROC为`0.766057`，CAEOS为`0.932796`，对应37胜2负，Wilcoxon `p=9.09e-11`；四种固定经验秩融合均回退。论文混合标签噪声原协议因CipherSpectrum需要实名授权而单列待办。
- NF-UNSW 的最低 AUROC 仍为 `0.430846`，说明高度重叠的 Analysis 等未知家族尚未解决，当前绝对性能不能包装为总体最先进。

## 6. 最终验收标准

1. 数据划分无完整特征指纹、采集会话或来源实体泄漏，未知类别不进入训练、模型选择和阈值校准。
2. 至少覆盖恶意家族、恶意工具、企业攻击行为和通用网络攻击四类场景，并报告多种子均值、标准差、最小值和显著性。
3. 与简单分类置信度、距离、密度、开放集神经方法和冲突消融进行同骨干、同划分、同采样量比较。
4. 分别验证独立模态证据、可靠度折扣、显式冲突、支持风险、锚定补偿和联合风险安全门的贡献。
5. 对失败家族、反向种子、模态污染和分布漂移给出边界分析，不选择性报告最优种子。

## 7. 下一步工作

1. 冻结 NF-UNSW 上的 v1.4.4 候选和 `0.055` 门槛，不再利用该数据集未知标签继续调参；在新数据集上检验门控迁移性。
2. CLOSR、CADE、Open-Detect、RoNeTC、FOSS和Sieve统一协议适配已完成；Sieve混合噪声原协议及M3S-UPD、TAO-Net和SiamXBERT继续单列复现，不将混合噪声、半监督、少样本或LLM生成任务分数与当前统一协议直接比较。
3. 增加具有来源、设备或时间标识的数据集，执行来源分组和跨采集批次验证。
4. 分析 Reconnaissance seed73 的反向触发和 Analysis 的低下界；结构作用域与联合权重消融已经证明已知类留一代理不能稳定预测结构支撑向真实未知类迁移，停止依据HIKARI外层标签继续调结构门槛。
5. 后续自有算法优化只在新数据集或预注册的新拆分上检验迁移性；现阶段优先补充协议边界明确的外部强基线，并把半监督、少样本、混合标签噪声和LLM未知细分类结果与当前纯监督留一协议分开报告。
6. 在实验矩阵完成后，将论文主张限定为“证据冲突感知的层级开放集风险选择”，并同步形成算法证明、复杂度分析和可复现实验章节。
