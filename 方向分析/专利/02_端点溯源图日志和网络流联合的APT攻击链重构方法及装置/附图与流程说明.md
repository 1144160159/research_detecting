# 附图与流程说明：端点溯源图、日志和网络流联合的 APT 攻击链重构方法及装置

## 图1 系统总体架构图

```mermaid
flowchart LR
    A1[端点溯源事件] --> B[多源数据采集模块]
    A2[系统/认证/应用日志] --> B
    A3[网络流/DNS/证书] --> B
    A4[告警/威胁情报] --> B
    B --> C[事件归一化模块]
    C --> D[实体对齐模块]
    D --> E[跨源溯源图构建模块]
    E --> F[正常行为基线压缩模块]
    F --> G[异常子图候选生成模块]
    G --> H[攻击阶段识别模块]
    H --> I[攻击链搜索与评分模块]
    I --> J[证据输出模块]
    J --> K[反馈更新模块]
    K --> F
```

**说明：** 图1展示从多源事件进入系统，到最终输出攻击链并反馈更新的完整流程。

## 图2 跨源事件归一化流程图

```mermaid
flowchart TD
    A[原始事件] --> B{事件来源}
    B -->|端点| C1[进程/文件/注册表字段映射]
    B -->|日志| C2[账号/认证/应用字段映射]
    B -->|网络| C3[五元组/DNS/证书字段映射]
    B -->|告警| C4[规则/威胁情报字段映射]
    C1 --> D[统一事件对象]
    C2 --> D
    C3 --> D
    C4 --> D
    D --> E[原始证据引用保留]
```

**说明：** 图2展示不同数据源如何映射到统一事件对象。统一事件对象保留原始证据引用，便于审计和复核。

## 图3 实体对齐流程图

```mermaid
flowchart TD
    A[统一事件对象] --> B[实体抽取]
    B --> C1[精确标识匹配]
    B --> C2[时间邻近匹配]
    B --> C3[资产上下文匹配]
    B --> C4[网络会话匹配]
    C1 --> D[实体对齐置信度]
    C2 --> D
    C3 --> D
    C4 --> D
    D --> E{是否超过阈值}
    E -->|是| F[合并为统一实体ID]
    E -->|否| G[创建候选实体版本]
```

**说明：** 图3展示实体对齐流程。对低置信实体不强制合并，而是保留候选版本，减少错误合并。

## 图4 溯源图构建与压缩流程图

```mermaid
flowchart TD
    A[统一实体与事件] --> B[增量添加节点和边]
    B --> C[更新边频次/时间/来源/风险]
    C --> D[正常行为基线匹配]
    D --> E{是否高频稳定低风险}
    E -->|是| F[摘要化压缩]
    E -->|否| G[保留原始边]
    F --> H[压缩溯源图]
    G --> H
```

**说明：** 图4展示压缩机制。正常边被摘要化，攻击相关边、敏感边和异常边被保留。

## 图5 攻击链搜索流程图

```mermaid
flowchart TD
    A[压缩溯源图] --> B[异常子图候选]
    B --> C[攻击阶段映射]
    C --> D[时间因果路径搜索]
    D --> E[阶段约束过滤]
    E --> F[路径置信评分]
    F --> G[攻击链排序]
    G --> H[关键节点/边/证据输出]
```

**说明：** 图5展示从异常子图到攻击链的搜索过程。攻击阶段约束用于过滤不符合攻击逻辑的路径。

## 图6 反馈更新闭环图

```mermaid
flowchart TD
    A[攻击链证据包] --> B[分析员复核]
    B --> C{复核结果}
    C -->|真实攻击| D[更新攻击模式/规则]
    C -->|误报| E[更新正常行为基线]
    C -->|证据不足| F[标记缺失数据源]
    D --> G[实体置信度更新]
    E --> G
    F --> G
```

**说明：** 图6展示复核反馈如何回写系统。真实攻击推动规则沉淀，误报推动正常基线更新，证据不足推动数据源补强。
