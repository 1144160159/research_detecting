# 现有技术对比表：端点溯源图、日志和网络流联合的 APT 攻击链重构方法及装置

## 一、对比结论

本方案区别于单一端点溯源、单一日志检测、单一网络流检测和普通告警聚合方法，其核心在于跨源统一事件表示、实体对齐、溯源图增量构建、正常基线压缩、攻击阶段约束路径搜索和复核反馈闭环。

## 二、最接近现有技术对比

| 对比对象 | 已有技术内容 | 主要不足 | 本方案区别 |
|---|---|---|---|
| [336] Dynamic provenance graph-based APT detector | 使用动态溯源图检测 APT | 侧重端点溯源图，对日志和网络流联合不足 | 融合端点、日志、网络流和情报，构建跨源攻击图 |
| [416] End-to-End Attack Scene Reconstruction | 主机内攻击场景重构，结合规则和异常模型 | 对跨主机、网络流和多源实体对齐覆盖不足 | 支持跨主机网络关系、认证日志和流量会话联合重构 |
| [528] RT-APT | 大规模溯源图实时 APT 异常检测 | 输出偏检测结果，阶段化攻击链和证据包不足 | 增加 ATT&CK 阶段映射、路径搜索和证据输出 |
| [557] TeRed | 正常行为驱动的溯源图压缩 | 主要解决图压缩，未完整处理日志和网络流融合 | 将正常基线压缩作为攻击链重构前置模块 |
| [847] Zoomer | 基于深宽溯源图学习识别 APT TTP | 重点在 TTP 识别模型，工程闭环不足 | 将 TTP 识别嵌入多源采集、实体对齐、路径搜索和反馈更新 |
| [109] KRYSTAL | 基于知识图谱的审计数据攻击发现 | 更偏审计数据和知识图谱发现 | 扩展到网络流、日志、端点事件联合攻击链 |
| [604] Alert2Vec | 告警子图表示和聚合 | 主要处理告警疲劳，不重构完整攻击链 | 将告警作为证据源之一，输出阶段化攻击路径 |

## 四、可主张的改进点

1. 统一端点、日志、网络流和威胁情报，解决单源证据不完整问题。
2. 引入跨源实体对齐置信度，避免错误合并或漏关联。
3. 使用正常行为基线压缩高频正常边，提升大规模图处理效率。
4. 使用攻击阶段约束搜索攻击链，提升路径解释性。
5. 通过复核反馈更新基线、规则和实体置信度，形成持续优化闭环。

## 五、潜在规避与保护建议

| 潜在规避方式 | 建议保护方式 |
|---|---|
| 不使用 MITRE ATT&CK，改用自定义攻击阶段 | 表述为“攻击阶段约束模型”，不限定具体框架 |
| 不使用图神经网络，使用规则图搜索 | 表述为“基于跨源溯源图进行路径搜索” |
| 只使用 EDR 和 NetFlow，不使用日志 | 数据源表述为端点、日志、网络流中的至少两类 |
| 将正常基线改为白名单 | 表述为“正常行为基线或等效正常模式集合” |
| 将人工复核改成自动处置反馈 | 反馈来源包括人工、规则、沙箱、处置系统 |

## 六、仍需补强的证据

1. 统一事件 schema 和实体类型表。
2. 实体对齐置信度公式或规则。
3. 正常行为基线压缩策略及攻击边保留策略。
4. 一个完整 APT 攻击链示例。
5. 图压缩率、攻击边保留率、攻击链完整率和复核量下降实验数据。
