# 附图与流程说明：流量大模型辅助的告警证据包生成与幻觉校验方法及装置

## 图1 系统总体架构图

```mermaid
flowchart LR
    A[安全告警] --> B[告警接入模块]
    B --> C[证据检索与抽取]
    C --> D[证据包构建模块]
    D --> E[提示构造模块]
    E --> F[大模型生成模块]
    F --> G[幻觉校验模块]
    G -->|通过| H[可审计告警报告]
    G -->|不通过| I[降级/补证/人工复核]
    H --> J[分析员反馈]
    I --> J
    J --> K[知识库/规则库/模板更新]
    K --> C
```

**说明：** 图1展示系统总流程。大模型生成的报告必须经过幻觉校验后才能输出。

## 图2 证据包构建流程图

```mermaid
flowchart TD
    A[告警对象] --> B1[流量证据]
    A --> B2[模型证据]
    A --> B3[资产证据]
    A --> B4[威胁情报证据]
    A --> B5[历史相似事件]
    A --> B6[攻击链/图上下文]
    B1 --> C[证据编号]
    B2 --> C
    B3 --> C
    B4 --> C
    B5 --> C
    B6 --> C
    C --> D[结构化证据包]
```

**说明：** 图2展示证据包来源。所有证据均分配证据编号，供报告结论引用。

## 图3 证据约束提示构造图

```mermaid
flowchart TD
    A[结构化证据包] --> B[证据序列化]
    B --> C[系统约束]
    B --> D[输出格式约束]
    B --> E[禁止项约束]
    B --> F[引用证据约束]
    C --> G[Prompt]
    D --> G
    E --> G
    F --> G
```

**说明：** 图3展示提示构造。系统约束要求模型只能基于证据回答，无证据时输出证据不足。

## 图4 幻觉校验流程图

```mermaid
flowchart TD
    A[模型生成报告] --> B[抽取关键结论]
    B --> C[证据引用校验]
    C --> D[证据支持度校验]
    D --> E[未见IOC校验]
    E --> F[禁止归因校验]
    F --> G[结构Schema校验]
    G --> H[多源一致性校验]
    H --> I{是否通过}
    I -->|是| J[输出报告]
    I -->|否| K[删除/降级/补证/复核]
```

**说明：** 图4展示幻觉校验步骤。校验不通过的内容不能作为确定结论输出。

## 图5 反馈更新流程图

```mermaid
flowchart TD
    A[分析员复核结果] --> B{复核类型}
    B -->|真实攻击| C[加入历史攻击案例]
    B -->|误报| D[加入误报模式库]
    B -->|证据不足| E[更新证据缺口模板]
    C --> F[规则候选生成]
    D --> G[提示模板调整]
    E --> H[检索策略调整]
    F --> I[知识库更新]
    G --> I
    H --> I
```

**说明：** 图5展示反馈闭环。复核结果用于提升后续证据检索和报告生成质量。
