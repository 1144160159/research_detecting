# 专利交底书草案：流量大模型辅助的告警证据包生成与幻觉校验方法及装置

## 一、发明名称

流量大模型辅助的告警证据包生成与幻觉校验方法及装置。

## 二、技术领域

本发明涉及网络安全运营、智能告警分析、网络流量大模型、检索增强生成、可解释检测和大模型幻觉校验领域，尤其涉及一种基于结构化证据包约束大模型生成告警解释，并对生成内容进行证据校验的方法及装置。

## 三、背景技术

网络安全检测系统通常输出告警名称、攻击类型、风险分数和少量字段。安全分析员需要人工检索流量、日志、资产、威胁情报和历史事件才能判断告警是否真实有效。随着大模型在安全分析中的应用，使用自然语言生成告警摘要、攻击解释和处置建议成为可能。

但直接使用大模型分析安全告警存在明显风险：

1. 大模型可能生成未被证据支持的攻击结论、IOC、归因或处置建议。
2. 大模型无法天然掌握企业内部资产、私有日志、检测模型输出和实时流量上下文。
3. 现有可解释检测方法多停留在特征重要性或规则命中，未形成可审计、可引用的证据包。
4. 生成文本中的每个结论是否由证据支持，通常缺少自动校验机制。
5. 分析员复核结果难以回写到提示模板、知识库、规则库和相似事件索引。

因此，需要一种将大模型限定在证据约束范围内，用于告警解释、复核辅助和处置建议生成，并对生成内容进行幻觉校验的方法及装置。

## 四、发明目的

本发明旨在解决以下技术问题：

1. 如何将检测告警、流量特征、模型分数、资产上下文、威胁情报和历史事件组织为结构化证据包。
2. 如何约束大模型只基于证据包生成告警解释，并要求每个关键结论引用证据编号。
3. 如何自动识别无证据结论、错误 IOC、错误归因和不符合结构的输出。
4. 如何将人工复核和处置结果回写到知识库、规则库和提示模板。

## 五、技术方案

### 5.1 方法总体流程

本发明提供一种流量大模型辅助的告警证据包生成与幻觉校验方法，包括：

1. 接收来自流量检测系统、入侵检测系统、开放集检测系统或安全运营平台的告警对象。
2. 对告警对象进行归一化，生成统一告警字段。
3. 围绕告警对象检索并提取流量证据、模型证据、资产证据、威胁情报证据、历史相似事件证据和攻击链上下文证据。
4. 为每条证据分配证据标识，构建结构化证据包。
5. 根据证据包生成证据约束提示，提示中规定大模型只能基于证据回答，且关键结论必须引用证据标识。
6. 调用流量大模型或通用大模型生成告警摘要、攻击假设、支持证据、待复核问题、处置建议和不确定性说明。
7. 对生成报告进行幻觉校验，包括证据引用校验、证据支持度校验、未见 IOC 校验、禁止归因校验、输出结构校验和多源一致性校验。
8. 对未通过校验的内容进行删除、降级、补证请求或标记人工复核。
9. 将通过校验的报告输出给安全分析员。
10. 根据分析员反馈更新历史事件索引、规则候选库、提示模板和幻觉校验规则。

### 5.2 证据包构建

结构化证据包至少包括：

1. 告警基础信息：告警编号、时间、来源、规则名、风险分数、检测标签。
2. 流量证据：五元组、包长序列摘要、协议字段、TLS/QUIC 指纹、域名、证书、流量方向和时间特征。
3. 模型证据：分类结果、置信度、不确定性、开放集风险、模态冲突、特征贡献。
4. 资产证据：资产类型、业务系统、暴露面、重要性、历史风险。
5. 威胁情报证据：IOC 命中、恶意域名、恶意 IP、证书指纹、家族标签。
6. 历史事件证据：相似告警、相似流量、历史误报、历史处置结论。
7. 图上下文证据：关联主机、会话、域名、账号、攻击链上下文。

### 5.3 证据约束生成

系统将证据包转换为大模型提示。提示中至少包括：

1. 禁止模型使用证据包外的事实作为确定结论。
2. 要求每个攻击判断、处置建议和 IOC 结论引用证据标识。
3. 对证据不足的部分输出“证据不足”或“需进一步复核”。
4. 禁止无证据组织归因、国家归因、攻击者归因或高危处置。
5. 要求输出符合预设结构，例如 JSON 或固定章节格式。

### 5.4 幻觉校验

幻觉校验模块对大模型输出进行以下检查：

1. **证据引用校验**：每个关键结论是否包含证据标识。
2. **证据支持度校验**：结论文本是否能被引用证据支持。
3. **未见 IOC 校验**：报告中出现的 IP、域名、哈希、证书和规则名是否存在于证据包。
4. **禁止归因校验**：报告是否包含未被允许的组织、国家、攻击者归因。
5. **结构校验**：报告是否符合预设 schema。
6. **多源一致性校验**：报告结论是否与检测模型、威胁情报、历史事件或第二模型输出一致。

对于未通过校验的结论，系统可执行删除、降级为不确定、要求补充证据或转人工复核。

### 5.5 反馈更新

分析员对报告的确认结果可用于更新：

1. 历史相似事件索引。
2. 误报模式库。
3. 规则候选库。
4. 提示模板。
5. 幻觉校验规则。
6. 证据检索策略。

## 六、装置组成

本发明还提供一种告警证据包生成与幻觉校验装置，包括：

1. **告警接入模块**：接收并归一化安全告警。
2. **流量证据抽取模块**：提取流量和模型相关证据。
3. **资产与情报检索模块**：检索资产上下文和威胁情报。
4. **历史事件检索模块**：检索相似告警和处置记录。
5. **证据包构建模块**：生成结构化证据包并分配证据编号。
6. **提示构造模块**：生成证据约束提示。
7. **大模型生成模块**：生成告警解释和处置建议。
8. **幻觉校验模块**：校验报告结论是否被证据支持。
9. **报告输出模块**：输出可审计报告。
10. **反馈更新模块**：根据复核结果更新知识库、规则库和提示模板。

## 七、有益效果

本发明至少具有以下效果：

1. 将大模型限制在结构化证据范围内，降低无证据幻觉。
2. 使告警解释中的关键结论可追溯到证据编号，提高审计性。
3. 将流量特征、模型输出、资产、情报和历史事件统一为证据包，减少分析员手工检索时间。
4. 通过幻觉校验过滤错误 IOC、错误归因和无依据处置建议。
5. 通过反馈更新持续改进提示模板、相似事件检索和规则候选生成。

## 八、可选实施方式

1. 大模型可为通用大模型、流量微调大模型、MoE-LoRA 模型、本地小模型或云端模型。
2. 证据检索可采用关键词检索、向量检索、知识图谱检索或混合检索。
3. 幻觉校验可采用规则校验、自然语言蕴含模型、第二模型交叉验证或人工抽检。
4. 输出报告可为 JSON、Markdown、工单格式或 SOC 平台字段。
5. 系统可部署在 SOC 平台、本地安全数据湖、私有云或混合云环境。

## 九、建议补充实验

1. 对比无校验 LLM、RAG LLM 和本发明方案。
2. 指标包括无证据结论比例、错误 IOC 率、证据引用覆盖率、报告结构完整率。
3. 运营指标包括单告警研判时间、人工复核量、规则候选采纳率和误报模式沉淀数。
4. 延迟和成本指标包括证据包构建时间、LLM 生成时间、校验时间、token 数和缓存命中率。
