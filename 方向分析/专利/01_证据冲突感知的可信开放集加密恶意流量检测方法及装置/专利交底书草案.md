# 专利交底书草案：证据冲突感知的可信开放集加密恶意流量检测方法及装置

## 一、发明名称

证据冲突感知的可信开放集加密恶意流量检测方法及装置。

## 二、摘要

本发明公开了一种证据冲突感知的可信开放集加密恶意流量检测方法及装置，属于网络安全、加密流量分析、入侵检测和开放集识别领域。该方法在不解密网络载荷的条件下，对加密网络流量进行会话重组和多粒度特征提取，分别从流统计、包长方向时序、TLS/QUIC 可见协议字段、字节摘要或时频特征、主机-会话-域名关系图等模态生成类别证据、不确定性和模态可靠度；根据各模态证据分布计算模态间证据冲突矩阵，并依据冲突程度和可靠度对模态证据进行折扣融合；再结合融合不确定性、模态冲突度、类别原型距离、能量分数和校准置信度计算开放集未知风险，输出已知正常、已知恶意、未知恶意候选或待人工复核结果。系统还维护未知候选池和已知类原型库，并根据人工复核、沙箱检测、威胁情报或规则验证结果更新检测阈值、类别原型、未知候选簇和模态可靠度参数。本发明能够降低未知加密恶意流量被高置信误判为已知类别的风险，并提升检测结果的可解释性、可审计性和持续适应能力。

## 三、技术领域

本发明涉及网络安全、加密流量分析、入侵检测、开放集识别、多模态学习、证据理论和不确定性估计领域，尤其涉及一种在不解密 TLS、QUIC、VPN、DoH 等加密载荷的条件下，对已知和未知加密恶意流量进行可信检测、拒识、复核和反馈更新的方法、装置、电子设备及计算机可读存储介质。

## 四、背景技术

随着 TLS、QUIC、VPN、DoH 等加密通信协议普及，恶意软件通信、命令控制、钓鱼投递、代理隧道、隐蔽扫描和数据外传行为越来越多地隐藏在加密通道中。传统深度包检测依赖明文载荷、静态特征或规则匹配，在加密环境下难以直接获得有效载荷内容。现有加密流量检测技术通常基于 NetFlow/IPFIX 统计、包长方向序列、握手元数据、证书字段、JA3/JA4 指纹、流间关系图或字节摘要对流量进行识别。

现有技术至少存在以下不足：

1. 多数检测模型按照闭集分类设计，默认训练阶段和测试阶段类别一致。当出现未知攻击族、新型代理协议、新型加密隧道或新业务伪装流量时，模型容易将未知样本强制归入已知类别，并给出较高置信度。
2. 普通开放集识别或分布外检测方法多依赖最大 softmax 置信度、能量分数、原型距离或重构误差中的单一信号，面对短流、弱异常、相似攻击变体、业务漂移和协议升级时稳定性不足。
3. 传统多模态融合方法常采用特征拼接、注意力加权或投票机制，没有显式刻画模态缺失、模态污染、模态冲突和模态可靠度。当某一模态受采样不足、字段缺失、协议升级或对抗扰动影响时，融合结果仍可能给出高置信错误判断。
4. 现有检测系统通常只输出类别和分数，缺少能够解释未知风险来源的证据包，安全分析人员难以判断拒识原因、冲突来源和相似历史样本。
5. 现有系统较少形成未知候选池、人工复核、沙箱验证、威胁情报验证、阈值更新和类别原型更新闭环，导致未知攻击发现结果难以持续沉淀。

因此，需要一种能够结合多粒度加密流量证据、显式感知模态冲突、输出可信开放集风险并支持在线反馈更新的检测方法及装置。

## 五、发明目的

本发明旨在解决以下技术问题：

1. 在加密载荷不可见的情况下，如何综合利用流统计、包序列、协议元数据、字节摘要、时频特征和关系图等多源侧信道证据。
2. 在不同模态证据不一致时，如何区分模态缺失、模态污染、证据不足、业务漂移和真实未知恶意风险。
3. 如何避免未知加密恶意流量被高置信误判为已知正常或已知恶意类别。
4. 如何将开放集未知风险转化为可复核、可审计、可持续学习的证据包和候选池。
5. 如何根据人工复核、沙箱检测、威胁情报或规则验证结果回写检测系统，实现阈值、原型、未知候选簇和模态可靠度持续更新。

## 六、核心技术构思

本发明的核心构思是：对同一条加密流量对象构造多个互补的证据模态，每个模态不直接输出单一分类结果，而是输出包含类别 belief、不确定性 uncertainty 和可靠度 reliability 的模态证据意见；系统进一步计算模态间证据冲突矩阵，将模态冲突既作为融合折扣依据，也作为开放集未知风险的组成信号；最终通过融合不确定性、冲突度、原型距离、能量分数和校准置信度共同完成已知类别判定、未知恶意候选判定和待复核判定。

与仅做多模态加权平均的方案不同，本发明不把冲突视为简单噪声，而是将冲突显式建模为安全检测场景中的风险线索。例如，协议元数据像正常浏览器访问，而包长时序和关系图同时接近命令控制通信，则该样本即使最大已知类置信度较高，也应被提升为未知恶意候选或待复核对象。

## 七、技术方案

### 7.1 术语和符号约定

为便于说明，设待检测流量对象为 `x`，已知类别集合为 `Y={1,...,K}`，模态集合为 `M={stat, seq, proto, byte, graph}`。其中：

1. `stat` 表示流统计模态，包括持续时间、上下行包数、上下行字节数、平均包长、包长方差、速率、突发次数等。
2. `seq` 表示包长方向时序模态，包括前 `N` 个包的长度、方向、到达间隔、burst 序列或应用数据单元长度。
3. `proto` 表示可见协议字段模态，包括 TLS/QUIC 握手字段、版本、扩展、SNI 可见字段、证书摘要、JA3/JA4 指纹、ALPN、QUIC 传输参数等。
4. `byte` 表示字节摘要或时频模态，包括首包或前若干包的不可逆字节摘要、n-gram 统计、熵特征、压缩表示、时间频域特征等。
5. `graph` 表示关系图模态，包括主机-会话、会话-域名、主机-证书、主机-目的地址、时间共现或告警共现关系图。

对于每一模态 `m`，模态证据生成模型输出非负证据向量 `e_m=(e_m1,...,e_mK)`、不确定性 `u_m` 和可靠度 `r_m`。在一种实施方式中，将 `e_m` 转换为 Dirichlet 参数：

```text
alpha_mk = e_mk + 1
S_m = sum_k alpha_mk
b_mk = e_mk / S_m
u_m = K / S_m
```

其中，`b_mk` 表示模态 `m` 对类别 `k` 的 belief，`u_m` 表示该模态意见的不确定性。证据生成方式不限于 Dirichlet evidence，也可以采用深度集成、MC Dropout、温度校准 softmax、贝叶斯神经网络或其他能够得到分类意见与不确定性的方法。

### 7.2 方法总体流程

本发明提供一种证据冲突感知的可信开放集加密恶意流量检测方法，包括如下步骤：

S101，采集加密网络流量，对报文进行会话重组、方向标记、时间窗口切分和流级聚合，生成待检测流量对象。

S102，对待检测流量对象提取多粒度特征，所述多粒度特征至少包括流统计特征、包长方向时序特征、TLS/QUIC 可见协议字段、字节摘要或时频特征、主机-会话-域名关系图特征中的两类或多类。

S103，对每一类特征执行模态质量评估，得到模态完整性、采样充分性、字段缺失率、短流标志、协议解析成功率、图邻居稀疏度等质量指标。

S104，将各类特征分别输入对应的模态证据生成模型，得到每个模态的类别证据、模态不确定性和模态可靠度。

S105，根据不同模态的类别 belief、不确定性和可靠度计算模态间证据冲突矩阵。

S106，根据模态可靠度和冲突矩阵，对各模态证据进行折扣处理，并对折扣后的证据进行融合，得到融合证据分布、融合不确定性和融合表示。

S107，根据融合证据分布、融合不确定性、模态冲突度、类别原型距离、能量分数、最大已知类置信度和场景校准阈值计算开放集未知风险。

S108，根据开放集未知风险输出已知正常、已知恶意、未知恶意候选或待人工复核结果，并生成包含模态贡献、冲突来源、相似样本和处置建议的证据包。

S109，将未知恶意候选和待复核样本写入未知候选池，根据人工复核、沙箱检测、威胁情报验证或规则引擎验证结果更新类别原型、未知候选簇、检测阈值和模态可靠度参数。

### 7.3 多粒度特征提取

系统可按照以下方式构造多粒度特征：

| 模态 | 示例特征 | 质量指标 | 作用 |
|---|---|---|---|
| 流统计模态 | 持续时间、包数、字节数、上下行比例、包长均值/方差、速率、突发次数 | 包数是否足够、持续时间是否过短、字段是否完整 | 提供轻量、稳定、低成本的全流量基础证据 |
| 序列模态 | 前 `N` 个包长、方向、到达间隔、burst 序列、ADU 长度 | 序列长度、截断比例、抖动程度 | 捕获加密通信行为模式和时序规避特征 |
| 协议模态 | TLS/QUIC 版本、扩展、ALPN、SNI 可见字段、证书摘要、JA3/JA4 | 解析成功率、字段缺失率、指纹稀有度 | 捕获协议实现、客户端库和伪装痕迹 |
| 字节/时频模态 | 首包字节摘要、n-gram、熵、压缩表示、时频谱特征 | 可采样字节数、熵异常、摘要覆盖率 | 在不解密载荷的前提下利用可见字节形态 |
| 图关系模态 | 主机-会话图、会话-域名图、证书共享图、时间共现图 | 邻居数、边类型完整性、窗口覆盖率 | 捕获群体行为、基础设施复用和横向关联 |

若某一模态缺失或质量低于阈值，该模态仍可输出低 belief、高不确定性和低可靠度的证据意见，而非直接中断检测流程。

### 7.4 模态证据生成与可靠度评估

对于每一模态，系统通过独立编码器提取模态表示 `h_m`，再通过证据头输出非负证据向量 `e_m`。模态编码器可采用 CNN、LSTM、TCN、Transformer、Mamba、GraphSAGE、GAT、统计模型或其组合。

模态可靠度 `r_m` 可由以下因素共同确定：

1. 当前模态质量 `q_m`，例如字段完整性、序列长度、解析成功率和图邻居数。
2. 当前模态不确定性 `u_m`，不确定性越高，可靠度越低。
3. 该模态在历史窗口中的校准误差、误报率和漏报率。
4. 该模态在当前协议类型、资产组、业务场景和时间窗口中的可用性。
5. 该模态与其他模态的一致性。

在一种实施方式中，可靠度可以表示为：

```text
r_m = sigmoid(a1 * q_m - a2 * u_m - a3 * ece_m - a4 * miss_m + a5 * scene_m)
```

其中，`ece_m` 为历史校准误差，`miss_m` 为字段缺失或采样不足惩罚，`scene_m` 为场景适配分数，`a1` 至 `a5` 为可训练或可配置参数。该公式仅为一种示例，实际实施中可使用规则函数、轻量模型或校准模型计算可靠度。

### 7.5 证据冲突矩阵计算

系统对任意两个模态 `i` 和 `j` 的 belief 分布计算差异度，并结合不确定性与可靠度得到模态间冲突分数 `C_ij`。在一种实施方式中：

```text
D_ij = 1 - cosine(b_i, b_j)
C_ij = D_ij * (1 - min(u_i, u_j)) * sqrt(r_i * r_j)
```

其中，`D_ij` 为 belief 分布差异，`u_i` 和 `u_j` 为两个模态的不确定性，`r_i` 和 `r_j` 为两个模态可靠度。该定义表示：当两个模态 belief 差异较大、二者都较自信且二者质量较高时，冲突分数更高；若某一模态本身高度不确定，则冲突不被过度放大。

冲突差异度 `D_ij` 也可采用 Jensen-Shannon divergence、KL divergence、L1 距离、Wasserstein 距离或其他类别分布差异度量。系统可形成冲突矩阵：

```text
C = [C_ij]_(|M| x |M|)
```

并计算全局冲突度和单模态冲突度：

```text
C_global = average(C_ij), i < j
c_m = average(C_mj), j != m
```

当某一模态与其他模态持续冲突，且自身不确定性较低时，系统判断该模态可能存在污染、漂移、采样异常、协议伪装或攻击规避；系统降低该模态对融合结果的影响，并将冲突来源写入证据包。

### 7.6 证据折扣与可信融合

系统依据模态可靠度和单模态冲突度计算证据折扣系数 `gamma_m`：

```text
gamma_m = clip(r_m * exp(-lambda * c_m), gamma_min, 1)
```

其中，`lambda` 为冲突惩罚系数，`gamma_min` 为最低保留系数。对于质量极低、缺失严重或明显异常的模态，可令 `gamma_m=0`；对于仅存在轻度冲突的模态，可保留部分证据，避免丢弃有价值信息。

折扣后的证据为：

```text
e'_mk = gamma_m * e_mk
```

融合证据可以采用如下任一方式实现：

1. 对折扣后证据进行加权求和，得到 `e_fused = sum_m e'_m`。
2. 将折扣后的证据意见输入 Dempster-Shafer 组合规则。
3. 对折扣后的类别 belief 执行加权几何平均或加权算术平均。
4. 使用深度集成、门控融合网络或专家混合网络实现等效融合。

在一种实施方式中，融合证据转换为融合 belief 和融合不确定性：

```text
alpha_fk = e_fused,k + 1
S_f = sum_k alpha_fk
b_fk = e_fused,k / S_f
u_f = K / S_f
```

其中，`b_f` 表示融合类别 belief，`u_f` 表示融合不确定性。

### 7.7 开放集未知风险判定

系统不单独依赖最大类别置信度判定 unknown，而是联合多个开放集风险分量。对于融合表示 `h` 和已知类原型库 `P={p_1,...,p_K}`，计算：

```text
p_max = max_k b_fk
d_proto = min_k distance(h, p_k)
E = energy_score(h)
```

其中，`p_max` 表示最大已知类 belief，`d_proto` 表示样本到最近已知类原型的距离，`E` 表示能量分数或分布外分数。开放集未知风险可表示为：

```text
R_unknown = sigmoid(w0
                  + w1 * norm(u_f)
                  + w2 * norm(C_global)
                  + w3 * norm(d_proto)
                  + w4 * norm(E)
                  + w5 * (1 - p_max)
                  + w6 * drift_scene)
```

其中，`drift_scene` 为当前资产组、协议类型或时间窗口的分布漂移指标，`w0` 至 `w6` 为可训练或可配置参数。也可以采用规则加权、逻辑回归、校准模型、梯度提升树或神经网络计算 `R_unknown`。

系统根据两个阈值进行决策：

1. 当 `R_unknown >= tau_unknown` 时，输出未知恶意候选，并写入未知候选池。
2. 当 `tau_review <= R_unknown < tau_unknown` 时，输出待人工复核。
3. 当 `R_unknown < tau_review` 时，输出融合 belief 最大的已知类别；该已知类别可进一步区分已知正常和已知恶意。

阈值 `tau_unknown` 和 `tau_review` 可以按全局、协议类型、资产组、时间窗口或业务域分别维护，并可根据目标误报率、复核容量和近期 unknown 召回率动态调整。

### 7.8 证据包输出

对于未知恶意候选、待复核样本和高风险已知恶意样本，系统生成结构化证据包。证据包至少包括：

1. 流量对象标识、时间、五元组、协议类型、资产组和采集位置。
2. 各模态 belief、不确定性、可靠度和折扣系数。
3. 模态冲突矩阵、最高冲突模态对和冲突解释。
4. 融合类别 belief、开放集未知风险和阈值命中原因。
5. 最近已知类原型及距离、相似历史样本、相似未知候选簇。
6. 可见协议字段摘要、包序列摘要、图关系摘要和威胁情报命中情况。
7. 建议动作，例如放行、阻断、限速、沙箱复核、情报查询或人工复核。

该证据包可用于 SOC 平台展示、审计留痕、告警解释、规则生成和后续模型更新。

### 7.9 未知候选池与反馈更新

系统维护已知类原型库、未知候选池和复核结果库。对于进入未知候选池的样本，系统按融合表示、风险分量、时间窗口、资产组和威胁情报命中情况进行聚类，形成未知候选簇。每个未知候选簇记录簇中心、簇内样本数、平均未知风险、代表性证据包、复核状态和处置状态。

反馈更新包括：

1. 对于复核为已知类别的样本，使用指数滑动平均更新对应类别原型：

```text
p_y = normalize((1 - beta) * p_y + beta * h)
```

2. 对于复核为新恶意家族或新攻击模式的样本，更新未知候选簇，并在满足样本数、纯度和威胁确认条件后生成新类候选。
3. 对于复核为正常新业务的样本，降低相似样本未知风险，更新场景阈值并记录业务白名单或弱白名单特征。
4. 对于误报集中出现的模态，降低该模态在相应场景下的可靠度；对于复核命中率高的模态，提高其可靠度。
5. 根据近期误报率、漏报率、unknown 召回率和人工复核容量调整 `tau_unknown` 与 `tau_review`。

### 7.10 训练与校准

在一种实施方式中，模型训练包括以下阶段：

1. 使用大量未标注或弱标注加密流量进行自监督预训练，例如序列掩码重建、协议字段预测、流量片段对比学习或图邻域对比学习。
2. 使用已知正常和已知恶意样本训练各模态证据头，使正确类别具有较高证据，错误类别和困难样本具有较高不确定性。
3. 使用类别原型约束、对比损失或中心损失拉近同类样本表示、拉远不同类样本表示。
4. 使用已知类留出、攻击族留出或协议留出构造伪 unknown 样本，校准开放集未知风险。
5. 使用模态缺失、字段遮蔽、序列截断、图邻居扰动和字节摘要扰动增强训练，提升系统对模态缺失和模态污染的鲁棒性。

训练目标可包括分类损失、证据正则损失、原型距离损失、开放集边界损失、校准损失和冲突一致性损失。上述训练方式仅为示例，并不限定本发明的保护范围。

### 7.11 可替代实施方式

1. 模态集合不限定为五类，可根据部署场景选择其中至少两类，也可增加 DNS、HTTP 可见字段、端点日志、IDS 告警或资产画像模态。
2. 证据生成方法不限定为 Dirichlet evidence，可替换为温度校准概率、深度集成、贝叶斯神经网络、MC Dropout 或其他不确定性估计方法。
3. 冲突计算不限定为余弦差异，可替换为 Jensen-Shannon divergence、KL divergence、L1 距离、Wasserstein 距离或学习得到的冲突评分。
4. 融合方式不限定为证据求和，可替换为 Dempster-Shafer 融合、加权平均、门控融合、专家混合或其他等效融合。
5. 开放集风险不限定为上述公式，可替换为 OpenMax、Mahalanobis 距离、能量分数、VAE 重构误差、深度集成分歧或上述分量的组合。
6. 反馈来源不限定为人工复核，可包括沙箱动态分析、威胁情报、规则引擎、EDR 告警、蜜罐命中或历史事件关联。

## 八、装置组成

本发明还提供一种证据冲突感知的可信开放集加密恶意流量检测装置，包括：

1. **流量采集与会话重组模块**：用于采集网络报文、日志或流记录，执行方向标记、会话重组、时间窗口切分和流量对象生成。
2. **多粒度特征提取模块**：用于提取流统计、包长方向时序、TLS/QUIC 可见协议字段、字节摘要、时频特征和关系图特征。
3. **模态质量评估模块**：用于计算模态完整性、解析成功率、序列长度、字段缺失率、图邻居稀疏度和采样充分性。
4. **模态证据生成模块**：用于为各模态生成类别证据、belief、不确定性和可靠度。
5. **证据冲突计算模块**：用于根据模态 belief、不确定性和可靠度计算模态间冲突矩阵、全局冲突度和单模态冲突度。
6. **证据折扣融合模块**：用于按照可靠度和冲突分数对模态证据进行折扣，并融合得到融合证据分布。
7. **开放集风险判定模块**：用于根据融合不确定性、模态冲突度、类别原型距离、能量分数和最大已知类置信度计算未知风险，并输出检测结果。
8. **未知候选池模块**：用于保存未知恶意候选、待复核样本、相似样本簇和复核状态。
9. **反馈更新模块**：用于根据人工复核、沙箱验证、威胁情报和规则验证结果更新原型、阈值、未知候选簇和模态可靠度。
10. **证据包输出模块**：用于输出模态贡献、冲突来源、相似样本、风险分量、复核建议和处置建议。
11. **模型与参数管理模块**：用于管理模态编码器、证据头、原型库、阈值配置、场景参数和版本信息。

该装置可以实现为边界网关、旁路流量探针、流量分析服务器、SOC 平台功能组件、云端检测服务或边云协同系统。

## 九、具体实施方式

### 9.1 实施例一：园区边界旁路检测

在园区网络出口部署流量镜像探针，探针采集 TLS 和 QUIC 加密流量的五元组、时间戳、包长、方向和握手元数据。系统对每条会话提取流统计、包长方向序列、TLS/QUIC 字段和主机-域名关系图特征。对于每个模态，系统分别输出类别 belief、不确定性和可靠度。

若某条流量的协议模态接近常见浏览器访问，但包长方向序列接近已知命令控制通信，且关系图显示该源主机近期连接多个低信誉域名，则系统计算得到较高模态冲突度和较高原型距离。即便融合后的最大已知类别 belief 指向普通 HTTPS 访问，开放集未知风险仍超过 `tau_unknown`，系统将其输出为未知恶意候选，并生成包含冲突模态对、相似历史样本和推荐沙箱复核动作的证据包。

### 9.2 实施例二：短流和字段缺失场景

对于只包含少量报文的短流，序列模态质量低，协议字段可能尚未完整出现。系统不会因字段缺失直接输出未知恶意，而是使对应模态输出高不确定性和低可靠度。若流统计模态和图关系模态均显示低风险，则未知风险保持较低；若短流同时命中可疑证书、稀有 JA4 指纹或异常关系图邻居，则未知风险升高并进入待复核或未知候选状态。

该实施方式能够减少短流场景下单一模态缺失导致的误报，同时保留对短连接恶意通信的发现能力。

### 9.3 实施例三：未知候选簇形成与新类发现

系统在连续多个时间窗口内发现若干未知恶意候选，它们具有相似的包长方向序列、相似证书摘要和共同的域名注册特征，但不接近任何已知恶意类别原型。未知候选池将这些样本聚为同一候选簇，并记录簇中心、代表样本和平均未知风险。

安全分析人员通过沙箱和威胁情报确认该候选簇属于新的恶意家族后，系统将该簇标记为新恶意家族候选，更新未知候选簇状态，并在满足训练样本数量和质量要求后更新模型或新增类别原型。后续相似流量可被更稳定地识别，并保留其从 unknown 到新类的演进记录。

### 9.4 实施例四：正常新业务漂移处理

某业务系统升级后引入新的 QUIC 客户端实现，导致协议指纹和包长序列与既有正常类原型存在差异，系统初期将部分样本输出为待复核。人工确认其为正常新业务后，反馈更新模块对该资产组和协议类型下的阈值进行校准，更新正常类原型，并降低该场景下协议模态冲突对 unknown 风险的影响。系统因此能够适应正常业务漂移，降低后续误报。

## 十一、有益效果

与现有技术相比，本发明至少具有以下有益效果：

1. 能够在加密载荷不可见场景下融合多粒度侧信道信息，提高对加密恶意流量的检测能力。
2. 能够显式识别模态冲突、模态缺失和模态不可靠情况，降低单一模态污染或协议字段缺失导致的高置信误判。
3. 能够将 unknown 判定建立在不确定性、冲突度、原型距离、能量分数和校准置信度的组合风险上，减少未知攻击被误归入已知类别的情况。
4. 能够输出可复核证据包，向安全分析人员说明冲突来源、风险分量、相似样本和建议动作，提高告警解释性和审计能力。
5. 能够通过未知候选池、类别原型库和反馈更新机制持续适应新攻击、新协议、新业务和网络环境漂移。
6. 能够针对不同资产组、协议类型和时间窗口动态维护阈值，在开放集召回率、误报率和人工复核工作量之间取得平衡。
7. 能够支持边界网关、旁路探针、流量分析服务器和 SOC 平台等多种部署形态。

### 12.1 方法独立权利要求建议

一种证据冲突感知的可信开放集加密恶意流量检测方法，包括：

1. 采集加密网络流量，对所述加密网络流量进行会话重组和流级聚合，得到待检测流量对象。
2. 对所述待检测流量对象提取至少两类多粒度特征，所述多粒度特征包括流统计特征、包长方向时序特征、加密协议可见字段特征、字节摘要或时频特征、关系图特征中的至少两类。
3. 将每一类多粒度特征输入对应的模态证据生成模型，得到各模态的类别证据、模态不确定性和模态可靠度。
4. 根据各模态的类别证据、模态不确定性和模态可靠度计算模态间证据冲突矩阵。
5. 根据所述模态间证据冲突矩阵和所述模态可靠度对各模态的类别证据进行折扣处理，并融合折扣后的类别证据，得到融合证据分布和融合不确定性。
6. 根据所述融合证据分布、融合不确定性、模态间证据冲突度、待检测流量对象到已知类原型的距离、分布外风险分数和最大已知类置信度计算开放集未知风险。
7. 根据所述开放集未知风险输出已知类别、未知恶意候选或待复核结果。
8. 将所述未知恶意候选或待复核结果写入未知候选池，并根据复核反馈更新已知类原型、未知候选簇、检测阈值或模态可靠度参数。

### 12.2 从属权利要求建议

1. 如上述方法，其中所述类别证据为非负证据向量，所述非负证据向量被转换为 Dirichlet 参数，以得到类别 belief 和模态不确定性。
2. 如上述方法，其中所述模态可靠度由模态质量、模态不确定性、历史校准误差、字段缺失率、场景适配分数中的至少两项确定。
3. 如上述方法，其中所述模态间证据冲突矩阵由两个模态的 belief 分布差异、不确定性和可靠度共同计算得到。
4. 如上述方法，其中所述折扣处理包括根据单模态冲突度降低对应模态证据对融合结果的贡献。
5. 如上述方法，其中所述开放集未知风险由融合不确定性、全局模态冲突度、类别原型距离、能量分数和最大已知类置信度加权得到。
6. 如上述方法，其中当开放集未知风险大于第一阈值时输出未知恶意候选，当开放集未知风险位于第一阈值和第二阈值之间时输出待复核结果，当开放集未知风险小于第二阈值时输出已知类别。
7. 如上述方法，其中所述未知候选池对未知恶意候选进行聚类，并记录候选簇中心、代表样本、平均风险、复核状态和处置状态。
8. 如上述方法，其中所述复核反馈来源包括人工复核、沙箱检测、威胁情报验证、规则引擎验证或历史事件匹配。
9. 如上述方法，其中所述检测阈值按照协议类型、资产组、业务场景或时间窗口分别维护和更新。
10. 如上述方法，其中系统输出证据包，所述证据包包括各模态 belief、不确定性、可靠度、折扣系数、冲突矩阵、未知风险分量、相似历史样本和处置建议。

## 十四、与现有技术的主要区别点

1. 本发明不是单纯的开放集分类器，而是将开放集拒识与加密流量多模态证据冲突、证据折扣融合、未知候选池和反馈更新闭环结合。
2. 本发明不是仅输出不确定性分数，而是将不确定性、模态冲突、原型距离、能量分数和置信度校准共同用于 unknown 风险判定。
3. 本发明不是普通多模态拼接或注意力融合，而是在融合前显式计算模态冲突矩阵，并依据冲突和可靠度对模态证据进行折扣。
4. 本发明不是只给出检测结果，而是输出包含冲突来源、模态贡献、相似样本和处置建议的证据包，便于安全运营复核。
5. 本发明不是离线一次性模型，而是通过未知候选池、类别原型库和复核反馈持续更新阈值、原型、候选簇和模态可靠度。
