# 专利交底书草案：证据冲突感知的可信开放集加密恶意流量检测方法及装置

## 一、发明名称

证据冲突感知的可信开放集加密恶意流量检测方法及装置。

## 二、技术领域

本发明涉及网络安全、加密流量分析、入侵检测、开放集识别和多模态证据融合领域，尤其涉及一种在不解密网络载荷的条件下，对未知加密恶意流量进行可信检测、拒识、复核和反馈更新的方法及装置。

## 三、背景技术

随着 TLS、QUIC、VPN、DoH 等加密通信协议普及，恶意软件、命令控制、钓鱼投递、代理隧道和数据外传行为越来越多地隐藏在加密通道中。传统深度包检测依赖明文载荷或静态规则，在加密环境下效果受限。现有研究通常使用流统计、包长方向序列、协议元数据、字节片段、时频特征或流间关系图对加密流量进行分类。

现有技术至少存在以下不足：

1. 多数检测模型按照闭集分类设计，默认训练阶段和测试阶段类别一致。当出现未知攻击族、新型代理协议或新业务伪装流量时，模型容易将其强制归入已知类别。
2. 普通开放集方法多依赖最大 softmax 置信度、能量分数、原型距离或重构误差中的单一信号，无法稳定区分短流、弱异常、业务漂移和真实未知恶意流量。
3. 传统多模态融合方法常采用特征拼接、注意力加权或投票机制，未显式刻画模态缺失、模态污染、模态冲突和模态可靠度。当某一模态受采样、协议升级或对抗扰动影响时，融合结果仍可能给出高置信错误判断。
4. 现有系统较少形成未知候选池、人工复核、阈值更新和类别原型更新闭环，导致未知攻击发现结果难以持续沉淀。

因此，需要一种能够结合多粒度加密流量证据、显式感知模态冲突、输出可信开放集风险并支持在线反馈更新的检测方法及装置。

## 四、发明目的

本发明旨在解决以下技术问题：

1. 在加密载荷不可见情况下，如何综合利用流统计、包序列、协议元数据、字节摘要和关系图等多源侧信道证据。
2. 在各模态证据不一致时，如何判断是模态污染、证据不足还是未知攻击风险。
3. 如何避免未知加密恶意流量被高置信误判为已知类。
4. 如何将未知样本、低置信样本和人工复核结果回写到检测系统，实现阈值、原型和候选簇持续更新。

## 五、技术方案

### 5.1 方法总体流程

本发明提供一种证据冲突感知的可信开放集加密恶意流量检测方法，包括如下步骤：

1. 采集加密网络流量，对报文进行会话重组和流级聚合，生成待检测流量对象。
2. 对待检测流量对象提取多粒度特征，至少包括流统计特征、包长方向时序特征、TLS/QUIC 可见协议字段、字节摘要或时频特征、主机-会话-域名关系图特征中的两类或多类。
3. 将各类特征分别输入对应的模态证据生成模型，得到每个模态的类别证据、模态不确定性和模态可靠度。
4. 根据不同模态的类别证据和不确定性计算模态间证据冲突矩阵。
5. 根据模态可靠度和冲突矩阵，对各模态证据进行折扣处理，并对折扣后的证据进行融合，得到融合证据分布。
6. 根据融合证据分布、融合不确定性、模态冲突度、类别原型距离、能量分数和置信度校准结果计算开放集未知风险。
7. 根据开放集未知风险输出已知正常、已知恶意、未知恶意候选或待人工复核结果。
8. 将未知恶意候选和待复核样本写入候选池，根据人工复核、沙箱检测或威胁情报验证结果更新类别原型、未知候选簇、检测阈值和模态可靠度参数。

### 5.2 多模态证据生成

对于每一模态，系统通过独立编码器提取模态表示，并通过证据头输出非负证据向量。证据向量可被转换为 Dirichlet 参数，从而得到类别 belief、不确定性 uncertainty 和模态可靠度 reliability。

模态可靠度可由以下因素共同确定：

1. 该模态特征是否完整，例如 TLS 字段是否缺失、包序列是否过短。
2. 该模态的历史校准误差和近期误报情况。
3. 该模态与其他模态的一致性。
4. 该模态在当前协议、资产组或业务场景下的可用性。

### 5.3 证据冲突计算与折扣融合

系统对任意两个模态的 belief 分布计算差异度，并结合不确定性得到模态间冲突分数。当某一模态与其他模态持续冲突，且自身不确定性较低时，表明该模态可能存在污染、漂移或攻击规避；系统降低该模态的融合权重，而不是直接丢弃所有模态信息。

折扣后的模态证据可通过 Dempster-Shafer 证据融合、Dirichlet evidence fusion、加权几何平均、深度集成或其他等效方式融合。

### 5.4 开放集未知风险判定

开放集未知风险至少由以下分量组成：

1. 融合不确定性。
2. 模态间冲突度。
3. 样本表示到最近已知类原型的距离。
4. 能量分数或分布外分数。
5. 最大已知类别置信度。
6. 当前场景下的校准阈值。

当未知风险大于第一阈值时，输出未知恶意候选；当未知风险位于第一阈值和第二阈值之间时，输出待复核；当未知风险低于第二阈值时，输出已知类别。

### 5.5 反馈更新

系统维护已知类原型库和未知候选池。对于复核为已知类的样本，使用指数滑动平均更新对应类别原型；对于复核为新恶意家族或新攻击模式的样本，更新未知候选簇；对于复核为正常新业务的样本，降低相似样本未知风险并更新校准阈值。

## 六、装置组成

本发明还提供一种证据冲突感知的可信开放集加密恶意流量检测装置，包括：

1. **流量采集与会话重组模块**：用于采集网络报文并形成流量对象。
2. **多粒度特征提取模块**：用于提取统计、序列、协议、字节、频域和图结构特征。
3. **模态证据生成模块**：用于为各模态生成类别证据、不确定性和可靠度。
4. **证据冲突计算模块**：用于计算模态间冲突矩阵。
5. **证据折扣融合模块**：用于按照可靠度和冲突分数融合多模态证据。
6. **开放集风险判定模块**：用于计算未知风险并输出检测结果。
7. **未知候选池模块**：用于保存未知恶意候选、低置信样本和相似样本簇。
8. **反馈更新模块**：用于根据人工复核、沙箱验证和威胁情报结果更新原型、阈值和模态可靠度。
9. **证据包输出模块**：用于输出模态贡献、冲突来源、相似样本和处置建议。

## 七、有益效果

与现有技术相比，本发明至少具有以下效果：

1. 能够在加密载荷不可见场景下融合多粒度侧信道信息，提高对加密恶意流量的检测能力。
2. 能够显式识别模态冲突和模态不可靠情况，降低单一模态污染导致的误判。
3. 能够将 unknown 判断建立在不确定性、冲突度、原型距离和能量分数的组合风险上，减少未知攻击被高置信误判为已知类的情况。
4. 能够输出可复核证据包，提升安全分析人员对检测结果的理解和审计能力。
5. 能够通过未知候选池和反馈更新机制持续适应新攻击、新协议和业务漂移。

## 八、可选实施方式

1. 模态编码器可采用 CNN、LSTM、TCN、Transformer、Mamba、GraphSAGE、GAT 或轻量统计模型。
2. 开放集风险可采用 OpenMax、Mahalanobis 距离、能量分数、原型距离、VAE 重构误差或深度集成不确定性。
3. 系统可部署于边界网关、旁路流量探针、流量分析服务器或 SOC 平台。
4. 反馈来源可包括人工复核、沙箱动态分析、威胁情报命中、规则引擎验证和历史事件匹配。

## 九、建议补充实验

1. 闭集分类器、普通开放集方法、不确定性融合方法和本发明方案对比。
2. 攻击族留出、未知协议留出、跨数据集迁移和真实园区流量验证。
3. 模态缺失、模态污染、短流截断和协议字段缺失消融。
4. 指标包括 Unknown Recall、AUROC、FPR@95TPR、误报率、吞吐量、P95 延迟、每流证据包大小和人工复核命中率。
