# 现有技术对比表：证据冲突感知的可信开放集加密恶意流量检测方法及装置

## 一、对比结论

本方案不是单纯复现开放集识别、OOD 检测或不确定性融合论文，而是将加密流量多模态侧信道、模态证据冲突、证据折扣融合、开放集风险判定、未知候选池和反馈更新组合成面向真实网络部署的完整技术流程。

## 二、最接近现有技术对比

| 对比对象 | 已有技术内容 | 主要不足 | 本方案区别 |
|---|---|---|---|
| [518] Reliable Open-Set Network Traffic Classification | 面向网络流量开放集分类，关注可靠拒识 | 多模态证据冲突和模态可靠性建模不足；缺少反馈更新闭环 | 增加多模态证据头、冲突矩阵、证据折扣融合、未知候选池和人工复核反馈 |
| [804] Trustworthy Detection of Encrypted Malicious Traffic via Uncertainty-Aware Fusion | 使用不确定性感知融合提升可信检测 | 更偏模型融合，未系统覆盖开放集阈值、原型更新和候选池维护 | 将不确定性与冲突度、原型距离、能量分数联合形成 unknown 风险 |
| [851] Towards Open Set Deep Networks | 提出 OpenMax 等开放集深度网络思想 | 原始应用场景不是加密恶意流量；不考虑多模态侧信道 | 将开放集风险落到加密流量统计、协议、序列、字节和关系图模态 |
| [853] Evidential Deep Learning | 使用证据学习量化分类不确定性 | 通用分类方法，不处理网络流量中的模态冲突和协议缺失 | 将 evidential opinion 用于每个流量模态，并计算模态间冲突 |
| [855] Energy-Based OOD Detection | 使用能量分数检测分布外样本 | 单一 OOD 信号，难以解释模态冲突来源 | 能量分数只是 unknown 风险的一部分，另结合不确定性、冲突度和原型距离 |
| [856] FOSS | 细粒度未知类检测和开放集攻击谱 | 未形成多模态证据包和反馈更新装置 | 输出可审计证据包，并维护未知候选簇 |
| [857] M3S-UPD | 多阶段自监督学习和未知模式发现 | 偏离线训练和模式发现，部署闭环不足 | 加入在线阈值、候选池、人工复核和模型更新 |
| [858] New Class Detection | 利用置信信息级联结构发现新类 | 侧重新类检测结构，未显式处理模态冲突 | 增加证据冲突矩阵和模态折扣机制 |
| [685] Mixed Noisy Labels | 研究混合噪声标签下未知加密恶意流量检测 | 主要关注训练标签污染，未完整覆盖推理证据冲突 | 将低质量标签问题扩展到推理阶段的未知候选和反馈更新 |

## 三、技术特征差异矩阵

| 技术特征 | 传统闭集检测 | 普通开放集/OOD | 不确定性融合方法 | 本方案 |
|---|---|---|---|---|
| 加密流量多粒度特征 | 部分支持 | 部分支持 | 支持程度不一 | 明确支持统计、序列、协议、字节/频域、图关系 |
| 多模态证据头 | 通常无 | 通常无 | 部分有 | 每个模态输出 evidence、belief、uncertainty、reliability |
| 模态冲突矩阵 | 无 | 无 | 通常不足 | 显式计算模态间冲突 |
| 证据折扣融合 | 无 | 无 | 部分有 | 依据可靠度和冲突度对证据折扣 |
| 开放集风险 | 无 | 有 | 部分有 | 不确定性、冲突度、原型距离、能量分数联合 |
| 未知候选池 | 无 | 较少 | 较少 | 有 |
| 人工复核反馈 | 较少 | 较少 | 较少 | 更新阈值、原型、候选簇和可靠度 |
| 可审计证据包 | 较少 | 较少 | 部分有 | 输出模态贡献、冲突来源、相似样本 |
| 在线部署指标 | 通常不足 | 通常不足 | 通常不足 | 关注吞吐、延迟、证据包大小和复核量 |

## 四、可主张的改进点

1. 将模态证据冲突作为 unknown 风险的重要组成，而不是只作为融合噪声处理。
2. 将多模态证据折扣和开放集拒识结合，提升未知攻击识别稳定性。
3. 建立未知候选池，将 unknown 结果转化为可复核和可持续学习的对象。
4. 将人工复核、沙箱和威胁情报反馈用于动态更新阈值、原型和候选簇。
5. 在技术效果中同时覆盖检测性能和工程部署性能。

## 五、潜在规避与保护建议

| 潜在规避方式 | 建议保护方式 |
|---|---|
| 将 Dirichlet evidence 换成深度集成或 MC Dropout | 权利要求中表述为“模态证据意见”，不限定具体不确定性模型 |
| 将 Dempster-Shafer 融合换成加权平均 | 表述为“基于冲突分数对模态证据进行折扣后融合” |
| 将能量分数换成 Mahalanobis 距离 | unknown 风险定义为多个分布外风险分量的组合 |
| 不使用图模态，只用统计和协议模态 | 多模态集合表述为至少两类特征 |
| 人工复核改为自动沙箱复核 | 反馈来源包括人工、沙箱、威胁情报、规则验证 |

## 六、仍需补强的证据

1. 给出模态冲突矩阵和折扣函数的具体公式。
2. 给出各模态字段和质量评估标准。
3. 给出 unknown 风险阈值的默认取值或更新策略。
4. 用实验数据证明 unknown recall、FPR@95TPR 和误报率改善。
5. 用部署实验证明吞吐和延迟满足实际场景。
