# 附图与流程说明：高速全流量多粒度特征抽取与自适应预算调度方法及装置

## 图1 系统总体架构图

```mermaid
flowchart LR
    A[高速链路流量] --> B[高速流量接入模块]
    B --> C[包级轻量特征提取模块]
    C --> D[流级聚合模块]
    D --> E[风险初筛模块]
    E --> F[预算调度模块]
    G[资源监测模块] --> F
    F --> H1[摘要路径]
    F --> H2[协议解析路径]
    F --> H3[关系图路径]
    F --> H4[深度复核路径]
    H1 --> I[特征输出]
    H2 --> I
    H3 --> I
    H4 --> I
    I --> J[检测模型/规则/SOC]
    J --> K[反馈更新]
    K --> F
```

**说明：** 图1展示装置整体结构。风险初筛和资源监测共同驱动预算调度模块，决定每条流进入何种特征抽取路径。

## 图2 特征层级结构图

```mermaid
flowchart TD
    A[L0 包级轻量特征] --> B[L1 流级统计特征]
    B --> C[L2 协议字段特征]
    C --> D[L3 关系图特征]
    D --> E[L4 深度特征]
    A -.低成本.-> F[摘要路径]
    C -.中成本.-> G[协议解析路径]
    D -.高成本.-> H[关系图路径]
    E -.最高成本.-> I[深度复核路径]
```

**说明：** 图2展示特征层级。层级越高，计算成本和信息量通常越高。

## 图3 自适应预算调度流程图

```mermaid
flowchart TD
    A[流窗口就绪] --> B[快速风险初筛]
    B --> C[读取资源状态]
    C --> D{是否资源拥塞}
    D -->|是| E{风险是否高}
    E -->|否| F[摘要路径]
    E -->|是| G[协议解析或异步复核]
    D -->|否| H{风险/置信度判断}
    H -->|低风险高置信| F
    H -->|中风险| I[协议解析路径]
    H -->|高风险| J[关系图路径]
    H -->|高风险低置信| K[深度复核路径]
```

**说明：** 图3展示调度逻辑。在资源拥塞时仍优先保留高风险流，低风险流降级为摘要。

## 图4 队列优先级调度图

```mermaid
flowchart TD
    A[待处理流任务] --> B[计算优先级]
    B --> C[风险值]
    B --> D[不确定性]
    B --> E[资产重要性]
    B --> F[时序规避风险]
    B --> G[特征成本]
    C --> H[任务排序]
    D --> H
    E --> H
    F --> H
    G --> H
    H --> I{是否满足延迟预算}
    I -->|是| J[按原路径执行]
    I -->|否| K[降级特征层级或异步处理]
```

**说明：** 图4展示队列调度机制。高风险、高不确定和高资产价值任务优先处理。

## 图5 关系图增量更新流程图

```mermaid
flowchart TD
    A[高风险流] --> B[抽取主机/会话/域名/证书节点]
    B --> C[建立通信/共享/共现边]
    C --> D[时间衰减更新]
    D --> E[局部子图特征提取]
    E --> F[过期边剪枝]
```

**说明：** 图5展示关系图路径。仅对满足条件的流构建或更新图结构，避免全量图计算。

## 图6 反馈更新流程图

```mermaid
flowchart TD
    A[检测结果/人工复核] --> B{反馈类型}
    B -->|误报| C[提高相似流放行阈值]
    B -->|漏报| D[提高相似流特征层级]
    B -->|新攻击| E[增加高风险规则/特征路径]
    C --> F[调度策略更新]
    D --> F
    E --> F
```

**说明：** 图6展示反馈如何影响后续预算调度。
