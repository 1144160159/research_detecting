## 1. 结论摘要

- 本地具备 TeRed 的较完整小规模数据与输出，最适合作为首个数据/压缩管线 pilot。
- KRYSTAL 含 CDM18 样例、RDF/TTL 产物和 backward-forward 查询，是当前最接近攻击子图输出的首个重构 smoke-test 候选；默认流程需 GraphDB，样例无完整链真值。
- Euler 代码存在，适合横向移动认证图基线，但本轮未确认完整 LANL 原始数据已下载。
- eaGle 存在若干规则、异常检测脚本和较大的 ground-truth 文件，但 README 只有简短占位说明，需要逆向整理入口与依赖。
- TraceCluster 仅有关键实现片段，仓库 README 明确说明完整实现未全部提供，不能直接作为“官方完整复现”。
- Open-CyKG 可提供 CTI/知识图谱语义参考，不提供运行时跨源攻击链真值。
- DIDS-MFL 可作为流级动态图异常种子参考，但与 APT 攻击链重构任务存在输出层级差异。

## 3. 已发现问题

1. `source/TeRed/main.py` 引用 `DATA_TO_COMPRESS`、`reduction_set/reduce_by_template.py` 引用 `COMPRESSED_FOLDER`，而当前 `settings.py` 分别暴露 `DATA_TO_REDUCE`、`REDUCED_FOLDER`；首次运行前必须做最小修复并记录来源。
2. TraceCluster 训练/测试脚本依赖 `feature.txt`、`label.txt`、`groundtruth.txt` 和图文件，当前目录未见完整数据包。
3. eaGle 的 README 不足以复现，需要从脚本参数、目录假设和论文方法反向建立运行说明。
4. 多个仓库 Python/PyTorch 版本不同，不能直接塞进一个全局环境；应按基线隔离环境或容器。
5. 当前没有证据表明本地已有同一攻击运行下完整的端点、日志和网络流三源原始数据。
6. Python 3.7 AST 静态检查结果为 TeRed 33/33、eaGle 8/8、TraceCluster 7/7 可解析；Euler 40 个 Python 文件中 37 个可解析。其余 3 个 `lanl_experiments/models/egcn_*.py` 实际是 33–37 bytes 的相对路径占位文本，目标文件存在于 `benchmarks/models/`，Windows 下不能按 Python 文件直接导入，运行前需恢复符号链接或改为显式模块引用。
