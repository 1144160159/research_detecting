# 858 篇论文组件候选池

- 语料快照：`综合分析/_data/papers_enriched.json`
- 记录数：858
- 筛选日期：2026-07-15
- 用途：发现可复用的研究组件、基线和失败风险；不是把每个组件都装入首稿

## 1. 筛选方法与解释边界

本轮采用三阶段筛选：

1. 在题名、摘要和项目增强字段中按 12 个组件族做高召回检索；
2. 结合相关性、题名命中、摘要方法描述和代码状态进行候选排序；
3. 对 11 个研究环节中的 53 篇代表论文读取逐篇精读记录，核对方法、可复用位置和主要局限。

语料元数据分布为：强相关 439 篇、中相关 251 篇、弱相关 168 篇；120 篇标注为已下载代码、1 篇部分下载、15 篇候选仓库不可访问，其余未发现代码。这里的“相关性”和“代码状态”来自项目语料增强字段，不等于本文最终采用等级。

自动检索的非互斥命中数如下。数字只表示关键词候选池规模，存在跨领域误召回，不能写成“已有多少篇论文解决了该问题”。

| 组件检索族 | 候选命中数 | 主要误召回来源 |
|---|---:|---|
| 跨源/多模态/对齐 | 59 | 多数是流量内部多视图，而非端点—日志—流量实体对齐 |
| 溯源/连续时间/异构图 | 51 | 含知识图谱、通用动态图和非安全任务 |
| 攻击链/调查/路径重构 | 19 | 部分只做流量解释或告警展示 |
| 阶段/TTP/ATT&CK | 146 | `stage/technique` 在分类论文中含义宽泛 |
| 不确定性/校准/可靠性 | 105 | 大量来自通用分类和加密流量 |
| 缺失/噪声/鲁棒性 | 161 | 多为对抗样本或标签噪声，不是传感器缺失 |
| 日志语义 | 23 | 部分针对软件故障而非攻击 |
| 网络流/横向移动 | 209 | 大量是单流分类，不提供跨主机证据边 |

| 规模化/在线 | 305 | 任务和“实时”定义差异大 |
| 数据集/真值/基准 | 240 | 多为单模态分类数据集 |

因此，论文设计依据是后续 53 篇组件级核验，而不是自动统计数量。

## 2. 状态标记

- `C+`：当前项目已发现本地代码；不代表完整可复现。
- `C?`：仅部分代码或候选仓库不可访问。
- `C-`：当前项目未发现代码。
- `D+sample`：本地存在已核验的小样例。
- `Dref`：论文引用了数据，但本项目未将其视为本地正式数据资产。

## 4. 首稿组件取舍

### 4.1 必需的四项

| 必需组件 | 主要证据来源 | 首稿实现原则 |
|---|---|---|
| 可审计统一事件与真值映射 | 258、44、624、795 | 保留原始指针、时间区间、传感器健康和 exact/heuristic 标签类型 |
| 概率式实体—时间对齐 | 44、258、280、852 | 输出候选集和概率，不强制唯一硬连接 |
| 受约束最小证据子图 | 379、416、808、624 | 先用可解释图搜索/优化，不先上大型异构 GNN |
| 软 ATT&CK 顺序与未知状态 | 847、109、795 | 允许跳阶段、并行、unknown；必须有无约束消融 |

### 4.2 插件或基线

- 日志种子：CCLog/LogMUSE/LogFiT；
- 跨机种子：EULER、HADES 会话规则；
- 流量种子：DawnGuard/ECNet 或 DIDS-MFL 现有模型；
- 重构基线：temporal BFS、k-shortest、KRYSTAL、EAGLE、CCLog-like Steiner；
- 效率层：TeRed 或 SParse 二选一；
- 校准基线：temperature scaling；
- 简单融合基线：host+flow 特征拼接、分数平均/最大、固定窗口硬连边。

### 4.3 首稿排除

- LLM 规则生成、RAG 或自然语言报告；
- 完整动态因果发现和强化学习搜索；
- GAN/扩散生成日志作为主训练策略；
- 三套独立深度编码器、注意力融合和大型异构 Transformer；
- Bayesian ensemble、EDL、Dempster-Shafer 同时叠加；
- 联邦学习、隐私保护、持续学习和自动漂移适配；
- 完整 CTI 知识图谱抽取；
- raw payload/bytes 大模型；
- 多种图压缩同时使用；
- Alert2Vec 式处置推荐。

这些组件不是“无价值”，而是会形成新的科学问题、威胁模型和评价协议，导致首稿无法归因。

## 5. 组件审查结论

858 篇语料提供了足够丰富的单点技术，但最缺的不是又一个编码器，而是把**跨源匹配是否可信**作为独立研究对象，并在链级输出中显式保留这种不确定性。最值得迁移的组件是 MIRAGE 的端点—流真值联结、UM-NIDS 的统一映射、CCLog 的 Steiner 式路径、EAGLE 的链式输出、HADES/EULER 的跨机会话证据、Zoomer/KRYSTAL 的阶段语义和 CCG-IDS 的最小证据/校准思想；其余组件应服从这一问题，而不是反过来定义论文。
