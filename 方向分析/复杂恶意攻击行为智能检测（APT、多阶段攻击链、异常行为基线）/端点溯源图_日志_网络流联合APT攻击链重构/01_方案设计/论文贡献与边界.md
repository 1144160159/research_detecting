# 论文贡献与边界

## 1. 工作题目

中文：**面向不完整与失配多源遥测的不确定性感知最小 APT 证据链重构**  
英文：**Uncertainty-Aware Minimal APT Evidence-Chain Reconstruction from Incomplete and Misaligned Multi-Source Telemetry**

## 2. 核心主张模板

端点溯源、主机/认证日志和网络流能够提供互补证据，但异步时钟、实体歧义和观测缺失也会产生伪跨源边。本文提出一种不确定跨源时序证据图，将实体—时间匹配候选及置信度传入受约束的最小充分证据子图重构；在操作性信息流、时间单调和软 ATT&CK 阶段顺序下输出可校准、可拒绝并能回溯原始记录的攻击链候选。

该主张只有在强真值对齐、链级指标、缺源/偏移鲁棒性和严格切分均通过后才可进入摘要。

## 3. 三项预期贡献

### C1：不确定性跨源对齐

把 `flow↔socket/process`、`auth↔session/process` 等映射表示为候选分布，显式保留时间区间、歧义集和传感器可靠度，并将其作为下游链边代价和最终置信来源。

必须证明：相对固定时间窗、五元组硬匹配和简单图拼接，对齐 edge F1、错误跨主机率和校准均改善。

### C2：最小充分证据子图

以异常 seed/POI 为终端，联合时间、会话、信息流、跨源支持和软阶段顺序，惩罚无支持桥接与冗余证据。允许 `unknown`、跳阶段和多分支；证据不足时输出 incomplete/abstain。

必须证明：相对 BFS、k-shortest、KRYSTAL、EAGLE、CCLog-like Steiner 和 HADES tracing，在链 edge F1/阶段覆盖与证据规模之间有可量化优势。

### C3：强真值—弱标签双协议

强真值靶场评价对齐边和完整链；LANL 评价多源互补、红队锚点排序和长时间误报；受控注入缺源、时钟漂移、实体冲突、NAT 和良性边，分离数据、对齐和解码三层误差。

必须证明：结论在 campaign/time/host-disjoint 下成立，并有按攻击运行的置信区间。

## 4. 最近似工作的差异

| 工作族 | 已覆盖 | 本研究需实证的差异 |
|---|---|---|
| CCLog [379] | 日志语义、provenance topology、Steiner 路径 | 独立 flow、候选边概率、跨机失配、拒绝与最小证据评价 |
| Multi-source log [342] | 应用+OS 日志、七阶段模板 | 不依赖完整已知子图库；允许歧义和未知阶段 |
| Hybrid host+flow [254] | 主机+网络流样本分类 | 对齐边和攻击子图，而非只做样本标签 |
| EAGLE [416] | 单机规则+异常子树 | 跨主机和三源失配；多分支最小证据链 |
| HADES/Commander [695,386] | 身份/会话跨机调查 | 非 AD 网络流、候选概率和缺证拒绝 |
| EULER [106] | 横向移动时序 link prediction | 预测边仅作候选，并与端点因果证据联合重构 |
| TeRed [557] | 正常模板溯源图归约 | 后置效率层；需证明跨源连接点和攻击链证据保持 |
| Zoomer/KRYSTAL [847,109] | TTP 识别/映射 | 阶段语义作为软顺序约束，不替代事件路径 |

## 5. 最小可发表版本

1. 一套可公开说明的统一事件与对齐真值格式；
2. oracle、精确/固定窗口/五元组硬匹配和概率对齐；
3. 一个简单、可解释的最小证据子图解码器；
4. 至少 18 次强真值攻击运行，含两个留出攻击族；
5. LANL 多源弱标签和长时间误报评价；
6. 对齐、事件、边、阶段、子图、校准和效率指标；
7. 30% 缺源、±5 秒偏移、实体冲突和良性边注入实验。

若只能完成少量强真值运行，链重构只能作为 case study，题目降级为“多源攻击调查子图排序”。

## 6. 不足时的降级题目

- 无完整链真值：**不确定性跨源对齐的 APT 调查子图排序**；
- 只有 LANL：**面向红队横向移动的多源时序事件图与可疑路径排序**；
- 只有端点+日志：**日志语义增强的端点证据链重构**；
- 只有端点+网络：**网络流互证的跨主机端点证据链重构**；
- 主方法无优势但失效曲线稳定：**ChainBreak：多源攻击链重构的失配失败边界基准**。

## 7. 明确不追求

- 以“三源融合”或模型规模本身作为创新；
- 通过堆叠 LLM、GAN、多个 GNN/Transformer、联邦/隐私和持续学习换取单数据集得分；
- 把 ATT&CK 文本相似度、社区或异常邻域直接称为完整攻击链；
- 将未标注 LANL 事件全部当作良性；
- 将不同场景或派生视图后验拼接后声称独立多源互证；
- 把操作性 provenance 依赖夸大为严格结构因果；
- 用可视化案例替代链级量化评价。
