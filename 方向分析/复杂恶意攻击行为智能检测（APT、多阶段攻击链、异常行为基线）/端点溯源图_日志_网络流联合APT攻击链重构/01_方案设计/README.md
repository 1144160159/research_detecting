## 稳定方案原则

- 先用可解释规则、时间路径和轻量表示建立强基线，再判断是否需要复杂 GNN/Transformer。
- 所有跨源边必须带来源、候选集合、时间偏差和置信度。
- 攻击阶段知识用于候选约束与解释，不得把测试真值阶段直接作为输入。
- 模型最终输出事件子图、阶段序列和证据包，而不是只有一个攻击概率。
- 对齐、检测和重构分别评价，避免端到端单一指标掩盖误连边。
- 首稿只保留统一事件、概率对齐、最小证据子图和链级失配评价；其他组件必须是基线、插件或后续工作。
