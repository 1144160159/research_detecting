# 端点溯源图、日志和网络流联合的 APT 攻击链重构

本目录是该论文方向的单一工作入口。研究目标不是再做一个节点异常分类器，也不是把三种模态简单拼接，而是在失配、缺源和实体歧义下显式建模跨源连接的不确定性，重构最小充分、可拒绝、可回溯的 APT 证据链。

## 一句话定位

面向日志缺失、时间偏差和攻击行为极度稀疏的真实网络，研究**不确定性对齐与最小充分证据子图**驱动的跨源 APT 攻击链重构方法。

## 当前版本和论文主张

- 版本：`v0.2-research-design`
- 工作题目：**面向不完整与失配多源遥测的不确定性感知最小 APT 证据链重构**
- 暂定英文题目：**Uncertainty-Aware Minimal APT Evidence-Chain Reconstruction from Incomplete and Misaligned Multi-Source Telemetry**
- 工作目标：IEEE TIFS / IEEE TDSC 风格的实证型安全论文；若系统实现和实时性证据更强，可转向 RAID / ACSAC。
- 当前允许的主张：已形成可验证的研究方案和本地资产基线。
- 当前禁止的主张：性能领先、端到端实时、全面覆盖 ATT&CK、真实园区有效。

## 当前最短执行路径

1. 冻结 [研究设计总纲](00_总览/研究设计总纲.md) 和 H1-H4，不继续增加模型模块；
2. 采集最小强真值三源 pilot，建立 `flow↔socket/process↔session` exact/ambiguous 映射；
3. 完成 oracle、精确连接、固定时间窗、五元组和简单约束搜索基线；
4. 注入时间偏移、缺源和实体冲突，执行两周 Go/No-Go；
5. 通过后扩展到 18-24 次攻击运行、LANL 11GB 主协议和 LANL 181GB 规模协议；失败则转 ChainBreak 基准。

## 研究质量门

1. **数据门**：至少一个数据集能生成同一时间轴上的端点、日志、流量三类观测，并有攻击事件或阶段真值。
2. **对齐门**：实体和事件匹配必须输出置信度、候选数、误匹配率与时间偏差统计。
3. **重构门**：主结果必须包含事件级、阶段级和整链级指标，不能只报告节点分类指标。
4. **对照门**：必须与单源、简单拼接、无阶段约束和代表性溯源图基线比较。
5. **鲁棒门**：必须测试缺源、延迟、噪声、背景规模和跨场景迁移。
6. **审计门**：每条预测攻击链都能回溯到原始事件 ID、数据源、时间戳和评分分解。

## 维护规则

1. 新实验先登记假设、数据版本、成功判据和泄漏边界，再运行。
2. `03_实验报告/` 只写已经核对的结果；运行失败和负结果写入 `07_过程记录/`。
3. `results/` 只保存轻量摘要、配置、哈希和运行编号；原始数据、模型参数、检查点和大图只保存在 GPU 服务器。
4. 文献进入论文正文前必须满足“本地 PDF/Zotero 条目、引用键、证据卡”三项要求。
