# 研究路线与里程碑

## 1. 总路线

按“问题冻结—强真值—简单基线—否证性 pilot—完整实验—规模扩展—论文冻结”推进。未通过质量门时先修数据或收缩主张，不用新增模型组件掩盖失败。

## 2. 阶段划分

### M0：研究问题与资产审计

- 状态：已完成首轮。
- 产物：858 篇组件候选池、53 篇人工核验、研究总纲、实验闭环、本地/远端资产清单。
- 结论：主方案为“不确定性跨源对齐+最小充分证据链”；LANL 不能单独承担完整链真值。

### M1：强真值最小闭环

- 采集至少 3 个 pilot run，覆盖端点、认证/日志、flow 和攻击步骤 manifest；
- 建立 `flow↔socket/process↔session` exact/ambiguous/unmatched 映射；
- 完成字段解析、时钟残差、传感器健康和两人标注一致性；
- 通过条件：解析率 `>=99%`、对齐真值可复核、p95 校时残差 `<=1s` 或有时间区间、不把歧义强标为唯一事实。

### M2：简单对齐与重构基线

- oracle、原始时间精确连接、`±1/5/30s` 固定窗、五元组/session 硬匹配；
- temporal BFS、k-shortest 和 CCLog-like Steiner；
- 统一输出 edge/chain 指标和证据包；
- 通过条件：所有基线在相同 seed、候选预算和评估器下可复核运行。

### M3：两周否证性 pilot

- 实现仅含时间区间、实体一致、行为一致和可靠度的概率对齐；
- 实现最小证据预算、软阶段顺序和 `unknown`；
- 注入时间偏移、5%-50% 缺源、别名/NAT 冲突和良性边；
- Go：中等扰动下链 F1 相对最佳硬连接约 `+8pp`，干净数据下降 `<=5pp`，最小证据显著降冗余且阶段覆盖下降 `<=2pp`；
- No-Go：转 ChainBreak 失败边界基准，不增加 GNN/LLM/GAN。

### M4：完整强真值与 LANL 主协议

- 扩展到 6-8 个攻击族、每族至少 3 次，共 18-24 次；
- 至少两个攻击族仅测试，运行 campaign/time/host-disjoint；
- LANL 11GB 完成 P/L/F 单源、两两、三源、置乱和弱标签 anchor-ranking；
- 通过条件：H1-H4 的预注册效应门和置信区间成立，失败场景有归因。

### M5：基线、消融与外部有效性

- KRYSTAL、EAGLE、HADES/EULER、CCLog-like、SParse-like 等分层基线；
- 对齐概率、时间/会话、跨源支持、阶段、unknown 和冗余逐项消融；
- CICAPT-IIoT2024/DIDS-MFL 只验证 flow seed；
- 通过条件：每个创新都有独立消融，未见攻击族和捷径检查不推翻结论。

### M6：规模与可选效率层

- LANL 181GB 评价 events/s、p95、RAM、存储和候选规模；
- 若需要，仅选择 TeRed 或 SParse 一种效率层；
- 通过条件：吞吐 `>=2×` 目标峰值、p95 `<=60s`，且攻击/跨源连接点证据保持达到预注册容差。

### M7：论文冻结

- 冻结数据 manifest、代码提交、环境、参数、主表和主张；
- 完成证据卡、BibTeX、论文大纲、图表、失败案例和复现说明；
- 审稿前检查“首次”“因果”“完整链”“实时”等高风险表述是否有证据。

## 3. 近期两周计划

| 时间 | 任务 | 产物 | 成功判据 |
|---|---|---|---|
| 第1-2天 | 强真值采集/现有小样审计 | schema、时钟、exact/ambiguous 映射 | 至少一个完整 run 可回放 |
| 第3-4天 | oracle 与硬匹配 | alignment baseline | edge P/R/F1、误连边和歧义可报告 |
| 第5-6天 | 简单链搜索 | BFS/k-shortest/Steiner | node/edge F1、冗余和证据包 |
| 第7-9天 | 概率对齐 | 候选概率、校准报告 | 干净数据接近 oracle，受扰动下降更缓 |
| 第10-11天 | 最小证据+软阶段 | constrained decoder | 阶段覆盖、冗余、拒绝状态 |
| 第12-13天 | 缺源/偏移/冲突注入 | failure curves | H1/H3/H4 可否证 |
| 第14天 | Go/No-Go 评审 | pilot report、决策记录 | 继续主方法或转 ChainBreak |

## 4. 终止或转向条件

- 无法建立可审计三源映射真值：降级双源或 ChainBreak，不虚构独立网络证据；
- 三源不优于最佳单源或置乱后收益不消失：删除多源互补主张；
- 对齐边改善但链级不改善：只保留对齐贡献或降级调查排序；
- 简单搜索与复杂模型相当：保留简单方案，不为新颖性堆模型；
- 只有 LANL：题目降级为红队横向移动检测与可疑路径排序；
- 方法有效但规模不足：开启“跨源连接点保真压缩”第二备选。
