## 实验设计原则

- 先评价数据与对齐，再评价检测与重构。
- 主表以攻击场景为配对单位，不把数百万事件当作独立统计样本。
- 所有模型选择在训练/验证场景完成，测试场景仅运行一次冻结方案。
- 同时报告效果、效率、分析负担和失败案例。
- 任何“联合优于单源”的结论都必须通过源缺失、源置换和同预算基线验证。
- LANL 未标注事件不得全部作为良性；完整链主结论必须来自强真值运行。
