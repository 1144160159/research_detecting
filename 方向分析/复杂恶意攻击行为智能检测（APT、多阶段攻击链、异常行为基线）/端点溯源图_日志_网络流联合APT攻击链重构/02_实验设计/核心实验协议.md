# 核心实验协议

- 版本：`v0.2-research-design`
- 状态：预注册草案；首个正式训练运行前冻结版本号和哈希
- 详细矩阵：[问题—假设—实验闭环](问题假设实验闭环.md)

## 1. 核心研究问题

- **SQ1 跨源对齐**：概率式实体—时间对齐能否比固定窗口/硬连接减少误连边？
- **SQ2 多源互补**：三源是否提供真实互补，还是由单源/身份捷径贡献？
- **SQ3 最小证据链**：不确定性、操作性依赖和软阶段约束能否提高链完整性并降低冗余？
- **SQ4 可信退化**：缺源、时钟漂移和实体冲突下能否平滑退化并拒绝过度补全？
- **SQ5 规模**：核心方法成立后，候选裁剪能否保留证据并满足吞吐/延迟？

## 2. 数据层级

### Strong-A：自建强真值多源运行

- 6-8 个攻击族、每族至少 3 次，共 18-24 次；
- 至少两个完整攻击族只用于测试；
- 同步端点、日志、认证、网络和攻击编排器记录；
- 人工确认关键事件/边/阶段和 exact/ambiguous 映射；
- 承担对齐和完整链主结论。

### Weak-B：LANL Cyber1 comprehensive 11GB

- auth、proc、DNS、flow 与 redteam 锚点；
- 承担多源消融、锚点排序和 `FP/host-day`；
- 未标注事件不直接当作良性；不报告无真值的完整链 edge F1。

### Scale-C：LANL unified 181GB

- 承担 events/s、p95、RAM、存储和候选缩减；
- 不承担比 Weak-B 更强的链真值结论。

### External-D：CICAPT-IIoT2024、DIDS-MFL

- 只验证 flow seed/encoder；
- 不与不相干端点数据拼接为三源攻击链。

### Pilot-E：DARPA/现有 provenance 小样例

- 转换、KRYSTAL/EAGLE/TeRed/CCLog-like baseline 的 smoke test；
- 不进入正式 SOTA 主表，除非数据来源、独立传感器和真值被重新核验。

## 3. 划分与泄漏边界

1. 按 campaign/run 划分；同一运行的相邻时间窗不得跨集合。
2. 至少一个 leave-one-attack-family-out；另报告 time-disjoint 和 host-disjoint。
3. 正常模板、阈值、窗口、候选预算、阶段矩阵和校准器只能由训练/验证集确定。
4. ATT&CK/Sigma 快照和映射规则在测试前冻结。
5. `attack_id`、step 真值、未来事件、人工链边和从真值派生的裁剪范围不得进入模型输入。
6. 同源派生视图标注 `derived_view=true`，不得声称独立多源互证。
7. 报告 host、user、process image、template 和脚本重叠，做标识字段删除/置乱检查。

## 4. 比较公平性

- 所有方法使用相同观测时间、候选预算、异常 seed 预算和评估器；
- oracle、硬连接和概率连接使用相同下游解码器，隔离对齐贡献；
- 重构基线尽量使用相同 seed，隔离解码贡献；
- 参数量和训练资源差异单独报告；简单基线不得因缺少调参而被人为削弱；
- 测试集不得用于选择阈值、路径长度、阶段权重、时间窗和停止条件。

## 5. 统计

- 学习方法默认 5 个种子；确定性规则记录配置哈希；
- 统计单位为攻击运行、场景或 host-day；
- 按运行 bootstrap 95% CI，场景数允许时用配对置换或 Wilcoxon；
- 多个核心指标同时检验时用 Holm 校正；
- 报告均值/中位数、离散程度、绝对/相对差值和效应量。

## 6. 结果成立条件

只有同时满足以下条件，才能支持“联合重构有效”：

1. 强真值对齐 edge F1 相对最佳硬匹配至少 +5 个百分点；
2. 至少两个独立攻击族上链级提升方向一致；
3. 三源相对最佳单源在预注册指标上有实际意义提升，辅助源置乱后收益消失；
4. 最小证据约束提高链 F1 或显著降低冗余且基本保持阶段覆盖；
5. 30% 缺源或 ±5 秒偏移后保持至少 80%，证据不足时能拒绝；
6. 结论可由数据 manifest、代码版本、配置和原始指标复核。

## 7. 负结果与降级

- 对齐改善但链不改善：只主张对齐方法，不主张端到端链提升；
- 节点检测改善但链不改善：降级为调查子图排序；
- 三源不优于最佳单源：删除“多源互补”主张；
- ATT&CK 消融无影响：仅作结果标注，不列贡献；
- 两周 pilot 未过 Go/No-Go：转 ChainBreak 失败边界基准；
- 只有 LANL 弱标签：题目降级为红队横向移动检测和可疑路径排序。

## 8. 运行与存储

每个 run 登记数据 hash、split、代码提交、配置 hash、种子、命令、环境、时间、退出码和指标。原始数据、模型参数、检查点、完整图和大结果只存 GPU 服务器；本地只保留基本代码、配置模板、manifest、哈希和轻量结果摘要。
