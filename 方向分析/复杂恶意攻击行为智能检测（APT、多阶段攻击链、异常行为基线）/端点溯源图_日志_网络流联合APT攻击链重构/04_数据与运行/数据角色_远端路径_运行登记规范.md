精读后新增数据准入要求：

1. 多主机主协议必须具有认证/登录会话、访问主机、被访问主机和对应 flow 的可核对关系；
2. `sensor_health` 至少登记 drop、reorder、clock uncertainty、integrity status；
3. 原生事实、候选关联、模型预测和真值必须分文件或分 typed edge 保存；
4. 合成数据不得在 manifest 的 `allowed_claims` 中包含“真实部署有效性”；
5. OpTC 若缺域控认证日志，不得用其单独支持 HADES 式 AD 全网因果主张。

## 6. 同步流程

1. 本地执行 `scripts/check_local_policy.py`；
2. 本地单元/集成测试通过；
3. `sync_to_gpu.cmd` 前向同步代码、测试、配置和文档；
4. 远端 Conda `py3.9` 执行语法检查和测试；
5. 生成代码 commit/config/environment 哈希；
6. 只读核验数据 manifest；
7. 创建 run 目录后运行；
8. 完成后生成输出哈希和状态；
9. 只回传轻量聚合指标、哈希和 manifest 摘要。

同步脚本不得删除远端数据、模型、运行和结果；远端紧急代码修改必须回写本地审查。

## 7. 实验前 preflight

- [ ] 数据路径存在且位于允许根目录；
- [ ] manifest、文件数、字节数和哈希符合冻结版本；
- [ ] 数据只读；
- [ ] schema 和转换器版本匹配；
- [ ] split 无 run/host/time/campaign 泄漏；
- [ ] truth 接口未进入训练配置；
- [ ] 模型/结果路径位于远端；
- [ ] 磁盘/GPU/RAM 配额足够；
- [ ] 代码、配置、环境和随机种子已记录；
- [ ] 无凭据写入命令、日志或 manifest。

## 8. 运行状态语义

| 状态 | 含义 |
|---|---|
| `complete` | 命令退出 0、必需产物存在、校验通过 |
| `failed` | 已知错误、非零退出、OOM 或校验失败 |
| `timeout` | 超时，结果不完整 |
| `unrun` | 环境/数据/授权不足，未开始 |
| `unknown` | 运行通道中断或无法独立确认 |

`timeout`、`unrun`、`unknown` 均不能算通过；不得把缺失指标填 0。

## 9. 结果回传边界

允许本地：

- 聚合 P/R/F1、PR-AUC、MCC、CI；
- 资源分位数；
- 无原始标识的失败类型计数；
- manifest/hash；
- 论文图表所需的小型聚合 CSV。

禁止本地：

- 原始事件、PCAP、JSONL/CSV payload；
- 完整预测链和含原始字段的证据包；
- embedding、feature matrix；
- `.pt/.pth/.ckpt/.onnx/.pkl/joblib`；
- 训练日志、缓存和数据库 dump；
- 凭据、token、私钥或浏览器认证材料。

## 10. 数据结论审计

任何图表生成前检查：

1. 数据集角色是否允许该结论；
2. 真值粒度是否与指标一致；
3. 未标注样本是否被错误当作良性；
4. 同一原始数据的派生视图是否被重复计为独立支持；
5. 合成数据是否被错误用于主要有效性；
6. 测试集是否参与阈值、候选预算或超参数选择。
