## 数据管理红线

- 原始数据、模型权重、缓存图、训练日志和逐事件大结果只保存在 GPU 服务器。
- 每个正式数据版本必须有来源、授权、文件清单、哈希、转换器版本和真值说明。
- 派生视图必须记录父数据和转换逻辑，不能按独立传感器统计。
- 原始真值与模型输入物理隔离；评估器单独读取 ground truth。
- 所有路径通过配置或环境变量传入，运行脚本不得依赖个人绝对路径。
- 本地 `source/EACR-APT` 只保存基本代码、测试和配置模板；同步不得拉回远端数据或模型。
