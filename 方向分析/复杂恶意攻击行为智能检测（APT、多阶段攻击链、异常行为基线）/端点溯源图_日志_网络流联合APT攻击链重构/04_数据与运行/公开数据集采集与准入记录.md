## 5. 完整性与目录约定

每个自动采集数据集采用：

```text
<dataset>/
  raw/                    # 官方原始压缩包
  metadata/               # 官方 API 记录
  manifests/
    source_files.tsv      # 文件、大小、官方校验值和 URL
    collection_state.json # 逐文件下载/校验状态与 SHA-256
```

采集器使用断点续传；完成后必须同时满足来源可提供的权威校验值与服务器侧 SHA-256。Zenodo/Dataverse 优先核对官方大小和 MD5；Git LFS 核对 OID 与对象大小；GitHub/GitLab 固定 commit/归档并核对文件清单；S3 核对对象枚举、大小和可用的 ETag。所有压缩包还要通过 TAR/ZIP 结构测试；先校验、后解压，不能边下载边覆盖派生目录。
