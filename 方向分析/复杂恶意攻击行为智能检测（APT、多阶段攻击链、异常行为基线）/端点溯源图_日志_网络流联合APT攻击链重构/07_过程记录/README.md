# 过程记录

本目录保存研究过程的可追溯事实，不覆盖历史决定。

- `实验迭代记录.md`：每次 run 的预注册、命令、偏差、结果与决定；
- `决策日志.md`：研究方案和范围选择；
- `风险与阻塞项.md`：责任、影响和解除条件；
- `变更记录.md`：问题、数据、指标和主张的版本演化。
- `研究方向收敛记录_20260715.md`：858 篇组件扫描后的主问题、创新取舍、数据决策和转向门。
- `论文精读与蓝图修订日志_20260729.md`：71篇全文精读审计、证据产物和 v1.1-deep-read 决策。

所有正式 run 使用 `RUN-YYYYMMDD-NNN`，所有决定使用 `DEC-YYYYMMDD-NN`。
