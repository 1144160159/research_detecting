## DEC-20260715-08：补充集按“主真值、泛化、基线、生成器”分层准入

- 日期：2026-07-15
- 状态：accepted
- 决策：CICAPT-IIoT2024 完整版、AutoLabel 与 OTRF APT29 进入主真值/对齐候选；NODLINK、APTsDataset、Linux/Windows-APT、Sandworm、PWNJUTSU 和 SAGA 进入跨系统或阶段辅助；StreamSpot 与 DAPT2020 只做基线/历史消融；SimuLand 只作为 Strong-Truth 场景生成器。DARPA E3 核心采用 CADETS 两包 JSON、THEIA-6r JSON 与 TRACE-1 官方 Avro binary，通过官方工具保留 TRACE 转 JSON 路径，避免同一 run 的完整 binary/JSON 双份。
- 采用证据：CIC 已完成 `43/43` 文件和独立 SHA-256/PCAP 检查，并在同一场景提供 provenance、网络与 Attack_info；AutoLabel `2/2` 已通过官方 MD5、本地 SHA-256 与 TAR 测试；OTRF APT29 `124/124` 文件校验通过；NODLINK、APTsDataset、StreamSpot、DAPT2020 均有固定提交或归档哈希；CAM PCAP `6/6` 已完成，完成判据仍以远端 manifest 为准。
- 取舍：不把 SimuLand 代码仓库、Splunk LFS 指针或 DARPA 元数据误记为数据 payload；LADEMU 未找到当前官方公开载荷，因此只保留方法引用；未明确许可的数据只允许受控服务器内部研究使用。
- 影响：公开数据已足够启动解析器、跨源连接率和扰动实验，但 R1 只降为 `mitigated-open`；在字段级 truth coverage 审计前，不取消自建 Strong-Truth。
- 重新审议：CIC/AutoLabel 字段审计无法建立可用跨源映射，或 DARPA/Splunk 官方 payload 持续不可达。
- 补充决策：准入 MAGIC 固定提交 `aa0b647e` 发布的 5 套预处理图，只用于基线复现和解析链路冒烟；DARPA THEIA-6r 的官方原始归档仍须独立完成，不以预处理图替代原始数据准入。

## DEC-20260715-07：公开数据采用“长期多源主集+步骤强标签+泛化集”组合

- 日期：2026-07-15
- 状态：accepted
- 决策：首批收集 DEDALE V2、AIT-LDS V2.1+NDS+ADS、CAM-LDS 和 AInception，共 236,282,009,486 字节；OpTC/DARPA 先收官方仓库、真值和 errata，原始大包待 Google Drive 条件恢复后按攻击期裁剪。
- 采用证据：DEDALE 提供 4 周同场景主机/网络/标签；AIT 可把日志、NetFlow 和告警按同一场景比较；CAM-LDS 提供攻击步骤；AInception 提供跨故事线泛化；OpTC 的 `bro-id` 最适合后续大规模端点—网络对齐。
- 取舍：DEDALE 不收数 TB PCAP；AIT 改用 V2.1 去 PCAP包+NDS，不重复下载旧版 130GB PCAP；OTRF Security-Datasets 因主线适配和许可表述问题降为 P2。
- 影响：公开集足以启动解析、融合、扰动和步骤恢复实验，但普遍不提供完整事件边因果真值，DEC-20260715-05 的自建 Strong-Truth 要求保持不变。
- 重新审议：OpTC 官方大包可稳定获取，或公开集经字段审计后不能建立同场景跨源连接。

## DEC-20260715-04：主问题收敛为不确定性对齐与最小证据链

- 日期：2026-07-15
- 状态：accepted
- 决策：不把“三源融合”本身当创新，主张收敛为跨源候选概率贯穿链推断，以及带 unknown/拒绝的最小充分证据子图。
- 证据：858 篇组件扫描显示多模态、异构图和单点检测组件充分，但跨源失配、实体歧义和链级不确定性仍是更直接可证伪的张力；CCLog、EAGLE、HADES、EULER、TeRed 分别覆盖相邻部分。
- 取舍：删除多编码器、LLM、GAN、联邦/隐私、持续学习和多压缩堆叠，降低新颖性包装风险并提高归因能力。
- 重新审议：两周 pilot 中概率对齐无优势，或简单硬连接已达到 oracle 上界。

## DEC-20260715-05：Strong-Truth 为第一数据门

- 日期：2026-07-15
- 状态：accepted
- 决策：自建 6-8 个攻击族、18-24 次运行承担完整链强真值；LANL 11GB 只做多源弱标签/误报，181GB 只做规模。
- 理由：LANL redteam 不是完整恶意事件/边/阶段真值，GPU 和大数据不能替代精确跨源映射。
- 取舍：增加隔离靶场、同步采集和双人标注成本；换取可审计 edge/chain 评价。
- 重新审议：获得许可清晰、含同场景独立三源精确映射和完整链真值的公开数据。

## DEC-20260715-01：论文对象与主线

- 日期：2026-07-15
- 状态：accepted
- 决策：选择“端点溯源图+日志+网络流联合的跨主机 APT 攻击链重构”，而非再做单纯节点分类或通用 GNN。
- 证据：当前语料中 CCLog [379] 覆盖日志+溯源重构但缺 flow；Hybrid IDS [254] 覆盖 host+flow 但只做分类；EAGLE [416] 局限于单主机。
- 取舍：创新集中在对齐、补断链、阶段解码和 chain-level 评价，工程与数据成本较高。
- 重新审议：外部检索发现同等三源链重构工作，或三源同轴数据在合理期限内不可获得。
