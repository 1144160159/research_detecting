# 研究方向收敛记录（2026-07-15）

## 1. 本轮输入

- 项目语料：`综合分析/_data/papers_enriched.json`，858 条；
- 组件候选：12 个自动检索族、11 个研究环节、53 篇人工核验代表论文；
- 现有代码：TeRed、EULER、KRYSTAL、EAGLE、TraceCluster、DIDS-MFL 等；
- 远端数据：LANL comprehensive 11GB、LANL unified 181GB、CICAPT-IIoT2024、DIDS-MFL；
- 约束：本地 `source/EACR-APT` 只保留基本代码，不保存数据、模型参数、检查点和完整实验结果。

## 2. 初始方向

初始题目为“端点溯源图、日志和网络流联合的证据对齐式 APT 攻击链重构”，初始方案包含统一事件、正常模板压缩、多类异常编码、跨源互证、ATT&CK 阶段约束和链重构。

## 3. 发现的问题

1. “多源融合”本身已有大量相邻工作，不能作为可靠创新定位；
2. 将压缩、三套编码器、开放集、知识图谱、阶段识别和链解码全部放入一篇，无法归因；
3. 最难且最可证伪的问题不是特征表达，而是跨源边在时钟偏移、实体歧义和缺失观测下是否可信；
4. LANL redteam 主要是锚点，不能单独提供完整事件/因果边/阶段链真值；
5. GPU 和大数据能解决算力、规模问题，不能替代跨源映射真值。

## 4. 最终决策

主方案收敛为：

> 面向不完整与失配多源遥测的不确定性感知最小 APT 证据链重构。

只保留四个必要组件：

1. 可审计统一事件与原始证据指针；
2. 概率式实体—时间对齐；
3. 带软阶段顺序和未知松弛的最小充分证据子图；
4. 强真值—弱标签双协议及受控失配评价。

日志/流量/端点异常模型是可插拔 seed；TeRed 为后置效率层；EULER、HADES、KRYSTAL、EAGLE、CCLog 为基线或机制参考。

## 5. 不进入首稿的内容

- LLM/RAG/自然语言报告；
- GAN/扩散合成作为主训练；
- 多个大型 GNN/Transformer 并联；
- 联邦学习、隐私、完整开放集、持续学习；
- 严格因果发现和强化学习搜索；
- 多套图压缩与多套不确定性方法叠加；
- 独立 SOC 告警处置/推荐层。

## 6. 数据决策

- 自建 18-24 次攻击运行承担强真值链评价；
- LANL 11GB 承担多源消融、红队锚点排序和长时间误报；
- LANL 181GB 承担规模；
- CICAPT-IIoT2024 与 DIDS-MFL 只承担 flow 外部验证；
- 不把未标注 LANL 事件全部当作良性，不后验拼接不同场景的数据声称三源融合。

## 7. 首个决策门

在扩展任何深度模型前完成两周否证性 pilot。若中等扰动下概率对齐+最小证据链相对最佳硬连接链 F1 提升不足约 8 个百分点，或干净数据下降超过 5 个百分点，则停止扩展主模型，转向 ChainBreak 失败边界基准。

## 8. 当前结论等级

本轮只完成研究设计和证据收敛，没有形成算法性能、SOTA、实时部署或真实园区有效性的实验结论。
