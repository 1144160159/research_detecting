### 已知事实

- `source/TeRed` 有 DARPA 小样例与压缩结果，但 `main.py` 使用 `DATA_TO_COMPRESS`，`settings.py` 当前定义为 `DATA_TO_REDUCE`，正式运行前需修复或兼容；

- `source/Euler` 含 `lanl_experiments`，原始 LANL 全量数据是否齐备待确认；
- Euler 的 Python 3.7 AST 检查为 37/40；3 个失败文件是指向 `benchmarks/models/` 的相对路径占位文本，需恢复原仓库符号链接语义；
- `source/eaGle` 有脚本/真值资产，但 README 无完整运行说明；
- `source/TraceCluster` README 明示只开放关键实现，不是完整复现包；
- 当前没有已核验的同一 campaign 端点+日志+flow 三源联合数据。

### 决策

本记录只算资产审计，不算实验结果。下一 run 优先为 KRYSTAL 的 `CDM→RDF→POI→攻击子图` smoke test，其后是 TeRed/Euler 最小基线；数据门未通过前不启动联合性能比较。
