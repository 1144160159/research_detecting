- 版本：`Evidence Map v1.0`
- 日期：2026-07-29
- 覆盖：71/71 篇直接核心论文
- 目的：把论文贡献映射到本项目决策，不把论文级别、原论文数字或相似名词自动当作可复用证据

## 1. 使用规则

1. 71 篇按 `L01–L71` 固定编号；完整 DOI、PDF 页数、来源 URL 和 SHA-256 以《补充顶会顶刊PDF下载清单_20260729.md》及本地 PDF 为准。
2. 论文中的指标定义、真值粒度、数据切分和运行环境不一定一致；原论文报告数字不得直接放入本项目主表。
3. 每个核心组件至少有一篇 P0 论文定义问题或约束，同时必须接受本项目强真值实验的独立否证。
4. 综述、复现研究和审计论文优先用于发现评测风险，不作为性能基线。
5. 合成数据论文只支持压力/失败边界，不能单独支持主要有效性。

## 3. 从71篇收敛出的组件选择

### 3.1 主方法必选

| 组件 | 主要文献支撑 | 选择原因 |
|---|---|---|

| 概率式跨源对齐 | L06、L26、L33、L45、L46、L64、L65、L68 | 现有组件提供融合/匹配，但需显式保留歧义 |

| 最小充分子图 | L04、L10、L29、L31、L32、L41、L42、L67 | 同时优化证据保留和调查负担 |
| ATT&CK 软先验 | L05、L17、L70 | 高层解释有价值，但闭世界规则有风险 |

| 证据包/QoA | L04、L10、L11、L12、L16、L69 | 评价调查价值而非只做节点分类 |

### 3.3 首稿暂缓

- 端到端大 GNN 解码；
- LLM 自动生成攻击链；
- 复杂知识图谱闭世界推理；
- H1—H4 通过前的大规模预训练和图归约；
- 用 SAGA 或其他合成集承担主要有效性。

## 5. 证据缺口

71 篇已足以设计方法、基线和指标，但不能替代以下实证缺口：

1. 同一 campaign 下端点—日志—flow 的精确对齐真值；
2. 跨源边校准和链级拒绝的统一 benchmark；
3. 缺源、时钟漂移、NAT/别名冲突的系统失效曲线；
4. 最小证据子图对分析员真实负担的可重复评价；
5. 在本项目统一真值、告警预算和硬件上的强基线复现。

因此论文主贡献能否成立，最终由 P0—P5 实验门而非文献数量决定。
