# 文献与证据

- 版本：v0.2-research-design
- 状态：已完成首轮本地语料定位，尚未完成 Zotero 证据门

本目录不复制 PDF，只保存索引、筛选理由和主张—证据绑定。PDF 继续由仓库 `paper/` 管理；精读材料来自 `综合分析/GPT5.5逐篇精读/`。

## 固定工作流

`paper-search-mcp → Zotero Inbox → 30–50 篇筛选 → MinerU/core reading → evidence cards → brief → ideas → survey/论文写作`

硬门：没有 Zotero 条目、citation key 和证据卡，不进入论文正文。当前核心索引只是候选池，不等于完成引证。

## 文件

- `核心论文索引.md`：30 篇已核验本地 PDF 的核心/桥接文献；
- `检索与筛选记录.md`：本轮检索范围与下一批筛选任务；
- `相似工作与研究空白.md`：最近似工作的差异与可证伪研究空白；
- `主张-证据矩阵.md`：把论文主张绑定文献证据和实验 run。
