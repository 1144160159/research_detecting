# 08_论文精读

本目录保存71篇核心论文的全文精读证据，不保存模型参数、原始实验数据或大规模运行结果。

- 当前状态：`71/71 deep_read_complete`
- 完成日期：2026-07-29
- 全文审计：1239 页，71/71 PDF 文本页覆盖率均为 1.0

## 精读完成标准

每篇论文只有同时满足以下条件才标记 `deep_read_complete`：

1. 本地 PDF 存在、可解析，页数和 SHA-256 已登记；
2. 阅读摘要、问题定义、方法/系统设计、实验、讨论/局限和结论；
3. 提取任务、威胁模型、数据、切分、基线、指标、主要结果和复现状态；
4. 至少登记3个页码证据定位，其中至少1个来自方法/设计、1个来自实验/结果；
5. 明确对本项目可复用的组件、不可复用边界和可能反驳当前蓝图的证据；
6. 完成内部有效性、外部有效性、构念有效性和统计结论有效性审查；
7. 进入71篇总表和跨论文综合矩阵。

PDF存在、摘要筛选或组件级映射均不等于精读完成。

## 文件结构

- `71篇全文精读证据卡.md`：逐篇精读卡；
- `71篇精读总表.md`：每篇状态、主题、证据页和对蓝图影响；
- `跨论文方法组件综合.md`：可复用组件、冲突、淘汰项和研究空白；
- `跨论文指标与实验标准.md`：指标定义、数据切分、基线和统计标准；
- `精读后蓝图修订说明.md`：精读前后方案变化；
- `_索引/`：PDF提取审计和页码定位信息；
- `scripts/`：可重复的PDF页级提取工具。

完整PDF仍位于工作区 `paper/`；临时全文页文本写入系统临时目录，不在项目中重复保存。
