# 复杂恶意攻击行为智能检测方向

本目录管理“APT、多阶段攻击链、横向移动、攻击路径还原、异常行为基线”相关研究。当前主线已经从占位状态切换为：

> **端点溯源图、日志和网络流联合的 APT 攻击链重构**

## 主线入口

- [端点溯源图_日志_网络流联合APT攻击链重构](端点溯源图_日志_网络流联合APT攻击链重构/README.md)

该主线以端点溯源事件为因果骨架，以认证/系统/安全日志补充身份与行为语义，以网络流补充跨主机通信证据，最终输出按时间与攻击阶段组织、能够回溯到原始观测的攻击链证据子图。

## 当前边界

- 当前版本为 `v0.1-planning`，已经完成问题定义、方案设计、实验预注册、数据资产审计和论文大纲。
- 尚未完成统一事件转换器、跨源对齐实现和联合模型实验，不宣称已有性能提升。
- DA-FDIDS 仅作为流级异常种子或动态图建模参考，不作为攻击链重构主模型；其当前代码没有完整攻击阶段识别与路径还原能力。
- 本方向的验收单位是“攻击事件/攻击阶段/攻击链”，不能只报告节点级分类准确率或孤立异常分数。

## 维护原则

1. 任何算法主张必须绑定数据集、划分、基线、指标和运行编号。
2. 任何攻击链必须能够追溯到原始事件 ID、时间戳和数据源。
3. 未经验证的设计只进入方案与预注册，不进入实验结论。
4. 原始大数据和模型权重不提交到本目录；本地只保存清单、校验信息、配置和轻量结果。
