# 风险与阻塞项

| 项目 | 风险 | 处置 |
|---|---|---|
| SSH/网络 | 当前网络路径可能被 TUN/VPN 接管导致远端连接超时 | 用直连/排除规则验证 10.0.5.103:25450；未连通前不宣称远端已落地 |
| Python 热路径 | 对象与字典开销无法满足高 Mpps | 先 profiling，再迁移结构数组/批处理/编译扩展 |
| 调度偏置 | 纯收益成本比可能饿死稀有关键流 | 增加保底队列、公平性和关键流覆盖门 |
| GPU 小批次 | 调度/拷贝开销抵消加速收益 | 自适应批大小、pinned buffer、异步 stream 与 CPU 回退 |
| 状态爆炸 | 高 churn 造成流表内存/回收压力 | 分片上限、时间轮、近似统计和显式驱逐指标 |
| 指标误读 | 合成烟测被当作生产吞吐 | 正式结论只来自真实回放、固定协议、至少三次复测 |
