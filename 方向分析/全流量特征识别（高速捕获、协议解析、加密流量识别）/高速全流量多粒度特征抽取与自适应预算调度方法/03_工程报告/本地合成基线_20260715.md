# 本地合成基线（2026-07-15）

## 结论

首版代码通过本地存储策略、语法检查和 9 项单元测试。组件成本排序支持当前级联设计：包级基础特征与 BERT-ps 风格包长序列适合高覆盖，多级向量只适合选择性升级，深层载荷特征成本最高。

## 环境与命令

- 本地 Python：3.7.6（代码同时约束为兼容远端 Python 3.9）；
- 输入：脚本内确定性合成记录，不读取或写入数据集；
- 组件命令：`python scripts/benchmark_components_synthetic.py --flows 5000 --packets-per-flow 8 --max-sequence 20`；
- 管线命令：`python scripts/benchmark_synthetic.py --packets 20000 --flows 1000 --budget-us 25000`。

## 组件微基准

| 组件 | packet/s | 相对基础成本 | 解释 |
|---|---:|---:|---|
| base packet | 377,110 | 1.00× | 固定字段投影 |
| BERT-ps style sequence | 310,783 | 1.21× | 带方向包长、IAT、mask |
| YaTC/UniNet style multi-level | 167,499 | 2.25× | 序列 + flow summary |
| flow state | 66,154 | 5.70× | Python 字典/状态更新，生产需分片和结构化优化 |
| deep payload | 41,277 | 9.14× | 逐字节分布/熵统计，应受预算控制 |

此次 deep payload 合成数据在单流内为同一字节，checksum 为 0，仅验证执行路径和相对成本，不能推断特征质量。

## 端到端烟测

- 20,000 packets / 1,000 flows；
- 处理时间 1.2378 s，16,158 packet/s；
- tier 分配：flow 475、deep 525、base 0；
- active flows：1,000；预算升级缺陷修复后 deep tier 可正常获得预算。

## 边界

这些是单次 Python 合成烟测，不包含 PCAP 解码、真实协议分布、模型推理、GPU 传输、网卡、NUMA 或丢包，因此只用于正确性和相对成本初判。正式结论必须在远端固定设备上预热并至少三次复测。
