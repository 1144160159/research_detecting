## 同步与远端验证

```cmd
sync_to_gpu.cmd
```

脚本会创建远端专属目录、仅同步代码、在 `py3.9` 执行策略检查/compileall/单测/合成烟测，并写入代码 SHA-256 manifest。真实数据实验必须另建远端 run manifest，至少记录输入、代码哈希、配置、设备、命令、开始/结束时间与退出状态。

## 远端 PCAP 基线矩阵

同步后先执行：

```bash
cd /opt/data/private/wangwt/ParkAttackKE/HFT-MGBS/source/HFT-MGBS
bash -n scripts/run_remote_pcap_matrix.sh
PCAP_PATH=/opt/data/private/wangwt/ParkAttackKE/datasets/<capture>.pcap \
  bash scripts/run_remote_pcap_matrix.sh
```

离线结果不能直接作为最终 Pareto 输入。候选封装完成后必须运行：

```bash
PYTHONPATH=. /opt/data/private/wangwt/anaconda3/bin/conda run -n py3.9 \
  python scripts/validate_candidate_evidence.py <candidate_evidence.json>
```

只有返回 `accepted=true` 的候选，才允许送入 `evaluate_pareto.py`。

## 故障处理

- SSH 失败：先验证 `10.0.5.103:25450` 路由与 TUN/VPN，再检查密钥权限。
- 本地策略失败：删除误落本地的禁入资产；不要用改规则绕过。
- 远端单测失败：停止实验，先在本地修复并重新前向同步。
- 性能下降：保留失败运行，按阶段 profiling 定位，不直接覆盖旧结果。
