# 性能优化路线

1. 建立正确性参考实现与可重复基准，固定输入哈希、CPU/GPU/驱动、亲和性和配置。
2. 分解采集、解析、流表、窗口、调度、深层特征、序列化各阶段的 CPU 周期、分配、cache miss 和队列等待。
3. 优先消除全表扫描、对象频繁创建、重复解析、跨核共享写和小批次 GPU 调用。
4. 依次评估结构数组、预分配缓冲、批处理、流分片、SIMD、异步流水、pinned memory、GPU stream。
5. 每个优化都执行特征一致性、预算不越界、吞吐、P99、丢包、内存峰值和长稳回归。

任何“最优化”结论必须给出优化前后同协议、同设备、同输入的对照；只看平均吞吐不足以通过验收。
