# 最优组合方案与阶段性结论

这里的“最优”定义为多目标 Pareto 最优：在给定吞吐、P99、丢包、CPU/GPU/内存预算下，最大化加密流量识别质量与关键流覆盖。未完成统一实验前，不指定某篇论文模型为最终最优。

## 推荐架构：固定低成本底座 + 置信度级联 + 压力闭环

### Tier 0：高速捕获与最小解析（全量）

- 生产接口预留 AF_XDP/DPDK/等价零拷贝适配器；首轮 GPU 实验用离线 PCAP 回放验证正确性与吞吐。
- 一次解析生成规范化五元组、方向、包长、时间戳、TCP flags、TLS/QUIC 可见元数据。
- 流表按 worker/NUMA 分片，使用上限与超时回收；禁止批次内全表扫描。
- 输出固定宽度基础记录，后续 tier 不重复解包。

### Tier 1：低成本多粒度特征（全量或高覆盖）

- HFT-MGBS packet/flow/window 统计；以 NTLFlowLyzer 定义做离线 oracle。
- BERT-ps 风格的前 K 个带方向包长、IAT 与有效掩码；不读取加密载荷内容。
- TLS/QUIC 握手可见字段和协议状态作为独立 feature group，按协议存在性启用。
- fast classifier 采用 FastTraffic 风格紧凑 1D 网络或经 AutoML4ETC 搜索得到的等预算子网。

### Tier 2：不确定流升级（选择性）

- 触发条件：fast 置信度低、类别间隔小、OOD/漂移分数高、关键资产/告警关联、稀有协议或抽样保底。
- 特征采用 YaTC 风格 multi-level flow representation；模型先用小型 masked encoder，避免直接部署完整教师。
- micro-batch 聚合后异步送 GPU；达到等待上限立即 CPU/fast-tier 回退，不阻塞捕获线程。

### Tier 3：教师与离线再分析（极少量/离线）

- ET-BERT/BERT-ps 完整模型用于教师、难例重标和蒸馏，不进入全量在线热路径。
- AutoML4ETC 只在远端搜索，目标函数同时包含 macro-F1/AUROC、参数量、显存、P99 和单样本能耗代理。
- BPF-DAG/UniNet 作为融合结构消融，不在代码不完整时宣称原方法复现。

### 自适应预算调度

每个候选升级计算：

`priority = risk × uncertainty × expected_gain × fairness_boost / estimated_cost`

预算来自 CPU/GPU 可用时间、队列水位、P99 偏差和批处理等待。调度器保留三类独立额度：关键流保障、探索/漂移采样、普通收益排序；过载时按 Tier 3 → Tier 2 → Tier 1 可选组降级，Tier 0 不关闭。

## 为什么当前推荐该组合

| 目标 | 选择 | 理由 |
|---|---|---|
| 全量低成本覆盖 | HFT-MGBS + BERT-ps 长度序列 | 无需解密，特征增量更新，扰动测试协议清晰 |
| 快速在线识别 | FastTraffic 风格轻量网络 | 代码规模小、目标即快速分类，适合建立第一条延迟基线 |
| 高精度补偿 | YaTC multi-level 表征 | 只给不确定流使用，可换取更丰富的 packet/flow 关系 |
| 教师/鲁棒性 | ET-BERT、BERT-ps | 预训练表征强，但不适合全量热路径 |
| 结构搜索 | AutoML4ETC | 能把模型选择转化为精度-资源联合搜索，而非人工拍脑袋 |
| 调度 | 可解释边际收益/成本 + 压力反馈 | 比直接上 RL 更稳定、可审计；RL 作为后续对照而非首发依赖 |

## 失败保护与工程约束

- 捕获线程不等待 GPU；所有深层请求有截止时间和有界队列。
- GPU OOM/超时、模型加载失败或反馈失效时自动回退到 Tier 0/1。
- 关键流最低覆盖与探索预算不能被普通高频类别挤占。
- 任何模型更换都不得改变基础特征 schema；模型、特征和调度配置分别版本化。
- 本地只保留代码/配置/测试/文档，所有 PCAP、特征、权重、profiling、日志和结果留在远端。

## 当前阶段结论

该级联方案是“最有希望进入实验的组合”，不是已验证最优。只有完成统一输入、等预算模型对比、调度消融、过载阶跃、三次复测和真实性能 profiling 后，才能冻结最终组合。
