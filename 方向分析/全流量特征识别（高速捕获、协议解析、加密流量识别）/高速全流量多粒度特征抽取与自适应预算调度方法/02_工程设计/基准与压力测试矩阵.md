# 基准与压力测试矩阵

| 维度 | 取值 |
|---|---|
| 输入来源 | 确定性合成、公开 PCAP、业务脱敏回放、在线镜像 |
| 包长 | 64B、IMIX、长包、真实分布 |
| 流型 | elephant、mice、高 churn、长连接、单向/双向 |
| 负载 | 25%、50%、75%、100%、过载阶跃、突发 |
| tier | base only、base+flow、full、adaptive |
| 预算 | 静态低/中/高、自适应、反馈中断 |
| 并行 | 单核、多核分片、NUMA、GPU 单/多 stream |
| 故障 | 数据源断连、队列堆积、GPU OOM/超时、进程重启 |

每个正式点至少 1 次预热 + 3 次测量，输出 manifest、输入哈希、配置、软件/硬件信息和原始指标；大型原始结果只存远端。
