# 工程路线与里程碑

本文件给出里程碑摘要；正式执行以 [`工程总目标与最优化执行流程`](./工程总目标与最优化执行流程.md) 的 G0—G9 阶段门为准。

| 阶段 | 交付物 | 通过条件 |
|---|---|---|
| M0 工程骨架 | 代码仓、目录、存储策略、远端镜像 | 本地策略检查、语法、单测、远端烟测全通过 |
| M1 正确性基线 | PCAP 适配器、特征字典、参考实现 | 与离线参考值逐字段一致，时间窗/流超时边界覆盖 |
| M2 性能基线 | 合成与真实回放基准、profiling | 吞吐/P99/丢包/资源数据可复现，瓶颈有证据 |
| M3 热路径优化 | 批处理、对象池/结构数组、并行分片 | 相对 M2 显著提升且特征一致性无回归 |
| M4 自适应调度 | 成本/收益在线估计、压力反馈、保障预算 | 过载时稳定降级，关键流覆盖率满足门槛 |
| M5 加速与部署 | AF_XDP/DPDK 或等价接入、GPU 异步批处理 | 目标设备连续运行、故障恢复、可观测性验收 |
| M6 工程定版 | 版本化配置、部署手册、回归门禁 | 三次稳定复测、manifest/哈希/指标齐全 |

阶段顺序不能跳过：先证明正确，再定位瓶颈，再做优化，最后宣称性能结果。
