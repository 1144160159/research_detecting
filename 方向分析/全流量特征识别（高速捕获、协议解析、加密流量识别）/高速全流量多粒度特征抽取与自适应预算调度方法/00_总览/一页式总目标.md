# 一页式总目标

## 总目标

构建可部署的高速全流量多粒度特征抽取系统：基础特征对所有流量稳定覆盖，流级、窗口级、载荷级和学习型特征依据风险、收益、资源压力与时延预算自适应升级，在不突破丢包/P99 延迟/CPU/GPU/内存约束的前提下，最大化有效特征收益。

完整的优化目标函数、G0—G9 阶段门、停止条件与当前执行顺序见 [`工程总目标与最优化执行流程`](./工程总目标与最优化执行流程.md)。

## 四条主线

1. **高速数据面**：解析、归一化、流表、窗口聚合与批处理，控制拷贝、分配和锁竞争。
2. **多粒度特征面**：packet → flow → window → deep 四级渐进抽取，保证特征版本、时间语义和血缘可追踪。
3. **自适应预算面**：根据风险优先级、边际收益/成本、P99 压力和队列水位动态升级或降级。
4. **工程验收面**：以真实回放吞吐、丢包率、P50/P95/P99、资源占用、特征收益和故障恢复联合验收。

## 明确边界

- 本方向不以论文、投稿或新颖性陈述为交付目标。
- 本地不保存数据、模型参数、特征缓存或运行产物。
- 未经过真实网卡/PCAP 回放与至少三次稳定复测，不宣称线速或最优。
- 调度优化不得以降低关键攻击/稀有流量覆盖率为代价，必须保留最低保障预算。
