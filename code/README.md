# code 工具与元数据目录

本目录保存论文筛选、元数据处理、全文抽取、统计生成等本地脚本和中间数据。

## 当前职责

- 保存 `papers_metadata.json` 等论文元数据。
- 保存批处理、解析、统计相关脚本。
- 为 `多模态开放集加密恶意流量检测/` 和 `AI驱动的网络流量检测分析系统/` 提供数据支撑。

## 常用脚本

| 脚本 | 用途 |
|---|---|
| `update_references_from_paper.py` | 以当前 `paper/` 目录为准，同步 `papers_metadata.json`，并重新生成根目录 `文献.md` 与 `文献引用.txt`。 |
| `generate_references.py` | 早期参考文献生成脚本，只生成 `文献.md`。 |
| `fix_all_dois.py` | DOI 校验、修复和重命名脚本，可能改动 PDF 文件名，使用前需确认。 |

## 使用口径

- 本目录不是最终报告入口，最终结论应写入专题目录。
- 新增脚本建议按用途命名，并在脚本顶部写明输入、输出和依赖。
- 自动生成的大体积缓存优先放入专题下的 `04_原始解析与缓存/`，不要混入根目录。
